# 1\. 设计意图

**1\.1 北极星贡献。**营地负责一局的收尾：白天在湖边闹，晚上回来围着篝火看照片。游戏里治愈的部分主要发生在这里。全队钓的鱼都在缸里，想看的看，想偷的偷。

**1\.2 体验设计。**

|体验|🎯 想塑造的体验|🛠️ 当前设计|🔍 达成度与缺口|
|---|---|---|---|
|回到营地就放松下来|从热闹切换到安静的落差感|篝火、休息、鱼缸观赏，都没有任务、没有压力|依赖视听氛围与猫演出落地|
|全队的收获在一处|「看，这是我们今天钓的」|共用大鱼缸＋标本位，鱼带主人色环|观赏与被偷共用一个舞台|
|每晚有仪式感的收尾|热闹的余味|篝火围坐翻看今天的照片|与印记册衔接，可跳过但要让人舍不得跳|

**1\.3 玩家策略路线。**回营时机（钓得正热 vs 回去卸鱼护）；献祭还是留缸观赏；饿了吃掉还是留着凑额度。

**1\.4 设计禁区。**

- ❌ **营地变成经营系统**——无生产链、无建造、无装修，营地是家不是第二个工作场。

- ❌ **回营变成事务处理**——管理负担最小化，回营的主体验是放松。

# 2\. 核心循环

1. 外出钓鱼、捣乱、探索

2. 回营地：渔获入缸、进食、休息修整

3. 献祭推进目标，或留缸观赏

4. 篝火围坐，翻看今天的照片

5. 带着图鉴与照片，开始下一局

# 3\. 机制清单

## 3\.1 设计意图核心

### 1\. 营地管理机制

**设计意图。**营地是生活循环的中心。

**机制。**仓库存储、装备整理、修竿点（配合装备册的木块维修）。

**⚠️ 最容易破的实施陷阱。**管理负担过高，玩家回营地变成处理事务。

### 2\. 共用大鱼缸机制

**设计意图。**本局的渔获全队放同一个缸，暂存、观赏，也会被偷。这也是营地里最主要的陈列。

**机制。**全队共用一缸（跟局走、跨天留存，局末随局清空）。缸是明天献祭额度的储备仓，鱼带主人色环，缸内鱼按实际鱼种游动，猫趴缸贴玻璃跟鱼；缸也是祭坛的备货仓，献祭从缸里挑（「今天献掉、留作明天储备、还是镇宅观赏」的取舍）；可被偷吃（不设保护，规则见联机册），图鉴钓到已记不受影响；稀有入缸 / 满缸抛印记。

**⚠️ 最容易破的实施陷阱。**缸变成纯仓库 UI。鱼要实体游动，能看到、能被偷走都靠这个。

### 3\. 休息点

**设计意图。**疲惫在营地有地方解决，倒地的猫也送回这里。

**机制。**休息恢复疲惫、救援送回的落点（衔接猫咪与状态册）；吃鱼不需要加工，从缸里或鱼护取了直接吃（有的鱼有毒，规则见猫册）。

**⚠️ 最容易破的实施陷阱。**休息做成必须干等的挂机。恢复要快，别把玩家钉在营地。

### 4\. 篝火回看仪式

**设计意图。**一局的治愈收尾。

**机制。**每晚入夜、篝火点亮，提供回看入口。参与自愿，可跳过或不围坐，不阻塞翻天；围坐者轮播当天的印记照片；夜晚无时限，全员同意后开始新的一天（翻天机制见局与进程册）；缸内的鱼跨天留存，只随局（run）结束一起清空，每晚不清。

**⚠️ 最容易破的实施陷阱。**变成强制过场。要能跳过，但内容得好到让人舍不得跳。

## 3\.2 实施考量

- **功能性 vs 治愈体验**：营地功能是生活辅助，不是经营系统（保留原稿结论）。

- **固定配置 vs 表达欲**：删除建造后，玩家的个性表达转移到猫外观、图鉴与照片，营地这边不再管表达。

# 4\. 系统边界

**硬性。**

- 无建造 / 无装饰收集 / 无营地成长与搬迁。

- 设施为固定配置（篝火 / 鱼缸 / 仓库与修竿点 / 标本位）。

**软性。**

- 每个设施都要有猫味交互演出（趴缸、蹭火堆取暖、缸边挑鱼、火边打滚）。

# 5\. 涌现案例

- 钓鱼系统（positive）：渔获的归宿与展示，钓鱼目标从「获得资源」延伸为「创造记忆」。

- 装备与道具（positive）：修竿与整理的发生地，「外出 → 回家 → 再出发」的节奏靠这一环。

- 猫咪与状态（positive）：休息 / 倒地救援送回点。

- 祭坛（positive）：备货仓与献祭动线，「参与世界 → 回归生活」。

- 偷窃与权限（positive / negative）：鱼缸是能偷吃的地方之一，乐趣与安全感的平衡见联机册。

# 6\. 体验锚定数字

- **鱼缸容量**：调它影响明天的献祭储备，也影响缸里有多少鱼可能被偷。

- **回看时长**：短了留不住余味，长了就拖。

# 7\. 视觉反馈通道

- 缸内鱼群实时反映本局收获。

- 篝火点亮＝收尾信号。

- 标本位陈列稀有鱼。

已知缺口（沿自原稿）：多人在营地里能对彼此做什么的互动细化；开放互动的乐趣是否大于不安全感需试玩验证。
