# 1\. 设计意图

**1\.1 北极星贡献。**热闹和治愈各占一段：白天限时，忙和闹都压在这段；夜晚不限时，是白天拼出来的放松。每天一个献祭额度，全队盯同一个数；失败全队一起摊，能当故事讲。

**1\.2 体验设计。**

|体验|🎯 想塑造的体验|🛠️ 当前设计|🔍 达成度与缺口|
|---|---|---|---|
|白天的心跳|「今天的额度还差三条！」全队为同一件事忙起来|白天限时＋每日献祭额度|有时间压力，捣乱才刺激，也逼着大家合作；压力只在白天有|
|夜晚是赚来的|达成之后松下来，「今天稳了」|达成额度才入夜；夜晚无时限：篝火回看、观赏、闲逛|治愈的部分固定放在夜晚，而且是白天拼出来的，玩家会更珍惜|
|团灭的戏剧|失败也是全队共同的故事，「差两条鱼，全员饿在湖边」这结局能笑着讲|额度未达＝这一局失败，进结算|失败演出的喜剧化归内容层；照片还在，失败不清跨局持久|
|翻天的仪式|「都好了吗？出发！」|全员同意开始新的一天（单人＝自己确认）|夜晚待多久玩家自己定，系统不催|

**1\.3 玩家策略路线。**今天多钓存缸（给明天减压）vs 献完就玩（享受当下）；冲额度 vs 蹲稀有（额度紧张的日子没空追图鉴）；偷缸里的储备＝偷明天的粮，代价是实的。

**1\.4 设计禁区。**

- ❌ **夜晚出现任何计时或催促**。

- ❌ **失败回滚跨局持久**（图鉴 / 印记 / 解锁永不回滚）。

- ❌ **局外元进度**（每日任务 / 赛季）。局与局之间只有收集与解锁，没有义务。

# 2\. 核心循环（双层）

**天循环：**

1. 新的一天开始（白天，限时）

2. 钓鱼 / 捣乱 / 凑额度

3. 向祭坛献祭，额度达成

4. 入夜（无时限：篝火回看 / 观赏 / 闲逛）

5. 全员同意，开始新的一天

**局循环：**开局初始化（营地 / 祭坛 / 时间）→ 天循环 × N → 结束（额度未达＝失败；或坚持到第 10 天（暂定）毕业＝圆满结局）→ 结算：图鉴 / 印记 / 解锁入册（跟人走），营地与缸清空（跟局走）。

# 3\. 机制清单

### 1\. 天的时间结构

白天＝时间驱动弧线（清晨→黄昏），额度截止点＝入夜判定；夜晚＝没有钟，时间不走。天弧线的光影细节归环境册。

**⚠️ 最容易破的实施陷阱。**夜晚偷偷藏着隐形计时（比如挂机踢人）。夜晚不能有任何钟。

### 2\. 每日献祭额度

每天一个额度，逐日上升（一局的压力曲线）；前期纯数量，后期附鱼种指向（把图鉴与装备准备串进白天）。达成 → 入夜；未达成 → 局失败。

**⚠️ 最容易破的实施陷阱。**额度松到形同虚设，白天就没人着急了。

### 3\. 失败与结算

失败＝这局立刻进结算夜：火照样生，照片照样看（「鱼没了，照片还在」），然后局结束。跨局持久永不因失败回滚。

**⚠️ 最容易破的实施陷阱。**失败画面做成冷冰冰的结算板。失败要演成喜剧，不是事故。

### 4\. 翻天

夜晚全员同意（就绪确认）→ 新的一天；单人＝自己确认；离开的玩家不阻塞（按在场者算，细则归联机册）。

### 5\. 局的终点

毕业终点：坚持到第 10 天（暂定）并达成额度＝圆满结局，一轮下来有头有尾；无尽模式后置。

### 6\. 跨局归属清单

跟人走＝鱼类图鉴、印记相册、装备与外观的解锁；跟局走＝营地、鱼缸（跨天留存、局末随局清空）、消耗品数量、猫状态、祭坛进度。解锁触发源＝图鉴节点＋天数 / 额度里程碑；解锁的形态归 A5 裁决。一句话：身份跟人走，物资跟局走。

### 7\. 单 / 多人形态

同一套局结构，靠参数调：额度按人数缩放、翻天＝自己确认、聚鱼时刻与回看照常；鱼的刷新按在场协作能力设上限（单人局不出巨型鱼，规则归鱼类图鉴册）；不做独立单人模式。

## 3\.2 实施考量

白天时长 × 额度松紧是全游戏的节奏命门（数值阶段的第一优先参数）；「白天有钟、夜晚无钟」把压力和治愈分开，是本册最重要的不变式；鱼缸跨天留存让「今天多钓」变成策略，被偷的损失也变大，偷取权限开关更要紧（联机册）。

# 4\. 系统边界

**硬性。**

- 夜晚无计时。

- 失败不回滚跨局持久。

- 无局外元进度。

**软性。**

- 翻天与失败都要有猫味演出（内容层）。

- 额度进度的呈现归交互层（方向：祭坛本体即进度可视化）。

# 5\. 涌现案例

- 额度快到截止时全队疯狂冲刺，这段最容易出印记素材（positive）。

- 缸里储备够多的「富裕日」，全队提前开始度假（positive）。

- 额度紧张的日子有人偷吃储备，被追着打，格外热闹（positive / negative，皮不毒护栏见联机册）。

- 最后一条鱼献不献（保命还是留着观赏）的全队争论（positive）。

# 6\. 体验锚定数字

- **白天时长**：决定每天有多赶。

- **每日额度曲线**（首日宽松度 / 爬升斜率）：一局的压力怎么爬，看这条。

- **失败率预算**：多久团灭一次。

- **一局天数**（暂定 10）：一轮的故事有多长。

# 7\. 视觉反馈通道

额度进度全队随时可见（祭坛就是进度条，形式归交互层）；入夜本身就是达成的仪式信号；额度告急的全场氛围信号归环境册（声音与光线）。

# 8\. 何时回审

额度曲线与天数数值定稿时；A5 / A6 裁决落定时。

# 9\. Playtest 验收预期

- 团灭时大家在笑还是在互相埋怨。

- 夜晚会不会被急性子秒过，无时限是否形同虚设。

- 「再来一天」与「再来一局」的意愿分别有多强。

- 额度压力是否侵入夜晚（不应该）。
