# 1\. 设计意图

**1\.1 北极星贡献。**备装是每局开场的社交环节：你挑了什么饵别人都看得到，等于把今天的目标说给大家听（「我今天就要那条大的」）；特殊饵什么时候用，旁边的猫会起哄（用不用？现在用？）；断竿和落空本身就是笑料。核心体验沿用原稿的判断：玩家为了遇见某种鱼而准备，走「准备 → 钓鱼 → 发现」的循环。放到派对里，这份准备还得是**别人看得见、说得上话的**：你带了什么，旁边的猫看得到、闻得到、起得了哄。

**1\.2 体验设计。**

|🎯 想塑造的体验|🛠️ 当前设计|🔍 达成度与缺口|
|---|---|---|
|出发前的期待感：「为了遇见某种鱼而准备」|鱼饵 / 鱼漂 / 道具按目标鱼搭配；装备与鱼偏好关联|结构成立；偏好规则看不看得懂，靠现场演出和图鉴线索两处解决（见 §3、§7）|
|装备是玩法选择，不是数值军备|功能差异化：不同装备改变钓法与目标，不做强度碾压|方向已定，有禁区护住；「万能最优解」需数值阶段验证|
|关键时刻的道具决策|一次性道具「现在用还是省着」，使用过程有戏可看|决策骨架成立；囤积倾向靠设计规避（见 §3）|
|工具的生活感|鱼竿耐久 \+ 下水捞浮木修竿：维护自己的生活工具，不是处理任务|循环成立；惩罚强度必须与钓鱼册对齐（见 §3 接口约束）|

**1\.3 玩家策略路线。**保留原稿五条取舍：

- **稳定收益 vs 稀有发现**：普通饵稳定钓常见鱼，还是消耗特殊饵赌一把稀有鱼。

- **当下口粮 vs 收集目标**：为饥饿和献祭钓口粮，还是为图鉴追特殊鱼。

- **装备专精 vs 灵活应对**：带一套针对目标鱼的专精装备，还是带通用装备见机行事。

- **道具保存 vs 当前使用**：现在用掉抓住眼前机会，还是留给更大的目标。

- **单人效率 vs 多人互动**：自己配好自己钓，还是分享饵料、帮朋友凑齐目标。

**1\.4 设计禁区。**原稿五条全保留：

1. ❌ **装备形成绝对强度差距**——不做「新竿全面碾压旧竿」的淘汰式成长。破坏「我今天想怎么钓」的自由选择。替代：功能差异化，针对不同鱼种、改变操作体验、给出不同策略路线。

2. ❌ **装备成为氪金或资源碾压入口**——不做付费优势装备，不强制装备升级。破坏治愈底色与社交公平。替代：探索获取、局内事件奖励；收集里程碑是否发装备，随 A5 与图鉴册收集节点口径一并裁定（待定：A5）。

3. ❌ **装备过度复杂化**——不加属性词条、随机强化、搭配公式。破坏轻松进场的体验，新手应该在钓鱼，不是在研究表格。替代：规则一句话说得清，比如「这个饵吸引什么鱼」「这个漂适合什么时候」。

4. ❌ **一次性道具成为必需品**——不做「没道具就钓不到稀有鱼」。破坏发现感：玩家应该觉得「我发现了一条鱼」，不是「我消耗道具抽了个奖」。替代：道具只提高机会、改变体验、增加趣味。

5. ❌ **装备绑定单一最优玩法 / 破坏社交公平**——不让所有人殊途同归到同一套配置，不让装备造成玩家阶层差距。破坏「各有各的钓法」。替代：收集型 / 稳定型 / 挑战型 / 展示型多路线并存；展示价值来自稀有发现与玩家故事，不来自强度。

# 2\. 核心循环

1. 出发前备装：从营地仓库取竿，挑饵、选漂、揣上窝料和道具，要合作抬大鱼的再背上抄网。

2. 湖畔开钓：装备组合决定今天奔着什么鱼去。

3. 消耗发生：特殊饵用掉、道具打出、竿耐久磨损。

4. 维护回路：水边捞浮木，回营地修竿点修竿。

5. 新解锁到手，下一次搭配又多一种可能。

6. 局末装备归置：解锁跟人走、剩余耗材跟局走（局末清空），清单见局与进程册。

# 3\. 机制清单

## 3\.1 设计意图核心

### 1\. 装备选择与出发准备

**设计意图。**开钓前要有准备的感觉：带什么装备就是在说今天想钓什么。别让玩家点一下就直接进流程。

**机制。**从仓库携带鱼竿、鱼饵、鱼漂进入钓鱼点，抄网、窝料、道具、草药一并揣上；不同组合影响钓鱼方向；队友装备可查看（钓鱼册既有接口）。携带与整理的操作成本靠分类和快捷选择压低（原稿解法保留），别让备装变成理仓库。

**猫味演出①。**备装的动作全是猫的：扒拉竿子、用爪子逐个拍拍饵袋，选好了叼起竿甩上背，抄网背着像个小行囊。「查看队友装备」就是凑过去闻，闻到谁带了小鱼干饵，会不由自主跟着人家走。

**抛印记事件④。**全队备好装、各叼各竿从营地小径一字排开出发的「出征照」（是否列入触发，待定：C7）。

**⚠️ 最容易破的实施陷阱。**选择太多，玩家开钓前得先学一堆规则。另一种是备装变成各自安静看菜单：准备阶段要发生在场景里、彼此看得见，别缩进 UI。

### 2\. 鱼饵机制

**设计意图。**饵要消耗、要挑，玩家才会盯着某一种鱼做准备。

**机制。**普通饵不消耗，撑起日常钓鱼；特殊饵消耗型，提高特殊鱼出现机会；不同饵对应不同鱼类倾向（偏好数据归鱼类图鉴册）。

**猫味演出①。**饵的名字和样子都从猫这边取。普通饵＝草地里现刨的**虫虫**，刨土这个动作本身就有得看；特殊饵方向如**小鱼干碎**、**猫薄荷团**、**亮晶晶**（碎贝壳亮片，吸引发光鱼）（待定：具体饵清单与对应鱼种，归鱼类图鉴册数据）。挂饵也有戏：挂小鱼干时忍不住先舔一口，围观猫集体咽口水；挂猫薄荷团被熏到，眼神涣散原地小打滚。

**落空安慰（接口）。**特殊饵消耗了却没钓到目标鱼，不能让玩家白挨一刀。方向：落空也有戏（空钩拖上来一团水草、一只螃蟹夹着钩子耀武扬威）；连续落空渐进提高下次机会；或部分返还（待定：方案取舍归数值阶段，并与 A2 失败惩罚的总口径对表）。

**抛印记事件④。**首次用特殊饵钓中对应目标鱼，准备终于换来回报的那一下。

**⚠️ 最容易破的实施陷阱。**特殊饵成为唯一正确答案，普通钓鱼失去意义，玩家被迫烧资源换效率。

### 3\. 鱼漂机制

**设计意图。**装备要给出不同的玩法路线，不是单纯提升数值。

机制。鱼漂全游戏共 4 种（已拍），每种两个参数：投掷距离与落点精准——决定够得着哪片水、投不投得进窝心。

**猫味演出①。**漂都是从猫的玩具箱里翻出来的：**羽毛漂（逗猫棒上拆的）、毛线球漂**、铃铛漂（咬钩时叮当作响）等（共 4 种已拍，具体命名与效果待内容层）。新漂到手先当玩具拍两下才舍得系上；盯漂的时候猫尾巴尖跟着漂的起伏一点一点。

**与钓鱼册信号的关系要摆正。**「咬钩信号远距离可感知」是钓鱼册拍定的**基础能力**，不装任何漂也成立。铃铛漂只是把「自己感知得到」变成「全场都听得见」：一响全场猫竖耳，等于自动帮你摇人围观。它是锦上添花，不是感知门槛（否则撞禁区 4）。

**抛印记事件④。**见「装备解锁机制」的首次解锁与成套记录。

**⚠️ 最容易破的实施陷阱。**出现「万能最强漂」，所有人殊途同归，策略空间消失。

### 4\. 鱼竿耐久与捞木修竿

**设计意图。**给工具一点生活感。水域除了钓鱼还能捞材料；耐久带出「外出 → 回营 → 再出发」的节奏（衔接营地册修竿点）。

**机制。**鱼竿有耐久，钓鱼过程缓慢损耗；玩家下水打捞浮木，回营地修竿点用浮木修理（营地册称「木块维修」，同一物，口径以「浮木」为准）。偶尔捞上来的不是木头：大螺壳、水草团、一条呆头呆脑挂在木头上的小鱼。

**接口约束（显式）。**耐久的惩罚强度必须与钓鱼册的失败预算对齐（丢饵：超窗 / 被拖落水；断竿：唯一器材失败，断线已废除）：共用同一份预算，玩家一次失败只挨一刀。断竿时挂着的鱼如何处置，按已裁的重试制对表（A2 主体已裁：按品质给尝试次数、不少于两次；断竿细则待数值阶段）。

**猫味演出①。**断竿要好笑，不要惨。搏斗中竿「咔嚓」断成两截，猫抱着半截愣三秒，耳朵慢慢压平，围观猫炸毛跳开；叼着断竿回营地那一路走得很委屈，尾巴拖地；修好后抱着竿蹭脸。捞木上岸甩一身水（湿毛抖水引用猫册）。

**抛印记事件④。**断竿瞬间是印记候选（待定：C4 失败瞬间是否进印记）。

**⚠️ 最容易破的实施陷阱。**维修频率过高，玩家感觉一直在伺候工具而不是钓鱼。

### 5\. 一次性特效道具

**设计意图。**关键时刻要有一个决策：现在用还是省着。用道具的过程做成全场围观的小节目。

**机制。**通过探索、局内事件获得；使用后提供短时间特殊效果，用于挑战特殊目标。和窝料的分工要清楚：窝料是钓鱼册的常规聚鱼手段，道具稀缺、只管短时特效，不抢窝料的活。

**猫味演出①。**道具方向如猫薄荷水弹（短时鱼群兴奋）、呼噜哨（待定：具体清单与效果；夜晚不钓鱼，不做夜钓类道具）。使用演出必须好笑：扔猫薄荷弹时自己先被熏到，原地打滚炸毛，全场笑翻。用之前的犹豫就是起哄点，队友会围着喊「用！用！用！」。

**抛印记事件④。**首次道具生效并钓中目标的瞬间。

**⚠️ 最容易破的实施陷阱。**道具价值太高导致囤积，玩家攒一仓库舍不得用，机制进不了循环。解法方向：使用场景明确，效果变化肉眼可见，同时不碰基础玩法底线。

### 6\. 草药与采集消耗品（接口条目）

**设计意图。**接住猫册的晕倒恢复出口，给森林湖一个采集理由（猫册原话）；本册管「怎么到手、怎么带」。

**机制。**草药在森林湖采集（分布归环境与氛围册），用于解除晕倒；效果与使用规则归猫册，采药 / 喂药演出也归猫册持有，本册不重复定义。本册管获取方式与携带占位。

**猫味演出① / 抛印记事件④。**见猫册草药机制（凑近闻打喷嚏；喷嚏复活弹起瞬间），本册引用不另抛。

**⚠️ 最容易破的实施陷阱。**变成必须刷的医疗资源（与猫册同款陷阱，两册共守）。

### 7\. 装备解锁机制

**设计意图。**成长来自「发现更多可能」，不是「变得更强」；解锁扩展选择空间。

**机制。**通过探索、局内事件获得新装备，解锁新的钓法；图鉴收集里程碑是否附带装备解锁，随 A5 与图鉴册节点奖励口径一并裁定。解锁跨局跟人走（清单见局与进程册）。（待定：A5 成长观——表达型 / 便利型 / 零成长尚在裁决。本册按「解锁＝更多选择而非更强数值」保留骨架，成长的存在形式与持久层归属等裁定后回审。）

**猫味演出① / 抛印记事件④。首次解锁仪式**：新装备第一次到手，猫把它高高举起，围观猫全部凑过来嗅，抛印记「第一次的○○」；**装备成套记录**：集齐一个系列（如逗猫棒全套：逗猫棒竿＋羽毛漂＋铃铛配件）触发合影式记录，抛印记。

**⚠️ 最容易破的实施陷阱。**新装备完全替代旧装备，旧的失去价值，成长变成单行道。

### 8\. 装备与鱼偏好关联

**设计意图。**「为了目标鱼做准备」这件事要真的有用，探索的乐趣从这里来。

**机制。**不同鱼有不同偏好，装备影响遇见目标鱼的机会；特殊鱼需要特殊准备。偏好数据由「鱼类图鉴」册持有，本册只消费不定义。规则得让人看得懂，靠两处：现场演出（本册，见下）＋图鉴线索回显（图鉴册「分布线索呈现」机制，答案要能在图鉴里翻到，不该靠背规则表）。

**猫味演出①。**规则靠演出说明白。用对饵，窝点鱼影聚得欢；用错饵，鱼影游到钩边绕一圈，嫌弃地一摆尾走了。玩家一眼能看出「为什么没上钩」。

**抛印记事件④。**与图鉴册「剪影转正」共用高光：按线索备对装备、终于抓到那条跑过的鱼，印记归属按图鉴册④执行。特殊饵首中见鱼饵条目。

**⚠️ 最容易破的实施陷阱。**规则不透明，玩家不理解失败原因，只觉得系统在随机耍人。

## 3\.2 实施考量

保留原稿六条取舍结论，口径更新：

- **装备深度 vs 易上手**：偏向易理解。保留鱼饵选择、鱼漂专属效果、特殊道具；不做属性词条与多层强化。装备服务钓鱼，不是独立养成玩法。

- **功能差异 vs 平衡成本**：功能差异优先。装备改变钓法、目标与操作体验，不是简单提升成功率。多花的平衡成本换来策略空间，值。

- **耐久生活感 vs 玩家便利**：保留维护感、压低负担。维修是「照顾自己的工具」，频率必须低到不打断钓鱼节奏；惩罚预算与钓鱼册合并计算（见 §3 接口约束）。

- **道具稀缺价值 vs 使用意愿**：鼓励使用。场景明确、变化明显，同时不碰基础玩法底线，别让道具变成仓库收藏品。

- **装备数量 vs 开发资源**：少量高价值。优先做能改变体验的核心装备，不铺量。

- **成长感 vs 旧装备价值**：避免淘汰式成长。「不同场景适用不同装备」，而不是「新的永远更强」。

# 4\. 系统边界

**硬性**：

- 鱼种偏好与分布数据归「鱼类图鉴」册，本册只消费。

- 修竿点、仓库的实体与动线归「营地」册，本册定义修理规则。

- 窝料的投掷玩法与盛宴聚鱼、抄网的用法归「钓鱼系统」册（正式版）；本册管获取携带与清单配方（窝料＝腥 / 香 / 酵三属性向量，配方表归本册定义）。

- 草药的效果与倒地救援规则归「猫咪与状态」册，本册只管获取与携带。

- 渔获容器（鱼护 / 共用大鱼缸）不属于装备：渔获流已拍定（图鉴即时记录 → 鱼护 → 大鱼缸 → 献祭 / 吃 / 观赏，局末随局清空），本册不碰。

- 装备不可被偷：负面互动上限是「单条鱼」（联机社交册口径），偷窃永远碰不到竿、漂、道具。

- 不引入世界观外元素：装备命名与形态一律猫世界化，无人类文化符号。

- 不引入本册之外的成长数值（经验 / 等级归项目级决策）。

**软性建议**（保留原稿四条，措辞按现行口径）：

- 鼓励装备提供多路线：收集型 / 稳定型 / 挑战型 / 展示型。

- 鼓励装备跟世界有联系：获取尽量来自湖畔探索与局内事件，增强归属感。

- 鼓励装备具有情感价值：第一根陪你的小树枝竿、朋友送的羽毛漂（待定：赠送机制是否存在，归联机社交册）、事件纪念道具。

- 鼓励简单规则产生深度选择：玩家想的是「今天我要准备什么」，不是「我要算多少属性」。

# 5\. 涌现案例

- 钓鱼系统（positive）：装备提供准备感与策略空间，钓鱼从单一行为变成「目标选择 → 装备准备 → 探索发现」。

- 鱼类图鉴（positive）：特殊鱼需要特殊准备，想集齐的人更愿意去凑装备；图鉴线索反过来指导备装。

- 营地（positive）：仓库与修竿点是装备的「家」，「外出 → 回营 → 再出发」的节奏落在这里。

- 祭坛（positive）：团队目标推动全队备装，走「装备准备 → 钓鱼贡献 → 共同推进」。

- 联机社交（positive）：分享饵料经验、围观道具使用、起哄「用！用！用！」都是热闹素材；铃铛漂让咬钩成为公共事件，围观自然发生。

- 猫咪与状态（neutral，待观察）：饿急了的猫会不会想把小鱼干饵直接吃掉。「饵还是粮」可能成为玩家自发的应急路线，是否开放为机制待观察。

- 囤积倾向（negative）：守财猫攒一仓库道具不用，靠 §3 道具设计（明确场景 \+ 明显效果）规避。

- 备装内卷（negative，待观察）：如果偏好规则过于精确，开钓前查攻略配装可能取代「随便钓钓」的松弛感，靠规则模糊度与禁区 3 兜底。

# 6\. 体验锚定数字

（不写数值，只记「调它会改什么」。）

- **装备效果差异程度**——调它改选择价值：过低没存在感，过高出唯一最优解。

- **鱼竿耐久消耗速度**——调它改维护节奏：过低机制没存在感，过高钓鱼被打断。

- 断竿率在「失败预算」中的占比——与钓鱼册丢饵率同池分配：调它改「工具惩罚 vs 操作惩罚」的比重，总量不得超预算（接口约束）。

- **特殊饵收益提升幅度**——调它改消耗决策的期待感：过低白花钱，过高普通饵作废。

- **装备获取速度**——调它改解锁节奏：过快探索动力塌，过慢没反馈。

- **道具出现频率**——调它改使用意愿：过低舍不得用，过高不稀奇。

- **草药获取难度**——调它改倒地恢复成本与森林湖采集动机（与猫册「草药恢复效率」联动调）。

- **装备管理成本（携带 / 整理 / 切换）**——调它改准备阶段负担：过高在管仓库，过低没规划感。

# 7\. 视觉反馈通道

- 装备外观即信息：竿 / 饵 / 漂外观差异一眼可辨，支撑收集感与展示欲。

- 耐久用竿身说话：裂纹渐多、缠上草绳藤条补丁，快断时钓鱼中竿身会「吱嘎」响。不做隐藏惩罚，断竿前玩家一定收到过预告。

- 效果在过程中被看见：特殊饵引来目标鱼影、错饵被鱼嫌弃摆尾、道具生效有全场可见的演出，玩家由此明白「为什么选它」。

- 偏好规则的「为什么」由图鉴册线索回显补完（本册演出管当下，图鉴管复盘）。

- 解锁与成套有仪式感反馈（见 §3 装备解锁）。

- 已知缺口（沿自原稿）：装备差异除数值外的体验区分度、修理动作的仪式感设计、道具与特殊饵剩余量的无 UI 化呈现（猫册软性倾向「表现优先于 UI」）。

# 8\. 何时回审

- A5 成长观（表达型 / 便利型 / 零成长）裁定时——§3 装备解锁机制整条重审。

- A5 成长观裁决落定时——§2 循环与 §4 边界联动更新。

- A2 重试制已裁——断竿处置、失败预算分配与落空安慰按重试制对表落地（数值阶段）。

- C4（失败瞬间进印记）裁定时——断竿抛印记条目定去留。

- C7 裁定、印记册总清单收录本册④事件时——④清单定稿。

- 鱼类图鉴册的偏好数据结构定稿时；首次多人 playtest 之后。

# 9\. Playtest 验收预期

- 新玩家不看说明，能否说出「换这个饵会改变什么」。

- 特殊饵落空时，玩家是笑（安慰演出起效）还是骂（白挨一刀）。

- 断竿的玩家是笑还是恼。

- 一局结束时道具使用率——囤积倾向是否出现。

- 备装阶段全场是热闹的（互相闻、起哄、讨论）还是安静的（各自看菜单）。

- 想帮忙抄网的玩家能否顺手拿到抄网——获取流程会不会成为参与协作的门槛。
