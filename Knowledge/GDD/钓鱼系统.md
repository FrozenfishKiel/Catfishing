# 1\. 设计意图

**1\.1 北极星贡献。**钓鱼是「湖畔派对」的主活动：大鱼要几只猫一起弄（协作的热闹），等待和搏斗里有整蛊和炸毛可看（搞怪空间），晚上篝火边翻的照片大多拍自这里（印记素材的主要产地）。猫的真实行为是本册的第一设计语言，全流程都照它来。

**1\.2 体验设计。**

|体验|🎯 想塑造的体验|🛠️ 当前设计|🔍 达成度与缺口|
|---|---|---|---|
|咬钩的悬念与围观|等待不空虚，咬钩瞬间有戏可看|三阶段咬钩信号（试探 / 真咬 / 完美响应窗）\+ 猫身体语言外化（耳朵支起、瞳孔收缩）|信号结构成立；远距离可感知与旁观可见性待实装验证|
|搏斗的力气喜剧|被鱼拖着跑也好笑，赢了很威风|张力\-体力对抗 \+ 猫式发力演出（后仰炸毛脚滑、咬线轴收线、被拽得踉跄惊叫）|骨架成立；失败按重试制（品质定次数、不少于两次），数值归数值阶段|
|合力捞大鱼的高光|「这条鱼是我们一起弄上来的」|搏斗合力拉竿（巨型鱼多人）、近岸抢抄、慢镜头合影|协作编排完整；5\-8 人的参与位待补|
|炫耀与留念|钓到的每条好鱼都有观众|举鱼展示、围观猫互动、结算入图鉴、印记抓拍|展示形式与渔获去向清单待定|

**1\.3 玩家策略路线。**（待补详表。示例取舍：打窝投入 vs 直接开钓；专心钓鱼 vs 帮人抄网 vs 捣乱；追稀有 vs 攒口粮。）

**1\.4 设计禁区。**

- ❌ 人类化操作与动作。所有行为都要能用猫的身体逻辑完成（「无人类双手」红线）。

- ❌ 强制任务与效率引导：协作和热闹靠机制诱发，不下指令。

- ❌ 把失败做成事故。失败只能是喜剧演出，损失必须可恢复。

# 2\. 核心循环

1. 选位与准备：走到水边钓鱼点，装备钓竿，选择窝料与鱼饵。

2. 打窝聚鱼：向水中投掷窝料吸引鱼群，产生持续效果。

3. 抛竿等待：抛出鱼线，等待咬钩；等待中可自由活动。

4. 刺鱼搏斗：咬钩瞬间提竿刺鱼，进入角力拉扯。

5. 拉近收线：收放线控制，将鱼拖至岸边浅水。

6. 抄网捞鱼：自己或队友出手将鱼擒获。

7. 庆祝展示：炫耀战利品，计入图鉴与印记。

单人可完成主循环；大型协作内容（盛宴聚鱼、巨型鱼）面向多人。鱼的刷新按在场协作能力设上限——单人局不会刷出需要多人的鱼（规则归鱼类图鉴册）。

# 3\. 机制清单

## 选位与准备

任意水边掏竿即进入钓鱼待机（钓点是玩家概念：打窝聚出的位置，或者自己看中的风景，不设固定机制点位）；背包切换钓竿 / 鱼饵 / 窝料；不同钓竿外观不同（树枝竿 / 玩具竿 / 逗猫棒竿）。多人各自独立准备，可查看队友装备。

## 打窝聚鱼

选择窝料后蓄力抛掷，抛物线预览；落水泛起涟漪、气泡与鱼影聚拢，窝料光环显示范围与剩余时间。窝料＝腥 / 香 / 酵三属性向量（已拍），窝点维护全队共享的窝料池：投料直接叠加、随时间半衰消散；池子总量决定上鱼速度，属性占比实时决定鱼种构成——补窝是增量，可以先腥引鱼、再香换鱼种。窝料示例：虫虫（主腥）/ 小鱼干碎（主香）/ 发酵浆果（主酵）；具体清单与配方归装备与道具册（魔法料类特殊窝料概率吸引稀有鱼保留）。多人可向同一水域投料，凑够窝料触发「聚鱼时刻」：大量鱼群涌现，同时给出「水下有巨大的影子出现……」的巨物预告。聚鱼时刻为统一机制，另有环境自然事件触发源（见环境册），两种触发共用一套演出、收益与稀缺预算；叠加规则与稀缺约束数值待定。

## 抛竿与等待

点击水面即抛、无蓄力，点哪落哪；鱼漂共 4 种（已拍），决定投掷距离与落点精准（清单与猫世界化命名归装备册）。鱼漂随水波起伏。咬钩信号分三阶段：试探期（鱼漂快速抖动、小水花；此时提竿必空竿，是可学习的规则）→ 真咬期（鱼漂猛然下沉、「咕咚」水声、猫瞳孔缩成竖线）→ 完美响应窗（真咬后 1 秒内提竿＝完美中鱼，鱼的力量与体力直接被削一截，特殊声效「喵嗷！」）。信号需远距离可感知（声音 \+ 猫身体语言 \+ 震动），等待中的玩家可自由活动。普通响应窗按鱼种 8\-15 秒（数值待调）；超窗未响应＝鱼离开、丢饵。

## 刺鱼与搏斗

窗口期提竿上钩，进入搏斗。三资源对抗：猫与鱼各有力量与体力，竿有强度与耐久（已拍）。鱼发力时只能放线跟鱼，猫体力缓慢回复；鱼乏时收线拉近，按鱼的力量消耗猫体力。猫体力不足会被鱼拉走往水里拖（队友可拽尾巴救援，拖到底＝落水、鱼逃）；力量与体力占优时可直接强拉起鱼，不够则消耗竿耐久，耐久尽头断竿。鱼的体力可通过挣扎激烈程度与头顶漩涡标志判读，耗尽进入乏力。挣扎 / 放松的切换信号待定。失败按重试制：按鱼品质与装备给尝试次数（品质越高 / 装备越差次数越少，不少于两次），次数用尽鱼逃回深水。中大型鱼靠搏斗合力：队友加入拉竿分摊力量与体力（代价是鱼冲刺更频繁）；巨型鱼需多人合力拉竿，成功触发慢镜头合影——为大鱼合力发生在搏斗阶段，不在抄网（已拍）。鱼的咬钩与挣扎节奏按性格模板区分（急躁 / 狡猾 / 沉稳等模板＋程序化微调，模板数据归鱼类图鉴册）。

## 浅水与捞取

乏力的鱼半浮水面，拖至近岸浅水出「捞鱼！」提示。单人捞取：观察鱼动作停顿的瞬间出手抱鱼，过早出手会扑空（计一次尝试，次数内可再试）。

## 协作抄网

鱼被遛乏拖进近岸抄网区后，在场任何猫都可以挥网抢抄：先到先得，鱼归第一个抄中的；提前出手＝扑空，罚 3 秒踉跄硬直（各自独立计算，硬直中别人可继续抄）。抢抄不算合力——为大鱼合力在搏斗阶段（见上节）；抄起后举鱼展示与庆祝照常。

## 收获展示与结算

举鱼展示（鱼比猫大时被压得颤颤巍巍）、围观猫互动；图鉴在钓到瞬间自动记录（鱼种 / 重量 / 稀有度；此后鱼被献、被吃、被偷都不影响记录）。渔获流向：入随身鱼护（钓点边暂存，可被偷）→ 带回营地入共用大鱼缸 → 献祭 / 吃掉回复饥饿 / 留缸观赏（承担被偷）；局末随局清空。鱼缸实体见「营地」册，偷吃规则见「联机社交」册。

## 多人互动层

窝点猫爪标记全队可见并显示剩余时间；求助信号全手动：喊不喊人由玩家自己（急促猫叫＋头顶图标），仅巨物保留全体提示（与巨物预告配套）；恶作剧（丢石头惊鱼 / 逗猫棒逗空竿）是「搞怪」的主要来源，开关与护栏规则归联机册（防骚扰牌子已入册），过程细则待定；协作有连携激励，形式待定。

## 实施考量

进出口径已定：咬钩前退出零损失，咬钩后放弃损失鱼饵。状态机细则（被打断后的回退、窝料保留等）需先定义再实装；多人同步（窝料池叠加、盛宴判定、巨物归属、抢抄判序、掉线兜底）是本册最大的工程风险点。机制数值细案（窝料池公式 / 三资源判定 / 抢抄参数）见子页「钓鱼系统 · 机制细案」。

# 4\. 系统边界

**硬性。**

- 不引入本册之外的成长数值（经验 / 等级由项目级决策统一定夺）。

- 不引入世界观外元素（人类文化符号、超自然意象）。

- 鱼种分布表由「鱼类图鉴」册持有，本册只消费不定义。

**软性。**

- 按键与 UI 呈现属交互阶段。

- 猫的通用动画规范（程序化尾巴耳朵、湿毛等）归「猫咪与状态」册，本册只引用。

# 5\. 涌现案例

- 一人续窝、众人垂钓的自发分工（positive）。

- 恶作剧引发的追逐打闹反而成为社交高光（positive）。

- 集体叠窝形成「开钓仪式」（positive）。

- 全员围观一名钓手导致没人钓鱼（neutral，待观察）。

- 连续被整蛊后玩家退出派对层（negative，靠恶作剧护栏规避）。

# 7\. 视觉反馈通道

猫的身体语言即信号系统：

- 耳朵支起 = 咬钩前兆；瞳孔缩成竖线 = 真咬。

- 耳朵压平 \+ 尾巴炸毛 = 紧张；湿毛抖水 = 落水收场。

- 张力读数看鱼线松紧和竿身弯曲；窝料光环显示范围与剩余时间。

已知缺口：挣扎 / 放松切换的可读信号、旁观者视角的信息可见性。演出速记与机制数值见子页「钓鱼系统 · 机制细案」。
