# 页面出处规则

出处只有两种：九册正文＋挂号表格（数值表格一律在「数值模拟与参数记录」页登记）。**数值一旦建了专表，表的值优先于参数页**——参数页只留依据、改数流程与尚未建表的参数。例外一处：钓鱼系统的机制规则出处＝其子页「钓鱼规则」，册正文第 3 章只留意图与指针。其他一切页面开头标三行头：属主 / 状态（草稿·已并入·已废弃）/ 出处链接。子页与草稿随便写，标清状态即可；口径冲突时以出处为准。受控冗余：结论可冗余、机制不可冗余——任何页面可就地写一句话结论与快照数字（标「快照」），判定条件、公式、清单成员只在唯一出处写；冗余结论句不得含从句。

# 阅读负担基准（第七尺）

- **一跳原则**：任一具体问题（怎么判定／数多少／谁负责）从任意入口页至多一跳可得答案。
- **一屏原则**：每页第一屏说清这页是什么、现行结论是什么；版本表放文末「版本历史」节，存量页随下次实质修改迁移。
- **括号预算**：九册正文每句至多两个括号（2026-09-02 由一个放宽）；账本「设计修改记录」、规格书「钓鱼规则」与三份同步页不受此条约束，它们本来就不是给设计师通读的。带日期的裁决注记在属主对账完成后清除，历史归版本表与同步页。
- **死概念不露面**：废案只存在于版本表、同步页与备份；正文与表格表面＝现行真相，警示标注设存续期。
- **待办集中**：待定与待补每页集中一处，正文只留短角标。
- **读者声明**：页首范围段写明谁读本页、带着什么问题来。
