# 1. 一竿流程与准备

猫带着装备来到水边准备钓鱼。

备装 → 可选打窝 → 抛竿 → 等待／试探 → 真咬／提竿 → 搏斗 → 收鱼／失败。

2026-09-16 用户确认：快捷栏选中鱼竿即手持待机，不再按 G 或 R 取竿。左键沿用瞄准、松开抛钩及后续提钩/收线。鱼钩抛出前可自由换格；抛出后统一显示“使用中”，到本竿终局前不能换格。R 架竿保留会话并释放快捷栏格位，世界竿继续可供其他玩家操作；E 接管原世界竿，通用拾取权限待定。X 收回当前手持竿并结束其会话。其他选中物品按左键使用；抄网与鱼护都不是必带。

开始前读取道具与角色输入；叼鱼限制见叼鱼态，道具操作的封闭边界见鱼饵与道具闸门。

# 2. 打窝、等待与抽鱼

## 2.1 窝点、投放与补窝

2026-09-16 用户确认：保留连续浓度场，不做水域鱼库存、窝中整数库存或落水时的鱼量快照；钓走一条鱼不扣窝料浓度。

每次投料建立独立的服务器窝料场，保存 `{X腥, P香, J酵}` 三轴非负浓度、中心、范围、起止时间和衰减曲线。同一水域内，覆盖浮漂冻结落水点的全部有效场按距离和时间衰减后相加，不选最近窝、不合并圆心。补窝新增一个场，不刷新旧场寿命。每漂只维护自己的等待进度，不复制一份窝库存。

当前四种正式窝料均为 `(1,0.5,0.2)`，单份新窝中心浓度合计 1.7；持续 180 秒，实际半径约 8.49 米。这些是资产快照，配方、持续时间和距离／时间曲线继续数据驱动，后续改节奏由对应资产配置。不同窝料目前同配方，不能仅凭名称认定其已有不同偏好。

叠加不设玩法容量上限。投料输入及物品消耗沿用当前正式入口；正在搏斗的猫不能掏窝料，其他可用道具的玩家可以补窝。

## 2.2 每漂独立计时

`A = X + P + J`，单位是浓度，不是鱼的条数。

| 条件 | 落水至试探开始的间隔 |
|-|-|
| A > 0 | `T = 15 / (1 + A/K)` 秒 |
| A = 0（含没有有效场覆盖落点） | `T = 120` 秒 |

`K` 与 `A` 同为浓度单位；当前暂定 `K = 17/3 ≈ 5.666667`，对应一份新窝中心约 11.54 秒、五份新窝中心 6 秒，待试玩校准。不能沿用旧库存模型的 K=100 条。既有角色咬钩间隔成长仍乘到间隔上；饵的种类权重由抽鱼消费，不再改变等待频率或慢浮下限。

补窝、衰减或场消失时，先按旧间隔结算已过去的进度，再按 `新剩余 = 旧剩余 × 新间隔 / 旧间隔` 折算，不重新等待一整轮。例：空窝已经等了 30 秒，完成 25%；补到当前间隔 6 秒时，剩余 4.5 秒。每漂进度相互独立，同窝多人不会抢走对方的机会。

等待从落水开始，飞行时间不计入进度。服务器每 0.1 秒重采样连续曲线，投放／移除事件即时刷新；浮漂轻点预警最多为最后 1.5 秒，高浓度短间隔可缩短预警，不为演出强加最低等待。到点才进入逐鱼试探，真咬仍需加该鱼的试探时长。无随机等待、无 40 秒截顶、无 3 秒慢浮下限。

浓度完全归零时从约 15 秒跳到 120 秒，按完成比例折算剩余；不加平滑或保底。入夜及会话结束清理计时与事件订阅，不跨天续用进度。

## 2.3 抽鱼与鱼饵消耗

每漂到点由服务器读取当刻落点浓度和该漂所用鱼饵，先按 `X/A、P/A、J/A` 选偏好类别，再按该类别中鱼种的饵权重选鱼；抽中结果在试探期冻结，之后有效提竿沿用它。不存在抽鱼扣窝库存、鱼逃回补或同刻争抢最后一条鱼。

鱼种分布、出现条件和协作能力过滤仍由鱼册提供。窝料表的目标鱼种加权以及基础池叠乘当前饵权重属于仍待接入的需求，本次不修改选鱼算法。当前空窝或无有效候选退回正式基础池：河纹鱼 0.4、小银鱼 0.3、泥鳅 0.2、臭鱼 0.1。

试探提竿不损饵，真咬成立才由既有权威事务扣当前饵 1 份；后续鱼逃或中断不退已消费的饵。此处的鱼饵库存与不再采用的水中鱼库存是不同资源。

## 2.4 浓度衰减

每个场按自己的年龄读取时间曲线，并乘距离曲线。补窝不会重启旧场衰减；到期即不再参与采样，稍后的视觉清理不能延长有效期。旧“每 30 秒乘 0.9 并向下取整”的整数游走方案退役。

当前保留正式线性时间曲线与 180 秒寿命。以后需要先浓后淡、平台后衰减或阶梯节奏时，调整曲线即可；同一场的三轴乘同一衰减系数，比例不因取整而漂移。混合年龄、位置不同的场仍可能改变总配比。

## 2.5 聚鱼时刻

2026-09-17 用户确认按“三类浓度分别达标、每次合格投料概率触发”实现，采样位置采用本次投料落点，事件沿用本次窝料场的圆心和半径。独立窝点不合并，浓度不变成鱼库存。

三种窝料都撒够了，鱼会集体开口一阵。

服务器在玩家投料扣量成功、首次发布窝料场时，读取落点的当前三轴浓度（包含本次投料及其他覆盖场的距离／时间衰减贡献）。腥、香、酵分别达到各自门槛才抽一次概率；不看总浓度门槛，不搜索全场热点，不按份数或采样点增加抽奖次数。请求重放和自然事件投料不触发。

事件为固定范围、固定时长的独立状态。已有活动事件与本次范围在同一水域相交（含相切）时不重复触发、不续时；结束后无冷却，下一次合格投料照常判定。门槛不按人数下调；当前携带限制鼓励合作，但不禁止单人通过补给达成。

| 参数或效果 | 第一版可配置试玩值 |
|-|-|
| 腥／香／酵浓度门槛 | 6／3／1.2（浓度单位，不是鱼条数） |
| 每次合格投料的触发概率 | 8%（原范围 5%～10%） |
| 持续时长 | 45 秒（原范围 30～60） |
| 咬钩速度倍率 | 2.5 倍（原范围 2～3） |

配置入口为 `Config/DefaultGame.ini` 的 `[/Script/Catfishing.CatChumFieldSettings]`，门槛键为 `GatheringConcentrationThreshold`。门槛按当前单份 `(1,0.5,0.2)` 的六份同点新料贡献暂定；实际投料因距离、时间衰减通常需要更多。不同 Base 配方会改变所需份数，鱼种基础池不参与浓度计算。以上为可调试玩初值，未经真人平衡验收；不是六份必触发，也不沿用旧每类 30 条。

聚鱼不增加或扣减浓度，不修改窝料寿命；各场照常衰减，即使源窝料先到期，事件仍持续到固定结束时间。范围内浮漂的等待间隔除以速度倍率，开始／结束按已完成比例折算剩余等待；后来抛入的浮漂同样生效，试探停留和真咬响应时长不变。加速不叠乘。表现为范围亮环、密集游动鱼影，不显示数字倒计时；正式美术和打包双端表现仍需验收。翻天、终局和世界退出清除事件。

环境事件触发和稀有道具收益归完整版，不在本版。概率是固定基础值，不随品质或浓度提高。旧整数库存的三类 30 条门槛和“聚鱼消耗存量”口径退役。

## 2.6 渔网与死水

> 尚未实现。以下为旧库存草案：库存扣减与 `min(随机条数, Total)` 已不适用于现行浓度场；产量限制、作用范围和死水恢复规则需另定，本次未授权实现。

一张渔网从窝里一次捞出一批鱼。

渔网是一次性道具。按落点所在窝点的当前概率构成抽取 5～8 条鱼，稀有不额外加权，湖心巨影永不入网；产出落在地上，先到先得。使用后该窝点进入 30 秒死水，所有浮漂的咬钩计时挂起，结束后按独立计时的折算规则恢复。

渔网扣存量：产出逐条按抽中鱼的偏好类别扣，扣法与抽鱼与扣减相同；实际条数是 `min(5～8 的随机数, 当前 Total)`，池里不够不凑数。没有窝点或空池也允许撒网，按基础池给 1～2 条小杂鱼低保，不扣存量。死水期内再撒网不禁止：第二张网正常结算，min 封顶照常保护存量，死水计时重置为 30 秒、不叠加。渔网产出不扣竿的基础磨损。

# 3. 抛竿与提竿

## 3.1 抛竿与浮漂落点

猫朝选中的水面甩出浮漂。

任意合法水边都能当钓点。站位不设合法区，岸上任意位置可抛，合法性只看落点：射程内的水面即合法，斜坡礁石交给关卡碰撞。鼠标左键点击湖面目标点抛竿，无力度条、无蓄力，猫爪按竿、甩竿的动作表达保持。

点击位置到猫站立点的距离为 D_click，不超过浮漂射程就能抛出，超过射程提示「够不到那边」；猫与点击点之间有遮挡同样抛不出，提示相同。实际落点相对点击位置随机偏移：以点击点为圆心的均匀圆盘，半径按漂的精准度映射，精准高／中／低为 0.5／1／1.5 米（快照，参数页为准），漂的种类与参数由挂号鱼漂表提供。偏出水面（落岸）判空竿收回、不损饵，重抛即可，散布是系统加的随机，不让玩家买单。超射程本被「够不到那边」拦下，偏移偶尔越界时落点收敛到射程圆边界。

## 3.2 等待与切饵

以实际浮漂落点按窝点归属选窝点，不在任何窝点内就按基础池和空池间隔处理。等待期间玩家可自由活动，鱼漂随水波起伏。

不设离开判定、不自动收竿：真咬响应窗只有 8～15 秒，跑远赶不回来就是超时鱼逃、损饵，惩罚已经在了，不另造闸。计时期间可以切饵、不重置计时，到点抽鱼时消费当时挂着的饵的权重；到点后再切饵无意义但无害，真咬扣的是当时挂着的那 1 份。采样位置在落水时冻结、不随演出漂移重算；场本身随补窝、衰减和到期变化。

## 3.3 鱼饵与主动道具闸门

进了咬钩，这份饵就花掉了。

无饵不能抛竿，鱼饵随抛竿挂出。咬钩前主动收竿收回鱼饵，零损失；进入咬钩后，无论上鱼、超时、放弃、断竿、落水，都消耗 1 份饵。携带 8 份对应 8 次咬钩机会（快照，参数页为准），用完回营地补给。试探期提竿不损饵（提竿响应）。

从咬钩判定成功到本竿结局落定，禁止主动掏用道具；抄网是收鱼出口，可以正常使用；备装时预穿戴的被动效果正常结算。增效道具按「进入咬钩」计一场，咬钩前收竿不计场。鱼体力不接受道具直接改动，猫体力道具只在搏斗外使用，竿耐久不能回补。

## 3.4 响应窗口与完美提竿

漂轻点是试探，猛沉才是真咬；提得准，这条鱼就软一截。

咬钩分试探期和真咬期。演出时序：抽中瞬间鱼影出现（按真鱼体型）→ 浮漂轻点进入试探期（时长按鱼种配，见鱼表格「试探期」列；该列没填时落 2～4 秒随机区间，区间是兜底不是正式取值口径）→ 漂猛沉即真咬并给提示。试探期提竿必空竿、不损饵，空竿揭图鉴剪影。真咬后的响应时长按鱼种为 8～15 秒，前 1 秒为完美窗；判定用服务器时间戳，客户端预表现。

| 提竿结果 | 规则 |
|-|-|
| 完美 | 普通鱼力量乘 0.8、体力乘 0.85；稀有鱼力量乘 0.85、体力乘 0.9 |
| 普通 | 完美窗后、响应窗结束前提竿，正常进入搏斗 |
| 超时 | 响应窗结束仍未提竿，鱼吐钩逃跑，饵已消耗 |

完美削减是三项削减：鱼力、鱼体力，再加初始线长按完美线长系数缩短（系数挂参数页）；不能变成一次额外伤害或只减某个临时速度。鱼册「力量」、`F_fish`、判定里的「鱼力」是同一个数；完美削减在入场时直接乘到本场实际值，此后运动求解、负载与消耗全用削后值。完美提钩通过降低鱼的力量和体力改善物理对抗，不触发倍数秒结算。恰好 1 秒算完美，闭区间，边界取对玩家有利的一侧。鱼册稀有度最高一档按稀有鱼取系数，其余档按普通鱼。

# 4. 搏斗与退出

## 4.1 资源与有效力量

| 量 | 含义与数据出处 |
|-|-|
| 猫体力 | 基础上限 100 点，成长接口归猫册。同一条体力也被钓鱼之外的物理动作消耗（抓、推、爬，见 6.2 统一出力池），进搏斗不补满（2026-09-11 拍） |
| 猫力 | 当前猫力量；品种基准普通／橘／狸花／缅因为 50／70／90／130，归猫册 |
| 鱼力量 F_fish | 鱼表按实际重量给出；完美在入场削减本场值 |
| 鱼体力 | 初始值＝鱼表「体力系数」× 实际重量（2026-09-08 改表，系数占位待模拟）；搏斗中按 4.4 的鱼体力扣减规则掉，读到 ≤ 0 即翻肚；完美的入场削减作为参数交给鱼侧 |
| 竿耐久 | 动态资源，三档上限 40／70／120，归零断竿 |
| 竿强度 | 静态配置，三档 25／60／210；瞬断规则见强度检查 |
| D | 鱼到猫的距离；初始为浮漂实际落点到猫的距离 |
| 可捞圆 | 挂在鱼身上、随鱼移动的圆，半径按鱼种配在鱼表格「可捞圈半径」列；抄手朝向的射线碰到它即够着，见 5.1 |
| 猫岸距 | 猫到岸的距离，参与被拖下水条件 |
| L、L_max | 已放线长与竿的最大线长；三档 L_max 为 60／80／100 米 |

力量比较用的是**持竿猫自己的当前力量**（2026-09-15 李前臻拍）。引擎的抓握是猫↔猫的机制，队友抓的是主控、不是竿——「猫握着竿」是玩家理解层的说法，不是一次物理抓握。所以队友帮拉**不产生第二个力量数**：他们通过物理拽住主控来影响实际位移，但竿强瞬断阈值只看主控一人。

## 4.2 鱼竿强度检查与物理搏斗

鱼竿要先扛住鱼和猫的拉力。

竿强度和竿耐久是两个量。竿强度管瞬断：竿强度不超过**持竿猫力量**与鱼力中较小的那个，就当场断竿，张力由两端较小者决定。**瞬断和耐久归零一样报废鱼竿**（2026-09-12 拍）——设计对两条路用的是同一个词、同一套表现（爪里只剩半截竿）、同一个结局类（器材失败），不报废的话强度门槛就没有牙齿，拿树枝竿反复试巨影只赔一份饵。前提是**鱼影必须先于提竿出现**（见演出时序），玩家看得见那团黑影才谈得上知情的赌博；这条前置不落地之前，瞬断报废不要单独上线。它是挑战巨影的装备门槛：参数页把巨影力量系数 K5 与竿强 210 配对挂号。

2026-09-16 用户确认：删除力量碾压与固定距离甩岸。通过鱼竿强度检查后，无论猫鱼力量比多少，都进入同一物理搏斗；小鱼可被猫移动拖上岸，大鱼可通过鱼线牵引把猫拖入水中，结果由实际运动和落岸／落水检测触发。换人继续原有 Runner，不按新主控力量直接交鱼。竿强瞬断仍只在搏斗开场和持竿猫换人时检查。实际拖上岸的鱼进入待拾取状态，不直接进入主钓手库存。

## 4.3 鱼行为与运动输入

鱼一阵向外冲、一阵向岸缓游，翻肚前一直在游。

临时骨架：上钩后先向外游；向外发力与向岸低强度游动（演出名「休息」）按鱼种的时长区间交替；鱼体力低于 50% 后休息期变长。鱼体力通过挣扎激烈程度和头顶漩涡给玩家读。演出名「休息」不表示意图速度归零，见搏斗消耗。

最近冲岸距离按鱼种／食性配置：食肉中鱼黑鱼、河口鲈活着不进离岸 1.5 米，森林长尾鱼、银月鳟可以进可抄圈，小鱼可近岸（快照，参数页为准）。冲岸距离列待鱼表补齐。鱼行为的正式输入与审核边界见行为与运动接口。

## 4.4 搏斗消耗、移动附加与磨损

猫出的力越大、线上越沉，体力扣得越多。

搏斗消耗按猫的出力计，收线、转竿、顶住三样各自计费，每一样都乘上线上的负载。

- 收线：按实际收回的线长计费，每米一个单价。
- 转竿：按竿实际转过的角度计费，每弧度一个单价。
- 顶住：线绷紧时每秒付支撑费，按负载的平方算；转竿的支撑与顶住只收较高的一项。
- 负载项＝空载系数＋当前负载×负载系数。当前负载是线上拉力占猫力量的比例，0 到 1；放线时线不绷紧，负载为 0，三样都不计。

被鱼拖走不另收费，拖拽的惩罚在位置落水（4.6）。鱼那边的体力按它没游成的距离扣，见鱼的行为 §4.5。实现注意：消耗随固定步运动求解走，求解抖动会抖体力条，需要一层平滑。单价、空载系数、负载系数、支撑单价的现值挂参数页（快照，参数页为准）。多人各自独立结算，不再乘辅助位角色倍率（2026-09-11 已废止，2026-09-15 同步漏项）。

移动附加是腿部消耗，按秒计费，与搏斗项并行相加，只看操作方向：按 W 前移（靠水）1.5 点/秒，按 S 后退（离水）3 点/秒（快照，参数页为准）。力量差不进腿部消耗，由搏斗项承担：负载越重扣得越多。W、S 在钓鱼中不翻转。

线绷紧的每一秒，竿耐久另扣 `鱼力 × 0.05`（快照，参数页为准），鱼力 75 时每秒扣 3.75。搏斗以渔获结束时，竿另扣基础磨损 1 点；渔网产出不扣。竿不可维修。

## 4.5 收放线与线长预算

放线用线长换喘息，线放完就得硬顶。

真咬成立那一刻，以竿尖到冻结咬钩落点的距离 `D₀` 检查最大线长；等待期移动不受线约束，当刻已超 L_max 则直接判脱钩鱼逃，饵已扣、不丢漂。提钩成功后的初始线长 `L₀` 取当时竿尖到鱼嘴的距离，不取猫到鱼的距离；完美中鱼时再乘完美线长系数并将鱼投影到缩短后的线长内（系数挂参数页，水面几何约束仍须满足）。L_max 三档 60／80／100 米。

放线是解除线轮锁定，不是主动出线。锁定时线长恒定，鱼拉的就是猫，张力传导、进对抗；解锁后线随鱼的实际外游出线，`L` 的增长等于鱼的实际位移，无张力、零消耗，没有「放线速率」这个参数。收线是主动卷回，`L` 回收；鱼发力时收线就是强对抗、费体力。体力与线长互为价格，收放循环不是免费的。线出尽（`L = L_max`）后解锁失效，张力全传给猫，被迫全额对抗，「什么时候舍得放线」才成为决策。

放线期间不判位置落水：放线就是松开对抗，拉力不再作用于猫，「鱼向外游＋力量不足」的拖拽前提消失。放线本身不恢复体力，搏斗中一律不恢复；猫册三选一的「放线回体速度」可以给放线加回体速率，基础为 0。放线时鱼向外则 D 增大，鱼向岸则 D 缓慢减小。

## 4.6 归零、位置落水与离竿

持竿猫力竭会被拖下水。

| 条件 | 结果 | 说明 |
|-|-|-|
| 鱼体力 ≤ 0 | 鱼翻肚 | 进入翻肚拖岸拖回；抄取另验可抄资格与几何边界 |
| 猫体力 ≤ 0 | 猫力竭 | 被拖下水，鱼逃 |
| 竿耐久 ≤ 0 | 断竿 | 鱼逃，器材失败 |
| 竿强度 ≤ min(持竿猫自己的力量, 鱼力) | 断竿（瞬断） | 搏斗开场或持竿猫换人时当场判；鱼逃，器材失败，**竿同样报废**（2026-09-12 拍）。与耐久归零共用同一结局与表现 |
| 主位离竿 | 无人值守放线 | 竿落地、会话继续；见本节末段 |

位置落水要同时满足三条：猫岸距归零、鱼向外游、持竿猫力量小于鱼力（取等不落水，鱼力必须大于持竿猫力量才拖得动猫；队友拽住他改变的是岸距会不会归零，不进这条比较，2026-09-15）。只判持竿者，被线拽的是他，竿、饵、漂、落水全是他的账。猫体力耗尽仍走资源落水出口，位置条件不能当成免除体力归零后果的保护；两个出口同刻满足时体力落水优先。

落水的后果是鱼逃、饵已扣、湿身喜剧演出，嘴里原有的鱼保留，没有其他损失。

主位在搏斗中主动走开、又没有队友接手时，竿落在原地，这一竿不结场：线随鱼向外放，放到尽头就拴住；没人顶就没人扣体力，离开的猫带走当时剩下的体力。饵在咬钩成立时已扣；鱼不逃，直到有人切线或入夜按 6.5 收口。放下的竿可以切线，也可以被接管：切线由原持竿者或竿的主人走到竿边 2.5 米内按下（快照，参数页为准），鱼逃、图鉴按鱼逃口径；接管是任何猫走到同一距离内接过这一竿继续遛，鱼与竿的状态完全继承、猫体力各是各的，不设体力准入，与〈多人钓鱼〉§2.4 的换人握手同一口径。落水与猫体力归零不走这条出口，仍按上表结场。

## 4.7 主动放弃

玩家可以主动放弃本竿，进入咬钩后饵已消耗。2026-09-16 用户确认的正式输入为 X 收回当前手持竿；收回前检查库存可接收，进行中的会话沿用主动放弃的唯一终局与扣饵入口。原“长按 1.5 秒”不再绑定正式 X 输入。图鉴按鱼逃同口径：上钩已揭的剪影保留，收集层不写（捕获事件）。

# 5. 收鱼与归属

猫叼住收来的鱼。

## 5.1 抄网与可抄资格

抄网够到鱼身上的圈，就能下网，不必等它累瘫。

抄网非必带，单一款式，没有长度、体型上限或成功率属性。可抄的对象是钩上的鱼或翻肚鱼。每条鱼身上挂一个可捞圆，圆心随鱼走，半径按鱼种配在鱼表格「可捞圈半径」列，占位按体重档小 60、中 90、大 120 厘米；抄手朝向的射线碰到圆就算够着，够着即必中。射线长度是抄网射程，现值 2 米（快照，参数页为准）。自由游动的鱼不可捞；湖心巨影的可捞圆为 0，不可抄，只能实际拖上岸后拾取。不按竿长、鱼重量或抄网等级判断，也不看鱼离岸多远。

## 5.2 挥网与叼鱼态

按 F 挥网，命中由服务器在判定瞬间验证。命中后鱼由挥网的猫叼在嘴里，实物归抄网者，图鉴见捕获事件。

没够着、对自由鱼或湖心巨影出手、被别人抢先，都算挥空；多个 F 目标并存时按视角中心选（F 目标选择）。挥空的猫进入 3 秒硬直（快照，参数页为准），无法操作。提示沿用「没够着」「被抢先」，不可抄的对象也要能从表现上认出来。

嘴里只能叼一条鱼。叼着鱼不能抛竿、不能再抄或拾第二条，得先放进鱼护或扔下。鱼护非必带，不带的猫也按这个规则处置后继续钓。落水时嘴里的鱼保留。

## 5.3 翻肚拖岸与拾取

没网就把鱼拖累，拖上岸再捡。

鱼体力耗尽即翻肚，之后鱼不再发力，只跟着线走：不放线时线长固定（4.5 的锁线规则），猫往后走，鱼就被拉得离岸更近，拖过岸线即按力竭处理、侧翻落在碰岸处。猫可以边走边收线，鱼始终朝猫的当前位置被拉，无对抗即无消耗；这一段不看 D，也不算最近岸线点。落岸不等于入袋，仍要按 F 拾取，拾取必中，鱼叼进拾取者嘴里、实物归拾取者。岸上的鱼谁都能拾，先到先得；钓手已得的图鉴登记不因别人拾走而取消。

水里翻肚的鱼超过苏醒时限仍未上岸就苏醒逃跑，时限是配置项，默认 30 秒（快照，参数页为准），拖动中计时照走，能拖多远看猫走多快。实际拖上岸后不再苏醒，但地上未拾取的鱼翻天消失，不能靠「离水安全」跨天囤鱼。

## 5.4 所有猫收鱼与服务器判序

谁先出手鱼归谁。

所有猫都能抢同一条可抄鱼，也能抢拾同一条岸上鱼。以服务器收到指令的时间戳判先到先得，第一个有效命中者得实物，其余各自进入 3 秒独立硬直，硬直中再按 F 无效，提示「爪子还在麻」。不能用客户端帧数替换服务器时间戳。

时间戳完全并列时按席位序（加入房间的先后，早者先）打破，确定、可复现。同一 tick 的事件结算序固定为收鱼 → 苏醒 → 落水，玩家利益优先：同刻收鱼加落水时鱼先进嘴，到手的鱼不被同刻落水吞掉；同刻被有效收取的翻肚鱼不再苏醒。这个顺序只管收鱼、苏醒、落水三件事，不扩展为换人、献祭和离局的全局优先序。

## 5.5 几何边界与 F 目标选择

鱼的位置以服务器物理碰撞箱中心为准。够不够着看抄手的身体朝向：从抄手位置沿面朝方向水平发一条射线，长度等于抄网射程，碰到鱼的可捞圆即够着；转镜头不改变朝向。另有三条拒绝条件，任一不满足都判「没够着」：抄手与鱼之间有遮挡；抄手脚下坡度超过 45 度；抄手与鱼的高差超过 2.5 米（三个数都是快照，参数页为准）。抄手必须站在岸上，嘴里不能叼着鱼。落岸鱼的可拾距离是 1.5 米，全游戏统一交互半径，与抄网射程是两个参数，都在参数页。

### F 目标选择

对着谁按 F，就对谁出手。

射线碰到可捞圆只是资格门槛；多个合法目标同时够着时，F 作用于玩家视角中心所指的那个。UI 以准星态提示当前 F 目标。

## 5.6 捕获事件与实物归属

上钩就揭剪影，收进嘴才算收集。

图鉴分两层。剪影层在上钩成立时揭开、永不撤销，试探期空竿同揭。收集层（名字、彩色立绘、出没区域、个人最佳重量）在成功收鱼时写入，归上钩者：实物被队友抢走不取消登记；鱼逃、放弃、中断则收集层不写、剪影保留。「上钩成立」是归属基准，不是收集层的写入时点；此后吃、献、被偷都不撤销记录。重量没有组队加成。

### 基础自然恢复

搏斗外自然恢复 5 点/秒，站立、岸上替补、摸鱼随队一律同一速率，没有场景乘数；搏斗中不恢复（快照，参数页为准；出处猫册数值成长页）。

### 统一出力池（钓鱼之外的消耗）

抓、推、爬与搏斗花同一条体力。

体力不只在钓鱼里扣（2026-09-11 裁决四）。钓鱼之外，每只猫按物理出力模型计费：本步想走的距离减去实际走成的距离，每米扣一个价（快照 2 点/米，参数页「多人·物理抓握出力」行为准）；平地走成了不扣，被墙、被队友、被负载挡住没走成的那段才扣。松键站稳也在出力：按抵抗当前负载所需反力占自身力量的比例折成意图距离再扣，无负载时不扣。抓着别人、被别人抓、推挤，只要身上有玩法负载就不恢复；卸载后按上面的 5 点/秒恢复，没有等待时间，也没有再入门槛（2026-09-13 力竭状态与三道恢复闸退役）。

体力归零不是一个状态：主动力量变为零，走不动、抓不住，能被别人拖动；一卸载就开始回，回多少动多少；接竿不设体力门槛（4.6）。钓鱼里的归零另有结局（4.6 落水）。进搏斗不补满：搏斗外剩多少就带多少进去，连续硬仗的代价和小鱼干的价值都在这一条上（道具册）。多人合力时的扣法见〈多人钓鱼〉§2.3。

## 6.4 渔获与消费交接

收上来的鱼先在嘴里，去哪由别的册子管。

抄取或拾取→嘴里→可选鱼护暂存→带回营地共用大鱼缸，再选择去向；也可以按叼鱼态规则先扔下。当天扔下等于赠送路径，谁都能捡；物品不能扔进湖里。翻天时地上未拾取的物品一并消失。

吃、献、卖、留缸观赏是渔获用途概览，经验、供奉、卖价与容量由接收册处理。钓鱼对同一条鱼输出鱼种、实际重量、上钩归属与实物持有人；上钩事件与成功收鱼事件分别对应捕获时点。渔网直接产出落地鱼，没有竿上钩过程。

转存接口要区分成功与拒收，满容器不得当作转存成功。鱼实例标识、接收确认、重复提交与拒收后的状态尚无已裁的工程实现。鱼护容量、跨天保存资格和鱼缸升级是外部输入。

## 6.5 生命周期输入与状态转移

入夜停止新咬钩，翻天清窝。

| 外部信号／阶段 | 钓鱼侧行为 | 损益与未裁边界 |
|-|-|-|
| 入夜 | 不再产生新咬钩；还没咬钩的浮漂剩余计时一律清掉，不冻结、不跨天续用；进行中的搏斗允许打完 | 入夜瞬间处于试探期的竿按空竿收回，不损饵、无需回补窝库存；真咬待响应的算进行中，允许提竿并打完，超时鱼逃；与入夜同刻到点的浮漂不再抽鱼 |
| 强制中断（献祭互动等） | 强制打断进行中的互动，按鱼饵消耗时点结账 | 试探中收竿未扣饵、无需回补窝库存；真咬后按鱼逃、不回滚、不丢漂；已揭剪影保留、不记捕获。与收鱼、断竿、换人同刻的关系未全定 |
| 翻天完成 | 窝点清空；旧浮漂剩余计时不跨天；地上未拾物品随世界清理消失 | 聚鱼窗口、死水随窝点一并清空；容器保存资格不等于地面物清理 |
| 下一轮钓鱼开放 | 从新的准备与打窝流程开始，不恢复昨天的咬钩倒计时 | 开放信号由局与进程提供；不以本地时钟推算任务人数 |
| 局结束 | 停止钓鱼，释放窝、漂、搏斗等本系统瞬态；已输出的捕获事实不因失败撤销 | 毕业上供不翻天、失败立即结束且不进结算夜，两者都需要局结束出口；释放时序待接口接线 |

钓鱼只消费中断与开放信号，不判断祭坛全员到齐、不计算每日目标。

# 7. 信息与反馈

规则提供事件、状态、目标和可见范围，动作表现集负责素材。动作不改变既定硬直时长与鱼归属。

## 7.1 必须可感知的操作反馈

| 场景 | 提示或表现 |
|-|-|
| 抛竿 | 左键点水面，猫甩竿 |
| 鱼向岸休息 | 状态文字变绿「鱼累了！按住左键拖回来！」；猫耳朵竖起、尾巴甩动 |
| 鱼向外发力 | 状态文字变红「鱼在发力！放线喘口气，拖线就是硬拼！」 |
| 鱼可抄 | 屏幕中央爪印图标＋「快抄！（按 F）」，以收鱼资格判定为准 |
| 猫体力偏低 | 体力条变红闪烁＋「猫喘气了！」与喘气表现 |
| 落水危险 | 爪扒地划痕＋「要滑下去了！」，不承诺未实现的拽尾巴救援 |
| 完美 | 金色水花＋瞳孔放大＋清脆一声「叮」＋「完美！」 |
| 断竿 | 咔嚓声、爪里只剩半截竿、猫愣住 |
| 鱼逃 | 耳朵耷拉、水面恢复平静 |
| 挥空 | 猫拍空或被绊、沙漏图标＋「爪子麻了！」 |
| 主动放弃 | 「放生了鱼…鱼饵和浮漂被带走了」 |
| 物理拖岸 | 鱼随实际牵引到达岸上后进入待拾取状态，无按力量倍数触发的甩岸演出 |

铃铛漂咬钩为叮铃声，鱼发力为线绷紧的嗡声，鱼休息时拍水声减弱；竿断为咔嚓，落水为扑通加喷嚏。基础咬钩信号要让漂主远距离感知，包含声音、身体语言与震动通道；铃铛漂把它增强为全场可闻。

## 7.2 世界可见性

鱼影按已抽定那条真鱼的体型演出，附近玩家都能看见，只让人感知有鱼及大致体型，不能据影认出鱼种。窝点的猫爪标记全队可见，读有效浓度 A 的浓／中／淡三档（阈值挂参数页），不表达剩余时间，不显示浓度数字；范围与鱼量通过光环、粒子、鱼影粗略表现，三档表现归张佳。聚鱼进行中标记变亮、鱼影加密，同样不出数字倒计时。

队友的装备通过身上、手里、嘴里的世界表现和凑近闻来了解，不新增查看装备的菜单。猫的耳朵、尾巴、瞳孔、炸毛要在半个湖外仍能辨读；落水、拍空、被绊都好笑不惨；线的松紧、竿身弯曲表达张力。

## 7.3 表现责任与回审

真咬、完美、危险、可抄、挥空、落水和断竿等事件由钓鱼提供，动画与音效由动作表现集接收。鱼向外发力时猫前滑、爪扒地、耳朵后压与瞳孔收缩，力量与低体力信号必须保持可读；猫体力低于 30% 给偏低提示（快照，参数页为准）。挥空表现不得改变既定硬直。素材细目见〈动作表现集〉页。线长余量给世界内表现（线轮上还剩几圈）；力量差不给数字，靠猫前滑、爪扒地和线的绷紧读；鱼体力靠挣扎激烈程度与头顶漩涡（鱼行为）。

修改任务曲线、卖价、容量或动画素材只变更其所属数据与资产；改变鱼意图含义、力量单位、命中帧、可操作时刻或生命周期顺序须回审对应接口。
