<title>鱼</title>

> 本册范围：鱼种数据的唯一归属——分布、窝料轴、体重轴、鱼饵偏好、吃鱼效果字段。数据本体在子页「鱼表格」（「第一版」sheet 为现行，旧 Sheet1 已废弃）。**RC 实装 20 种**（2026-09-02 拍定）；鱼表格现有 16 种，还缺 4 种；W2 配表接入先接 13 种跑通管线。三个数各有各的名字，别互相冒充。
> 
> 图鉴 2026-08-27 拆出独立成册：怎么解锁、怎么呈现、谁登记，全归「图鉴」册。本册只管鱼是什么样的，不管玩家怎么认识它。

# 1. 设计意图

**1.1 北极星贡献。**全项目都围着鱼转，大鱼要合力抬，偷鱼是搞怪素材，献祭拿鱼当贡品，照片主角是鱼，篝火边聊的也是鱼。本册的活是把这条鱼定义清楚，让引用它的五个册子拿到同一份。

- **给热闹供弹药**：「就差那条鱼了」，全队就一起撒窝料备鱼饵；「帮我把剪影的鱼抓到」就是开团喊人的由头。靠的是分布与偏好字段能被玩家读懂。
- **一鱼多头供**：同一条鱼要同时供给钓鱼册的搏斗档位、猫册的吃鱼效果、商店册的定价、图鉴册的条目。字段从这几头倒推。

**1.2 体验设计。**

| 体验 | 🎯 想塑造的体验 | 🛠️ 当前设计 | 🔍 达成度与缺口 |
|-|-|-|-|
| 体验一·为了遇见某种鱼而准备 | 出发前有目标，钓到时有意义，不是无脑重复甩竿 | 窝料轴＋鱼饵偏好字段；线索怎么呈现归图鉴册 | 依赖分布线索的可读性；线索给多细待定 |
| 体验二·一条鱼有它自己的分量 | 8 kg 的鱼和 1 kg 的鱼，从上钩那一刻手感就不一样 | 体重轴分档＝搏斗协作门槛（单人可起／需队友帮拉／多人合力） | 档位与鱼表的实配比留数值阶段 |

**1.3 玩家策略路线。**

- **补图鉴 vs 攒渔获**：换条件去蹲没钓过的鱼，还是刷经验和献祭储备。
- **高价值小鱼单干 vs 巨物开团**：体重轴与稀有轴分开以后两条路都能走——独狼玩家刷个头小但值钱的鱼，派对玩家合力抬巨物。稀有度既然是价值判断，小鱼一样可以很值钱。
- **好鱼去哪**：献祭推进度 / 留缸镇宅。钓到那一刻图鉴就记上了，怎么处置都不伤收集——这个取舍敢做，靠的是图鉴册的记录护栏。

**1.4 设计禁区。**

- ❌ **现实时钟限定鱼**——没有真实时间（已拍定），不存在「周末限定」「错过等一周」。任何鱼的出现条件都能在一局之内等到或创造出来。
- ❌ **没有下游的字段**——每个字段都要说得出谁在消费它，不为建模而建模。

# 2. 一条鱼的一生

1. 按分布与当前窝料条件刷新进水域（刷新上限按在场协作能力，单人局不出需要多人的鱼）。
2. 被鱼饵偏好命中，上钩。
3. 按体重轴进搏斗档位：单人可起 / 需队友帮拉 / 多人合力拉竿。
4. 上岸，进鱼护与共用大鱼缸。
5. 去向：献祭 / 吃（触发吃鱼效果）/ 卖 / 留缸观赏。
6. 局末随局清空——图鉴上已记的内容不受影响（见图鉴册）。

# 3. 机制清单

## 3.1 设计意图核心

### 1. 鱼种档案

每种鱼一条档案，字段如下；数据本体在子页「鱼表格」。

| 字段 | 内容 | 谁在用 |
|-|-|-|
| 基本信息 | 名字 / 外观 / 缸内游动表现 | 营地册（缸内鱼按实际鱼种游动）、图鉴册插画 |
| 分布·区域 | 出现在哪片水域（河流 / 森林湖）；含「无窝料基础池」保底档（Total=0 时的小鱼杂鱼，2026-08-15 拍定归本册） | 钓鱼册抽鱼、环境册定义区域 |
| 窝料轴 | 按照鱼的环境偏好，用窝料打造相应的鱼窝环境 | 钓鱼册（窝料概率吸引鱼群的玩法在钓鱼册；道具册只管窝料获取携带） |
| 体重轴 | 搏斗协作门槛分档：单人可起 / 需队友帮拉 / 多人合力拉竿 | 钓鱼册协作编排 |
| 稀有度 | **价值判断，不是遭遇难度**（2026-08-27 拍定）——这条鱼值不值钱。价值不限于数值：经验与吃鱼效果算，社交演出价值同样算——咸鱼不能吃、零经验，价值全在拿来吓唬朋友；臭臭鱼的价值是屏蔽互动那 90 秒。五档：普通 / 少见 / 稀有 / 珍稀，外加「事件」（湖心巨影特例）。值在鱼表格「稀有度」列 | 图鉴册（展示）、营地册（稀有入缸触发）、道具册（特殊窝料与四叶草的加权对象）、A6 单人门槛，已于 2026-09-02 关账 |
| 偏好 | 鱼饵倾向（窝料不进偏好——窝料按档位起效，不按鱼种，见钓鱼册） | 道具册（不同鱼类有不同偏好、特殊鱼需要特殊准备） |
| 吃鱼效果 | 限时 buff＋经验值（局内成长制，2026-08-15 拍定；规则归猫册，本册持数据） | 猫册（消费）、商店册（同尺换算）、图鉴册（知识层） |
| 可捞圈半径 | 抄手朝向的射线碰到鱼身上这个圆即可抄；小鱼小圈、大鱼大圈，湖心巨影 0＝不可抄（2026-09-09 可抄几何裁定）。值在鱼表格「可捞圈半径」列，占位按体重档填 | 钓鱼册（可抄判定 §5）、程序（逐鱼字段） |
| 最近冲岸距离 | 活着时不进离岸多少米，0＝可到岸边；按鱼种／食性给、不按体重档（参数页「贴岸阀」行）。值在鱼表格「最近冲岸距离」列，快照 0／1.5 米，正式值随「鱼的行为」方案定 | 鱼的行为页（冲岸节拍）、钓鱼册 |
| 饵权重与基础池 | 每鱼×每饵的抽鱼权重，以及无窝料基础池的成员与概率，两张子表「饵权重」「基础池」（2026-09-10 建，占位） | 钓鱼册抽鱼第二步、程序 |

### 2. 分布与刷新

- 出现在哪片水域由分布字段定；「无窝料基础池」是保底档——Total=0 时也有小鱼杂鱼可钓。
- 刷新上限按在场协作能力设定：单人局不刷出需要多人的鱼。
- 稀有度不参与抽鱼（2026-08-27 拍定）：出不出这条鱼，看分布、窝料轴与鱼饵偏好；稀有度说的是钓到之后它值多少。难度来自「要备对装备」，价值来自「钓到了给多少」，两件事分开。
- 剪影不由世界进度驱动（2026-08-27 改口径）：开局满图是影，靠玩家行为逐个揭开，规则归图鉴册。剪影揭没揭开不影响这条鱼在不在水里——刷新只看本册的分布与条件。

### 3. 体重轴与协作门槛

分档即搏斗协作门槛：单人可起 / 需队友帮拉 / 多人合力拉竿。合力发生在搏斗阶段，抄网一律抢抄（钓鱼册口径）。重量一律按真实值记录，无组队加成。每种鱼身上有一个可捞圆：抄手朝向的射线碰到圆即可抄，小鱼圈小、大鱼圈大，湖心巨影为 0 即不可抄；半径在鱼表格「可捞圈半径」列，占位已填（2026-09-09 可抄几何裁定，判定写在钓鱼规则 §5）。

### 4. 窝料轴与鱼饵偏好

窝料决定「哪一类」，鱼饵决定「哪一条」——属性命中后，候选鱼按当前鱼饵的偏好权重取。窝料不进鱼种偏好字段。玩法归钓鱼册，携带与获取归道具册。逐鱼×逐饵的权重值，以及无窝料基础池的成员与概率，在鱼表格子表「饵权重」「基础池」（2026-09-10 建，占位，张佳定）。

### 5. 吃鱼效果字段

限时 buff＋经验值按鱼种配置，负面（中毒等）同样按鱼种配。规则归猫册，本册持数据。毒鱼的经验按同体重档 1.5\~2× 上浮（拼死吃河豚），保住倒地救援的内容供给。

## 3.2 实施考量

- **数据先行 vs 体验先行**：先立 schema 让引用有收口点，但字段从体验需求倒推，不为建模而建模。
- **一鱼多头消费**：改一个字段要过一遍钓鱼、猫、商店、图鉴四个下游，别单点改。

# 4. 系统边界

**硬性。**

- 本册是鱼种分布表与鱼种数据的唯一归属。
- 图鉴的解锁规则、页面呈现与登记归属归图鉴册，本册只提供字段。

**软性。**

- 鱼名与外观走猫世界观趣味（在 A4 裁决范围内），不用人类文化梗。
- 缸内游动模型与图鉴插画尽量同源，省一份美术成本。

# 5. 涌现案例

- 收集党与献祭党抢稀有鱼去向，但图鉴已记，冲突降级成「摆缸里还是献掉」的良性拌嘴（positive，记录护栏的价值）。
- 毒鱼当诱饵防偷（positive，见猫册「毒鱼防盗陷阱」；成立条件是图鉴知识层未解锁）。
- 体重轴与稀有轴分开之后，独狼玩家靠稀有小鱼也能推进（positive，A6 单人门槛的依托；A6 已关账）。

# 6. 体验锚定数字

（不填数值，只记调它会改什么。）

- **鱼种总数**（RC 拍定 20，现有 16）——调它改收集长线的长度与内容成本；也直接改窝料三属性每桶的鱼数，桶越满，为某一条鱼做准备的命中率越低。
- **分布密度**（每个条件格里有几种鱼）——调它改「换条件钓鱼」的动机强度。
- **体型档数与协作门槛线**——调它改多人协作被触发的频率。
- **单局可遇鱼种覆盖率**——调它改单局新鲜感与跨局收集节奏的配比。

# 7. 视觉反馈通道

- 共用大鱼缸是活的鱼册：缸内按实际鱼种游动（营地册口径）。
- 体重档在上钩手感上就读得出来，不靠数字告知（沿用钓鱼册信号语言）。

# 8. Playtest 验收预期

- 玩家能不能自己说出「想钓那条鱼，我该去哪、带什么窝料鱼饵」（线索可读性的实测，与图鉴册同题）。
- 体重三档的手感是否真的能被分辨。
- 稀有鱼「献掉还是留缸」的讨论是否发生。
