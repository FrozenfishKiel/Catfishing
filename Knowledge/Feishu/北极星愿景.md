# 愿景

**「一群猫好友的湖畔钓鱼派对：为大鱼合力，为整蛊炸毛，篝火边翻翻今天的照片。」**

情绪排序：**热闹为主（好友聚在一起玩起来很热闹），快乐与搞怪并存（一起笑，也笑话彼此——失败与翻车是内容），治愈是底色与余味（湖畔视听与猫的真实行为做容器，篝火与印记回看做收尾，不与热闹抢戏）。玩家扮演湖畔的猫咪，吃鱼获得成长（本局内生效）。单人可玩是功能底线**，设计资源向多人倾斜——「好友聚在一起」是愿景中心。

# 体验基调

**画面视觉。**3D，卡通柔和风格，色彩明亮温暖。场景是开阔的湖畔：浅滩湖水、芦苇、花草、树木树荫，昼夜循环，会下雨、黄昏晚霞、夜晚月光。角色是一只只造型可爱的猫咪，毛发柔和，动作细腻：舔毛、甩尾巴、打哈欠、耷拉耳朵、打滚。

**听觉氛围。**轻松舒缓的环境 BGM；湖水波浪、鸟叫、风吹草木、雨滴、篝火噼啪的环境音效。

**玩起来是什么感觉。**你操控一只猫咪在湖边，可以一个人玩，也可以最多 4 只猫一起联机结伴钓鱼、休闲互动。主要事情是钓鱼：抛竿，鱼上钩之后进行博弈对抗拉扯；等待咬钩时可以看花、看飞鸟，也可以趁别人钓鱼时去偷别人的鱼。会累、会被雨淋湿。回营地把渔获放进共用的大鱼缸，点起篝火，和别的猫咪围在一起休息。游戏自动记下你的高光时刻（雨天钓到大鱼、和朋友篝火相聚等）供回看。大家联机各自钓鱼也行，聚在一起合作也行，没有强制任务。

# 差异化方向

| # | 方向 | 说明 | 验证判据 |
|-|-|-|-|
| 1 | 猫的真实行为喜剧 | 所有动作是真猫行为；失败与翻车全是喜剧演出 | 玩家能复述 3+ 个「猫做了 X 笑死我」的瞬间；笑点来自动作而非文字 |
| 2 | 无任务的机制式热闹 | 协作与整蛊由机制诱发（聚鱼时刻 / 抢抄与巨物合力 / 恶作剧），不靠任务驱动 | 一局内玩家自发组织协作或整蛊不少于 3 次（无引导） |
| 3 | 印记记忆 | 热闹瞬间（含失败翻车）自动成为可回看、可分享的记忆 | 玩家主动回看 / 分享印记；「篝火边看照片」被测试者提为喜欢的环节 |

# 设计语言（质量闸门）

所有系统设计必须能回答以下四问；回答不了的方案标红灯要求重做：

1. 它好笑吗？笑点是不是「猫」？
2. 它让一群人更热闹，还是更安静？
3. 被整 / 失败的那个人，也笑得出来吗？（皮不毒红线）
4. 它会留下值得回看的瞬间吗？

# 长线目标与结束态

无「通关」概念：局与局之间只有收集与解锁，没有义务（不做每日任务 / 赛季类元进度）。一局的终点＝坚持到第 10 天（暂定）并达成额度即毕业圆满结局，额度未达成＝这一局失败；无尽模式后置。长线追求＝跨局跟人走的三样：图鉴、印记相册、外观解锁——营地与渔获跟局走，不入长线。不做跨局数值成长（局内成长＝吃鱼 buff＋经验三选一，规则见猫咪与状态册），鱼的重量按真实记录；解锁＝表达型（A5 尾项已裁，2026-08-13 随商店拍定关账）。
