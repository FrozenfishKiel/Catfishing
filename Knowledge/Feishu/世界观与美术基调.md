# 1. 世界观边界

- 纯猫的湖畔世界：**没有人类，也没有人类文化符号**——物件、命名、仪式都不从人类世界直译。
- **无人类双手红线**：一切行为都要能用猫的身体逻辑完成（叼、扒、扑、蹭、拍），不出现需要「手」的精密操作。
- 超自然只开一个口子：**祭坛**。除祭坛外不引入超自然意象；祭坛的包装尺度见 §3。
- 时间是局内的：昼夜是局内时间流，与现实时钟无关（结构见「局与进程」册）。

# 2. 猫世界化规范（命名与形态）

# 3. 祭坛与世界观外来物

已拍定：祭坛存在，献祭是渔获的主要去向与全队共同目标（目标结构见「局与进程」册；无「献祭者」个人角色，献祭是全队共同投入）。

已裁（A4·方案 B）：祭坛＝猫世界讲得通的仪式对象；「古神」类克苏鲁措辞废除。**内容层二选一已于 2026-08-21 落定：岸边猫神石像**——立在营地旁的水边、面朝湖心，献祭时全队朝同一个方向坐成一排，画面收在湖水与晚霞上。老猫长者案否决，三条理由：超自然口子只开祭坛这一个，换成 NPC 等于关掉，世界进度（森林复苏）就没了载体；「祭坛本体即进度可视化」要求实体能演进，石像可用苔藓褪去与纹路点亮，老猫做不到；营地已有商人猫收鱼换钱，再放一只收鱼换进度的猫，会让「卖它等于少献它」这个核心取舍失去空间表达。连带口径：「大渔」旗改为庆祝粒子或围观猫集体仰头嚎；「点赞撒花」改为围观猫凑上来蹭你、闻鱼、兴奋刨地；「快来帮忙」语音改为急促猫叫＋头顶图标（与求助全手动口径配套）。达成与失败的演出守治愈底色：失败好笑不惨。各册引用本节口径。

# 4. 美术基调

- 情绪排序落进画面：白天湖畔承载热闹，夜晚篝火承载治愈——一局之内完成明暗与冷暖的节奏（具体色彩基调待定）。
- **行为可读性优先**：笑点靠猫的身体语言（耳朵、尾巴、瞳孔、炸毛），任何风格选择都不得牺牲这些信号的远距离辨识度——隔着半个湖也要看得出「那只猫炸毛了」。
- 失败画面好笑不惨：翻车演出是内容，不是事故现场。
