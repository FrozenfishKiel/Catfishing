<title>猫咪与状态</title>

> 本分册范围：猫咪的动作行为表现（舔毛 / 甩尾 / 打哈欠 / 打滚等真实猫行为）、中毒与倒地救援、淋湿与疲惫演出、吃鱼成长（限时 buff＋经验三选一），以及各册共用的猫通用动画规范。谁读：策划看 §1～§3 的意图与机制；程序接成长数值走三个子页与参数页；动画与美术看 §3 演出与 §3.2 通用规范。
> 
> **术语声明（本册为属主）**：钓鱼搏斗内口径：猫与鱼各有「力量」与「体力」；品种决定初始力量（普通猫50 / 橘猫70 / 狸花猫90 / 缅因猫130）；三选一选项池为开放框架，现行项与数值见子页「升级效果」。品种力量差是有意设计，但选猫时必须让玩家知情：选猫界面用非数值示意（力气＝鱼骨 icon ×1\~×4）＋一句性格化文案（如「缅因：劲儿大，鱼怕它」），不显示具体数字（呈现实现归交互层）。饥饿与疲惫不再是数值状态。

# 1. 设计意图

**1.1 北极星贡献。**

- **成为一只猫**：玩家不是在操控角色，是在当一只湖畔的猫。行为表现、身体状态、对环境的反应一起做到位，玩家才会觉得「我正在作为一只猫生活」。全项目的猫味演出以本册为源头。
- **状态是喜剧发生器**：体力、中毒、淋湿首先是搞怪素材（画龙走路、翻肚皮晕倒、炸毛抖水都是笑点），其次才用来调节奏。失败与翻车是内容，不是事故。
- **倒地是聚人事件**：玩家倒地 → 伙伴围观、舔脸、拖回营地。这一串下来会留下「朋友救过我一次」的记忆，也是现成的印记素材。
- **世界生命感**：舔毛、甩尾、打哈欠、打滚、对天气的反应，让湖畔像有猫在过日子，而不只是一张场景图。治愈的日常感就靠这些。

**1.2 体验设计。**

| 体验 | 🎯 想塑造的体验 | 🛠️ 当前设计 | 🔍 达成度与缺口 |
|-|-|-|-|
| 体验一·像真实猫一样生活 | 猫的身份认同。 | 舔毛 / 甩尾 / 打哈欠 / 打滚 / 伸懒腰 / 趴下休息等行为库，并与状态联动。 | 达成度高，猫咪行为是系统核心识别点；副作用是动作数量增加会提高动画成本，需按「高识别、高情感」排优先级。 |
| 体验二·能从身体读出状态 | 不看 UI 也知道自己累了、中毒了。 | 疲惫与淋湿为纯演出，中毒有全套失态表现，动作外化优先；无常驻状态条，成长信息按需显示（吃鱼瞬时浮层／主动面板，见数值成长「信息显示」节）。 | 达成度高；演出触发节奏需实测。 |
| 体验三·探索中有好笑的自然风险 | 方便 vs 安全的取舍，翻车了也笑得出来。 | 有的鱼有毒，吃了会中毒；解法是伙伴救援与回营休息；中毒与晕倒全程做成喜剧演出。 | 达成度中高；副作用是中毒机制需要避免成为惩罚陷阱。 |
| 体验四·多人之间产生真实帮助 | 「朋友救过我一次」。 | 吃到重毒鱼 → 倒地 → 伙伴寻找、围观互动、搬运回营地恢复。 | 达成度高，自然形成合作；副作用是救援流程过长会降低体验，倒地者和救援者两边都得有戏看。 |

**1.3 玩家策略路线。**

- 路线一·稳健成长型：只吃认识的安全鱼种，稳稳攒经验。
- 路线二·赌一口型：不认识的鱼也敢吃，博更肥的 buff 与经验，代价是可能中毒翻车。
- 路线三·多人互助型：结伴探索、互相救援、分享渔获。
- 路线四·专注献祭型：好鱼让给祭坛推进度，自己少吃——个人成长让位于全队目标。
- 路线五·蹭吃蹭喝型（懒猫觅食）：不钓鱼，偷别人的鱼吃成长或叼去卖钱。规则归「联机社交」册，本册只认「偷吃获得成长」这个出口。

**1.4 设计禁区。**

- ❌ **复杂生存模拟**——破坏休闲治愈体验。不做：饮水系统、温度系统、多疾病系统。替代路径：少量核心状态 + 强表现反馈。
- ❌ **宠物养成结构**——破坏「玩家就是猫」的定位。不做：亲密度、等级成长、属性培养。替代路径：通过行为变化体现生命感。
- ❌ **高频死亡惩罚**——倒地要好笑，死亡不好笑；破坏治愈底色，也让人不想开下一局。不做：任何状态死亡、普通状态导致永久失败。替代路径：倒地 + 救援恢复，且单人不卡死。
- ❌ **复杂食物系统**——挤占钓鱼和营地核心体验。不做：烹饪、菜谱、食材组合（烹饪机制已拍定删除）。替代路径：鱼直接吃，一步到位。

# 2. 核心循环

1. 外出：钓鱼、捣乱、探索，猫的演出随局内时间与活动变化（哈欠、瞌睡、淋湿）。
2. 吃鱼成长：钓到或偷到的鱼吃掉——获得限时 buff 并积累经验；不认识的鱼可能有毒，赌不赌自己定。
3. 经验满触发三选一：三个本局永久加成里挑一个当场生效（选项池 11 项见子页「升级效果」）。
4. 翻车支线：吃到轻毒鱼出洋相，吃到重毒鱼直接倒地（喜剧演出）→ 伙伴围观、舔脸、拖回营地，单人可爬行自救。
5. 带着攒出来的身板继续下一轮；一切成长局末清零。

倒地是支线不是必经环节；不赌陌生鱼的玩家整局都见不到它，见到的人也应该笑着被拖走。

# 3. 机制清单

## 3.1 设计意图核心

### 1. 猫咪行为表现机制

**设计意图。**让玩家感受到自己是猫。

**机制。**舔毛、甩尾、打哈欠、打滚、伸懒腰、休息、睡觉等行为库，并与状态联动：累了瞌睡点头；看见别人的鱼护忍不住盯着舔嘴（馋是天性，不是数值）；无聊时追自己尾巴、拍水面、盯蜻蜓（与钓鱼册「等待期可自由活动」衔接）。

**猫味演出①。**本册即猫味源头。群体行为自带喜剧：打哈欠会传染，一只打完一排跟着打；营地睡觉挤成叠罗汉。

**抛印记事件④。**多猫同步打哈欠；篝火边叠罗汉睡成一堆。

**⚠️ 最容易破的实施陷阱。**只堆动作数量，没有状态关联。

### 2. 吃鱼成长机制（限时 buff＋经验三选一）

**设计意图。**吃鱼是猫变强的唯一入口，也是「这条鱼吃掉、献掉还是卖掉」取舍的本体（饥饿系统已删除，改局内成长制）。

**机制。**吃掉一条鱼最多得到三样：限时临时 buff（按鱼种配置，字段归鱼册与鱼表格）、经验值（攒满经验槽触发三选一，三个本局永久加成里挑一个当场生效）。成长规则三个子页分工：规则层（经验档与槽、触发、buff 叠加、黄色体力定义、体力回复）见[数值成长](https://qcniqd0mjfwg.feishu.cn/wiki/Na20wnqTXiwM7TkKf4kcnaQ0npf)；全部吃鱼效果的目录见[吃鱼效果](https://qcniqd0mjfwg.feishu.cn/wiki/O753wiu7yiuBtMkburWcicZnnre)；三选一选项详述见[升级效果](https://qcniqd0mjfwg.feishu.cn/wiki/Sisrw4FzWiL2AekXetFc7Vxunqg)。成长只在本局有效，局末清零（跨局归属见局与进程册）。吃掉的鱼不影响图鉴（钓到瞬间已记录）。吃鱼效果按鱼种有好有坏，中毒等负面效果见本册中毒条目。（两条待办见 §11-3、§11-8。）

**猫味演出①。**吃鱼叼住甩头吞下，吃完舔爪抹脸、满足眯眼；经验满时猫伸个大懒腰、抖一抖毛发亮；三选一做成三条小鱼干选叼哪条（交互层细化）。

**抛印记事件④。**首次三选一；一圈猫趴在缸边挑今天吃哪条。

**⚠️ 最容易破的实施陷阱。**buff 表做成要背的攻略题。每种鱼给什么要一句话说得清、演出看得见（吃了速度鱼跑起来带风）。

### 3. 疲惫演出（纯表现型）

**设计意图。**猫会累是生命感的一部分，但它是演出不是数值（疲惫值数值制已废除）。

**机制。**随局内时间与活动量触发分档演出：轻→打哈欠；中→走路拖沓、尾巴耷拉；重→坐下就瞌睡点头。无数值条、无任何玩法惩罚、不影响搏斗体力；回营或原地趴一会儿只是把演出档位归零的猫味动作。

**猫味演出①。**累猫走路四条腿打架、原地坐下秒睡、瞌睡点头点到差点栽进水里又惊醒。

**抛印记事件④。**一排猫在篝火边东倒西歪睡着；湖边钓着鱼瞌睡点头的剪影。

**⚠️ 最容易破的实施陷阱。**偷偷挂回数值惩罚（累了拉不动鱼）。它只准好笑，不准碍事。

### 4. 中毒（吃鱼负面效果）与失态演出

**设计意图。**吃鱼效果有好有坏（中毒是吃鱼诸多效果中的一种，不再是独立的毒鱼风险机制）：认识的鱼知道吃了会怎样，不认识的赌一口；翻车过程本身是内容。

**机制。**每种鱼的食用效果按鱼种配置（效果定义与目录见子页[吃鱼效果](https://qcniqd0mjfwg.feishu.cn/wiki/O753wiu7yiuBtMkburWcicZnnre)，按鱼种分配在鱼表格「吃鱼效果」列，归鱼册）：增益与经验之外也可能是负面效果，按鱼各配、无渐进升级——最重的一档＝吃下即倒地（现行即河豚）。认识一种鱼分两层（归鱼册图鉴）：钓到＝记外观与名字，首次吃过＝图鉴补食用效果——每种鱼保留一次真实的「赌一口」。中毒不是惨状而是好笑的失态：走路画龙（直线走成 S 形、脚步交叉绊自己）、瞳孔变成漩涡、打嗝冒泡泡、产生幻觉，头顶气泡里把队友看成一条大鱼、对着石头哈气、扑向不存在的小鱼扑空打滚。加重则晕倒：原地晃三晃、定格一拍、慢镜头翻成四脚朝天，舌头露出一小截，尾巴尖还一翘一翘（表示没事，就是躺会儿）。

**猫味演出①。**如上，幻觉与晕倒姿势全套喜剧化；不用骷髅、毒液等事故感符号，中毒标识用头顶转圈的小鱼。

**抛印记事件④。**画龙走路一头撞进队友怀里；翻肚皮晕倒瞬间（见 §11-2）。

**⚠️ 最容易破的实施陷阱。**两头都会破：毒鱼太少太好认，机制没存在感；太多太难认，吃鱼变扫雷、中毒变惩罚陷阱。守住两条：损失必须可恢复，演出必须比损失更让人记得住。

### 5. 倒地与救援机制

**设计意图。**创造多人故事，倒地是聚人事件。

**机制。**吃到重毒鱼 → 倒地（唯一倒地来源＝中毒重档，按鱼种配置）；倒地者可缓慢爬行；**倒地满一段时间后自己站起来**（2026-09-07 李前臻拍，时长占位 **60 秒**，参数页为准）——所以爬回营地与队友搬运都是加速手段，不是唯一出路，也不会出现全队倒地把一天卡死。伙伴可搬运回营地解除（营地是救援送回落点，见营地册）；翻天时仍在倒地的自动救起，清晨在营地醒来。倒地者视角不黑屏：镜头贴地，能看见围过来的猫脸怼镜头。被救的人也有戏看。夜晚献祭时若仍在倒地：不能自己把鱼叼上祭坛，队友可代献他鱼护里的鱼；**倒地者不计入「全员到齐」的翻天判定**（2026-09-05 拍，否则一次中毒能卡住全队的一天）——「临翻天吃毒鱼几乎零成本」是已知的时间套利，代献让它保留一点社交代价（得求人）而不是完全免费。

**与钓鱼的衔接。**钓鱼中倒地（回应钓鱼册 B3 昏迷归属）：中断钓鱼、进入本册倒地流程；钓鱼状态机被打断后的回退细则归钓鱼册。落水后的湿毛表现见本册淋湿机制，落水处置已裁（A2，2026-09-02）：鱼逃＋饵已扣＋湿身演出，无额外损失；嘴里叼着的鱼保留。口径在钓鱼规则 4.6，本册持湿毛与抖水演出。

**旁观者互动。**凑近嗅嗅、爪子戳戳肚皮、舔脸（把倒地猫舔得一脸毛乱；是否附带微量恢复见 §11-4）、有的猫干脆在旁边躺平陪倒凑热闹。

**搬运演出。**叼后颈拖着走（猫妈叼小猫式），被叼住后颈的猫触发镇静反射，瞬间蜷成放松的一团；一路拖出两道痕；拖到一半掉了，滚一圈，捡起来继续拖；两猫可协作抬运（一个叼脖子一个托屁股）。

**猫味演出①。**见上，倒地—围观—拖运—复活全链路都是段子。

**抛印记事件④。**倒地被拖回营地全程；围观舔脸救醒瞬间；双猫抬运。

**⚠️ 最容易破的实施陷阱。**救援流程过长。拖运要短到是段子，不能长到变苦差。

### 6. 淋湿与抖水机制

**设计意图。**让天气与落水在猫身上留下好笑又真实的痕迹（表现型状态，不是数值条）。

**机制。**雨天渐湿、落水全湿；湿毛贴身瘦一圈（原来是只小细猫）；上岸 / 回檐下后从头到尾波浪式抖水，水珠四溅；半干时毛蓬成一团。雨天猫会下意识往树下、叶子下钻。与钓鱼册「湿毛抖水＝落水收场」的表现衔接由本册持有规范。

**猫味演出①。**抖水甩旁边的猫一脸，被甩的一脸嫌弃跟着抖，连锁抖水。

**抛印记事件④。**雨天集体炸毛合影；抖水甩人一脸的连坐瞬间。

**⚠️ 最容易破的实施陷阱。**淋湿变成负面 debuff。它是演出素材，不该带数值惩罚。

## 3.2 实施考量

- **状态真实感 vs 游戏压力**：数值状态全部退役（饥饿删除、疲惫纯演出），只留中毒一个风险态；生命感靠演出不靠管理负担。
- **风险感 vs 休闲体验**：毒鱼中毒提供风险，但不能阻止探索。选择：晕倒可恢复，不永久损失。
- **多人互动价值 vs 单人可玩性**：救援增强社交，但不能依赖多人。选择：单人可通过休息与爬行自救恢复。
- **动作丰富度 vs 开发成本**：优先做高识别、高情感动作。

**通用动画规范（本册持有，各册引用）。**实时物理动画混合关键帧动画，表现猫的软体感与笨拙：猫爪抓握 / 怀抱按目标物自动贴合，双脚随地面坡度调整站立；尾巴与耳朵由程序化动画驱动，随运动、情绪与风向摆动，紧张时尾巴炸毛变粗，害怕时耳朵压平；入水后毛发变塌，出水抖身水珠粒子四溅。**多猫交互动作同属通用层。**扑倒滚成一团（恶作剧反制与偷鱼被抓共用一套演出，供联机册引用）、碰鼻子（打招呼与双人庆祝共用）、舔脸、叼后颈搬运。演出素材与验收以根目录「动作表现集」为全项目唯一标准；本册持通用动画技术规范层，素材归表现集。

# 4. 系统边界

**硬性。**

- 不增加复杂生存指标；不做生命值系统。
- 不做宠物成长系统；不做复杂医疗系统；不做烹饪系统（拍定删除，鱼直接吃）。
- **状态与成长跟局走**：中毒 / 淋湿 / 吃鱼成长（buff、经验、三选一加成）均为一局内的，开局重置、局末即弃；跨局持久载体只有图鉴、印记相册与外观解锁三样（项目级已拍定），猫的状态与成长不在其中。
- 状态术语以本册声明为准（疲惫＝纯演出；经验 / 三选一归本册；搏斗内的力量 / 体力归钓鱼册），其他册不得另造叫法。

**软性。**

- 状态优先通过视觉表现，行为反馈优先于 UI 提示，鼓励玩家观察猫咪。
- 保持失败可恢复，单人不卡死。
- 休息的设施实体归营地册；本册只定义状态的进出规则。

# 5. 涌现案例

- 钓鱼系统（positive）：鱼不只用于收集，也是成长来源，形成钓鱼 → 吃鱼 → 变强再钓；风险是「刷小鱼刷经验」成最优解，靠经验值按体重档规避（小鱼经验低）。
- 营地（positive）：营地成为恢复和生活中心，回家 → 休息；风险是不能让营地成为唯一选择。
- 环境与氛围（positive）：天气影响猫的表现（雨天湿毛、抖水）；风险是避免环境变成惩罚。
- 联机社交（positive）：倒地救援形成玩家故事；风险是避免依赖在线玩家。
- 道具（neutral / positive）：鱼竿等资源联动；风险是不要扩展成复杂生存装备体系。
- 装死骗舔脸（positive，待观察）：有猫故意躺平假装倒地骗围观，本身是搞怪内容，但要看会不会干扰真救援的判断。
- 围观救援变全员看戏（neutral，待观察）：一猫倒地全队来围观，没人钓鱼，与钓鱼册「全员围观」同款现象。
- **毒鱼防盗陷阱**（positive，机制允许的组合）：把河豚这类毒鱼故意留在鱼护里当诱饵，偷鱼贼盲吃翻车、全场围观。成立条件是「吃过才知道效果」这一层——鱼的外观与名字本来就看得见（图鉴收集层），但没吃过就不知道后果；老玩家认得河豚也知道下场，陷阱只对没交过学费的人生效，认鱼知识因此多了一个用途：防己也防人。风险：若将来给偷鱼加「一眼看穿效果」的辅助，这条自动失效。

# 6. 体验锚定数字

（数值本体交由数值模拟，此处只记调它会改什么。）

- **鱼种经验系数与经验槽长度**（经验＝系数×重量，2026-09-07 改；拍定见参数页）——调它改三选一出现频率与「刷小鱼最优」倾向。系数按鱼种独立给，正是防这个倾向的旋钮。
- **buff 时长与强度**——调它改「吃哪条」决策的重量。
- **毒鱼比例与毒性强度**——调它改吃鱼的风险感与认鱼知识的价值。
- **中毒幻觉时长**——调它改好笑与烦人的分界。

# 7. 视觉反馈通道

- 动作反馈：打哈欠、舔毛、甩尾、动作迟缓、蜷缩休息。
- 环境反馈：淋湿毛发、雨天抖水、草地休息、往树下躲雨。
- 状态反馈：累了瞌睡点头（纯演出）、中毒画龙走路 + 头顶转圈小鱼、晕倒四脚朝天；吃鱼 buff 生效有肉眼可见的变化（形态归内容层）。
- 社交反馈：围观舔脸、叼后颈拖运、双猫抬运、营地恢复。

已知缺口三条见 §11-5～7。状态 UI 口径（2026-08-21 改拍「按需显示」）：无常驻状态条；搏斗内体力条（含黄色段）归钓鱼册；成长信息在需要它的时刻显示——吃鱼瞬时浮层、覆盖刷新的一次性反馈、三选一卡已叠次数、主动查看面板随时可开（细则见数值成长「信息显示」节）。

# 8. 何时回审

- 落水处置已随 A2 关账（2026-09-02），本条回审触发器结清。

# 9. Playtest 验收预期

- 不看任何 UI，玩家能否从猫的动作读出「我累了 / 我中毒了」。
- 倒地的玩家是笑还是恼；贴地镜头 + 围观互动能否让等救援不无聊。
- 救援方是否觉得拖运值得做、像段子而不是跑腿。
- 中毒演出看第 N 次是否仍好笑，有无重复疲劳。
- 单人玩家倒地能否自行脱困，全程无卡死。
- 经验槽快满时，三选一是否成为被期待的时刻。
