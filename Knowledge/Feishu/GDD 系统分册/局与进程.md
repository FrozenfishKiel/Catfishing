<title>局与进程</title>

> 本分册范围：纵向骨架，管「局」与「天」的双层结构、每日任务与世界进度、失败与终点判定、跨局归属清单、单 / 多人形态。祭坛的目标结构定义在此（联机册持社交层、营地册持动线、形象包装归 A4）。

# 1. 设计意图

**1.1 北极星贡献。**热闹和治愈各占一段：白天限时，忙和闹都压在这段；夜晚不限时，是白天拼出来的放松。每天一个任务，全队盯同一根进度条；涨到头是毕业，掉到零是团灭，两头都是全队一起摊。

**1.2 体验设计。**

| 体验 | 🎯 想塑造的体验 | 🛠️ 当前设计 | 🔍 达成度与缺口 |
|-|-|-|-|
| 白天的心跳 | 「今晚还差六点才够交！」全队为同一件事忙起来 | 白天限时纯生产（钓鱼攒缸，白天不可献祭），压力对照缸里够不够今天的任务 | 有时间压力，捣乱才刺激，也逼着大家合作；压力只在白天有 |
| 夜晚放松，上供收尾 | 烤够了火，全队叼着鱼聚到祭坛边，为最后交哪几条吵一轮，然后有人去按石像 | 入夜篝火自动点亮；夜里无时限，火边／观赏／闲逛／吃鱼／卖鱼。把鱼摆到祭坛上，全员到齐后与石像互动一次，互动就是翻天，当场结算 | 治愈的部分固定放在夜晚，而且是白天拼出来的。上供既是收尾画面也是翻天动作，不用再多一个「就绪」按钮 |
| 每天涨一截或掉一截 | 所有人盯着同一个数，今天交没交齐当场看得见 | 交齐任务＝世界进度上涨，没交齐＝下跌；到 100% 毕业，到 0 团灭 | 一天没交上不是当场输，是欠了债要还，所以失败讲得成一个故事 |
| 团灭的戏剧 | 「我们撑了六天，第七天没撑住」，这结局能笑着讲 | 进度归零＝局失败，立刻结束 | 失败演出的喜剧化归内容层，压在归零那一刻；照片还在，失败不清跨局持久 |

**1.3 玩家策略路线。**今天多钓存缸（给明天减压）vs 今天多献（进度多涨一截）；献大鱼推进度 vs 留大鱼吃和卖；冲点数 vs 蹲稀有（任务紧的日子没空追图鉴）；臭臭鱼能凑够今天的任务但削掉今天的涨幅，保命还是保进度；偷缸里的储备＝偷明天的粮，代价是实的。

**1.4 设计禁区。**

- ❌ **夜晚出现任何计时或催促**。
- ❌ **失败回滚跨局持久**（图鉴 / 印记 / 解锁永不回滚）。
- ❌ **局外元进度**。局与局之间只有收集与解锁，没有义务。

# 2. 核心循环（双层）

**天循环：**

1. 清晨：全员在营地醒来，按在场人数确定当日任务
2. 白天（限时）：钓鱼 / 捣乱 / 攒缸——白天不可献祭
3. 入夜（时间驱动）：不再有鱼上钩，进行中的搏斗打完（压哨鱼照常可献）
4. 夜晚（无时限）：火边 / 观赏 / 闲逛 / 吃鱼 / 卖鱼，想待多久待多久
5. 全队到石像前献祭＝翻天开关：一次性上供，当场结算——交齐则世界进度涨、没交齐则跌；到 100% 毕业，到 0 团灭，都没到就天亮进新的一天

**局循环：**开局初始化（营地 / 祭坛 / 时间，世界进度 10%）→ 天循环 × N → 结束（进度 100%＝毕业圆满结局；进度 0＝团灭）→ 结算：图鉴 / 印记 / 解锁入册（跟人走），营地与缸清空（跟局走）。天数没有上限，一局几天是打出来的。

# 3. 机制清单

## 3.1 设计意图核心

### 1. 天的时间结构

白天＝时间驱动弧线（清晨→黄昏），到点即入夜、入夜不判定任务；入夜后不再有鱼咬钩，进行中的搏斗允许打完（压哨鱼进夜后照常可献）；**还没咬钩的浮漂，剩余计时入夜即清掉**，不冻结也不跨天续用（2026-09-07 拍）——入夜停产是硬口径，留着计时会让人守在水边等一个不会来的咬钩。夜晚＝没有钟，时间不走；任务结算点＝献祭仪式那一刻，也就是翻天。天弧线的光影细节归环境册。

### 2. 每日任务

每天清晨按在场人数确定当日任务：今天要交多少点供奉。任务逐日变大，只数供奉点、不点名鱼种。**当天内不变，中途有人加入或退出都不重算**：清晨四个人、白天走掉三个，剩下的人就得扛完四人份；反过来一人开局、三人后来加，那天格外轻松。这是有意的——任务是清晨那一刻定下的约定，不跟着人数漂；交不齐只掉进度、不输掉这一局，所以扛不住的那天认了。

献祭放在夜晚收尾，同时是翻天的开关。白天只攒不献；入夜后把要献的鱼一趟趟叼到石像前的祭坛上摆着——祭坛是一块地不是容器，鱼扔在那儿就算摆上了，谁想叼回去随时可以。**两个圈：摆鱼的祭坛范围小，判定「人到齐了」的到场范围更大**（2026-09-07 拍），所以不必挤在石像脚下才算数；半径占位摆鱼 `2 米`／到场 `8 米`（2026-09-08 拍，参数页为准）。全员到齐后与石像互动一次：祭坛上的鱼一起消失，过场，天亮。互动那一刻才锁定，之前搬进搬出都算数，所以「今天交哪几条」是围着祭坛现场议的。锁定与叼鱼落在同一刻时按服务器判序，没有「搬运中」的特殊状态（2026-09-08 拍）。祭坛空着也能互动，结算为没交齐。

商人猫夜里照常营业、吃鱼也在夜里，所以「吃它、卖它还是献它」要到互动那一刻才落定。不去互动就一直留在夜里，视为玩家自由。

**供奉点数是任务与进度共用的货币。**每条鱼值多少点按体重档取，一条巨影抵一串小鱼。钓大鱼对全队目标的贡献，因此和它的难度对得上。

| 实际体重档 | 单条供奉点数 |
|-|-|
| 小：w<1 kg | 1 点（参数页为准） |
| 中：1≤w<5 kg | 2 点（参数页为准） |
| 大：5≤w<15 kg | 4 点（参数页为准） |
| 巨影档：w≥15 kg | 10 点（参数页为准） |

「巨影档」是重量档名，湖心巨影是鱼种名，不能互代。多交超出当日任务没有额外收益、也不滚存到明天（2026-09-08 拍）——任务是每日闸，超出的留给吃与卖。

**任务大小按九成完成率校准**，也就是正常打十天里最多欠一次。任务逐日变大还要守住这个完成率，玩家产能就得跟着涨，靠吃鱼成长与换竿，见猫册数值成长页。曲线数值见参数页。

### 3. 世界进度

一根 0\~100% 的条，开局 10%（参数页为准），跟局走。翻天结算时交齐了就涨，没交齐就跌。到 100% 毕业，到 0 局失败。

**涨幅跟任务大小走：要的鱼越多，交齐后涨得越多。**任务逐日变大，所以一局的后半段推进得比前半段快。

**降幅走自己一条曲线，不跟涨幅挂钩。**开局阶段刻意压低——否则首日一次没交上就直接归零，十局里会有一局在第一天结束。当天没交齐扣多少是固定的，差一点和差很多一样扣。已知风险（09-05 裁决保留）：正因降幅固定，「肯定不够时不交」在损失上更优——提交 39 点和 0 点同样掉进度，前者还多搭 39 点的鱼；此风险暂不解决，不加部分进度、不按短缺比例罚分，试玩后再看。

**臭臭鱼能凑数，但要付涨幅。**它计入当日任务的点数，帮你把今天凑够；代价是削弱当日的进度涨幅。全靠臭臭鱼凑齐的一天，最低也只是原地踏步、不会倒退——真倒退的话凑数比不交还差，这条路就没人走了。削弱函数首版：每条臭臭鱼扣当日涨幅的 `25%`，线性叠加（2026-09-08 拍，参数页为准，待试玩校准）。

进度同时驱动森林的复苏与枯萎，演出规格归环境册。不做个人供奉排名，局末结算用非排序趣味头衔加全员合影。

### 4. 失败与结算

**失败＝世界进度归零，这一局立刻结束，不进结算夜。**买卖直接冻结、本局金币与装备清零，没有收摊仪式也不再生火。毕业则相反：把进度顶到 100% 的那一次上供不翻天，当场转成这一局的结算夜——庆祝演出、商人猫收摊、剩余公款换小鱼干、篝火与合影，玩家自己决定什么时候真正离开（收摊仪式见商店册）。跨局持久永不因失败回滚。

### 5. 翻天

翻天没有单独的确认按钮，献祭本身就是它：全员到祭坛 → 与石像互动 → 当场结算进度涨跌 → 天亮。夜里因此不会弹「大家准备好了吗」，只有「走，去交鱼」这一个动作。**「全员」＝当前还在局里的玩家**，离开的不阻塞；**倒地的猫豁免**，不计入到场判定，队友仍可代献他鱼护里的鱼，见猫册。单人＝自己走到祭坛。互动时强制打断一切进行中互动，翻天后全员清晨在营地醒来，未获救的倒地者自动救起；恶意拖着不来由房主踢人兜底，组局规则见联机册。绝大多数日子里上供不决定胜负，只是把今天记一笔。钓鱼侧分别消费入夜、强制中断、翻天完成、下一轮开放与局结束五个信号，状态转移与本竿损益见〈钓鱼规则〉页——本册持有天循环与任务结算，不持有钓鱼事务（2026-09-08 移交口径）。

### 6. 局的终点

**唯一的胜利条件是世界进度到 100%。**天数没有上限，一局几天由队伍自己打出来，交得齐就推得快。三条曲线首版（参数页 v0.24）按 `120 分钟＝10 天` 校准；这只是校准口径，改任何一条曲线它都会变。无尽模式后置。

### 7. 跨局归属清单

跟人走＝图鉴、印记相册、外观解锁（A5 已关账＝解锁是表达型；装备属团队装备库、跟局走）；跟局走＝营地、鱼缸与局内图鉴（跨天留存、局末随局清空）、消耗品数量、公款与团队装备库（公有、随局清空，已确认；局末收摊仪式见商店册）、猫状态、祭坛进度与世界进度。解锁触发源＝天数 / 世界进度里程碑。一句话：身份跟人走，物资跟局走。

### 8. 单 / 多人形态

同一套局结构，靠参数调：任务按人数缩放、翻天＝自己确认、聚鱼时刻与回看照常；鱼的刷新按在场协作能力设上限（单人局不出巨型鱼，规则归鱼册）；不做独立单人模式。世界进度用百分比、不按人数缩放总量，所以中途有人进出不会让进度条错位；当日任务则是清晨快照、不重算，人数变化的后果由当天在场的人担着，见 §3.1.2。

## 3.2 实施考量

白天时长与任务松紧决定每天有多赶，但决定整局压力的是**鱼缸容量**。缸无损跨天，储备够多就能拿前几天的盈余顶后面几天，一串日任务于是被合并成一个累计闸。容量可用公款升级，所以这个闸口开多大是队伍自己买的：卖鱼换钱升缸和献鱼推进度抢同一批鱼，而缸随局清空，不会滚成跨局军备。档位与价格归营地册和商店册，跟本册的任务曲线一起定。「白天有钟、夜晚无钟」把压力和治愈分开，是本册最重要的不变式。鱼缸跨天留存让「今天多钓」变成策略，被偷的损失也跟着变大，所以偷取权限开关更要紧，见联机册。

# 4. 系统边界

**硬性。**

- 夜晚无计时。
- 失败不回滚跨局持久。
- 无局外元进度。
- 失败局不进结算夜。

**软性。**

- 翻天与失败都要有猫味演出（内容层）。
- 进度条的呈现归交互层（方向：祭坛本体即进度可视化）。

# 5. 涌现案例

- 任务快够不着时全队疯狂冲刺，这段最容易出印记素材（positive）。
- 缸里储备够多的「富裕日」，全队提前开始度假（positive）。
- 进度掉了两天之后的翻身局，全队憋着一口气（positive）。
- 有人往祭坛塞臭臭鱼凑数，另一半人心疼涨幅，当场吵起来（positive / negative）。
- 最后一条大鱼献不献，推进度还是留着吃，全队围在祭坛边你放我拿，直到有人去按石像（positive / negative）。

# 6. 体验锚定数字

- **白天时长**：决定每天有多赶。已拍定，值见参数页。
- **世界进度初始值**：决定开局能扛几次没交齐。已拍定，值见参数页。
- **任务曲线**（起点与爬升斜率）：按九成完成率校准，要贴着产能曲线走。首版已入参数页 v0.24。
- **涨幅曲线与降幅曲线**：涨幅跟任务大小走，降幅自己一条、开局压低。这两条一起决定一局多少天、以及团灭多久出现一次。
- **臭臭鱼的削弱强度**：决定「凑数保命」这条路值不值得走。首版每条 −25% 涨幅（参数页为准）。
- **一局天数**：不再是设计数字，是上面几条算出来的结果；首版曲线按 120 分钟＝10 天校准（v0.24）。

# 7. 视觉反馈通道

白天全队可见「缸内可献点数 vs 今日任务」，形式归交互层；夜晚献祭仪式中祭坛即进度条。进度涨跌都要看得见：森林随进度复苏或枯萎，规格归环境册。缸存量告急的全场氛围信号也归环境册。

# 8. 何时回审

任务曲线与涨跌幅第一版数值出来时。A5 与 A6 均已关账——解锁＝表达型；单人不刷需要多人的鱼、不做独立单人模式。

# 9. Playtest 验收预期

- 团灭时大家在笑还是在互相埋怨。
- 夜晚会不会被急性子秒过，无时限是否形同虚设。
- 进度掉一截之后，队伍是憋着劲追还是就此摆烂。
- 「再来一天」与「再来一局」的意愿分别有多强。
- 任务压力是否侵入夜晚（不应该）。
