<title>道具</title>

> 本册为道具的规则出处。正文数字（漂射程、竿强度与耐久、可抄距离等）均为实现快照——**数值以册下五张挂号表格为准**（鱼竿／鱼漂／窝料／鱼饵／道具总表），表里没有的看「数值模拟与参数记录」页；改数走那一页的流程：先过模拟验证再落表。

# 1. 设计意图

**1.1 北极星贡献。**

备装是每局开场的社交环节。你挑了什么鱼竿别人都看得到，等于把今天的目标说给大家听（「我今天就要那条大的」）；特殊饵什么时候用，旁边的猫会起哄（用不用？现在用？）；断竿和落空本身就是笑料。核心体验：玩家为了遇见某种鱼而准备，走「准备 → 钓鱼 → 发现」的循环。放到派对里，这份准备还得是**别人看得见、说得上话的**：你带了什么，旁边的猫看得到鱼竿和抄网、起得了哄。

**1.2 体验设计。**

| 🎯 想塑造的体验 | 🛠️ 当前设计 | 🔍 达成度与缺口 |
|-|-|-|
| 出发前的期待感：「为了遇见某种鱼而准备」 | 鱼饵 / 鱼漂 / 道具按目标鱼搭配；装备与鱼偏好关联 | 结构成立；偏好规则看不看得懂，靠现场演出和图鉴线索两处解决 |
| 装备是玩法选择，不是数值军备 | 策略差异由饵／窝料／漂承担；功能装备（竿／抄网／鱼护）是门槛分层——决定能钓什么、装多少，不做同档内的数值军备 | 方向已定，有禁区护住；「万能最优解」需数值阶段验证 |
| 关键时刻的道具决策 | 一次性道具「现在用还是省着」，使用过程有戏可看 | 决策骨架成立；囤积倾向靠设计规避 |
| 断竿的赌注与补给 | 鱼竿耐久磨损、不可修复；磨到头或强拉赌输＝断竿，去商店买新竿（商店系统设计中） | 循环成立；惩罚强度必须与钓鱼册对齐 |

**1.3 玩家策略路线。**

- **稳定收益 vs 稀有发现**：普通饵稳定钓常见鱼，还是消耗特殊饵赌一把稀有鱼。
- **当下口粮 vs 收集目标**：为吃鱼成长和献祭钓口粮，还是为图鉴追特殊鱼。
- **装备专精 vs 灵活应对**：带一套针对目标鱼的专精装备，还是带通用装备见机行事。
- **道具保存 vs 当前使用**：现在用掉抓住眼前机会，还是留给更大的目标。
- **单人效率 vs 多人互动**：自己配好自己钓，还是分享饵料、帮朋友凑齐目标。

**1.4 设计禁区。**

1. ❌ **装备形成绝对强度差距**——功能装备按门槛分层（高档竿能钓更大的鱼）是设计内的；禁的是同一档位里堆数值、以及用装备替代饵／窝料／漂的策略选择。替代：价值差异化，针对不同鱼种、改变操作体验、给出不同策略路线。
2. ❌ **装备成为氪金或资源碾压入口**——不做付费装备，不做装备升级。破坏治愈底色与社交公平。替代：公款购买（卖鱼换公款，经济归商店册）、探索获取、局内事件奖励；收集里程碑＝商店上新货（件仍要买）。
3. ❌ **装备过度复杂化**——不加属性词条、随机强化、搭配公式。破坏轻松进场的体验，新手应该在钓鱼，不是在研究表格。替代：规则一句话说得清，比如「这个饵吸引什么鱼」「这个漂够得着哪片水」。
4. ❌ **一次性道具成为必需品**——不做「没道具就钓不到稀有鱼」。破坏发现感：玩家应该觉得「我发现了一条鱼」，不是「我消耗道具抽了个奖」。替代：道具只提高机会、改变体验、增加趣味。
5. ❌ **装备绑定单一最优玩法 / 破坏社交公平**——不让所有人殊途同归到同一套配置，不让装备造成玩家阶层差距。破坏「各有各的钓法」。替代：收集型 / 稳定型 / 挑战型 / 展示型多路线并存；展示价值来自稀有发现与玩家故事，不来自强度。

# 2. 核心循环

1. 出发前备装：从团队装备库取竿，挑饵、选漂、抄网、揣上窝料和道具
2. 湖畔开钓：装备组合决定今天奔着什么鱼去。
3. 消耗发生：特殊饵用掉、道具打出、鱼竿耐久磨损（鱼竿不可修复）。
4. 达成成就或者购买新装备：下一次搭配又多一种可能。
5. 游戏结束装备归置：解锁清单与图鉴跟人走、件与耗材随局清空。（全册「局」＝一整局游戏；「场」＝一次搏斗。）

# 3. 机制清单

## 3.1 设计意图核心

### 1. 装备选择与出发准备

**设计意图。**开钓前要有准备的感觉：带什么道具就是在说今天想钓什么。别让玩家点一下就直接进流程。

**机制。**从团队装备库（公款所购与免费基础件都在这里，叫法与商店册统一）携带鱼竿、鱼饵、鱼漂进入钓鱼点，抄网、窝料、鱼护、道具一并揣上。不同组合影响钓鱼方向。携带是格数制：背包格数有限（快照待数值阶段定），竿、漂、抄网、鱼护、道具各占一格，饵与窝料按份计——想带备用漂就得少带别的，出门后湖畔可换，但换的前提是背了。装备没有「查看」UI：队友看到的是你身上背的、手里拿的、嘴里叼的（世界表现），凑近闻是同一件事的猫式演出。玩家自己打开装备栏时，鱼竿鱼饵等装备分开摆，不把所有道具杂糅在一起，便于玩家看道具。

**鱼护。**鱼护是道具之一，定位是随身渔获容器，非必带：不带鱼护也能出门钓鱼，抄起的鱼先叼在嘴里。叼鱼态规则：嘴里只能叼一条；叼着鱼不能抛竿、不能再抄或拾第二条，必须先放进鱼护或扔下（扔下＝赠送路径，物品不灭失）才能继续钓；落水时嘴里的鱼保留。不带鱼护的猫每条鱼都得先处置再开下一竿，这就是鱼护的价值。容量与获取方式归本册内容层，初始配置待定。

| 抄网 | 可抄条件 | 获取 |
|-|-|-|
| 抄网（单一款式，无属性数值） | 钩上或翻肚的鱼、且离岸 < 1 米 → 抄取必中；自由游动的鱼不可捞 | 商店购买 |
| 湖心巨影 | 特例：任何抄网都抄不动 | 只走合力消耗战 |

细则见钓鱼规则第五章。

**猫咪装道具动作。**备装的动作全是猫的：扒拉竿子、用爪子逐个拍拍饵袋，选好了叼起竿甩上背，抄网背着像个小行囊。想知道队友带了什么就凑过去闻（看世界表现，不开栏），闻到谁带了小鱼干碎（饵名，与道具「小鱼干」区分），会不由自主跟着人家走。

**抛印记事件。**全队备好装、各叼各竿从营地小径出发。

**⚠️ 最容易破的实施陷阱。**选择不要太多，否则玩家开钓前得先学一堆规则。也不要把备装变成各自安静看菜单：准备阶段要发生在场景里、彼此看得见，别缩进 UI。

### 2. 鱼饵机制

**设计意图。**饵要消耗、要挑，玩家才会盯着某一种鱼做准备。

**机制。**鱼饵随抛竿挂出；进入咬钩后无论结局（上鱼／超时／放弃／断竿／落水）都消耗 1 份，咬钩前主动收竿零损失（口径见钓鱼规则 3.3）。窝料决定上钩的是哪一类鱼，鱼饵决定是哪一条：属性命中后按鱼对饵的偏好权重再选一次（钓鱼规则 2.3；偏好数据在鱼表格「偏好饵」列，归鱼册）。

**鱼饵获得。**普通饵营地免费自取（保底件之一，携带上限 8 份——2026-08-19 由 5 改，参数页为准）；特殊饵商店购买、每日进货限量（商店册口径）；草地也有概率捡到。

**鱼饵丢失时安慰。**特殊饵消耗了却没钓到目标鱼，不能让玩家白挨一刀。方向：空钓时图鉴会出现鱼的虚影；连续落空渐进提高下次机会。这条 2026-08-27 被图鉴册接走当剪影解锁的触发之一——空钓的补偿就是揭开那条鱼的线索层。

**抛印记事件。**首次用特殊饵钓中对应目标鱼，终于换来回报的那一刻。

**⚠️ 最容易破的实施陷阱。**不要让特殊饵成为唯一正确答案，否则普通钓鱼失去意义，玩家被迫烧资源换效率。

### 3. 鱼漂机制

**设计意图。**装备要给出不同的玩法路线，不是单纯提升数值。

**机制。**鱼漂 3 种起步，保留扩充口：羽毛漂／毛线球漂／铃铛漂。每种漂是射程档位×落点精准×特效的组合，射程分 3/5/7 米档，决定够得着哪片水、投不投得进窝心。等级制不采用，依据本册禁区①⑤：不做纯升级梯子。羽毛漂 3 米射程、精准高（近而准）、免费基础款营地自取（与树枝竿、普通饵同为保底三件）；毛线球漂 5 米、精准中；铃铛漂 7 米、精准低（远但飘）、咬钩铃响全场可闻；后两种公款购买。参数唯一出处＝「参数与校准记录」拍定表。三种漂的参数与特效组合归数值阶段细调；第 4 种等设计需求出现再命名。

**猫味演出。**漂都是从猫的背包里翻出来的：羽毛漂（逗猫棒上拆的）、毛线球漂、铃铛漂（咬钩时叮当作响）。新漂到手先当玩具拍两下才舍得系上；看着漂的时候猫尾巴尖跟着漂的起伏动。

**与钓鱼册信号的关系要摆正。**「咬钩信号远距离可感知」是钓鱼册拍定的基础能力，不装任何漂也成立。铃铛漂只是把「自己感知得到」变成「全场都听得见」：一响全场猫竖耳，等于自动帮你摇人围观。

**抛印记事件。**见「装备解锁机制」的首次解锁。

**⚠️ 最容易破的实施陷阱。**不要出现「万能最强漂」，否则所有人殊途同归，策略空间消失。

### 4. 一次性特效道具

**设计意图。**关键时刻要有一个决策：现在用还是省着。用道具的过程做成全场围观的小节目。

**机制。**主要经商店购买，探索与局内事件是惊喜补充；使用后提供短时间特殊效果，用于挑战特殊目标。和窝料的分工要清楚：窝料是钓鱼的常规聚鱼手段，道具稀缺、只管短时特效，不抢窝料的活。

**猫味演出。**现行道具清单与归类以 §3.3 四类表和「道具总表」为准；猫薄荷水弹、呼噜哨是早期方向示意，未立项（进点子库）。夜晚不钓鱼，不做夜钓类道具。使用演出必须好笑：扔猫薄荷弹时自己先被熏到，原地打滚炸毛，全场笑翻。用之前的犹豫就是起哄点，队友会围着喊「用！用！用！」。

**抛印记事件。**首次用幸运四叶草钓中稀有鱼、首次渔网撒下全场围观的瞬间。

**⚠️ 最容易破的实施陷阱。**道具价值不要太高导致囤积，玩家攒一仓库舍不得用，机制进不了循环。解法方向：使用场景明确，效果变化肉眼可见，同时不碰基础玩法底线。

### 5. 装备解锁机制

**设计意图。**成长来自「发现更多可能」，不是「变得更强」；解锁扩展选择空间。

**机制。**主要通过商店购买获得新装备，探索获取＋局内事件奖励为辅。图鉴收集里程碑可附带装备解锁。解锁＝商店上新货：解出的新品类进商店货架，具体件用公款购买（金币全队共有、购买全队广播，交易归商店册）。解锁清单跟人走，下一局货架一开始就有这些货；件与公款跟局走。

**猫味演出 / 抛印记事件。**首次解锁仪式：新装备第一次到手，猫把它高高举起，围观猫可以选择凑过来嗅。

**⚠️ 最容易破的实施陷阱。**新装备完全替代旧装备，旧的失去价值，成长变成单行道。

### 6. 装备与鱼偏好关联

**设计意图。**「为了目标鱼做准备」这件事要真的有用，探索的乐趣从这里来。

**机制。**不同鱼有不同偏好，装备影响遇见目标鱼的机会；特殊鱼需要特殊准备。偏好数据在鱼册里查看。

**猫味演出。**规则靠演出说明白。用对饵，打窝范围内的鱼影让玩家看着开心；用错饵，鱼影游到钩边绕一圈，嫌弃地一摆尾走了。玩家一眼能看出「为什么没上钩」。

**抛印记事件。**触发聚鱼时刻（保留；聚鱼只有投料一条触发路径，见钓鱼规则 §2.5）。

**⚠️ 最容易破的实施陷阱。**规则不透明，玩家不理解失败原因，只觉得系统在随机耍人。

### 7. 窝料机制

一把窝料往水里添一批鱼，添的是哪类鱼看配方。

**设计意图。**窝料是钓鱼的常规聚鱼手段：先打窝再抛竿，钓什么类的鱼在打窝时就定了大半。它是循环消耗品，平价管够；道具只管短时特效，不抢窝料的活（§3.1.4）。

**机制。**每种窝料一组配方 `{腥, 香, 酵}`，三个非负整数，单位是鱼的条数，允许某一类为零；投放一份就按配方往窝点加这么多条对应偏好的鱼。腥、香、酵是分类名：腥对应虫虫、小鱼干碎等，香对应谷物，酵对应发酵的果实或谷物，猫靠嗅觉辨别。窝料决定上钩的是哪一类鱼，鱼饵决定是哪一条（§3.1.2）。配方不必让单人凑齐三类，聚鱼时刻是合作奖励（钓鱼规则 2.5）。携带上限 5 份（快照，参数页为准），三选一「窝料携带 +2」作用于此。投出去的窝料可以叼起再抛，叠加进窝点、不重置衰减计时。窝点的存量、衰减、聚鱼时刻、投掷落点与射程归钓鱼规则第 2 章；本册只管配方、携带与获取。

**接口。**窝料表（本册子件）提供：名称、腥／香／酵增量（条）、定位文案、视觉表现。钓鱼规则在窝料落水那一刻读一次配方、加进窝点，此后与窝料实体无关。表里增删配方不需要改钓鱼规则。

**目标鱼种加权（2026-09-08 李前臻拍）。**窝料表加一列「目标鱼种加权」：填鱼种与倍率，钓鱼规则抽鱼第二步对该鱼种的权重乘这个倍率；没填的窝料只靠腥／香／酵配比。巨鱼窝由此真能偏向大鱼——它的腥占比只比虫虫窝高 7 个点，光靠配比对不上名字。倍率占位由数值侧填，正式值走模拟。聚鱼触发概率不按窝料品质或窝点总存量加成，窝料表不建品质字段。

**猫味演出。**演出文案在窝料表「视觉表现」列（打开虫盒时猫的嫌弃、发酵谷物的味道）。投料落水泛涟漪、出鱼影，落点指示的画法归张佳。

**⚠️ 最容易破的实施陷阱。**别把窝料做成「打窝越贵鱼越稀有」的付费梯子：配方只决定类别分布，稀有度不进抽鱼概率（钓鱼规则 2.3）。

## 3.2 实施考量

- **装备深度 vs 易上手**：偏向易理解。保留鱼饵选择、鱼漂专属效果、特殊道具；不做属性词条与多层强化。装备服务钓鱼，不是独立养成玩法。
- **功能差异 vs 平衡成本**：功能差异优先。装备改变钓法、目标与操作体验，不是简单提升成功率。多花的平衡成本换来策略空间值。
- **断竿代价 vs 补给便利**：无维修，断竿后商店购新（商店系统归道具设计）。保底竿已拍：1 级竿在营地免费自取、不限量，断竿或公款见底永远有竿可用；付费墙是「能钓什么」，不是「能不能钓」。竿价与断竿率同池调，别把买竿变成惩罚循环。耐久损耗走分层案：每钓一条固定 -1 基础磨损，线绷紧的每一秒另按鱼力×系数扣。竿另有「强度」参数参与搏斗判定，三档竿的强度／耐久／L_max／获取以册下「鱼竿」表为准，与册首口径一致；改数仍走参数页的流程，先过模拟验证再落表。
- **道具稀缺价值 vs 使用意愿**：鼓励使用。场景明确、变化明显，同时不碰基础玩法底线，别让道具变成仓库收藏品。
- **装备数量 vs 开发资源**：少量高价值。优先做能改变体验的核心装备，不铺量。点子库（Demo 不做）：假饵类（消耗耐久可复用的诱饵）；窝料介绍文案只给模糊描述（「腥味比较重」「明显是发酵过的」）不显示成分数值、另配一件较难获取的魔法道具让猫看清成分（原「窝料定位」页存档点子，2026-08-19 并入）。
- **成长感 vs 旧装备价值**：避免淘汰式成长。「不同场景适用不同装备」，而不是「新的永远更强」。

## 3.3 道具分类与资源边界

**总闸门：搏斗内没有任何道具操作。**搏斗态＝从咬钩判定成功起到结局落定（上鱼／断竿／落水／超时／放弃）止；这段时间里没有任何主动的道具操作，拖、放、僵持就是全部。两点例外说清：抄网是收鱼出口、不在闸内（搏斗内按 F 挥网照常）；备装时预穿戴的被动效果（如爪爪套减耗）在搏斗内正常结算——禁的是「搏斗中掏东西出来用」。评审过程见「裁决同步 · 装备与商店」。

**四类分类。**新道具先归类再设计，归不进四类的先问一遍该不该做：

| 类别 | 成员 | 职责一句话 |
|-|-|-|
| 功能装备 | 鱼竿／鱼漂／抄网／鱼护 | 静态决定「能钓什么、装多少」，永不提供临时数值 |
| 循环消耗 | 鱼饵／窝料 | 给每次尝试定价，就是失败预算，平价管够 |
| 增效消耗 | 小鱼干／爪爪套／幸运四叶草 | 花钱买「下一场机会更好」，搏斗外结算，一场清空 |
| 社交演出 | 湿毛器／恶作剧假鱼／响响筒 | 只碰情绪和画面，数值层零效果 |

渔网不单设类：它是循环消耗的极端定价特例，全游戏仅此一件，立成类别就会长出第二件。

**资源边界五条。**每条核心资源对道具开不开放，一次说死：

| 资源 | 对道具 | 理由 |
|-|-|-|
| 鱼体力 | 封闭 | 碰鱼体力就是伤害道具，钓鱼变成输出比拼，军备竞赛从这里开轴 |
| 猫体力 | 搏斗外开放、搏斗内封闭 | 搏斗内的体力管理本身就是玩法；开了口子，巨影合力会退化成「一人带够药」 |
| 竿耐久 | 回补封闭 | 「不可修复→换竿」是金币主出口，道具永不加耐久点数 |
| 出鱼概率 | 开放，道具主场 | 咬钩前改权重正是「提高机会、不替代玩法」；只改权重、无保底必出（渔网是已拍的唯一例外）；「金币不直通稀有概率」只约束增效道具（幸运四叶草维持意外收获，不进商店）——稀有饵／特殊窝料属循环消耗，走商店进货限量，不受此条约束 |
| 纯演出 | 全开放 | 热闹是第一优先级，这里最便宜最安全；护栏＝零数值副作用、不打断他人搏斗操作、有次数或冷却 |

按此边界落位：小鱼干＝搏斗外使用、瞬间回满猫体力（搏斗外自然回复已拍 5 点/秒、空条约 20 秒回满——小鱼干的价值窗口＝连续硬仗之间省下这 20 秒，定价与携带上限按此定，见猫册「数值成长」页；饵名「小鱼干碎」与之区分）；爪爪套＝备装时穿戴、下一场搏斗生效、一场耗尽、同类不叠。增效消耗的计次口径与鱼饵一致：进入咬钩即计一场／一竿，结局无关；咬钩前收竿不计。

**渔网特例（唯一破格，已拍）。**用「贵＋一次性」换破格。产出按当前钓点概率构成（含打窝塑形）roll 5～8 条；稀有不加权，湖心巨影永不入网。随身限 1 张，每队每局限购 1～2 张（公款购买）。定价不低于网内期望渔获市价的 1.2 倍——纯算钱必亏，买的是省时和场面。用后 30 秒死水，全钓点共享。落地细则挂账钓鱼规则：撒网以落点所在窝点为准；死水＝该窝点所有浮漂咬钩计时挂起；5～8 条产出落地先到先得拾取。具体数字归数值阶段。

**验证红线。**数值模拟固定保留「零道具通关」用例：一切内容零增效／零演出／零渔网可打（功能装备按商店可购计入），逐版本验证。道具只能让路更顺，不能变成路本身。

# 4. 系统边界

**硬性**：

- 鱼种偏好与分布数据归鱼册。
- 窝料的投掷玩法与聚鱼时刻、抄网的用法归「钓鱼系统」册（正式版）。
- 共用大鱼缸不属于装备（实体归营地册）；随身鱼护属本册功能装备。渔获流已拍定：图鉴即时记录 → 叼嘴／鱼护 → 大鱼缸 → 献祭 / 吃 / 卖商店 / 观赏，局末随局清空。
- 装备不可被偷：好友只可以偷鱼，偷窃碰不到竿、漂、道具，但玩家可以选择主动分享道具。
- 物品当天不灭失、跨天不保留：赠送和丢弃是同一个「扔下」行为；水面有空气墙，物品丢不进湖里；落在地上的东西当天谁都能捡，翻天时一并消失（2026-09-05 改口径，原「次日清晨出现在营地」作废）。想留就得在翻天前放进鱼护、鱼缸或团队装备库。
- 不引入世界观外元素：装备命名与形态一律猫世界化，无人类文化符号。
- 不引入本册之外的成长数值（经验 / 等级归项目级决策）。

**软性建议**：

- 鼓励装备提供多路线：收集型 / 稳定型 / 挑战型 / 展示型。
- 鼓励装备跟世界有联系：获取尽量来自金币购买。
- 鼓励装备具有情感价值：第一根陪你的小树枝竿、朋友扔给你的羽毛漂（赠送＝把身上的东西扔下让人拾取，无交易界面；社交规则归联机社交册）、事件纪念道具。
- 鼓励简单规则产生深度选择：玩家想的是「今天我要准备什么」，不是「我要算多少属性」。

# 5. 涌现案例

- 钓鱼系统（positive）：装备提供准备感与策略空间，钓鱼从单一行为变成「目标选择 → 装备准备 → 探索发现」。
- 图鉴（positive）：特殊鱼需要特殊准备，想集齐的人更愿意去凑道具；图鉴线索反过来指导备装。
- 营地（positive）：「外出 → 回营 → 再出发」的节奏落在这里。
- 祭坛（positive）：团队目标推动全队备装，走「装备准备 → 钓鱼贡献 → 共同推进」。
- 联机社交（positive）：分享饵料经验、围观道具使用、起哄「用！用！用！」都是热闹素材；铃铛漂让咬钩成为公共事件，围观自然发生。
- 囤积倾向（negative）：守财猫攒一仓库道具不用，靠道具设计（明确场景 + 明显效果）规避。
- 备装内卷（negative，待观察）：如果偏好规则过于精确，开钓前查攻略配装可能取代「随便钓钓」的松弛感。

# 6. 体验锚定数字

- **装备效果差异程度**——调它改选择价值：过低没存在感，过高出唯一最优解。
- **特殊饵收益提升幅度**——调它改消耗决策的期待感：过低白花钱，过高普通饵作废。
- **装备获取速度**——调它改解锁节奏：过快探索动力塌，过慢没反馈。
- **道具出现频率**——调它改使用意愿：过低舍不得用，过高不稀奇。
- **装备管理成本（携带 / 整理 / 切换）**——调它改准备阶段负担：过高在管仓库，过低没规划感。

# 7. 视觉反馈通道

- 装备外观即信息：竿 / 饵 / 漂外观差异一眼可辨，支撑收集感与展示欲。
- 效果在过程中被看见：特殊饵引来目标鱼影、错饵被鱼嫌弃摆尾、道具生效有全场可见的演出，玩家由此明白「为什么选它」。
- 偏好规则的「为什么」由图鉴册查询。
- 解锁与成套有仪式感反馈。

# 8. 何时回审

- 数值阶段给出定价、携带格数与增效道具效果第一版参数时。
- 商店册的经济参数定稿时——竿价与断竿率同池调，两边要一起看。
- 抄网的可抄条件、鱼护的叼鱼态处置有变更时。
- 「饵还是粮」边界与猫册有观察结论时——小鱼干碎等食物系鱼饵能否直接吃。
- 有新道具或新类别提案时：先过 §3.3 的四类归类与资源边界五条，归不进去的先问该不该做。
- 首次多人 playtest 之后——囤积倾向、备装阶段是热闹还是各自看菜单，两条都要实测。

# 9. Playtest 验收预期

- 新玩家不看说明，能否说出「换这个饵会改变什么」。
- 特殊饵落空时，玩家是笑还是恼。
- 断竿的玩家是笑还是恼。
- 一局结束时道具使用率——囤积倾向是否出现。
- 备装阶段全场是热闹的（互相闻、起哄、讨论）还是安静的（各自看菜单）。
- 想帮忙抄网的玩家能否顺手拿到抄网——获取流程会不会成为参与协作的门槛。
