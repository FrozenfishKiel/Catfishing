<title>钓鱼规则</title>

> 本页是钓鱼系统的实现规格，管单人一竿从备装到收鱼的全部规则与判定；多人叠加的合力、换人、抢收与合力移动见〈多人钓鱼〉页。读者是程序与各册属主，带着「怎么判定、数多少、谁负责」来。

属主：钱成澔。状态：现行规格。出处：机制以本页为准；数值均为实现快照，以「数值模拟与参数记录」页及其挂号专表为准，建议值与占位值随文标注，不升级为正式配置。

多人扩展入口（见〈多人钓鱼〉页）：多人可以叠加投料、合力拉竿、换人、抢收和举鱼展示。

# 1. 一竿流程与准备

猫带着装备来到水边准备钓鱼。

备装 → 可选打窝 → 抛竿 → 等待／试探 → 真咬／提竿 → 搏斗 → 收鱼／失败。

装备即状态：手持鱼竿就是钓鱼待机，不设模式键。准备态可走动、瞄准、切饵；收竿或换手持物退出，搏斗中不能直接退，只能走主动放弃。准备由各玩家独立进行，抄网与鱼护都不是必带。岸边只能切换已经带出的物品，换饵与窝料的具体操作归交互总规。

开始前读取道具与角色输入；叼鱼限制见叼鱼态，道具操作的封闭边界见鱼饵与道具闸门。

# 2. 打窝、等待与抽鱼

## 2.1 窝点、投放与补窝

一把窝料往这片水里添一批鱼。

窝点维护 `{X腥, P香, J酵}` 三个存量，每格是窝点里对应偏好鱼的条数。打窝就是按窝料配方向窝点加鱼：`新存量 = 旧存量 + 本次投放增量`。配方与投放量都是非负整数，允许某一类为零，存量因此永远是整条鱼；衰减产生的小数在衰减那一步就地向下取整（游走衰减）。腥、香、酵三类的含义与配方归道具册「窝料机制」节。

窝点是以首次窝料落点为圆心、半径 5 米（快照，参数页为准）的圆，初始存量就是首次投料的三属性增量。服务器维护共享存量，同一窝点的所有浮漂读同一份数据。

新投料落在已有窝点圆内，就向该窝点加算存量，沿用原圆心和半径；否则新建窝点。浮漂按实际落点归属，落在几个相交窝点里选圆心最近的。几何归属只有一条规则，投料并窝与浮漂归属共用：近者优先（比圆心距离）、等距早者优先（创建序号小者）、边界算内（距离 ≤ 半径）。

叠加没有设计上限，多人可以往一个窝里连续投。代码可以留一个正常游玩碰不到的工程安全夹，但不能把它当作游戏容量上限。

投窝料和抛竿是同一套操作：点击定点、无蓄力、无散布，点哪落哪；射程挂参数页，超程提示够不到；投到岸上的窝料变成掉落物，可以捡回。落点指示的画法与键位归张佳。投料落水泛涟漪、出现鱼影。

叼起窝料再次抛入同一个窝，执行叠加，不重置衰减计时。补窝受道具总闸门约束：正在搏斗的猫不能掏窝料，其他处于可用道具状态的玩家可以为同一个窝补料，边界见鱼饵与道具闸门。

## 2.2 每漂独立计时

窝里的鱼越多，咬钩等得越短。

`Total = X + P + J`，单位是鱼的条数。基础间隔按窝里有没有鱼分两档：

| 条件 | 基础间隔 |
|-|-|
| Total > 0 | T_base = 15 秒 |
| Total = 0（含落点不在任何窝点内） | T_base = 120 秒 |

`T_actual = T_base / (1 + Total/K)`，`K = 100`，K 与 Total 同用条数单位，比值无量纲。Total 越大间隔越短，但在有限存量下不会到零。

计时器挂在浮漂上，每漂独立。存量因补窝、衰减或钓走而改变后，剩余时间按 `新剩余 = 旧剩余 × 新间隔 / 旧间隔` 折算，不重开完整计时。例：Total 为 100 时间隔 7.5 秒；补到 200 后间隔 5 秒，原剩 3 秒折成 2 秒。

窝空时间隔从约 15 秒跳到 120 秒，这个落差是有意的：它告诉玩家窝空了，该补窝或换地方。不加平滑、最低间隔或保底。

## 2.3 抽鱼与扣减事务

抽中哪条鱼，那条鱼就当场离开窝。

某个浮漂计时到点，服务器执行一次原子事务：读取该浮漂主人当前挂的饵 → 按当刻三类占比选类别 → 在该类候选里按这份饵的权重选鱼种 → 当场扣 1 条库存。主人由到点的浮漂确定，不为窝点先抽一条公共鱼再比各人的饵，也不在多个饵命中的玩家之间随机分钩。

两步选鱼：Total 大于零时，先按 `X/Total、P/Total、J/Total` 选偏好类别，再在该类别的候选鱼中按漂主当前饵的偏好权重选鱼种，目标饵权重高、非目标饵权重低但不为零。鱼种分布、出现条件和在场协作能力过滤由鱼册提供；稀有度本身不进抽鱼概率；窝料表给了「目标鱼种加权」的窝料，第二步对该鱼种的权重再乘表里的倍率，没填的窝料只靠三类占比与饵权重（道具册「窝料机制」）。Total 为零时从基础池选，基础池同样按当前饵的权重选，但不扣存量：它是空窝的兜底体验，不是资源。候选为空或总权重为零时也落基础池；随机区间的端点算在区间内。

例：`{20,50,30}` 三类概率为 20%、50%、30%。钓走一条腥鱼，`X←X−1`，P、J 不变，变成 `{19,50,30}`，随后重算 Total、占比和浮漂剩余计时。

库存在抽中那一刻就扣：抽与扣是同一个原子事务，抽中即受惊离窝，之后无论试探跑鱼、空竿、鱼逃还是入夜中断，一律不回滚。新手在试探期乱提竿等于惊跑一条鱼，惩罚可读，也符合钓鱼直觉。饵的两个作用分开：种类权重在抽鱼时消费，数量在真咬成立时扣当时挂着的那 1 份，试探期提竿不损饵。透支、预留和回退机制都不存在。

同窝多漂同刻到点按服务器时间戳判序，时间戳完全并列按席位序（服务器判序）。A 漂抽走最后一条后，B 漂到点时 Total 为零，自然落基础池。鱼候选输入见鱼候选与实例。

## 2.4 游走衰减

窝里的鱼会随时间逐批游走。

每 30 秒统一执行一次 `新存量 = floor(旧存量 × 0.9)`，逐分量计算、向下取整，对应鱼自己游走，单次减少一成。存量因此恒为整数，不存在半条鱼，也不会扣成负数。`1 → floor(0.9) = 0`，向下取整自带清零，不需要另设归零规则。

不用四舍五入的原因：`1×0.9=0.9→1`、`5×0.9=4.5→5`，任何不大于 5 的分量都会成为不动点，窝点永远散不掉。

例：虫虫窝 `{腥10, 香2, 酵1}` 逐次衰减为 `{9,1,0} → {8,0,0} → {7,0,0}`。弱分量先散，窝点会随时间变「纯」，鱼种比例向主窝料漂移，这是本规则的直接后果，不是缺陷。

## 2.5 聚鱼时刻

三种窝料都撒够了，鱼会集体开口一阵。

三类存量都达到门槛后，每次投料独立判定一次触发；触发后咬钩加速、鱼群密度演出增强，衰减照常进行，期间再投料不重复触发；没有冷却，窗口结束后下一次合格投料照常判定。聚鱼是合作奖励：门槛不为单人下调，单人携带量天然凑不齐三类是有意设计。

| 参数或效果 | 建议快照 |
|-|-|
| 每类门槛 | 30 条（原范围 30～50） |
| 每次合格投料的触发概率 | 8%（原范围 5%～10%） |
| 持续时长 | 45 秒（原范围 30～60） |
| 咬钩速度倍率 | 2.5 倍（原范围 2～3） |

以上是建议值，不是已选定的参数组合（快照，参数页为准）。资格例：门槛 30 时，`{45,52,38}` 三类最小值 38 有资格，`{45,52,12}` 没有；有资格仍要过概率判定，不能写成必触发。

聚鱼只有投料一条触发路径，范围就是触发它的那个窝点。聚鱼不加存量：它是加速咬钩的爆发窗口，消耗现有存量、自带刹车；加了存量就会变成投料→触发→加鱼的正反馈。环境事件触发和稀有道具收益归完整版，不在本版。触发概率是一个固定的基础值，不随窝料品质或窝点总存量变化。

## 2.6 渔网与死水

一张渔网从窝里一次捞出一批鱼。

渔网是一次性道具。按落点所在窝点的当前概率构成抽取 5～8 条鱼，稀有不额外加权，湖心巨影永不入网；产出落在地上，先到先得。使用后该窝点进入 30 秒死水，所有浮漂的咬钩计时挂起，结束后按独立计时的折算规则恢复。

渔网扣存量：产出逐条按抽中鱼的偏好类别扣，扣法与抽鱼与扣减相同；实际条数是 `min(5～8 的随机数, 当前 Total)`，池里不够不凑数。没有窝点或空池也允许撒网，按基础池给 1～2 条小杂鱼低保，不扣存量。死水期内再撒网不禁止：第二张网正常结算，min 封顶照常保护存量，死水计时重置为 30 秒、不叠加。渔网产出不扣竿的基础磨损。

# 3. 抛竿与提竿

## 3.1 抛竿与浮漂落点

猫朝选中的水面甩出浮漂。

任意合法水边都能当钓点。站位不设合法区，岸上任意位置可抛，合法性只看落点：射程内的水面即合法，斜坡礁石交给关卡碰撞。鼠标左键点击湖面目标点抛竿，无力度条、无蓄力，猫爪按竿、甩竿的动作表达保持。

点击位置到猫站立点的距离为 D_click，不超过浮漂射程就能抛出，超过射程提示「够不到那边」；猫与点击点之间有遮挡同样抛不出，提示相同。实际落点相对点击位置随机偏移：以点击点为圆心的均匀圆盘，半径按漂的精准度映射，精准高／中／低为 0.5／1／1.5 米（快照，参数页为准），漂的种类与参数由挂号鱼漂表提供。偏出水面（落岸）判空竿收回、不损饵，重抛即可，散布是系统加的随机，不让玩家买单。超射程本被「够不到那边」拦下，偏移偶尔越界时落点收敛到射程圆边界。

## 3.2 等待与切饵

以实际浮漂落点按窝点归属选窝点，不在任何窝点内就按基础池和空池间隔处理。等待期间玩家可自由活动，鱼漂随水波起伏。

不设离开判定、不自动收竿：真咬响应窗只有 8～15 秒，跑远赶不回来就是超时鱼逃、损饵，惩罚已经在了，不另造闸。计时期间可以切饵、不重置计时，到点抽鱼时消费当时挂着的饵的权重；到点后再切饵无意义但无害，真咬扣的是当时挂着的那 1 份。浮漂归属在落水瞬间定死、不随漂移重算：归属是抽鱼的数据源，动态重归属会开「漂进别人窝白拿存量」的口子，漂移只是演出。

## 3.3 鱼饵与主动道具闸门

进了咬钩，这份饵就花掉了。

无饵不能抛竿，鱼饵随抛竿挂出。咬钩前主动收竿收回鱼饵，零损失；进入咬钩后，无论上鱼、超时、放弃、断竿、落水，都消耗 1 份饵。携带 8 份对应 8 次咬钩机会（快照，参数页为准），用完回营地补给。试探期提竿不损饵（提竿响应）。

从咬钩判定成功到本竿结局落定，禁止主动掏用道具；抄网是收鱼出口，可以正常使用；备装时预穿戴的被动效果正常结算。增效道具按「进入咬钩」计一场，咬钩前收竿不计场。鱼体力不接受道具直接改动，猫体力道具只在搏斗外使用，竿耐久不能回补。

## 3.4 响应窗口与完美提竿

漂轻点是试探，猛沉才是真咬；提得准，这条鱼就软一截。

咬钩分试探期和真咬期。演出时序：抽中瞬间鱼影出现（按真鱼体型）→ 浮漂轻点进入试探期（时长 2～4 秒随机，占位，快照，参数页为准）→ 漂猛沉即真咬并给提示。试探期提竿必空竿、不损饵，空竿揭图鉴剪影。真咬后的响应时长按鱼种为 8～15 秒，前 1 秒为完美窗；判定用服务器时间戳，客户端预表现。

| 提竿结果 | 规则 |
|-|-|
| 完美 | 普通鱼力量乘 0.8、体力乘 0.85；稀有鱼力量乘 0.85、体力乘 0.9 |
| 普通 | 完美窗后、响应窗结束前提竿，正常进入搏斗 |
| 超时 | 响应窗结束仍未提竿，鱼吐钩逃跑，饵已消耗 |

完美削减是三项削减：鱼力、鱼体力，再加初始线长按完美线长系数缩短（系数挂参数页）；不能变成一次额外伤害或只减某个临时速度。鱼册「力量」、`F_fish`、判定里的「鱼力」是同一个数；完美削减在入场时直接乘到本场实际值，此后运动求解、负载、消耗、碾压判定全用削后值。临界鱼可以被完美推进碾压区：鱼力 40 削到 32，猫力 65 由不碾压变碾压，奖励自然放大。恰好 1 秒算完美，闭区间，边界取对玩家有利的一侧。鱼册稀有度最高一档按稀有鱼取系数，其余档按普通鱼。

# 4. 搏斗与退出

## 4.1 资源与有效力量

| 量 | 含义与数据出处 |
|-|-|
| 猫体力 | 基础上限 100 点，成长接口归猫册 |
| 猫力 | 当前猫力量；品种基准普通／橘／狸花／缅因为 50／70／90／130，归猫册 |
| 鱼力量 F_fish | 鱼表按实际重量给出；完美在入场削减本场值 |
| 鱼体力 | 初始值＝鱼表「体力系数」× 实际重量（2026-09-08 改表，系数占位待模拟）；此后由鱼行为模型按鱼自己的规则维护（占位规则见鱼的行为 §4.5），钓鱼只读，读到 ≤ 0 即翻肚；完美的入场削减作为参数交给鱼侧 |
| 竿耐久 | 动态资源，三档上限 40／70／120，归零断竿 |
| 竿强度 | 静态配置，三档 25／60／210；瞬断规则见强度检查 |
| D | 鱼到猫的距离；初始为浮漂实际落点到猫的距离 |
| 可捞圆 | 挂在鱼身上、随鱼移动的圆，半径按鱼种配在鱼表格「可捞圈半径」列；抄手朝向的射线碰到它即够着，见 5.1 |
| 猫岸距 | 猫到岸的距离，参与被拖下水条件 |
| L、L_max | 已放线长与竿的最大线长；三档 L_max 为 60／80／100 米 |

`F_total` 是本次对抗的有效总力量，无辅助时就是持竿猫的当前力量；`K_pos` 是参与者消耗倍率，单人恒为 1.0。多人附篇只提交力量和角色倍率，瞬断、碾压和猫体力消耗都由本章统一计算。

当前力量 ＝ 猫种基础力量 × 成长加成，不随体力衰减，体力低不降力量。操作不改力量，操作只是运动学输入。

## 4.2 强度检查与碾压

鱼竿要先扛住鱼和猫的拉力。

竿强度和竿耐久是两个量。竿强度管瞬断：竿强度不超过总力量与鱼力中较小的那个，就当场断竿，张力由两端较小者决定。它是挑战巨影的装备门槛：参数页把巨影力量系数 K5 与竿强 210 配对挂号。

猫力达到鱼力的 2 倍可以碾压，直接把鱼甩上岸；否则进入搏斗。瞬断和碾压都是瞬时判定，只在搏斗开始时和合力变动时（辅助加入或退出、换人）检查，检查序固定为 ①竿强瞬断 → ②碾压 → ③常规搏斗。碾压达标立即飞鱼、跳过或中断搏斗循环，不是搏斗中的持续状态。力量比较统一用 F_total。飞上岸的鱼进入待拾取状态，不直接进主钓手库存。

## 4.3 鱼行为与运动输入

鱼一阵向外冲、一阵向岸缓游，翻肚前一直在游。

临时骨架：上钩后先向外游；向外发力与向岸低强度游动（演出名「休息」）按鱼种的时长区间交替；鱼体力低于 50% 后休息期变长。鱼体力通过挣扎激烈程度和头顶漩涡给玩家读。演出名「休息」不表示意图速度归零，见搏斗消耗。

最近冲岸距离按鱼种／食性配置：食肉中鱼黑鱼、河口鲈活着不进离岸 1.5 米，森林长尾鱼、银月鳟可以进可抄圈，小鱼可近岸（快照，参数页为准）。冲岸距离列待鱼表补齐。鱼行为的正式输入与审核边界见行为与运动接口。

## 4.4 搏斗消耗、移动附加与磨损

猫出的力越大、线上越沉，体力扣得越多。

搏斗消耗按猫的出力计，收线、转竿、顶住三样各自计费，每一样都乘上线上的负载。

- 收线：按实际收回的线长计费，每米一个单价。
- 转竿：按竿实际转过的角度计费，每弧度一个单价。
- 顶住：线绷紧时每秒付支撑费，按负载的平方算；转竿的支撑与顶住只收较高的一项。
- 负载项＝空载系数＋当前负载×负载系数。当前负载是线上拉力占猫力量的比例，0 到 1；放线时线不绷紧，负载为 0，三样都不计。

被鱼拖走不另收费，拖拽的惩罚在位置落水（4.6）。鱼那边的体力按它没游成的距离扣，见鱼的行为 §4.5。实现注意：消耗随固定步运动求解走，求解抖动会抖体力条，需要一层平滑。单价、空载系数、负载系数、支撑单价的现值挂参数页（快照，参数页为准）。多人时每人的消耗再乘〈多人钓鱼〉给的角色倍率。

移动附加是腿部消耗，按秒计费，与搏斗项并行相加，只看操作方向：按 W 前移（靠水）1.5 点/秒，按 S 后退（离水）3 点/秒（快照，参数页为准）。力量差不进腿部消耗，由搏斗项承担：负载越重扣得越多。W、S 在钓鱼中不翻转。

线绷紧的每一秒，竿耐久另扣 `鱼力 × 0.05`（快照，参数页为准），鱼力 75 时每秒扣 3.75。搏斗以渔获结束时，竿另扣基础磨损 1 点；渔网产出不扣。竿不可维修。

## 4.5 收放线与线长预算

放线用线长换喘息，线放完就得硬顶。

真咬成立那一刻的鱼猫距离就是初始线长 `L₀ = D₀`；完美中鱼时 L₀ 再乘完美线长系数（快照，参数页为准）；等待期移动不受线约束，当刻已超 L_max 则直接判脱钩鱼逃，饵已扣、不丢漂。L_max 三档 60／80／100 米。

放线是解除线轮锁定，不是主动出线。锁定时线长恒定，鱼拉的就是猫，张力传导、进对抗；解锁后线随鱼的实际外游出线，`L` 的增长等于鱼的实际位移，无张力、零消耗，没有「放线速率」这个参数。收线是主动卷回，`L` 回收；鱼发力时收线就是强对抗、费体力。体力与线长互为价格，收放循环不是免费的。线出尽（`L = L_max`）后解锁失效，张力全传给猫，被迫全额对抗，「什么时候舍得放线」才成为决策。

放线期间不判位置落水：放线就是松开对抗，拉力不再作用于猫，「鱼向外游＋力量不足」的拖拽前提消失。放线本身不恢复体力，搏斗中一律不恢复；猫册三选一的「放线回体速度」可以给放线加回体速率，基础为 0。放线时鱼向外则 D 增大，鱼向岸则 D 缓慢减小。

## 4.6 归零、位置落水与离竿

持竿猫力竭会被拖下水。

| 条件 | 结果 | 说明 |
|-|-|-|
| 鱼体力 ≤ 0 | 鱼翻肚 | 进入翻肚拖岸拖回；抄取另验可抄资格与几何边界 |
| 猫体力 ≤ 0 | 猫力竭 | 被拖下水，鱼逃 |
| 竿耐久 ≤ 0 | 断竿 | 鱼逃，器材失败 |
| 主位离竿 | 无人值守放线 | 竿落地、会话继续；见本节末段 |

位置落水要同时满足三条：猫岸距归零、鱼向外游、总力量小于鱼力（取等不落水，鱼力必须大于总力量才拖得动猫）。只判持竿者，被线拽的是他，竿、饵、漂、落水全是他的账。猫体力耗尽仍走资源落水出口，位置条件不能当成免除体力归零后果的保护；两个出口同刻满足时体力落水优先。

落水的后果是鱼逃、饵已扣、湿身喜剧演出，嘴里原有的鱼保留，没有其他损失。

主位在搏斗中主动走开、又没有队友接手时，竿落在原地，这一竿不结场：线随鱼向外放，放到尽头就拴住；没人顶就没人扣体力，离开的猫带走当时剩下的体力。饵在咬钩成立时已扣；鱼不逃，直到有人切线或入夜按 6.5 收口。放下的竿只能回来切线：原持竿者或竿的主人走到竿边 2.5 米内按切线（快照，参数页为准），鱼逃，图鉴按鱼逃口径。要接着钓这一竿，得在离开时有队友按〈多人钓鱼〉接手。落水与猫体力归零不走这条出口，仍按上表结场。

## 4.7 主动放弃

玩家可以主动放弃本竿，进入咬钩后饵已消耗。放弃输入是搏斗中长按收竿键 1.5 秒（快照，参数页为准），带进度条 UI，松手即取消。图鉴按鱼逃同口径：上钩已揭的剪影保留，收集层不写（捕获事件）。

# 5. 收鱼与归属

猫叼住收来的鱼。

## 5.1 抄网与可抄资格

抄网够到鱼身上的圈，就能下网，不必等它累瘫。

抄网非必带，单一款式，没有长度、体型上限或成功率属性。可抄的对象是钩上的鱼或翻肚鱼。每条鱼身上挂一个可捞圆，圆心随鱼走，半径按鱼种配在鱼表格「可捞圈半径」列，占位按体重档小 60、中 90、大 120 厘米；抄手朝向的射线碰到圆就算够着，够着即必中。射线长度是抄网射程，现值 2 米（快照，参数页为准）。自由游动的鱼不可捞；湖心巨影的可捞圆为 0，不可抄，只能翻肚拖岸或碾压落岸后拾取。不按竿长、鱼重量或抄网等级判断，也不看鱼离岸多远。

## 5.2 挥网与叼鱼态

按 F 挥网，命中由服务器在判定瞬间验证。命中后鱼由挥网的猫叼在嘴里，实物归抄网者，图鉴见捕获事件。

没够着、对自由鱼或湖心巨影出手、被别人抢先，都算挥空；多个 F 目标并存时按视角中心选（F 目标选择）。挥空的猫进入 3 秒硬直（快照，参数页为准），无法操作。提示沿用「没够着」「被抢先」，不可抄的对象也要能从表现上认出来。

嘴里只能叼一条鱼。叼着鱼不能抛竿、不能再抄或拾第二条，得先放进鱼护或扔下。鱼护非必带，不带的猫也按这个规则处置后继续钓。落水时嘴里的鱼保留。

## 5.3 翻肚拖岸与拾取

没网就把鱼拖累，拖上岸再捡。

鱼体力耗尽即翻肚，之后只有一条运动规则：鱼沿鱼→猫方向（每 tick 取当前值）以固定速率被拖动，速率建议 2 米/秒（快照，参数页为准），触岸即在碰岸处落地。猫可以边走边收，鱼始终朝猫的当前位置被拉，无对抗即无消耗；这一段不看 D，也不算最近岸线点。落岸不等于入袋，仍要按 F 拾取，拾取必中，鱼叼进拾取者嘴里、实物归拾取者。岸上的鱼谁都能拾，先到先得；钓手已得的图鉴登记不因别人拾走而取消。

水里翻肚的鱼超过苏醒时限仍未上岸就苏醒逃跑，时限是配置项，默认 30 秒（快照，参数页为准），拖动中计时照走，有效救援半径约 60 米（速率×时长）。拖上岸或碾压甩上岸后不再苏醒，但地上未拾取的鱼翻天消失，不能靠「离水安全」跨天囤鱼。

## 5.4 所有猫收鱼与服务器判序

谁先出手鱼归谁。

所有猫都能抢同一条可抄鱼，也能抢拾同一条岸上鱼。以服务器收到指令的时间戳判先到先得，第一个有效命中者得实物，其余各自进入 3 秒独立硬直，硬直中再按 F 无效，提示「爪子还在麻」。不能用客户端帧数替换服务器时间戳。

时间戳完全并列时按席位序（加入房间的先后，早者先）打破，确定、可复现。同一 tick 的事件结算序固定为收鱼 → 苏醒 → 落水，玩家利益优先：同刻收鱼加落水时鱼先进嘴，到手的鱼不被同刻落水吞掉；同刻被有效收取的翻肚鱼不再苏醒。这个顺序只管收鱼、苏醒、落水三件事，不扩展为换人、献祭和离局的全局优先序。

## 5.5 几何边界与 F 目标选择

鱼的位置以服务器物理碰撞箱中心为准。够不够着看抄手的身体朝向：从抄手位置沿面朝方向水平发一条射线，长度等于抄网射程，碰到鱼的可捞圆即够着；转镜头不改变朝向。另有三条拒绝条件，任一不满足都判「没够着」：抄手与鱼之间有遮挡；抄手脚下坡度超过 45 度；抄手与鱼的高差超过 2.5 米（三个数都是快照，参数页为准）。抄手必须站在岸上，嘴里不能叼着鱼。落岸鱼的可拾距离是 1.5 米，全游戏统一交互半径，与抄网射程是两个参数，都在参数页。

### F 目标选择

对着谁按 F，就对谁出手。

射线碰到可捞圆只是资格门槛；多个合法目标同时够着时，F 作用于玩家视角中心所指的那个。UI 以准星态提示当前 F 目标。

## 5.6 捕获事件与实物归属

上钩就揭剪影，收进嘴才算收集。

图鉴分两层。剪影层在上钩成立时揭开、永不撤销，试探期空竿同揭。收集层（名字、彩色立绘、出没区域、个人最佳重量）在成功收鱼时写入，归上钩者：实物被队友抢走不取消登记；鱼逃、放弃、中断则收集层不写、剪影保留。「上钩成立」是归属基准，不是收集层的写入时点；此后吃、献、被偷都不撤销记录。重量没有组队加成。

## 6.4 渔获与消费交接

收上来的鱼先在嘴里，去哪由别的册子管。

抄取或拾取→嘴里→可选鱼护暂存→带回营地共用大鱼缸，再选择去向；也可以按叼鱼态规则先扔下。当天扔下等于赠送路径，谁都能捡；物品不能扔进湖里。翻天时地上未拾取的物品一并消失。

吃、献、卖、留缸观赏是渔获用途概览，经验、供奉、卖价与容量由接收册处理。钓鱼对同一条鱼输出鱼种、实际重量、上钩归属与实物持有人；上钩事件与成功收鱼事件分别对应捕获时点。渔网直接产出落地鱼，没有竿上钩过程。

转存接口要区分成功与拒收，满容器不得当作转存成功。鱼实例标识、接收确认、重复提交与拒收后的状态尚无已裁的工程实现。鱼护容量、跨天保存资格和鱼缸升级是外部输入。

## 6.5 生命周期输入与状态转移

入夜停止新咬钩，翻天清窝。

| 外部信号／阶段 | 钓鱼侧行为 | 损益与未裁边界 |
|-|-|-|
| 入夜 | 不再产生新咬钩；还没咬钩的浮漂剩余计时一律清掉，不冻结、不跨天续用；进行中的搏斗允许打完 | 入夜瞬间处于试探期的竿按空竿收回，不损饵、已抽库存不回；真咬待响应的算进行中，允许提竿并打完，超时鱼逃；与入夜同刻到点的浮漂不再抽鱼 |
| 强制中断（献祭互动等） | 强制打断进行中的互动，按抽扣时点结账 | 试探中收竿未扣饵、已抽库存不回；真咬后按鱼逃、不回滚、不丢漂；已揭剪影保留、不记捕获。与收鱼、断竿、换人同刻的关系未全定 |
| 翻天完成 | 窝点清空；旧浮漂剩余计时不跨天；地上未拾物品随世界清理消失 | 聚鱼窗口、死水随窝点一并清空；容器保存资格不等于地面物清理 |
| 下一轮钓鱼开放 | 从新的准备与打窝流程开始，不恢复昨天的咬钩倒计时 | 开放信号由局与进程提供；不以本地时钟推算任务人数 |
| 局结束 | 停止钓鱼，释放窝、漂、搏斗等本系统瞬态；已输出的捕获事实不因失败撤销 | 毕业上供不翻天、失败立即结束且不进结算夜，两者都需要局结束出口；释放时序待接口接线 |

钓鱼只消费中断与开放信号，不判断祭坛全员到齐、不计算每日目标。

# 7. 信息与反馈

规则提供事件、状态、目标和可见范围，动作表现集负责素材。动作不改变既定硬直时长与鱼归属。

## 7.1 必须可感知的操作反馈

| 场景 | 提示或表现 |
|-|-|
| 抛竿 | 左键点水面，猫甩竿 |
| 鱼向岸休息 | 状态文字变绿「鱼累了！按住左键拖回来！」；猫耳朵竖起、尾巴甩动 |
| 鱼向外发力 | 状态文字变红「鱼在发力！放线喘口气，拖线就是硬拼！」 |
| 鱼可抄 | 屏幕中央爪印图标＋「快抄！（按 F）」，以收鱼资格判定为准 |
| 猫体力偏低 | 体力条变红闪烁＋「猫喘气了！」与喘气表现 |
| 落水危险 | 爪扒地划痕＋「要滑下去了！」，不承诺未实现的拽尾巴救援 |
| 完美 | 金色水花＋瞳孔放大＋清脆一声「叮」＋「完美！」 |
| 断竿 | 咔嚓声、爪里只剩半截竿、猫愣住 |
| 鱼逃 | 耳朵耷拉、水面恢复平静 |
| 挥空 | 猫拍空或被绊、沙漏图标＋「爪子麻了！」 |
| 主动放弃 | 「放生了鱼…鱼饵和浮漂被带走了」 |
| 碾压 | 鱼落身后草地、猫翘尾巴，仍需拾取 |

铃铛漂咬钩为叮铃声，鱼发力为线绷紧的嗡声，鱼休息时拍水声减弱；竿断为咔嚓，落水为扑通加喷嚏。基础咬钩信号要让漂主远距离感知，包含声音、身体语言与震动通道；铃铛漂把它增强为全场可闻。

## 7.2 世界可见性

鱼影按已抽定那条真鱼的体型演出，附近玩家都能看见，只让人感知有鱼及大致体型，不能据影认出鱼种。窝点的猫爪标记全队可见，读窝内 Total 的浓／中／淡三档（阈值挂参数页），不表达剩余时间，不显示存量数字；范围与鱼量通过光环、粒子、鱼影粗略表现，三档表现归张佳。聚鱼进行中标记变亮、鱼影加密，同样不出数字倒计时。

队友的装备通过身上、手里、嘴里的世界表现和凑近闻来了解，不新增查看装备的菜单。猫的耳朵、尾巴、瞳孔、炸毛要在半个湖外仍能辨读；落水、拍空、被绊都好笑不惨；线的松紧、竿身弯曲表达张力。

## 7.3 表现责任与回审

真咬、完美、危险、可抄、挥空、落水和断竿等事件由钓鱼提供，动画与音效由动作表现集接收。鱼向外发力时猫前滑、爪扒地、耳朵后压与瞳孔收缩，力量与低体力信号必须保持可读；猫体力低于 30% 给偏低提示（快照，参数页为准）。挥空表现不得改变既定硬直。素材细目见〈动作表现集〉页。线长余量给世界内表现（线轮上还剩几圈）；力量差不给数字，靠猫前滑、爪扒地和线的绷紧读；鱼体力靠挣扎激烈程度与头顶漩涡（鱼行为）。

修改任务曲线、卖价、容量或动画素材只变更其所属数据与资产；改变鱼意图含义、力量单位、命中帧、可操作时刻或生命周期顺序须回审对应接口。
