# 钓鱼核心流程（实现对照基准）

依据：`Knowledge/GDD/钓鱼规则`（实现规格书，2026-08-18）。范围只含钓鱼；渔获去向/供奉不在本文。
口径冲突时以本文所引规格书为准；页内数字为快照，数值拍定以「参数与校准记录」为准。

## 0. 总览

```
[准备] 带饵/窝料/竿(/网/护) 走到任意水边
   ├─ Q 蓄力抛窝料 → [窝料场] 固定范围，三轴贡献在重叠区按共享曲线收敛   （可选、可重复）
   └─ 左键点水面 → [抛竿] 射程/精准校验，落点查询所在面积单元
                      ↓
                   [等待] 读取该单元聚鱼总量和加权鱼种分布             ← 咬钩前可收竿，零损失
                      ↓
                   [真咬] 8~15s 响应窗；1s 内=完美               ← 进入即扣 1 饵，任何结局都扣
                      ├─ 超窗 → 鱼跑
                      └─ 提竿 → [遛鱼] 左键收 / 右键松开线杯 / 不动；鱼 向外游⇄向内游
                                  ├─ 断线 → 鱼逃（鱼竿未损坏时可直接开始新会话）
                                  ├─ 猫脚点持续进入危险水深 → 落水失败
                                  ├─ 鱼体力归零，或被绷紧鱼线拖过岸线 → 翻肚成鱼干，同一约束系统零猫体力消耗地继续收近
                                  └─ 鱼进入抄网射线范围（体力不限）→ 可抄
                                        ↓
                                  [收鱼] 带网 F 抄（范围合法即直接叼嘴）/ 翻肚收至竿尖表面投影后 E 拾取
```

## 1. 打窝
- 操作：选窝料 → Q 长按蓄力 → 抛物线预览 → 松手投出
- 每片湖/河持有固定可钓面积、水域鱼总数和各鱼种数量；各鱼种在所属水域内按面积平均分布，窝料不会凭空生成鱼，只改变同一水域内的局部分配
- 窝料 = `{腥X, 香P, 酵J}` 三维向量；每次投放保留自己的中心、影响半径、数量、距离衰减和时间衰减
- 当前测试版用全局 `InfluenceAreaMultiplier=2.0` 把每种窝料资产的基础影响面积统一放大到 2 倍；对应半径只乘 `√2≈1.414`，不会误放大成 4 倍面积
- 多个影响范围重叠时先叠加三维贡献，再交给一条全项目共享的收敛曲线；曲线输出“剩余容量填充率”而不是固定最终倍数，总鱼量按 `基础鱼量 + 填充率×(区域上限-基础鱼量)` 增长，因此持续补窝会趋近本区域上限
- 固定 `8×` 只有在区域上限本身不超过基础鱼量 `8×` 时才能保证触顶；湖面积导致 `上限/基础量` 改变时，实际倍率上限必须动态取 `区域上限/基础鱼量`。鱼种偏好继续由“三维贡献 · 鱼种偏好”加权并归一化，不与总鱼量上限混算
- 水域按窝料覆盖关系切成互不重叠的面积单元；鱼种按“面积比 × 该鱼种窝料倍率”在单元间守恒分配，不为每种鱼或每种重叠组合单独建表
- 每个单元的聚鱼总量还受 `水域鱼总数 × AreaCapacityCurve(单元面积/水域面积)` 限制；多个窝区争用同一批鱼时按统一受限分配，不能让各区总和超过水域鱼总数
- 具体收敛曲线、面积容量曲线、窝料持续时间和携带数量仍待数值阶段拍定；详细公式见 `Docs/Architecture/项目技术方案.md` §7.1.1

## 2. 抛竿
- 左键点水面，无蓄力（有预览不蓄力）；无饵不能抛
- 射程：D_click ≤ 浮漂射程，否则"够不到那边"
- 精准：落点 = 点击点 + 随机偏移（半径由浮漂精准度定；3 种浮漂）
- 窝料查询：落点读取所在面积单元；重叠时消费所有覆盖该点的有效窝料，不再只取最近圆心
- 咬钩前任意时刻可收竿，收回饵，零损失

## 3. 等待 → 咬钩
- 计时器挂浮漂级；咬钩节奏读取当前面积单元的聚鱼总量，正式换算曲线待数值阶段拍定
- 单元聚鱼总量变化时，剩余等待时间按新旧目标等待时长的比例折算
- 鱼种：正式方向是先取水域鱼种库存占比，再乘该鱼种的三维窝料倍率并归一化；无窝时退回水域基础分布。当前测试版先按“水域 → 挑战度安全上限 → 时段/天气扩展门 → 最低人数 → 挑战档 → 窝料/鱼饵/基础权重归一化”选择；时段和天气门默认旁路，不改变出鱼，人数门继续生效
- 试探期：正式三阶段（试探→真咬→完美窗），灰盒先做两阶段
- 入夜后不再咬钩；进行中搏斗允许打完

## 4. 真咬 → 提竿
- 响应窗按鱼种 8~15s
- 完美提竿：咬钩后 1s 内（服务器时间戳）→ 普通鱼 力量×0.80/体力×0.85；稀有鱼 ×0.85/×0.90
- 普通提竿：1s 后至窗口结束前 → 正常遛鱼
- 超时：鱼吐钩，扣饵，结束
- 饵：进入咬钩后无论结局（上鱼/超时/放弃/断线/落水）扣 1 份，上鱼也扣

## 5. 遛鱼
资源：猫/鱼力量、双方等效质量、双方体力、钓组承载、本场鱼线耐久、D（竿尖到鱼的直线距离）、L_paid/L_max（已放出线长/竿上限）。鱼的个体力量由本次实际重量乘 `FightStrengthPerKilogram` 得到；猫的基础 `FishingStrength` 用同一系数反推等效系统质量。体力下降只降低猫的当前驱动力，不改变质量。

鱼行为：Encounter 上的 `ST_FishFight` 控制发力⇄休息拓扑；每段内部由服务器种子选择目标游向并限速转弯，可横切、绕竿和假动作。朝竿尖 ±60° 算向内，每次重选时的向内概率随体力下降由 `FullStaminaInwardProbability` 增长至 `ExhaustedInwardProbability`。活鱼自行撞到真实岸线时，本步移除安全内缩点的法向瞬移、保留沿岸位移，后续沿岸/向水内平滑游离；若猫端沿绷紧鱼线把鱼拖过岸线，则鱼立即按力竭处理、侧翻进入 `ExhaustedReel`。上钩瞬间=发力；鱼体力<50% 后休息期变长。

鱼线：`Slack=max(L_paid-D,0)`。不按键为 Locked，左键 Reeling 只减少 `L_paid`，右键 FreeSpool 只允许鱼实际外游时被动增加 `L_paid`。后退只改变猫/竿端点，不改变线长；原地收线只改变线长，不伪造猫位移。

受力比例 `LineLoad = pow(max(dot(鱼游向, 竿尖→鱼的水平鱼线方向), 0), AngleStrengthExponent)`。双方都先按 `加速度 = 当前有效力量 × FightAccelerationPerStrength` 产生意图，鱼性格游速和收线速度只作为上限；鱼、猫移动与卷线再汇入唯一线长误差。只有鱼的沿线加速度高于猫时，力量差才按双方质量生成猫端牵引和后退限速；相等时自然僵持，猫更强时约束修正落在鱼端。猫端在每个角色移动帧平滑追赶20 Hz目标，不累加冲量，也不直接插值角色位置。

统一求解表

| 鱼状态 | 操作 | 条件 | D | 资源 | 结局 |
|---|---|---|---|---|---|
| 平静/向内游 | 左键 | 收线请求达到线端 | 力量差+双端质量约束 | 统一做功×平静倍率 | 低消耗收线窗口 |
| 平静/向内游 | 右键松线 | L < L_max 且约束确实解除 | D 按真实游向变化；仅外游超过线端时 L_paid 跟随 | 鱼支付自由游动做功；主猫恢复 | 鱼自由游动/向内形成垂线 |
| 发力 | Locked/Reeling | 形成约束误差 | 先比较沿线加速度，鱼占优部分再按质量分配 | 实际位移+被挡意图均计费 | 可能自然僵持或拖动任一端 |
| 发力 | 任意 | 线负载超过承载或耐久耗尽 | 保留当步位置 | — | 断线，鱼逃；鱼竿仍可用 |
| 向外游 | 右键松线 | D < L_max | L_paid 被鱼带到新的 D | 主位恢复 | 自由带线、喘气 |
| 向外游 | 右键松线 | D 到达 L_max 后继续外冲 | 截在 L_max | 双方恢复张力消耗；主猫停止恢复 | 已无线可放，进入对抗 |

体力：`有效努力距离 = 实际沿线位移 + max(意图沿线位移-实际沿线位移,0)×等长系数`，再乘力量、做功系数和性格倍率。Locked 绷紧时，鱼的外游意图同时形成猫端的等长保持意图；右键只有在尚可自由出线、约束确实解除时恢复猫体力。多人猫端总消耗按有效力量占比分摊。鱼体力归零或被猫端牵引越岸后，由 StateTree 切入 `ExhaustedReel`，鱼端加速度和猫端牵引在同一权威写口立刻归零；同一 Runner 仅继续求解收线把鱼拖近，不再扣任何猫的体力。越岸鱼干每步吸附当前 XY 的真实地面，不沿用水面 Z；到竿尖 `LandingCompletionDistanceToRodCentimeters` 内才转换为可拾取鱼。猫体力归零只让有效力量降为 0。猫落水只在 Condition 确认脚点达到危险浸没深度后成立。

## 6. 收鱼
- 抄网 = 权威装备；当前开发期服务器默认给每名玩家一份 `StarterScoopNet` 并自动选中，正式版关闭临时开关后再从商店/奖励获得；有效长度取全局 `ScoopReachCentimeters` 与抄网 DA 射程的较小值
- 可抄：鱼已上钩且进入“水平抄网线段 ∩ 鱼目标圆”范围；活鱼/翻肚均可，鱼的剩余体力不参与判定
- 带网：F → 范围、站位、视线和装备校验通过后直接叼嘴里；挥空仍受 3s 冷却
- 无网：鱼体力耗尽或被拖上岸后翻肚 → 水内贴水面、岸上逐步贴地拖至竿尖附近 → E 拾取，必中，先到先得
- 翻肚 30s 苏醒逃跑尚未实现（TODO）
- 多人：服务器先处理者先得到嘴叼世界鱼；其余各自受 3s 冷却，冷却中 F 无效
- 两轨记录：渔获归抄/拾者；图鉴首钓与个人纪录归上钩钓手
