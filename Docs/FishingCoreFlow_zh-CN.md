# 钓鱼核心流程（实现对照基准）

依据：`Knowledge/GDD/钓鱼规则`（实现规格书，2026-08-18）。范围只含钓鱼；渔获去向/供奉不在本文。
口径冲突时以本文所引规格书为准；页内数字为快照，数值拍定以「参数与校准记录」为准。

## 0. 总览

```
[准备] 带饵/窝料/竿(/网/护) 走到任意水边
   ├─ Q 蓄力抛窝料 → [窝点] 圆形池，并池叠加，30s×0.9 衰减   （可选、可重复）
   └─ 左键点水面 → [抛竿] 射程/精准校验，落点归属某窝点
                      ↓
                   [等待] 浮漂级计时器 T = T_base/(1+Total/100)   ← 咬钩前可收竿，零损失
                      ↓
                   [真咬] 8~15s 响应窗；1s 内=完美               ← 进入即扣 1 饵，任何结局都扣
                      ├─ 超窗 → 鱼跑
                      └─ 提竿 → [遛鱼] 左键拖 / 右键放 / 不动；鱼 向外游⇄向内游
                                  ├─ 断竿 / 拖下水 → 鱼逃
                                  ├─ 碾压 → 鱼甩上岸（岸上态）
                                  ├─ 鱼体力归零 → 翻肚（D=0）
                                  └─ 鱼贴岸 <1m → 可抄态
                                        ↓
                                  [收鱼] 带网 F 抄（概率）/ 翻肚拖上岸 F 拾取（必中） → 叼在嘴里
```

## 1. 打窝
- 操作：选窝料 → Q 长按蓄力 → 抛物线预览 → 松手投出
- 窝料 = {腥X, 香P, 酵J} 正整数向量；窝点 = 落点为圆心、半径 5m 的圆
- 并池：新落点圆心落进已有圆 → 向量相加，沿用原圆心/半径；否则新建
- 叠加无设计上限（只留工程安全夹）；每 30s 全局 ×0.9；Total<1 → 归零
- 补窝直接叠加，不重置衰减计时；携带 5 份（暂定）

## 2. 抛竿
- 左键点水面，无蓄力（有预览不蓄力）；无饵不能抛
- 射程：D_click ≤ 浮漂射程，否则"够不到那边"
- 精准：落点 = 点击点 + 随机偏移（半径由浮漂精准度定；3 种浮漂）
- 窝点归属：落点所在圆；多圆相交取圆心最近；不在圆内 → Total=0 档
- 咬钩前任意时刻可收竿，收回饵，零损失

## 3. 等待 → 咬钩
- 计时器挂浮漂级；T = T_base/(1+Total/K)，T_base=15s(有窝)/120s(无窝)，K=100
- Total 变化时剩余时间按新旧 T 比例折算
- 鱼种：Total>0 按 X/P/J 占比抽偏好；Total=0 → 基础鱼池
- 试探期：正式三阶段（试探→真咬→完美窗），灰盒先做两阶段
- 入夜后不再咬钩；进行中搏斗允许打完

## 4. 真咬 → 提竿
- 响应窗按鱼种 8~15s
- 完美提竿：咬钩后 1s 内（服务器时间戳）→ 普通鱼 力量×0.80/体力×0.85；稀有鱼 ×0.85/×0.90
- 普通提竿：1s 后至窗口结束前 → 正常遛鱼
- 超时：鱼吐钩，扣饵，结束
- 饵：进入咬钩后无论结局（上鱼/超时/放弃/断竿/落水）扣 1 份，上鱼也扣

## 5. 遛鱼
资源：猫力量（普通50/橘70/狸花90/缅因130）、猫体力（上限100）、竿强度（静态 25/60/130）、
竿耐久（动态 40/70/120）、鱼力量/鱼体力（鱼种）、D（鱼到猫距离，初始=落点到猫距离）、L/L_max（线长/竿上限）

鱼行为（临时）：向外游(发力)⇄向内游(休息) 按鱼种时长区间交替；上钩瞬间=向外游；鱼体力<50% 后休息期变长

判定表（向外游+拖 按 ①→④ 顺序，先命中先生效，取等从严）

| 鱼状态 | 操作 | 条件 | D | 资源 | 结局 |
|---|---|---|---|---|---|
| 向内游 | 左键拖 | 无条件 | 大减 | 猫体力 -= 鱼力×0.15/s | 够近→可抄 |
| 向内游 | 右键/不动 | 无条件 | 小减 | 无 | 鱼自己靠近 |
| 向外游 | 左键拖 | ① 竿强度 ≤ min(猫力,鱼力) | 不变 | — | 断竿，鱼逃 |
| 向外游 | 左键拖 | ② 鱼力 ≥ 猫力 | 不变 | — | 拖下水，鱼逃 |
| 向外游 | 左键拖 | ③ 猫力 ≥ 鱼力×2.0 | 归零 | 无 | 碾压，鱼甩上岸 |
| 向外游 | 左键拖 | ④ 其余 | 不变 | 消耗战 | 僵持 |
| 向外游 | 右键放 | L < L_max | 增加 | 猫体力 +1.5/s | 喘气 |
| 向外游 | 右键放 | L ≥ L_max | — | — | 右键失效，只能拖 |

僵持消耗战（每秒）：竿耐久 -= 鱼力×0.1；鱼体力 -= 猫力×0.08；猫体力 -= 鱼力×0.12
归零优先级：鱼体力 → 猫体力 → 竿耐久。鱼体力归零 → 翻肚，D=0。每钓上一条另 -1 竿耐久。

## 6. 收鱼
- 抄网 = 可选道具，无自身长度，唯一属性=成功概率；鱼护 = 可选道具
- 可抄：鱼-岸距离 < 1m（全局固定）；活鱼/翻肚均可
- 带网：F → 按概率判定；成功叼嘴里；失败 3s 硬直
- 无网：鱼体力耗尽翻肚 → 拖上岸 → F 拾取，必中，先到先得
- 碾压甩上岸 = 岸上态，任何猫可拾取
- 水里翻肚 30s 无人处置 → 苏醒逃跑；上岸后离水安全
- 多人：服务器时间戳先到先得；其余各自 3s 硬直；硬直中 F 无效
- 两轨记录：渔获归抄/拾者；图鉴首钓与个人纪录归上钩钓手
