# 钓鱼核心流程（实现对照基准）

依据：`Knowledge/GDD/钓鱼规则`（实现规格书，2026-08-18）。范围只含钓鱼；渔获去向/供奉不在本文。
口径冲突时以本文所引规格书为准；页内数字为快照，数值拍定以「参数与校准记录」为准。

## 0. 总览

```
[准备] 带饵/窝料/竿(/网/护) 走到任意水边
   ├─ Q 蓄力抛窝料 → [窝料场] 固定范围，三轴贡献在重叠区按共享曲线收敛   （可选、可重复）
   └─ 左键点水面 → [抛竿] 射程/精准校验，落点查询所在面积单元
                      ↓
                   [等待] 读取该单元聚鱼总量和加权鱼种分布             ← 咬钩前可收竿，零损失
                      ↓
                   [真咬] 8~15s 响应窗；1s 内=完美               ← 进入即扣 1 饵，任何结局都扣
                      ├─ 超窗 → 鱼跑
                      └─ 提竿 → [遛鱼] 左键收 / 右键松开线杯 / 不动；鱼 向外游⇄向内游
                                  ├─ 断线 / 拖下水 → 鱼逃（断线后鱼竿可直接开始新会话）
                                  ├─ 碾压 → 鱼在当前位置力竭侧翻
                                  ├─ 鱼体力归零 → 在当前位置翻肚
                                  └─ 鱼进入抄网射线范围（体力不限）→ 可抄
                                        ↓
                                  [收鱼] 带网 F 抄（范围合法即直接叼嘴）/ 翻肚收至竿尖表面投影后 E 拾取
```

## 1. 打窝
- 操作：选窝料 → Q 长按蓄力 → 抛物线预览 → 松手投出
- 每片湖/河持有固定可钓面积、水域鱼总数和各鱼种数量；各鱼种在所属水域内按面积平均分布，窝料不会凭空生成鱼，只改变同一水域内的局部分配
- 窝料 = `{腥X, 香P, 酵J}` 三维向量；每次投放保留自己的中心、影响半径、数量、距离衰减和时间衰减
- 当前测试版用全局 `InfluenceAreaMultiplier=2.0` 把每种窝料资产的基础影响面积统一放大到 2 倍；对应半径只乘 `√2≈1.414`，不会误放大成 4 倍面积
- 多个影响范围重叠时先叠加三维贡献，再交给一条全项目共享的收敛曲线；曲线输出“剩余容量填充率”而不是固定最终倍数，总鱼量按 `基础鱼量 + 填充率×(区域上限-基础鱼量)` 增长，因此持续补窝会趋近本区域上限
- 固定 `8×` 只有在区域上限本身不超过基础鱼量 `8×` 时才能保证触顶；湖面积导致 `上限/基础量` 改变时，实际倍率上限必须动态取 `区域上限/基础鱼量`。鱼种偏好继续由“三维贡献 · 鱼种偏好”加权并归一化，不与总鱼量上限混算
- 水域按窝料覆盖关系切成互不重叠的面积单元；鱼种按“面积比 × 该鱼种窝料倍率”在单元间守恒分配，不为每种鱼或每种重叠组合单独建表
- 每个单元的聚鱼总量还受 `水域鱼总数 × AreaCapacityCurve(单元面积/水域面积)` 限制；多个窝区争用同一批鱼时按统一受限分配，不能让各区总和超过水域鱼总数
- 具体收敛曲线、面积容量曲线、窝料持续时间和携带数量仍待数值阶段拍定；详细公式见 `Docs/Architecture/项目技术方案.md` §7.1.1

## 2. 抛竿
- 左键点水面，无蓄力（有预览不蓄力）；无饵不能抛
- 射程：D_click ≤ 浮漂射程，否则"够不到那边"
- 精准：落点 = 点击点 + 随机偏移（半径由浮漂精准度定；3 种浮漂）
- 窝料查询：落点读取所在面积单元；重叠时消费所有覆盖该点的有效窝料，不再只取最近圆心
- 咬钩前任意时刻可收竿，收回饵，零损失

## 3. 等待 → 咬钩
- 计时器挂浮漂级；咬钩节奏读取当前面积单元的聚鱼总量，正式换算曲线待数值阶段拍定
- 单元聚鱼总量变化时，剩余等待时间按新旧目标等待时长的比例折算
- 鱼种：正式方向是先取水域鱼种库存占比，再乘该鱼种的三维窝料倍率并归一化；无窝时退回水域基础分布。当前测试版先按“水域 → 挑战度安全上限 → 时段/天气扩展门 → 最低人数 → 挑战档 → 窝料/鱼饵/基础权重归一化”选择；时段和天气门默认旁路，不改变出鱼，人数门继续生效
- 试探期：正式三阶段（试探→真咬→完美窗），灰盒先做两阶段
- 入夜后不再咬钩；进行中搏斗允许打完

## 4. 真咬 → 提竿
- 响应窗按鱼种 8~15s
- 完美提竿：咬钩后 1s 内（服务器时间戳）→ 普通鱼 力量×0.80/体力×0.85；稀有鱼 ×0.85/×0.90
- 普通提竿：1s 后至窗口结束前 → 正常遛鱼
- 超时：鱼吐钩，扣饵，结束
- 饵：进入咬钩后无论结局（上鱼/超时/放弃/断线/落水）扣 1 份，上鱼也扣

## 5. 遛鱼
资源：单猫力量（普通50/橘70/狸花90/缅因130；搏斗猫总体力量固定为两只猫力量相加，当前运行时第二项为0）、猫体力（上限100）、钓组承载（静态 25/60/130）、
本场鱼线耐久（40/70/120，每次新会话重置）、鱼力量/鱼体力（鱼种）、D（竿尖到鱼的直线距离）、L_paid/L_max（已放出线长/竿上限）

鱼行为：Encounter 上的 `ST_FishFight` 控制发力⇄休息拓扑；每段内部由服务器种子选择目标游向并限速转弯，可横切、绕竿和假动作。朝竿尖 ±60° 算向内，每次重选时的向内概率随体力下降由 `FullStaminaInwardProbability` 增长至 `ExhaustedInwardProbability`。活鱼撞到真实岸线时，本步移除安全内缩点的法向瞬移、保留沿岸位移，后续沿岸/向水内平滑游离；力竭收近阶段改为直追冻结投影。上钩瞬间=发力；鱼体力<50% 后休息期变长。

鱼线：`Slack=max(L_paid-D,0)`。无输入时 `L_paid` 固定，鱼向内会产生垂线，鱼向外会先吃完余线再形成张力；左键主动减少 `L_paid`。右键只是松开线杯：鱼实际向外游到线端后才被动增加 `L_paid`，鱼静止/向内时不增加，在 `L_max` 内不限制鱼。鱼在锁线绷紧状态继续外冲时，即使玩家不按键也会继续消耗鱼体力和本场鱼线耐久；猫体力只按自身蓄力或辅助捣乱规则结算。

受力比例 `LineLoad = pow(max(dot(鱼游向, 竿尖→鱼的水平鱼线方向), 0), AngleStrengthExponent)`。它连续控制鱼线磨损、牵引效率和强对抗资格；正对外冲满载，横向/向内不产生正面鱼线力量。猫力先按每位参与者的个人蓄力折算并相加，再乘竿向杠杆和持竿移动修正；鱼体力仍按既有平静/挣扎、张力和性格倍率消耗。猫体力不再按鱼力量反推，而按个人当前蓄力结算。只有 `LineLoad` 连续达到性格阈值和确认时间才进入下表的强对抗重大裁决。

判定表（向外游+拖 按 ①→④ 顺序，先命中先生效，取等从严）

| 鱼状态 | 操作 | 条件 | D | 资源 | 结局 |
|---|---|---|---|---|---|
| 平静/向内游 | 左键拖 | 本步进入带载牵引 | 鱼自由位移后叠加有限向内牵引 | 鱼按平静档；猫按个人蓄力消耗 | 低消耗收线窗口 |
| 平静/向内游 | 右键松线 | L < L_max | D 按真实游向变化；仅外游超过线端时 L_paid 跟随 | 无 | 鱼自由游动/向内形成垂线 |
| 发力 | 左键拖 | 强对抗① 钓组承载 ≤ min(猫力,鱼力) | 不变 | — | 断线，鱼逃；鱼竿仍可用 |
| 发力 | 左键拖 | 强对抗② 鱼力 ≥ 猫力 | 不变 | — | 拖下水，鱼逃 |
| 发力 | 左键拖 | 强对抗③ 猫力 ≥ 鱼力×2.0 | 保留死亡瞬间位置 | 无 | 碾压，鱼力竭侧翻 |
| 发力 | 左键拖 | 强对抗④ 其余 | 鱼自由位移后受锁线/有限牵引约束 | 鱼按挣扎档；猫按个人蓄力；鱼线磨损×`LineLoad` | 僵持 |
| 发力 | 左键拖 | 未达到强对抗阈值 | 按 `(1-LineLoad)` 叠加有限牵引 | 鱼按挣扎档；猫按个人蓄力；鱼线磨损×`LineLoad` | 角度收线窗口 |
| 向外游 | 主位力量归零/右键松线 | D < L_max | L_paid 被鱼带到新的 D | 无辅助捣乱时主位体力 +3/s | 自由带线、喘气 |
| 向外游 | 右键松线 | D 到达 L_max 后继续外冲 | 截在 L_max | 恢复张力消耗 | 已无线可放，进入对抗 |

实时合力与体力（每秒）：`总猫力 = 主位基础力量×主位蓄力 + Σ(辅助基础力量×辅助蓄力)`，主位蓄力上限 1.0、辅助上限 0.75；主位体力消耗 `10×主位蓄力×持竿成本倍率`，每位辅助消耗 `10×1.5×自身蓄力`。主位蓄力为 0 而辅助仍发力时，主位额外支付全部辅助当前消耗的 50%，且不获得放线恢复。本场鱼线耐久仍按鱼力、`LineLoad` 与当前档位磨损；鱼体力仍按实时有效猫力与 `BaseDrainMultiplier/StruggleDrainMultiplier` 结算。
归零优先级：鱼体力 → 猫体力 → 本场鱼线耐久。鱼线耐久归零产生 `LineBroken`，只结束当前会话并释放占用，不修改鱼竿 `bBroken`；鱼体力结算后 ≤ `FishExhaustionThreshold`（当前 0.5）会吸附为真正的 0，并切入 `ExhaustedReel`。鱼在同一权威帧侧翻且不再挣扎；玩家继续按住左键时，服务器把鱼逐步收至竿尖表面投影，最多到该点并生成可拾取鱼。投影 XY 不校验是否仍在 WaterRegion 内，Z 取水面与竿尖下方地面中较高者。

## 6. 收鱼
- 抄网 = 权威装备；当前开发期服务器默认给每名玩家一份 `StarterScoopNet` 并自动选中，正式版关闭临时开关后再从商店/奖励获得；有效长度取全局 `ScoopReachCentimeters` 与抄网 DA 射程的较小值
- 可抄：鱼已上钩且进入“水平抄网线段 ∩ 鱼目标圆”范围；活鱼/翻肚均可，鱼的剩余体力不参与判定
- 带网：F → 范围、站位、视线和装备校验通过后直接叼嘴里；挥空仍受 3s 冷却
- 无网：鱼体力耗尽翻肚 → 收至竿尖表面投影 → E 拾取，必中，先到先得
- 碾压同样进入力竭侧翻与收近路线，任何猫都可拾取最终物品
- 翻肚 30s 苏醒逃跑尚未实现（TODO）
- 多人：服务器先处理者先得到嘴叼世界鱼；其余各自受 3s 冷却，冷却中 F 无效
- 两轨记录：渔获归抄/拾者；图鉴首钓与个人纪录归上钩钓手
