## 1. 一竿流程与准备

猫带着装备来到水边准备钓鱼。

备装 → 可选打窝 → 抛竿 → 等待／试探 → 真咬／提竿 → 搏斗 → 收鱼／失败。

岸边只能切换已经带出的物品；换饵与窝料的具体操作归交互总规。

抄网与鱼护均非必带。准备由各玩家独立进行。

装备即状态——手持鱼竿即钓鱼待机，不设模式键；准备态可走动、瞄准、切饵；收竿或换手持物退出（搏斗中不能直接退，走 [主动放弃](#abandon)）。

开始前读取[道具与角色输入](#input-role)。叼鱼限制见[叼鱼态](#mouth)，操作封闭边界见[鱼饵与主动道具](#bait)。

## 2. 打窝、等待与抽鱼

<a id="nest"></a>

### 2.1 窝点、投放与补窝

一把窝料往这片水里添一批鱼。

窝点维护 `{X腥, P香, J酵}`，每格表示窝点里对应偏好鱼的条数。打窝是向窝点增加对应偏好的鱼；腥、香、酵保留为分类名称。腥对应虫虫、小鱼干等食物，香对应谷物，酵对应发酵果实或谷物，猫靠嗅觉辨别。

配置和投放量按整数表达。原文称“正整数”，但材料自己的投料示例含零，故允许零分量；负值投料没有出处。存量恒为非负整数：每格永远是整条鱼，不存在半条。衰减产生的小数在衰减那一步就地向下取整，见 [游走衰减](#decay)。

窝点是以首次窝料落点为圆心的圆形区域，半径 5 米（快照，参数页为准）。初始存量为首次投料的三属性增量。服务器维护共享存量，同窝点所有浮漂读取同一份数据。

新投料的落点在已有窝点圆内，向该窝点加算存量，沿用原圆心和半径；否则新建窝点。浮漂按实际落点归属；落在相交窝点内，选圆心最近的窝点。

几何归属统一一条规则——近者优先（比圆心距离）、等距早者优先（创建序号小者）、边界算内（≤半径），投料并窝与浮漂归属共用。

`新存量 = 旧存量 + 本次投放增量`。多人可以叠加，没有设计上限；代码可保留正常游玩碰不到的工程安全夹，但不能把它当作游戏容量上限。

窝料投掷与抛竿同构（09-08 李前臻拍）：点击定点、无蓄力、无散布，点哪落哪；射程挂参数页，超程提示够不到；投到岸上＝窝料成掉落物可捡回。落点指示的画法归张佳。投料落水泛涟漪、出现鱼影。

叼起携带的窝料再次抛入，执行叠加，不重置衰减计时器。补窝的“任何时刻”受道具总闸门约束：正在搏斗的猫不能主动掏窝料；其他处于可用道具状态的玩家可以为同窝补料。物品操作和被动效果边界见 [鱼饵与道具闸门](#bait)。

<a id="timer"></a>

### 2.2 每漂独立计时

窝里的鱼让等待变短。

`Total = X + P + J`，单位是鱼的条数。咬钩间隔仍按下式计算：

| 条件 | 基础间隔 |
|---|---|
| Total > 0 | T_base = 15 秒（快照，参数页为准） |
| Total = 0，含落点不在任何窝点内 | T_base = 120 秒（快照，参数页为准） |

`T_actual = T_base / (1 + Total/K)`，`K = 100`（快照，参数页为准）。为使比值无量纲，K 与 Total 使用相同的存量单位。Total 增大时 T_actual 趋近于零，在有限非负存量下不等于零。

计时器挂在浮漂上，每漂独立。存量因补窝、游走衰减或钓走扣减改变后，按 `新剩余时间 = 旧剩余时间 × 新间隔 / 旧间隔` 折算，不重开完整计时。

验算：Total 为 100 时，`15/(1+100/100)=7.5 秒`；补到 200 后间隔为 `5 秒`，原剩 `3 秒` 折成 `3×5/7.5=2 秒`（快照，参数页为准）。

切档断层判为有意设计——`T(1)≈14.85 秒` 对 `T(0)=120 秒` 的 8 倍悬崖是「窝空了，补窝或走人」的强信号，重要状态就该可感知；不加平滑、最低间隔或保底，`120` 挂参数页可调。原 `Total<1` 清零的执行边界见 [游走衰减](#decay)。（快照，参数页为准）

<a id="draw"></a>

### 2.3 抽鱼与扣减事务

窝里抽中的鱼当场离开存量。

某个浮漂计时到点，执行一次原子事务：读取该浮漂主人当前挂的饵 → 按当刻属性占比选类 → 按该饵权重选鱼 → 当场扣 1 条库存。主人由到点浮漂确定；不先为窝点抽一条公共鱼再比较各人的饵，也不在多个饵命中的玩家间随机分钩。（快照，参数页为准）

沿用已有两步选鱼的结构：Total 大于零时，先按 `X/Total、P/Total、J/Total` 选偏好类别，再在该类别的候选鱼中按这位漂主当前饵的偏好权重选择鱼种。目标饵权重高，非目标饵权重低但不为零。鱼种分布、可出现条件及在场协作能力过滤由鱼册提供；稀有度本身不作为一般抽鱼概率。Total 为零时从无窝料基础池选择，基础池同样消费当前饵的偏好权重。

验算：`{20,50,30}` 的 Total 为 `100`，三类概率为 `20/100=20%、50%、30%`，和为 `100%`（快照，参数页为准）。本例仅验算类别分布，不冒充鱼种权重表。

钓走一条鱼，从它偏好的那一格扣一条；例如钓走腥鱼，`X←X−1`，P、J 不变。随后重算 Total、属性占比与浮漂剩余计时。示例 `{20,50,30}→{19,50,30}`，Total 为 `99`，占比变为 `19/99≈19.1919%、50/99≈50.5051%、30/99≈30.3030%`，间隔变为 `15/1.99≈7.537688 秒`（快照，参数页为准）。

小数问题已消解：存量恒为整数，`0.6 条` 这种状态不会出现，扣成负数也不可能。基础池不扣存量——它是空窝兜底体验，不是资源。（快照，参数页为准）

库存扣点＝抽中——抽与扣同一原子事务，抽中即受惊离窝：无论后续试探跑鱼、空竿、鱼逃、入夜中断，一律不回滚（新手试探期乱提竿＝惊跑一条鱼，惩罚可读且符合钓鱼直觉）。饵扣点＝真咬成立不变（试探期提竿不损饵）；饵的两个作用分离——种类权重在抽鱼时消费，数量在真咬时扣当时挂着的那 1 份。同窝多漂同刻按服务器时间戳判序（复用[服务器判序](#order)）；扣在抽中、原子执行，透支与预留、回退机制均不存在。A 漂抽走最后一条后，B 漂到点时 `Total=0` 自然落基础池。（快照，参数页为准）

时间戳完全并列的席位序约定见[服务器判序](#order)。鱼候选输入见[鱼候选与实例](#input-fish)，空候选和零权重保持未定。

<a id="decay"></a>

### 2.4 游走衰减

窝里的鱼会随时间逐批游走。

每 30 秒统一执行 `新存量 = 旧存量 × 0.9`，对应鱼自己游走，单次减少 10%（快照，参数页为准）。不再解释为气味消散。

取整规则：衰减逐分量计算后向下取整，`新存量 = floor(旧存量 × 0.9)`。存量因此恒为整数，不存在半条鱼，[抽鱼与扣减](#draw) 的“扣成负数”也不可能出现。（快照，参数页为准）

旧稿的“Total 小于 1 强制归零”不再需要单列：`1 → floor(0.9) = 0`，向下取整自带归零。（快照，参数页为准）

为什么不用四舍五入：`1×0.9=0.9→1`、`2×0.9=1.8→2`、`5×0.9=4.5→5`，任何不大于 5 的分量都是不动点、永远衰减不掉，窝点将无法自然消失（快照，参数页为准）。

验算（虫虫窝 `{腥10, 香2, 酵1}`，逐分量向下取整）：`{10,2,1} → {9,1,0} → {8,0,0} → {7,0,0}`。弱分量先散，窝点会随时间变“纯”，鱼种比例向主窝料漂移；这是本规则的直接后果，不是缺陷。（快照，参数页为准）

<a id="gather"></a>

### 2.5 聚鱼时刻

均衡投料带来短时的咬钩加速。

三类存量都达到门槛后，每次投料独立判定触发；触发后加快咬钩、鱼群密度演出增强，衰减继续，期间投料不重复触发。聚鱼按**合作奖励**定位（09-08 李前臻拍）：门槛不为单人下调，单人携带量天然凑不齐三类是有意设计。

| 参数或效果 | 原文范围与建议快照 |
|---|---|
| 每类门槛 | 30—50 条；原总结建议 30 条（快照，参数页为准） |
| 每次合格投料基础概率 | 5%—10%；原总结建议 8%（快照，参数页为准） |
| 持续时长 | 30—60 秒；原总结建议 45 秒（快照，参数页为准） |
| 咬钩速度倍率 | 2—3 倍；原总结建议 2.5 倍（快照，参数页为准） |
| 冷却 | 3—5 分钟；原总结建议 4 分钟（快照，参数页为准） |
| 品质加概率的意图 | +2%—3%（快照，参数页为准）；品质字段缺失，未具备实现条件 |
| 总存量加概率的意图 | 每 100 条 +1%，上限 +5%（快照，参数页为准）；取整及百分比叠加方式待定 |

以上建议不是已选定参数组合。验算按门槛 `30`：`min(45,52,38)=38≥30`，有触发资格；`min(45,52,12)=12<30`，无资格（快照，参数页为准）。有资格仍需概率判定，不能写成必触发。

以固定基础概率 `8%` 且不计加成、忽略触发后的冷却为纯概率例：连续 `10` 次合格独立判定至少成功一次为 `1−0.92^10≈56.5612%`，平均需 `1/0.08=12.5` 次判定（快照，参数页为准）。这不是有冷却的每分钟触发率。

冷却从聚鱼结束后起算，相邻触发最短 `45+240=285 秒`（快照，参数页为准）——`600 秒` 白天最多容纳 2 个完整 `45 秒` 窗口；首触发足够早（约 t≤30 秒）时可启动第 3 次、末次被入夜截断。

聚鱼触发只有投料一条路径，环境自然事件的触发入口不在本版、归后续版本的完整版。范围＝触发它的窝点。不加存量——聚鱼是加速咬钩的爆发窗口，消耗现有存量、自带刹车；加存量会变成投料→触发→加鱼的正反馈泵。稀有道具收益随完整版一并后置。

### 2.6 特殊窝料

特殊窝料提高特定鱼机会的意图保留。验算现有两配方：巨鱼窝 `(16,2,1)` 的腥类占比 `16/19≈84.2105%`，虫虫窝 `(10,2,1)` 为 `10/13≈76.9231%`（快照，参数页为准）；这只能证明偏好类别分布不同，不能证明同一腥类内大鱼获得额外权重。

<a id="cast-net"></a>

### 2.7 渔网与死水

一张渔网从窝里一次捞出一批鱼。

渔网是一次性道具，按落点所在窝点的当前概率构成抽取 5—8 条鱼，稀有不额外加权、湖心巨影永不入网；产出落地，先到先得拾取。使用后该窝点进入 30 秒死水，所有浮漂咬钩计时挂起（快照，参数页为准）。渔网产出不扣竿的基础磨损。

渔网扣存量——产出逐条按抽中鱼的偏好属性扣，复用 [抽鱼与扣减](#draw) 钓走扣法；实际条数 `= min(5—8 的 roll, 当前 Total)`，池里不足不凑数；无窝点／空池撒网允许，按基础池低保 `1—2 条` 小杂鱼（快照，参数页为准），不扣（基础池无账，与 [抽鱼与扣减](#draw) 一致）。死水结束后咬钩计时按[独立计时](#timer)的折算规则恢复。死水期内再撒网**不禁止**（09-08 李前臻拍）：第二张网正常结算（min 封顶照常保护存量），死水计时重置为 `30 秒`、不叠加。

## 3. 抛竿与提竿

<a id="cast"></a>

### 3.1 抛竿与浮漂落点

猫朝选中的水面甩出浮漂。

任意合法水边都可成为玩家的钓点。鼠标左键点击湖面目标点抛竿，无力度条、无蓄力；猫爪按竿、甩竿的动作表达保持。窝料投掷的蓄力不迁入抛竿。

站位不设合法区，岸上任意位置可抛，合法性只看落点（射程内水面即合法），斜坡礁石交给关卡碰撞。

点击位置到猫站立点距离为 D_click。`D_click≤浮漂射程` 可以抛出，超过射程提示“够不到那边”。实际落点相对点击位置随机偏移，半径由漂的精准度属性决定。

漂按种类区分，参数由挂号鱼漂表提供。偏移为以点击点为圆心的均匀圆盘，半径按漂精准度映射——精准高／中／低 ＝ `0.5／1／1.5 米`（快照，参数页为准）。偏出水面（落岸）判空竿收回、不损饵（散布是系统加的随机，不让玩家买单），重抛即可；超射程本被“够不到那边”拦截，偏移偶尔越界时落点收敛到射程圆边界。

<a id="waiting"></a>

### 3.2 等待与切饵

以实际浮漂落点按 [窝点归属](#nest) 选窝点；不在窝点内按基础池和空池间隔处理。等待期间玩家可自由活动，鱼漂随水波起伏。

不设离开判定、不自动收竿——真咬响应窗只有 `8—15 秒`，跑远赶不回来＝超时鱼逃损饵，自然惩罚已在，不再造闸。切饵：计时期间可切、不重置计时（到点抽鱼时消费当前饵的权重，[抽鱼与扣减](#draw)）；到点后再切饵无意义但无害（权重已消费），真咬扣的是当时挂着的那 1 份。浮漂归属在落水瞬间定死、不随漂移重算——归属是抽鱼数据源，动态重归属会开“漂进别人窝白嫖存量”的口子，漂移只是演出。（快照，参数页为准）

<a id="bait"></a>

### 3.3 鱼饵与主动道具闸门

无饵不能抛竿，鱼饵随抛竿挂出。咬钩前主动收竿收回鱼饵，零损失；进入咬钩后，无论上鱼、超时、放弃、断竿、落水，都消耗 1 份饵。携带 8 份对应 8 次咬钩机会（快照，参数页为准），用完回营地补给。试探期提竿不损饵，见 [提竿响应](#strike)。（快照，参数页为准）

从咬钩判定成功到本竿结局落定，禁止主动掏用道具；抄网是收鱼出口，可正常使用；备装时预穿戴的被动效果正常结算。增效消耗同样按进入咬钩计一场，咬钩前收竿不计场。鱼体力不接受道具直接改动，猫体力道具只在搏斗外使用，竿耐久不能回补。

<a id="strike"></a>

### 3.4 响应窗口与完美提竿

完美提竿削弱这条鱼的力量和体力。

正式咬钩有试探、真咬、完美响应窗。演出时序（09-08 李前臻拍）：抽中瞬间鱼影出现（按真鱼体型）→ 浮漂轻点进入试探期（时长挂参数页）→ 漂猛沉即真咬并给提示。试探期提竿必空竿、不损饵，空竿揭图鉴剪影；错饵摆尾演出删除。真咬后的响应时长按鱼种为 8—15 秒，前 1 秒为完美窗；采用服务器时间戳，客户端预表现（快照，参数页为准）。

| 提竿结果 | 规则 |
|---|---|
| 完美 | 普通鱼力量乘 0.8、体力乘 0.85；稀有鱼力量乘 0.85、体力乘 0.9（快照，参数页为准） |
| 普通 | 完美窗后、响应窗结束前提竿，正常进入遛鱼 |
| 超时 | 响应窗结束仍未提竿，鱼吐钩逃跑，饵已消耗 |

验算：以力量、体力各 `100` 为测试输入，普通鱼削后为 `80、85`，稀有鱼为 `85、90`（快照，参数页为准）。这是两个资源的削减，不能变成一次额外伤害或只减某个临时速度。

字段三处一名——鱼册「力量」＝`F_fish`＝判定「鱼力」，同一个数；完美削减在入场时直接乘到本场实际值，此后运动求解、K_over、消耗公式、碾压 2 倍判定全用削后值（临界鱼可被完美推进碾压区，`F=40` 削后 `32`，猫 `65` 由不碾压变碾压，奖励自然放大）；恰 `1 秒` 算完美——`≤1 秒` 闭区间，边界取对玩家有利侧。（快照，参数页为准）

## 4. 搏斗与退出

<a id="resources"></a>

### 4.1 资源与有效力量

| 量 | 含义与数据出处 |
|---|---|
| 猫体力 | 基础上限 100 点，成长接口归猫册（快照，参数页为准） |
| 猫力 | 当前猫力量；品种基准普通／橘／狸花／缅因为 50／70／90／130（快照，参数页为准） |
| 鱼体力、鱼力量 | 鱼种及实际重量相关字段由鱼表提供；鱼体力保留，翻肚依赖它 |
| 竿耐久 | 动态资源，三档上限 40／70／120（快照，参数页为准），归零断竿 |
| 竿强度 | 静态配置，三档 25／60／210（快照，参数页为准）；瞬断规则见[强度检查](#strength) |
| D | 鱼到猫的距离；初始为浮漂实际落点到猫的距离 |
| 鱼岸距 | 鱼到岸的距离，专用于可抄判定，不能用 D 替代 |

`F_total` 表示本次对抗的有效总力量；无辅助时取持竿猫当前力量。`K_pos` 表示参与者消耗倍率；单人恒为 `1.0`（快照，参数页为准）。扩展只提交力量和角色倍率，瞬断、碾压、鱼体力扣减及猫体力消耗由本章统一计算。

当前力量 ＝ 猫种基础力量 × 成长加成，不随体力衰减——体力低不降力量。操作不改力量（操作是运动学输入）。

<a id="strength"></a>

### 4.2 强度检查与碾压

鱼竿要先扛住鱼和猫的拉力。

竿耐久与竿强度不能混称。竿强度瞬断保留——多人口径统一为 `竿强度≤min(总力量,鱼力)` 即断（张力由两端较小者决定），检查先于碾压（序见本节下文）；它是挑战巨影的装备门槛，参数页 v0.8「巨影 K5＋竿强 210」的挂号数值以此为锚（快照，参数页为准）

左键拖、右键放。由猫力与鱼力、鱼的方向和猫的操作方向共同决定结果；猫力达到鱼力的 2 倍可碾压飞鱼，否则进入搏斗（快照，参数页为准）。碾压是瞬时判定——只在搏斗开始时与合力变动时（辅助加入或退出、换人）检查；检查序为 ①竿强瞬断 → ②碾压 → ③常规搏斗，碾压达标立即飞鱼、跳过或中断搏斗循环，不是搏斗中的持续状态。本章力量比较统一使用 F_total。飞鱼进入岸上待拾取状态，不能直接把渔获放进主钓手库存。

W＝前移（靠水）、S＝后退（离水），钓鱼中不翻转。力量相近使用比值 `0.8 ≤ 猫力/鱼力 ≤ 1.25`，取等入相近档；与碾压线 `2.0` 之间为猫强，三档互斥穷尽（快照，参数页为准）。多人代入本章有效总力量。

<a id="behavior"></a>

### 4.3 鱼行为与运动输入

临时骨架：上钩初始向外游；向外发力与向内低强度游动（演出名「休息」，意图速度仍非零，见 [搏斗消耗](#cost)）按鱼种时长区间交替；鱼体力低于 50% 后休息期变长（快照，参数页为准）。鱼体力通过挣扎激烈程度与头顶漩涡提供可读线索。

最近冲岸距离按鱼种／食性配置。食肉中鱼黑鱼、河口鲈活着不进离岸 `1.5 米`；森林长尾鱼、银月鳟可进入可抄圈，小鱼可近岸（快照，参数页为准）。完整鱼种阈值表未导出，冲岸距离列尚未建。

鱼行为输入与审核边界见[行为与运动接口](#input-behavior)。演出名“休息”不表示意图速度归零。

<a id="cost"></a>

### 4.4 搏斗消耗、移动附加与磨损

猫顶住鱼的游动会消耗搏斗体力。

`C_battle = ΔD_blocked × (1+V_fish/V_base) × (F_fish/F_base) × K_dir × K_over × K_pos × R_base`（快照，参数页为准）

- `ΔD_blocked`：被抵消的意图游动量——每 tick 运动求解按玩家操作（放线＝线不绷；收线／顶住＝线绷紧）与力量对比解出实际位移，`ΔD_blocked = ΔD_intent − ΔD_actual`，是运动求解的副产物。消耗是「抵抗鱼做功」。翻肚前鱼的意图速度恒不为零——它总在往一个地方游，不存在「鱼歇」状态；零消耗只来自你不抵消（放线，或顺着它的方向走）。顶住（僵持）＝全额抵消照扣；被拖走的部分不计费（被拖的惩罚在位置危险，不在体力）。意图归零即翻肚，搏斗结束、进 [翻肚拖岸](#belly) 拖回。
- `K_dir = f(θ)`：θ 为鱼意图方向与逃离方向（鱼→猫连线的反向，非岸法线）的夹角，连续函数、运行时计算。锚点 `f(0°)=1.0`、`f(180°)=0.2`，建议 cos 线性插值 `0.6 + 0.4·cosθ`（曲线挂参数页）。原「向外／横向／向岸 1.0/0.5/0.2」三档由本曲线替代（横向在本曲线下为 `0.6`，非旧值 `0.5`），横向分类不再需要。（快照，参数页为准）
- `K_over`：超载因子 `min( max(1, F_fish/F_total), 1.5 )`（封顶挂参数页）——力量不够还硬顶时按力量比付超载惩罚，旧表猫弱行的 `×1.3／×1.5` 恰是该比值的采样。玩家操作不再进消耗公式，只作运动学输入；验收锚点三例：放线＝0、僵持＝1.0 全额、猫弱硬顶＝×力量比。实现注意：消耗随运动求解精度走，求解抖动会直接抖体力条，需一层平滑。（快照，参数页为准）
- `K_pos`：参与者消耗倍率；单人恒为 `1.0`。（快照，参数页为准）
- `R_base`：单位「点/米」——每抵抗一米意图位移的体力换算率（快照，参数页为准）。量纲由此闭合，程序按 tick 结算位移即可。

移动消耗为 `3 点/秒×力量对比系数`（快照，参数页为准）：猫强时后退乘 `1.0`、前移乘 `0.5`；猫力相近写 `1.5`；按 S 后退另加 `2 点/秒`的猫弱行保留。前移列相近档取 `2.25`，后退列 `3 → 4.5`；挂参数页。移动附加是腿部消耗、按秒计费，与搏斗项的做功计费并行相加（快照，参数页为准）。猫弱硬顶的搏斗倍率由 K_over 计算，弱档待定项见[集中缺口](#gaps)。

两条僵持资源扣减（源文档 9.3 未接上、自备份暂留，接线待办见附录 C [open-10](#open-10)）：服务器每秒一次，`竿耐久−=鱼力×0.05`、`鱼体力−=F_total×0.08`（快照，参数页为准）。验算：鱼力 `75`、猫力 `50`，每秒分别扣 `3.75` 耐久和 `4` 鱼体力（快照，参数页为准）。

搏斗以渔获结束，每条鱼另扣基础磨损 `1 点`（快照，参数页为准）；渔网不扣。竿不可维修。

<a id="line"></a>

### 4.5 收放线与线长预算

放线用线长换取更少的搏斗消耗。

`L_max`（三档 `60/80/100`，快照，参数页为准）保留，线长经济：`L₀＝真咬成立瞬间的鱼猫距 D₀`（等待期移动不受线约束；当刻已超 L_max 则直接判脱钩鱼逃，饵已扣、不丢漂）。放线＝解除线轮锁定，不是主动出线——锁定时线长恒定、鱼拉的就是猫（张力传导，进对抗）；解锁时线随鱼的实际外游出线（`L 增长＝鱼实际位移`），无张力零消耗，无「放线速率」参数。收线主动卷回、L 回收——鱼发力时收线＝强对抗＝费体力，体力与线长互为价格，收放循环不是白嫖。线出尽（`L=L_max`）后解锁失效，张力全传猫、被迫全额对抗——「什么时候舍得放线」才成为决策。（快照，参数页为准）

放线期间不判位置落水——放线＝松开对抗，拉力不再作用于猫，「鱼向外游＋力量不足」的拖拽前提消失。「零成本规避风险」被 `L_max` 堵住：线长是放线的预算（[资源字段](#resources)），放完右键失效、被迫恢复对抗与落水风险——规避有限额，不是无代价。放线的距离变化：鱼向外时 D 增大；鱼向岸时 D 缓慢减小。

<a id="position"></a>

### 4.6 归零与位置落水

持竿猫力竭后会被拖下水。

| 条件 | 结果 | 说明 |
|---|---|---|
| 鱼体力 ≤ 0 | 鱼翻肚 | 进入 [翻肚拖岸](#belly) 拖回（朝猫方向、触岸即落）；抄取另验 [可抄资格](#netcatch)／[几何边界](#geometry)（快照，参数页为准） |
| 猫体力 ≤ 0 | 猫力竭 | 被拖下水，鱼逃（快照，参数页为准） |
| 竿耐久 ≤ 0 | 断竿 | 鱼逃（快照，参数页为准） |

鱼翻肚后进入 [翻肚拖岸](#belly) 收鱼流程。落水后果为鱼逃、饵已扣、湿身演出，嘴里原有鱼保留；断竿是器材失败。全流程不从旧多人稿引入额外落水扣耐久、维修或世界进度惩罚。

位置落水需同时满足：猫到岸距离归零、鱼向外游、总力量小于鱼力。后果为鱼逃、饵已扣、湿身喜剧演出，没有其他落水损失；嘴里原有鱼保留。猫体力耗尽仍保留资源落水出口，不能把位置条件当成免除体力归零后果的保护。

位置落水只判主钓手——被线拽的是持竿者；风险与所有权对齐（竿、饵、漂、落水全是主钓手的账）。取等不落水（鱼力须大于总力量才拖得动猫）。两出口同刻满足时体力落水优先——资源出口先于空间出口。救援不新增，维持原判。

<a id="abandon"></a>

### 4.7 主动放弃

玩家可以主动放弃本竿，进入咬钩后饵已消耗。放生了鱼…鱼饵和浮漂被带走了。

放弃输入＝搏斗中长按收竿键 `1.5 秒`（进度条 UI，松手即取消）。多人只有主钓手能放弃——竿、饵、漂的损失都是他的。图鉴按鱼逃同口径：上钩已揭的剪影保留，收集层不写（见[捕获事件](#capture)）。（快照，参数页为准）

<a id="landing"></a>

## 5. 收鱼与归属

猫叼住收来的鱼。

<a id="netcatch"></a>

### 5.1 抄网与可抄资格

抄网非必带，单一款式，无自身长度、体型上限或成功率属性。判定同时满足：对象是钩上的鱼或翻肚鱼；鱼到岸边距离小于 `1 米`（快照，参数页为准）。满足即必中，无概率抽取。自由游动的鱼不可捞；湖心巨影特例不可抄，需翻肚拖岸或碾压落岸后拾取。

抄网价值是鱼活着贴岸即可提前收鱼，不必等鱼体力耗尽。以测试距离验算：`0.999<1` 成立，`1<1` 不成立，`1.001<1` 不成立（快照，参数页为准）。不能改为按竿长、猫鱼距离、鱼重量或抄网等级判断。

<a id="mouth"></a>

### 5.2 挥网与叼鱼态

按 F 挥网，判定瞬间由服务器验证。命中后鱼由挥网的猫叼在嘴里，实物渔获归抄网者；图鉴见[捕获事件](#capture)。

没够着或对自由鱼、湖心巨影出手均挥空，被抢先也挥空；多个 F 目标并存时按视角中心选择（见[F 目标选择](#target)）；挥空猫进入 `3 秒` 硬直，无法操作（快照，参数页为准）。可归因提示沿用“没够着”“被抢先”，不可抄对象也必须能从表现识别。

嘴里只叼一条鱼，叼着不能抛竿、不能再次抄取或拾取，需先放入鱼护或扔下。鱼护非必带；不带的猫也能按此处置继续钓。落水保留嘴里原有的鱼。

<a id="belly"></a>

### 5.3 翻肚拖岸与拾取

不带网时，耗尽鱼体力令鱼翻肚，继续拖至岸上，再按 F 拾取；拾取必中，鱼叼进拾取者嘴里，实物归拾取者。岸上的鱼所有猫都能拾，先到先得；钓手既得图鉴登记不因被别人拾走而取消。

水里翻肚的鱼超过苏醒时限仍未上岸即苏醒逃跑；时限为配置项，表里填，默认 `30 秒`，拖动中计时照走。拖上岸或碾压甩上岸之后不再苏醒逃跑，但地上未拾取的鱼翻天消失，不能据“离水安全”跨天囤鱼。（快照，参数页为准）

翻肚后收尾只有一条运动规则——鱼沿鱼→猫方向（每 tick 取当前值）以固定速率拖动，触岸即在碰岸处落地（速率建议 `2 米/秒`，快照，参数页为准）。猫可边走边收，鱼始终朝「猫当前位置」被拉，无对抗即无消耗；「D 归零」的旧说法删除——D 只属搏斗阶段，收尾不看它，「最近岸线点」目标计算也不需要。苏醒倒计时在拖动中照走（有效救援半径＝速率×时长≈60 米，远钓大物自带一点「拖得回来吗」的张力）。落岸不等于自动入袋，最后仍要按 F 拾取。（快照，参数页为准）

<a id="order"></a>

### 5.4 所有猫收鱼与服务器判序

所有猫均可抢同一条可抄鱼，也可抢拾同一条岸上鱼。以服务器收到指令的时间戳判先到先得，第一个有效命中者获得实物，其余竞争者挥空、各自进入 `3 秒` 独立硬直（快照，参数页为准）。硬直中再次按 F 无效，提示“爪子还在麻”。

时间戳完全并列时按房间席位序（加入顺序早者先）打破，确定、可复现。同一 tick 的事件结算序固定为收鱼 → 苏醒 → 落水——玩家利益优先：同刻收鱼＋落水时鱼先进嘴（落水保留嘴里的鱼），到手的鱼不被同刻落水吞掉；苏醒指水中翻肚鱼的苏醒逃跑（[翻肚拖岸](#belly)）——同刻被有效收取的鱼不再苏醒。不能用客户端帧数替换服务器时间戳。

席位序是加入房间的先后顺序。此处三事件顺序只处理收鱼、苏醒、落水，不扩展为换人、献祭和离局的全局优先序。

<a id="geometry"></a>

### 5.5 几何边界与 F 目标选择

鱼位于可抄边缘时，以服务器物理碰撞箱中心确定鱼的位置，并对鱼岸距使用 [可抄资格](#netcatch) 的严格小于判定。挥网者侧补条件——挥网者到鱼 ≤ 1.5 米才算够着，超出＝挥空「没够着」；`1.5 米` 同时是落岸鱼的可拾距离，全游戏统一交互半径、参数页一处管全部。不加朝向或扇形判定（挥空有 3 秒硬直，误判代价高，距离圈够用）。岸线测距＝对象到最近岸线点的直线距离，水岸边界由关卡碰撞数据给出。（快照，参数页为准）

<a id="target"></a>

#### F 目标选择

F 的目标选择按视角中心：距离 `≤1.5 米` 只是资格门槛，多个合法目标同时在圈内时，F 作用于玩家视角中心所指的那个。UI 以准星态提示当前 F 目标。（快照，参数页为准）

<a id="capture"></a>

### 5.6 捕获事件与实物归属

图鉴按两层制：剪影层在上钩成立即揭、永不撤销（空钓／错饵摆尾同揭）；收集层（名字、彩色立绘、出没区域、个人最佳重量）在成功收鱼时写入、归属上钩者——实物被队友抢走不取消登记，鱼逃／放弃／中断则收集层不写、剪影保留。「上钩成立」是归属基准，不是收集层的写入时点；此后吃、献、被偷不撤销记录。重量没有组队加成。

## 6. 外部接口与生命周期

<a id="harvest-output"></a>

### 6.4 渔获与消费交接

抄取或拾取→嘴里→可选鱼护暂存→带回营地共用大鱼缸，再选择去向；亦可先按叼鱼态规则扔下。当天扔下等于赠送路径，谁都能捡；物品不能扔进湖里。翻天时，地上未拾取的物品一并消失，原“清晨自动回营”作废。

吃、献、卖、留缸观赏是渔获用途概览。经验、供奉、卖价与容量由接收册处理，钓鱼输出同一条鱼的鱼种、实际重量、上钩归属与实物持有人。上钩事件与成功收鱼事件分别对应[捕获时点](#capture)。渔网直接产出落地鱼，来源不含竿上钩过程。

转存接口需区分成功与拒收；满容器不得当作转存成功。鱼实例标识、接收确认、重复提交及拒收后的具体状态尚无已裁工程实现，见[接口待明确项](#interface-open)。鱼护容量、跨天保存资格和鱼缸升级属于外部输入。

<a id="lifecycle"></a>

### 6.5 生命周期输入与状态转移

入夜停止新咬钩。

| 外部信号／阶段 | 钓鱼侧行为 | 损益与未裁边界 |
|---|---|---|
| 入夜 | 入夜后不再产生新咬钩；还没咬钩的浮漂剩余计时一律清掉，不冻结、不跨天续用；进行中的搏斗允许打完 | 试探、真咬待响应的逐态映射及同刻抽鱼顺序未定；不扩大“搏斗可打完”的范围 |
| 强制中断（献祭互动等） | 献祭互动强制打断进行中互动；按抽扣时点结账 | 试探中收竿退未扣饵，已抽库存不回；真咬后按鱼逃、不回滚、不丢漂；已揭剪影保留、不记捕获。与收鱼、断竿、换人同刻关系未全定 |
| 正常翻天完成 | 窝点翻天清空；旧浮漂剩余计时不跨天；地上未拾物品按世界清理消失 | 聚鱼活动／冷却、死水及其他局日瞬态清理时点待明确；容器保存资格不等于地面物清理 |
| 下一轮钓鱼开放 | 从新的准备与打窝流程开始；不恢复昨天咬钩倒计时 | 开放信号由局与进程提供；不以本地时钟推算任务人数 |
| 局结束 | 停止钓鱼；释放窝／漂／搏斗等本系统瞬态，已输出捕获事实不因失败撤销 | 毕业上供不翻天，失败立即结束、不进结算夜；两者均需局结束出口。具体释放时序待接口接线 |

基础抽扣唯一依据为[抽鱼与扣减事务](#draw)。钓鱼只消费中断与开放信号，不判断祭坛全员到齐、不计算每日目标。

## 7. 信息与反馈

规则提供事件、状态、目标和可见范围；动作表现集负责素材。动作不额外改变既定硬直时长与鱼归属。鱼向岸“休息”为演出名；力量差、鱼体力、线长余量和角色反馈阈值尚待确认。

<a id="signals"></a>

### 7.1 必须可感知的操作反馈

| 场景 | 提示或表现 |
|---|---|
| 抛竿 | “左键点水面 → 猫甩竿” |
| 鱼向岸休息 | 状态文字变绿：“鱼累了！按住左键拖回来！”；猫耳朵竖起、尾巴甩动 |
| 鱼向外发力 | 状态文字变红：“鱼在发力！放线喘口气，拖线就是硬拼！”；具体回复数值见[集中缺口](#gaps) |
| 鱼可抄 | 屏幕中央爪印图标＋“快抄！（按 F）”，必须通过[收鱼资格](#netcatch)判定 |
| 猫体力偏低 | 体力条变红闪烁＋“猫喘气了！”与喘气表现 |
| 落水危险 | 爪扒地划痕＋“要滑下去了！”，不承诺未实现的拽尾巴救援 |
| 完美 | 金色水花＋瞳孔放大＋“完美！”（瞳孔口径仍待核对，见[集中缺口](#gaps)） |
| 断竿 | 咔嚓声、爪里只剩半截竿、猫愣住 |
| 鱼逃 | 耳朵耷拉、水面恢复平静 |
| 挥空 | 猫拍空或被绊、沙漏图标＋“爪子麻了！” |
| 主动放弃 | “放生了鱼…鱼饵和浮漂被带走了” |
| 碾压 | 鱼落身后草地、猫翘尾巴，仍需拾取（保留待核） |

铃铛漂咬钩为叮铃声，鱼发力为线绷紧的嗡声，鱼休息时拍水声减弱；竿断为咔嚓，落水为扑通加喷嚏。

基础咬钩信号应让漂主远距离感知，包含声音、身体语言与震动通道；铃铛漂增强为全场可闻。

<a id="visibility"></a>

### 7.2 世界可见性

鱼影保留世界内表现，附近玩家都能看见；鱼影按已抽定那条真鱼的体型演出，只让人感知有鱼及大致体型，不能据影认出鱼种。

窝点猫爪标记全队可见，范围、鱼量通过光环、粒子、鱼影粗略表现，不直接显示存量数字。标记读窝内 Total 的**浓／中／淡三档**（阈值挂参数页），不表达剩余时间——衰减模型没有「剩余时间」字段，模糊浓淡即口径（09-08 李前臻拍），张佳按三档做表现。

队友装备通过身上、手里、嘴里的世界表现及凑近闻来了解。

猫的耳朵、尾巴、瞳孔、炸毛需在半个湖外仍能辨读。落水、拍空、被绊都好笑不惨。线的松紧、竿身弯曲表达张力；窝点范围与鱼量只粗略表现，鱼影不暴露具体鱼种。队友装备通过世界表现可见，不能新增查看装备菜单。

<a id="presentation"></a>

### 7.3 表现责任与回审

真咬、完美、危险、可抄、挥空、落水和断竿等事件由钓鱼提供，动画／音效由动作表现集接收。鱼向外发力的猫前滑、爪扒地、耳朵后压与瞳孔收缩，力量与低体力信号必须保持可读。猫体力偏低的旧提示阈值低于 30%（快照，参数页为准）。挥空表现不得改变既定硬直。素材细目转交动作表现集，原文在迁移对照表中逐项定位。

修改任务曲线、卖价、容量或动画素材只变更其所属数据与资产；改变鱼意图含义、力量单位、命中帧、可操作时刻或生命周期顺序须回审对应接口。
