本分册范围：局内昼夜与天气（雨 / 雾 / 晚霞 / 月光）、河流与森林湖双区域的探索结构、自然事件（彩虹 / 萤火虫 / 鱼群等）、看花观鸟的等待体验；环境对鱼情与猫咪状态的修正入口；森林湖草药等采集点的分布点位。时间一律为**局内时间流**（无现实时间同步）；「营地环境改造」随营地建设删除，收缩为一条轻量种花提案（见 §3.1-6）。本册是印记相册的重要素材场——环境印记撑起篝火回看的「风景页」，每个自然事件都显式标注是否抛印记事件。

## 1. 设计意图

### 1.1 北极星贡献

- **惊喜的发起者（热闹）**：自然事件是全队放下手头事、聚到一起的天然号角——「都过来看！」由世界主动喊出，不用任何任务指令。
- **印记的素材场（回看）**：特殊天气、自然现象、鱼群事件，让玩家产生「那天我们一起遇到了……」这样的记忆。
- **支撑探索与发现**：森林湖特殊事件、风景点、隐藏观察点，鼓励玩家主动观察世界，而不是只追求效率。
- **治愈的底色（不抢戏）**：光照、水声、风声铺在热闹底下；等待与看花观鸟的安静时刻由环境接住。让湖畔不是静态地图，而是持续发生变化的空间——让人愿意一局一局回来。

### 1.2 体验设计

**体验一 · 这一局的湖畔有自己的一天**：🎯 一局像过完湖畔的一天，从开局到篝火有光线与气氛的完整旅程。🛠️ 局内时间流——开局即起点，昼夜与天气随局内时钟推进，不读现实时钟；天气产生视觉和声音变化。🔍 结构成立。局内时间流顺带消解了旧方案「时间流速过快会错过事件」的压力：事件跟局走，全员同局同时可见，这局没赶上下局还会来，不存在「没上线就错过」。缺口：一局时长与昼夜节拍的匹配归数值阶段。

**体验二 · 世界会主动给玩家惊喜**：🎯 玩家通过观察世界发现变化。🛠️ 森林湖鱼群事件；彩虹、萤火虫等自然现象；鸟群、水面变化等环境反馈。🔍 达成度较高。副作用沿自原稿：事件过少会降低期待，过多会影响日常节奏——用「少量高价值事件」原则约束。

**体验三 · 探索比效率更重要**：🎯 提供非资源目标。🛠️ 河流负责日常生活，森林湖负责发现；沿途风景点、观察点、特殊植物与草药采集点。🔍 中高。探索奖励不足时玩家仍可能回归效率路线——环境事件抛出的印记是主要的非资源奖励。

（原稿体验「玩家拥有属于自己的自然空间」已随营地建设删除移除：无摆放装饰、无景观改造；个性表达由猫外观、图鉴与照片承接。剩余的种花可能性见 §3.1-6 取舍建议。）

### 1.3 玩家策略路线

- **日常生活型**：在河流边钓鱼，欣赏环境变化——稳定、休闲。
- **探索发现型**：前往森林湖，等待特殊事件，寻找隐藏观察点，顺路采草药——追求未知和惊喜。
- **多人事件型**：招呼全队参与鱼群事件、一起看彩虹晚霞，共同推进祭坛目标——追求共同经历。

### 1.4 设计禁区

- ❌ **复杂生态模拟**——破坏开发资源和核心体验。替代：少量高价值自然事件表达生命感。
- ❌ **高压力天气系统**——破坏治愈与自由。替代：天气只提供氛围与鱼情机会（如雨天某些鱼更活跃），不做惩罚。
- ❌ **大规模地形改造**——湖畔是固定舞台。
- ❌ **环境强制影响玩家进度**——环境提供机会，而不是制造阻碍。
- ❌ **任何机制读现实时钟**——时间源只有局内时间流。

## 2. 核心循环

开一局，湖畔的一天从头开始（待定：起点时段）
→ 光线与天气随局内时钟推移，鱼情跟着变
→ 自然事件按时段登场，「都过来看」把散开的玩家聚拢
→ 事件里钓鱼、扑萤、围观、抓拍进印记
→ 天色沉下来，回营地篝火收尾（衔接营地册）
→ 局末环境状态随局清空；带走的只有图鉴与照片，下一局又是新的一天

## 3. 机制清单

### 3.1 设计意图核心

**1. 局内时间流（昼夜循环）**
设计意图：给一局一个「今天」的形状——开局有清晨的新鲜，收尾有夜晚的余味；建立世界陪伴感。
机制：时钟源为局内时间流，开局启动、随局推进、局末即弃；无现实时间、无离线概念。昼夜改变光照、环境音、鱼情修正（供钓鱼册消费）与自然事件的出场时段（萤火虫只在夜里、晚霞只在黄昏）。（待定：一局覆盖一个昼夜还是多个昼夜；起点时段。）
猫味演出①：入夜全体猫瞳孔放大变圆，草丛里亮起两排反光的眼睛；清晨有猫伸懒腰打大哈欠；正午有猫找树荫瘫成一滩。
抛印记事件④：昼夜本身不单独抛印记——④由时段专属自然事件承载（晚霞 / 月光 / 萤火虫，见 §3.1-4 事件表），宁缺毋滥。
最容易破的实施陷阱：时间变化只有视觉效果，没有体验价值——昼夜至少要挂上「事件出场时段」和「鱼情差异」两件事才算数。

**2. 天气机制**
设计意图：增强情绪变化，给每一局不同的脸色。
机制：晴 / 雨 / 雾等按局内时钟切换，产生视觉和声音变化；对鱼情做机会向修正；天气是部分自然事件的前置条件（雨后出彩虹）。天气在猫身上的痕迹（淋湿 / 抖水）只做演出表现，不带数值惩罚——淋湿规范归猫册（表现型状态），本册只触发。
猫味演出①：雨天炸毛甩水；一群猫挤在大叶子下躲雨探头探脑；有猫伸爪接雨滴；雾天猫走两步就回头找同伴、尾巴竖成小旗子；雨停全员集体抖毛，水花四溅。
抛印记事件④：全员挤在一处躲雨的团子同框——抛印记。
最容易破的实施陷阱：天气成为纯装饰，没有记忆点——每种天气至少绑一个专属演出或专属事件。

**3. 双区域探索结构（河流 / 森林湖）**
设计意图：形成探索差异——河流负责日常生活，森林湖负责发现。
机制：河流是近营地的日常水域，开阔顺手；森林湖藏得深一点、要走一段路，鱼种与事件偏稀有；风景点与隐藏观察点集中在沿途与湖区。森林湖沿途与湖区设**草药等采集点**——分布点位本册持有（草药用途见猫册的晕倒解除，获取定价见装备册），给「走这一段路」多一个理由。两区域同属「湖畔」主场景。（待定：与钓鱼册钓点定义统一——钓鱼点在两区域如何分布、是否带属性差异，需与钓鱼册、鱼类图鉴册对齐；装备册「捞浮木」的水域点位一并在此统一。）
猫味演出①：去森林湖的路上有可扑的蝴蝶、可追的落叶；猫穿过草丛沾一身草籽，停下来舔毛整理；采药凑近闻会打喷嚏（演出规范见猫册）。
抛印记事件④：首次抵达森林湖——穿过树林视野豁然开朗的瞬间（单猫剪影或全队首达合影）——抛印记。
最容易破的实施陷阱：两个区域只是视觉换皮——差异要落在「能遇到什么」上：不同鱼、不同事件、不同风景、不同采集物。

**4. 自然事件机制（印记素材场）**
设计意图：创造偶然惊喜，让世界主动给全队一个聚拢的理由；本册对印记相册「风景页」的主要供给。
机制：事件按局内时钟与天气条件出场，少而精；必须远距离可感知（声音 + 光 + 猫身体语言，复用钓鱼册咬钩信号的思路），否则各玩各的没人聚拢。每个事件显式标注是否抛印记（触发写法等 C7 裁决：清单式还是规则式）：

| 自然事件 | 出场条件（局内） | 抛印记事件④ | 猫味演出① |
|---|---|---|---|
| 彩虹 | 雨后放晴 | 抛——彩虹下的全员同框 | 猫歪头看天，有猫试图伸爪去够 |
| 萤火虫 | 夜晚 · 草木边 | 抛——猫跃起扑萤的瞬间 | 扑空空抓；萤火虫落在鼻尖上看成斗鸡眼；追着光点转圈 |
| 晚霞 | 黄昏 | 抛——湖边一排猫剪影 | 猫不自觉坐成一排看天，尾巴尖同步轻摆 |
| 月光湖面 | 夜晚 · 晴 | 抛——月下湖面与两排反光猫眼 | 有猫对着水里的月亮伸爪拍，拍碎了愣住 |
| 鸟群 / 蝴蝶 | 白天 | 不单独抛（作演出素材融入其他印记） | 看鸟时喉咙发出咔咔咔；匍匐压低身子挪近；扑空后立刻舔毛装没事 |
| 森林湖鱼群 | （待定，见机制 5） | 抛——沸腾水面与手忙脚乱的猫 | 猫沿岸急得来回踱步，尾巴炸成瓶刷 |

最容易破的实施陷阱：事件频率失衡——过少没期待，过多冲垮日常节奏。

**5.（提案 · 待定）聚鱼时刻：两种触发源统一**
现状：本册原稿有「森林湖周期性鱼群事件」，钓鱼册（正式版）有多人叠窝触发的「盛宴聚鱼」，两者的表现与收益高度重叠。
提案：统一为一个机制「聚鱼时刻」，两种触发源——
- **玩家触发**：多人向同一水域叠加窝料（即钓鱼册「盛宴聚鱼」，规则以钓鱼册为准，本册不改动它）；
- **自然触发**：森林湖按局内时钟 / 天气条件自发涌现鱼群（本册供给）。
两种触发进入同一套演出与钓鱼收益（鱼群涌现、巨物预告、稀有概率提升）。玩家学一次就认识两个入口：「自己攒出来的盛宴」和「世界白送的盛宴」。（待定：是否采纳统一命名；自然触发的条件与频率；与钓鱼册「盛宴稀缺性约束」共用一个稀缺预算还是各算各的——需与钓鱼册对齐后定稿。）
猫味演出①：水面开始沸腾时，全场猫耳朵齐刷刷转向同一方向；奔向水边的猫急刹不住，前爪撑地滑出一段；到岸边挤成一排探头，尾巴集体竖起轻抖。
抛印记事件④：抛——全队奔向同一片水域的场面。
最容易破的实施陷阱：两套鱼群各写各的逻辑——玩家学两遍，程序做两遍。

**6.（取舍建议 · 待定）种花：轻量环境交互，不是建造**
背景：原稿「营地周围环境改造」（种花 / 摆放装饰 / 改变景观）中，摆放装饰与景观改造随营地建设删除一并移除。
取舍建议：种花若保留，只能是环境册自己的轻量交互——固定花坛点位，种下当局开花，局末随局清空；不存档、不成长、不装修。价值点是「花招来蝴蝶蜜蜂 → 给猫可扑的东西 → 给印记加布景」，定位是氛围道具而非建造玩法。本册建议：砍掉也可接受（表达欲已由猫外观、图鉴与照片承接）；若美术余量允许再做，优先级排在自然事件之后。（待定：保留与否。）
猫味演出①（若保留）：猫埋种子刨土刨得满脸土；对着刚开的花打喷嚏；扑花间蝴蝶压倒一片花。
抛印记事件④（若保留）：花丛里滚作一团扑蝶——可抛。

### 3.2 实施考量

- 环境丰富度 vs 开发成本 → 少量高价值事件。
- 真实模拟 vs 游戏节奏 → 保留真实感，但服务体验。
- 随机事件 vs 可控体验 → 系统按局内时钟排程周期事件，随机只做小抖动。
- 种花自由度 vs 系统复杂度 → 由原「限制营地附近改造」进一步收缩为「固定点位轻量交互或不做」（见 §3.1-6）。
- 所有环境状态（时间、天气、事件进度）是一局的属性，局末即弃、无持久化——多人同步按局内广播做，不需要跨局存档。

## 4. 系统边界

硬性：
- 不读现实时钟——一切时间机制以局内时间流为源。
- 不做复杂生态模拟、不做生存压力环境、不做大地图环境编辑、不做天气惩罚核心玩法。
- 无跨局环境存档——环境状态跟局走，局末清空。
- **轴的定义权在本册，鱼表在图鉴册**：区域 / 时段 / 天气三条轴的枚举（有哪些区域、哪些时段、哪些天气）由本册定义；鱼落在轴上哪一格，由「鱼类图鉴」册的分布表持有——本册只提供修正入口，不写鱼表。
- 猫的淋湿、疲惫值等状态归「猫咪与状态」册，本册只触发不定义；草药的用途归猫册、获取定价归装备册，本册只持分布点位。

软性：
- 环境变化优先服务情绪；事件少而有记忆点；鼓励玩家观察世界；强化自然反馈。
- 每个新自然事件立项前先过四问④：会留下值得回看的瞬间吗——既不抛印记也没有演出的事件不要做。

## 5. 涌现案例

- 钓鱼系统（positive）：昼夜天气造成鱼情差异，给钓点选择提供理由；聚鱼时刻是环境与钓鱼的合流点。风险：环境事件过强导致玩家只等刷新不钓鱼。
- 营地（positive）：环境是营地治愈收尾的背景板——天色沉下来是全队往回走的自然信号，篝火在夜色里才显得暖（局末是否固定入夜，待定，见 §10）。
- 祭坛（positive）：自然鱼群帮助推进献祭目标，创造多人事件。风险：玩家只为任务进入环境。
- 联机社交（positive）：自然事件提供共同活动理由，「都过来看」是天然的聚拢广播。原稿「错过事件导致玩家差距」的风险在局制下消解：事件对同局全员同时可见，不存在离线错过。
- 印记图鉴（positive）：本册是素材场，环境印记撑起篝火回看的「风景页」。
- 猫咪与状态（neutral）：雨天淋湿只做演出表现（猫册口径：表现型状态，不带数值惩罚），环境不作为惩罚来源。
- 待观察（neutral）：全员看晚霞导致没人钓鱼——大概率是治愈时刻，但若高频打断主循环需调事件时长。

## 6. 体验锚定数字

（不写数值，只写调它会改什么。）
- 局内时间流速（昼夜节拍）：调它改一局的生活节奏与事件排布密度。
- 天气变化频率：调它改环境新鲜感和稳定性。
- 自然事件出现频率（含聚鱼时刻的自然触发）：调它改世界惊喜程度与祭坛推进速度。
- 单个事件持续时长：调它改「赶得上吗」的紧迫感与围观人数。
- 探索点密度（风景点 / 观察点 / 采集点）：调它改玩家探索动力。

## 7. 视觉反馈通道

- 视觉：天色与光照变化、湖面波纹、鱼跃、鸟群聚集、植物随时段的细节变化。
- 声音：雨声、水流声、风声、森林环境音；夜晚虫鸣是「入夜」的听觉信号。
- 行为（猫即信号）：猫群集体扭头看向同一方向 = 有事件发生；瞳孔变圆 = 入夜；全员抖毛 = 雨停。事件的远距离感知复用钓鱼册「声音 + 猫身体语言」的信号思路。

已知缺口：
- 一局昼夜节拍与时长匹配（数值阶段）。
- 双区域鱼类差异表（归鱼类图鉴册，待对齐）。
- 自然事件完整清单与出场条件表（本册补齐后交印记册对 C7）。
- 猫与环境互动的动画清单（与猫咪与状态册对齐）。

## 8. 何时回审

- 「聚鱼时刻」统一提案与钓鱼册对齐有结论时。
- C7（印记触发形态）裁决后，回填事件表的触发写法。
- 钓点定义与双区域统一（含捞浮木、草药点位落图）有结论时。
- 一局时长与昼夜节拍第一版数值出来时。
- 首次多人 playtest 之后（事件聚拢力验证）。

## 9. Playtest 验收预期

- 自然事件出现时，散在各处的玩家会不会放下手头事聚过来（聚拢力）。
- 一局结束后玩家能否说出「这局什么天气、遇到了什么」（记忆点）。
- 有没有玩家整局蹲守事件刷新而不钓鱼（事件过强的信号）。
- 篝火回看时，环境印记（彩虹 / 晚霞 / 萤火虫）是被停留观看还是快速划过。
- 玩家会不会为了草药或风景专程去一趟森林湖（探索理由是否成立）。
