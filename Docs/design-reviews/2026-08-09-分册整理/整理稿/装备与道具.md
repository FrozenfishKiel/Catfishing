# 装备与道具

本分册范围：鱼竿的耐久与维修、鱼饵 / 浮漂的解锁与专属效果、一次性特效道具的获取与使用。鱼竿的种类外观基准（树枝竿 / 玩具竿 / 逗猫棒竿）在「钓鱼系统」册定义，本册管它们的解锁、损耗与修理；窝料的玩法归钓鱼册，本册只管获取与携带。

## 1. 设计意图

### 1.1 北极星贡献

装备是「湖畔派对」的开场戏与聊天素材：出发前的备装是每局的目标宣言（「我今天就要那条大的」），特殊饵和道具是围观与起哄的天然话题（用不用？现在用？），断竿与落空是翻车喜剧的素材源。核心体验保留原稿的判断——让玩家产生「为了遇见某种鱼而准备」的期待感，形成「准备 → 钓鱼 → 发现」的循环；在派对语境下，这份准备感还要是**可见、可聊的**：你的装备别人看得到、闻得到、起哄得了。

### 1.2 体验设计

| 🎯 想塑造的体验 | 🛠️ 当前设计 | 🔍 达成度与缺口 |
|---|---|---|
| 出发前的期待感：「为了遇见某种鱼而准备」 | 鱼饵 / 浮漂 / 道具按目标鱼搭配；装备与鱼偏好关联 | 结构成立；偏好规则的可读性待落地（见 §7） |
| 装备是玩法选择，不是数值军备 | 功能差异化：不同装备改变钓法与目标，不做强度碾压 | 方向已定为禁区护住；「万能最优解」需数值阶段验证 |
| 关键时刻的道具决策 | 一次性道具「现在用还是省着」，使用过程有戏可看 | 决策骨架成立；囤积倾向靠设计规避（见 §3） |
| 工具的生活感 | 鱼竿耐久 + 下水捞浮木修竿：维护自己的生活工具，不是处理任务 | 循环成立；惩罚强度必须与钓鱼册对齐（见 §3 接口约束） |

### 1.3 玩家策略路线

保留原稿五条取舍：

- **稳定收益 vs 稀有发现**：普通饵稳定钓常见鱼，还是消耗特殊饵赌一把稀有鱼。
- **当下口粮 vs 收集目标**：为饥饿和献祭钓口粮，还是为图鉴追特殊鱼。
- **装备专精 vs 灵活应对**：带一套针对目标鱼的专精装备，还是带通用装备见机行事。
- **道具保存 vs 当前使用**：现在用掉抓住眼前机会，还是留给更大的目标。
- **单人效率 vs 多人互动**：自己配好自己钓，还是分享饵料、帮朋友凑齐目标。

### 1.4 设计禁区

原稿五条全保留：

1. ❌ **装备形成绝对强度差距**——不做「新竿全面碾压旧竿」的淘汰式成长。破坏「我今天想怎么钓」的自由选择。替代：功能差异化——针对不同鱼种、改变操作体验、提供不同策略路线。
2. ❌ **装备成为氪金或资源碾压入口**——不做付费优势装备，不强制装备升级。破坏治愈底色与社交公平。替代：探索获取、成就解锁、局内事件奖励。
3. ❌ **装备过度复杂化**——不加属性词条、随机强化、搭配公式。破坏轻松进场的体验，新手应该在钓鱼，不是在研究表格。替代：规则一句话说得清——「这个饵吸引什么鱼」「这个漂适合什么时候」。
4. ❌ **一次性道具成为必需品**——不做「没道具就钓不到稀有鱼」。破坏发现感：玩家应该觉得「我发现了一条鱼」，不是「我消耗道具抽了个奖」。替代：道具只提高机会、改变体验、增加趣味。
5. ❌ **装备绑定单一最优玩法 / 破坏社交公平**——不让所有人殊途同归到同一套配置，不让装备造成玩家阶层差距。破坏「各有各的钓法」。替代：收集型 / 稳定型 / 挑战型 / 展示型多路线并存；展示价值来自稀有发现与玩家故事，不来自强度。

## 2. 核心循环

1. 出发前备装：从营地仓库取竿，挑饵、选漂、揣上道具。
2. 湖畔开钓：装备组合决定今天奔着什么鱼去。
3. 消耗发生：特殊饵用掉、道具打出、竿耐久磨损。
4. 维护回路：水边捞浮木，回营地修竿点修竿。
5. 新解锁到手，下一次搭配又多一种可能。
6. 局末装备归置。（待定：装备解锁是否跨局跟人走，见 §3 装备解锁机制）

## 3. 机制清单

### 3.1 设计意图核心

**1. 装备选择与出发准备**

- 设计意图：让玩家在开钓前产生准备感，用装备表达今天的目标，而不是无脑进入流程。
- 机制：从仓库携带鱼竿、鱼饵、浮漂进入钓鱼点；不同组合影响钓鱼方向；队友装备可查看（钓鱼册既有接口）。
- 猫味演出①：备装是一套猫仪式——扒拉竿子、用爪子逐个拍拍饵袋，选好后叼起竿甩上背；「查看队友装备」＝凑过去闻，闻到带小鱼干饵的猫会不由自主跟着人家走。
- 最容易破的实施陷阱：选择过多，玩家开钓前先学一堆规则；以及备装变成各自安静看菜单——准备阶段要发生在场景里、彼此可见，别缩进 UI。

**2. 鱼饵机制**

- 设计意图：通过消耗与选择制造目标感，让玩家为某种鱼做准备。
- 机制：普通饵不消耗，撑起日常钓鱼；特殊饵消耗型，提高特殊鱼出现机会；不同饵对应不同鱼类倾向。
- 猫世界化①：饵的命名与形态全部走猫的世界——普通饵＝草地里现刨的**虫虫**（刨土动作本身就是戏）；特殊饵方向如**小鱼干碎**、**猫薄荷团**、**亮晶晶**（碎贝壳亮片，吸引发光鱼）（待定：具体饵清单与对应鱼种，归鱼类图鉴册数据）。挂饵演出：挂小鱼干时忍不住先舔一口，围观猫集体咽口水；挂猫薄荷团被熏到，眼神涣散原地小打滚。
- 落空安慰（接口）：特殊饵消耗了却没钓到目标鱼，不能让玩家白挨一刀。方向：落空也有戏（空钩拖上来一团水草、一只螃蟹夹着钩子耀武扬威）；连续落空渐进提高下次机会；或部分返还。与钓鱼册的咬钩概率方差口径统一（待定：方案取舍归数值阶段）。
- 抛印记事件④：首次用特殊饵钓中对应目标鱼——「准备终于得到回报」的瞬间。
- 最容易破的实施陷阱：特殊饵成为唯一正确答案，普通钓鱼失去意义，玩家被迫烧资源换效率。

**3. 浮漂机制**

- 设计意图：让装备提供不同玩法路线，而不是单纯提升数值。
- 机制：不同浮漂拥有专属效果，针对不同鱼类、环境或操作体验。
- 猫世界化①：漂的形态从猫的玩具箱里来——**羽毛漂**（逗猫棒上拆的）、**毛线球漂**、**铃铛漂**（咬钩时叮当作响）（待定：具体清单与效果）。铃铛漂直接服务钓鱼册「咬钩信号远距离可感知」的拍定决策：铃声是全场可闻的公共信号，一响全场猫竖耳。演出：新漂到手先当玩具拍两下才舍得系上；盯漂时猫尾巴尖跟着漂的起伏一点一点。
- 抛印记事件④：见下方「装备解锁机制」的首次解锁与成套记录。
- 最容易破的实施陷阱：出现「万能最强漂」，所有人殊途同归，策略空间消失。

**4. 鱼竿耐久与捞木修竿**

- 设计意图：给工具一点生活感，让水域不只是钓鱼的地方，也是材料来源；耐久推动「外出 → 回营 → 再出发」的节奏（衔接营地册修竿点）。
- 机制：鱼竿有耐久，钓鱼过程缓慢损耗；玩家下水打捞浮木，回营地修竿点用木块修理。偶尔捞上来的不是木头——大螺壳、水草团、一条呆头呆脑挂在木头上的小鱼（意外小惊喜）。
- **接口约束（显式）**：耐久的惩罚强度必须与钓鱼册「断线丢饵、鱼逃」的惩罚**总量对齐**——两者共用同一份「失败预算」，玩家一次失败只挨一刀，不允许断线又断竿双重损失。断竿时挂着的鱼如何处置，与失败惩罚方案一并裁定（待定：A2）。
- 猫味演出①：断竿要好笑不要惨——搏斗中竿「咔嚓」断成两截，猫抱着半截愣三秒，耳朵慢慢压平，围观猫炸毛跳开；叼着断竿回营地的委屈步，尾巴拖地；修好后抱竿蹭脸。捞木上岸甩一身水（湿毛抖水引用猫册）。
- 抛印记事件④：断竿瞬间是印记候选（待定：C4 失败瞬间是否进印记）。
- 最容易破的实施陷阱：维修频率过高，玩家感觉一直在伺候工具而不是钓鱼。

**5. 一次性特效道具**

- 设计意图：创造关键时刻的决策——「现在用还是省着」，并把使用过程做成全场围观的小节目。
- 机制：通过探索、局内事件获得；使用后提供短时间特殊效果，用于挑战特殊目标。与窝料分工明确：窝料是钓鱼册的常规聚鱼手段，道具是稀缺的短时特效，不抢窝料的角色。
- 猫世界化①：道具方向如**猫薄荷水弹**（短时鱼群兴奋）、**萤火罐**（夜钓引鱼）、**呼噜哨**（待定：具体清单与效果）。使用演出必须好笑：扔猫薄荷弹时自己先被熏到，原地打滚炸毛，全场笑翻；开萤火罐时被萤火虫勾走注意力，扑空差点栽进水里。用之前的犹豫本身就是起哄点——队友围着喊「用！用！用！」。
- 抛印记事件④：首次道具生效并钓中目标的瞬间。
- 最容易破的实施陷阱：道具价值太高导致囤积，玩家攒一仓库舍不得用，机制进不了循环。解法方向：有明确使用场景、效果变化肉眼可见、不影响基础玩法底线。

**6. 装备解锁机制**

- 设计意图：成长来自「发现更多可能」，不是「变得更强」；解锁扩展选择空间。
- 机制：通过收集、探索、局内事件获得新装备，解锁新的钓法。（待定：A5 成长观——表达型 / 便利型 / 零成长尚在裁决；以及装备解锁是否跨局跟人走。本册按「解锁＝更多选择而非更强数值」保留骨架，成长的存在形式与持久层归属等裁定后回审。）
- 猫味演出① / 抛印记事件④：**首次解锁仪式**——新装备第一次到手，猫把它高高举起，围观猫全部凑过来嗅，抛印记「第一次的○○」；**装备成套记录**——集齐一个系列（如逗猫棒全套：逗猫棒竿＋羽毛漂＋铃铛配件）触发合影式记录，抛印记。
- 最容易破的实施陷阱：新装备完全替代旧装备，旧的失去价值，成长变成单行道。

**7. 装备与鱼偏好关联**

- 设计意图：强化「为了目标鱼做准备」的探索体验。
- 机制：不同鱼有不同偏好，装备影响遇见目标鱼的机会；特殊鱼需要特殊准备。偏好数据由「鱼类图鉴」册持有，本册只消费不定义。
- 猫味演出①：规则的可读性用演出说话——用对饵，窝点鱼影聚得欢；用错饵，鱼影游到钩边绕一圈、嫌弃地一摆尾走了。让玩家看得懂「为什么没上钩」。
- 最容易破的实施陷阱：规则不透明，玩家不理解失败原因，只觉得系统在随机耍人。

### 3.2 实施考量

保留原稿六条取舍结论，口径更新：

- **装备深度 vs 易上手**：偏向易理解。保留鱼饵选择、浮漂专属效果、特殊道具；不做属性词条与多层强化。装备服务钓鱼，不是独立养成玩法。
- **功能差异 vs 平衡成本**：功能差异优先。装备改变钓法、目标与操作体验，不是简单提升成功率——平衡成本换策略空间，值。
- **耐久生活感 vs 玩家便利**：保留维护感、压低负担。维修是「照顾自己的工具」，频率必须低到不打断钓鱼节奏；惩罚预算与钓鱼册合并计算（见 §3 接口约束）。
- **道具稀缺价值 vs 使用意愿**：鼓励使用。有明确场景、有明显变化、不碰基础玩法底线，避免变成仓库收藏品。
- **装备数量 vs 开发资源**：少量高价值。优先做能改变体验的核心装备，不铺量。
- **成长感 vs 旧装备价值**：避免淘汰式成长。「不同场景适用不同装备」，而不是「新的永远更强」。

## 4. 系统边界

**硬性**：

- 鱼种偏好与分布数据归「鱼类图鉴」册，本册只消费。
- 修竿点、仓库的实体与动线归「营地」册，本册定义修理规则。
- 窝料的投掷玩法与盛宴聚鱼归「钓鱼系统」册（正式版，接口不改），本册只管窝料的获取与携带。
- 渔获容器（鱼护 / 共用大鱼缸）不属于装备：渔获流已拍定（图鉴即时记录 → 鱼护 → 大鱼缸 → 献祭 / 吃 / 观赏 → 局末放生），本册不碰。
- 不引入世界观外元素：装备命名与形态一律猫世界化，无人类文化符号。
- 不引入本册之外的成长数值（经验 / 等级归项目级决策）。

**软性建议**（保留原稿四条，措辞按现行口径）：

- 鼓励装备提供多路线：收集型 / 稳定型 / 挑战型 / 展示型。
- 鼓励装备与世界产生联系：获取尽量来自湖畔探索与局内事件，增强归属感。
- 鼓励装备具有情感价值：第一根陪你的小树枝竿、朋友送的羽毛漂（待定：赠送机制是否存在，归联机社交册）、事件纪念道具。
- 鼓励简单规则产生深度选择：玩家想的是「今天我要准备什么」，不是「我要算多少属性」。

## 5. 涌现案例

- 钓鱼系统（positive）：装备提供准备感与策略空间，钓鱼从单一行为变成「目标选择 → 装备准备 → 探索发现」。
- 鱼类图鉴（positive）：特殊鱼需要特殊准备，装备成为收集动力的放大器。
- 营地（positive）：仓库与修竿点是装备的「家」，强化「外出 → 回营 → 再出发」节奏。
- 祭坛（positive）：团队目标推动全队备装——「装备准备 → 钓鱼贡献 → 共同推进」。
- 联机社交（positive）：分享饵料经验、围观道具使用、起哄「用！用！用！」都是热闹素材；铃铛漂让咬钩成为公共事件，围观自然发生。
- 猫咪与状态（neutral，待观察）：饿急了的猫会不会想把小鱼干饵直接吃掉——「饵还是粮」可能成为玩家自发的应急路线，是否开放为机制待观察。
- 囤积倾向（negative）：守财猫攒一仓库道具不用，靠 §3 道具设计（明确场景 + 明显效果）规避。
- 备装内卷（negative，待观察）：如果偏好规则过于精确，开钓前查攻略配装可能取代「随便钓钓」的松弛感——靠规则模糊度与禁区 3 兜底。

## 6. 体验锚定数字

（不写数值，只记「调它会改什么」。）

- **装备效果差异程度**——调它改选择价值：过低没存在感，过高出唯一最优解。
- **鱼竿耐久消耗速度**——调它改维护节奏：过低机制没存在感，过高钓鱼被打断。
- **断竿率在「失败预算」中的占比**——与钓鱼册断线率同池分配：调它改「工具惩罚 vs 操作惩罚」的比重，总量不得超预算（接口约束）。
- **特殊饵收益提升幅度**——调它改消耗决策的期待感：过低白花钱，过高普通饵作废。
- **装备获取速度**——调它改解锁节奏：过快探索动力塌，过慢没反馈。
- **道具出现频率**——调它改使用意愿：过低舍不得用，过高不稀奇。
- **装备管理成本（携带 / 整理 / 切换）**——调它改准备阶段负担：过高在管仓库，过低没规划感。

## 7. 视觉反馈通道

- 装备外观即信息：竿 / 饵 / 漂外观差异一眼可辨，支撑收集感与展示欲。
- 耐久用竿身说话：裂纹渐多、缠上草绳藤条补丁，快断时钓鱼中竿身发出可闻的「吱嘎」声——不做隐藏惩罚，断竿前玩家一定收到过预告。
- 效果在过程中被看见：特殊饵引来目标鱼影、错饵被鱼嫌弃摆尾、道具生效有全场可见的演出——让玩家理解「为什么选它」。
- 解锁与成套有仪式感反馈（见 §3 装备解锁）。
- 已知缺口（沿自原稿）：装备差异除数值外的体验区分度、偏好规则的可理解性呈现、修理动作的仪式感设计。

## 8. 何时回审

- A5 成长观（表达型 / 便利型 / 零成长）裁定时——§3 装备解锁机制整条重审。
- 装备解锁是否跨局跟人走确认时——§2 循环与 §4 边界联动更新。
- A2 失败惩罚方案裁定时——断竿处置与失败预算分配落地。
- C4（失败瞬间进印记）裁定时——断竿抛印记条目定去留。
- 鱼类图鉴册的偏好数据结构定稿时；首次多人 playtest 之后。

## 9. Playtest 验收预期

- 新玩家不看说明，能否说出「换这个饵会改变什么」。
- 特殊饵落空时，玩家是笑（安慰演出起效）还是骂（白挨一刀）。
- 断竿的玩家是笑还是恼。
- 一局结束时道具使用率——囤积倾向是否出现。
- 备装阶段全场是热闹的（互相闻、起哄、讨论）还是安静的（各自看菜单）。
