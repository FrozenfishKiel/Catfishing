# 鱼类图鉴

本分册范围：全项目鱼种数据的唯一归属（SSOT）——分布表、稀有度与体型两轴、性格指纹、去向用途的结构定义；以及图鉴的收集与翻看体验。钓鱼、装备、环境、猫、营地五册只消费本册的鱼表，不各自定义。本册只立结构，不填数值（数值阶段另办）。图鉴与印记相册是仅有的两件跨局持久资产：局会结束、营地会清空、剩鱼会放生，但「我钓到过它」永远留在图鉴里。

## 1. 设计意图

### 1.1 北极星贡献

鱼是全项目的硬通货：合力的对象（大鱼）、搞怪的赃物（偷鱼）、献祭的贡品、照片的主角、篝火边的谈资。本册管两件事：鱼长什么样（数据结构），以及收集它们的感觉（图鉴体验）。

- **给热闹供弹药**：「就差那条雨天鱼了」是全队一起等雨的理由；「帮我把上次跑掉的那条抓回来」是开团喊人的理由。图鉴的缺口会变成一群猫的共同行动。
- **给跨局留念想**：游戏是局制的，图鉴是跨局的。一局的热闹散场后，沉淀下来的是图鉴上多出的几页——下一局「还想再来」的钩子。
- **给失败留台阶**：跑掉的鱼在图鉴留下剪影，失败不清零，变成「它还在湖里等我」的念想（细则见 §3，待定：A2 相关）。

### 1.2 体验设计

**体验一·为了遇见某种鱼而准备**（沿用装备册口径）：🎯 出发前有目标，钓到时有意义，不是无脑重复甩竿。🛠️ 分布表（区域 × 时段 × 天气）+ 鱼饵偏好字段；图鉴页展示已发现的线索。🔍 依赖分布线索的可读性；线索给多细待定（给太细变攻略兑换，见 §3 陷阱）。

**体验二·翻图鉴是治愈的小仪式**：🎯 像睡前翻手账，随时可翻、越翻越厚。🛠️ 三态页（未知 / 剪影 / 已记录）、个人最佳重量、首钓时的条件回显、猫味翻页演出。🔍 呈现形态未定（纯 UI 还是世界内物件，涉及「无人类文化符号」红线，待定：A4 相关）。

**体验三·差点抓到的它还在湖里**：🎯 把「跑了一条大的」从挫败变成悬念，输的人也笑得出来、还想再来。🛠️ 剪影机制：上过钩又跑掉的鱼，图鉴留一页黑影。🔍 骨架成立；哪些失败留剪影、要不要抓拍瞬间，依赖失败惩罚方案（待定：A2 相关；C4 相关）。

**体验四·听声辨鱼的老手感**：🎯 熟练玩家凭咬钩节奏就能喊出「这条是滑鱼，稳住」，围观的猫跟着紧张。🛠️ 鱼种性格指纹（咬钩节奏 + 挣扎节奏），接钓鱼册三阶段信号与搏斗系统。🔍 逐鱼定制还是模板复用两案未裁（待定：C6，见 §3）。

### 1.3 玩家策略路线

- **补图鉴 vs 攒渔获**：换条件去蹲没钓过的冷门鱼，还是在熟悉钓点刷口粮和献祭储备。
- **稀有小鱼单干 vs 巨物开团**：两轴分离让两条路都通向图鉴——独狼玩家蹲稀有小鱼，派对玩家合力抬巨物（门槛线待定：A6）。
- **好鱼去哪**：献祭推进度 / 留缸镇宅 / 吃掉回饥饿——反正钓到瞬间图鉴已记，怎么处置都不伤收集。这个取舍敢做，全靠记录模型兜底。

### 1.4 设计禁区

- ❌ **图鉴绑强度成长**——集齐给数值加成，会把收集从「想要」变成「必须」，也预判了未裁的成长观（待定：A5）。替代路径：荣誉型反馈（称号、演出、印记），不碰强度。
- ❌ **现实时钟限定鱼**——没有真实时间（已拍定），不存在「周末限定」「错过等一周」。任何鱼的出现条件都能在一局之内等到或创造出来。
- ❌ **记录会丢**——被偷、被吃、被献、放生，一律不回滚图鉴。这是「鱼可以随便流走」的全部下游设计（偷了就吃 / 献祭 / 局末放生）的地基，动它全塌。
- ❌ **图鉴变任务列表**——不下达「今日收集目标」，不弹每日提醒。缺口自己长在页面上，目标由玩家翻出来，不由系统派下来。

## 2. 核心循环

1. 翻图鉴，看到缺口（空页 / 剪影 / 没破的纪录）
2. 按线索备装备、挑条件（选饵选钓点，等时段等天气）
3. 钓到瞬间自动入册（新页 / 破纪录 / 又跑了留剪影）
4. 入册演出与围观反馈（举鱼、合影、比重量）
5. 营地里翻看比对，「你居然有这条？」
6. 带着新缺口，开下一局

单人可走完整循环；条件凑齐（等雨、聚鱼、抬巨物）天然把多人卷进来。

## 3. 机制清单

### 3.1 设计意图核心

**1. 鱼种档案 schema（本册核心资产，只定结构不填数值）**

每种鱼一条档案，字段如下：

| 字段 | 内容 | 谁在消费 |
|---|---|---|
| 基本信息 | 名字 / 外观 / 缸内游动表现 | 营地册（缸内鱼按实际鱼种游动）、图鉴插画 |
| 分布·区域 | 出现在哪片水域（区域体系沿环境册的河流 / 森林湖结构，待定：与钓点定义待统一） | 钓鱼册、环境册 |
| 分布·时段 | 局内昼夜时段（时钟源是局内时间流，已拍定） | 环境册 |
| 分布·天气 | 晴 / 雨 / 晚霞 / 月光等 | 环境册 |
| 稀有度轴 | 出现难度与收集价值分档 | 钓鱼册、装备册（魔法窝料概率吸引稀有鱼） |
| 体型轴 | 捕捞协作门槛分档：单人可抱 / 双人抄网 / 多人合力（档位线待定：A6） | 钓鱼册协作编排 |
| 性格指纹 | 咬钩节奏（试探习惯 / 真咬干脆度）+ 挣扎节奏（挣扎值消耗模式 / 冲刺习惯） | 钓鱼册信号与搏斗系统 |
| 偏好 | 鱼饵 / 窝料倾向 | 装备册（不同鱼类有不同偏好、特殊鱼需要特殊准备） |
| 去向用途 | 食用价值档（生 / 熟，生吃风险归猫册）· 献祭价值（祭坛认法待定：祭坛重议中）· 观赏价值（缸内表现 + 标本资格，营地册） | 猫册、祭坛、营地册 |
| 特殊条件（可选） | 少数特殊鱼额外挂触发：特殊饵 / 魔法窝料 / 聚鱼事件（盛宴聚鱼与森林湖鱼群的分工待定） | 装备册、环境册 |

**两轴分离是本表的立身之本**：稀有度管「多难遇到」，体型管「要几只猫」。稀有小鱼单人可得（独狼也能集齐），常见大鱼照样要合力（协作不被稀有度垄断）——单人可玩是底线，热闹靠体型轴制造。

最容易破的实施陷阱：schema 大而全但没人消费。每个字段必须至少有一个下游册实际在用；填数值阶段发现没人读的字段，删掉。

**2. 记录模型（已拍定，不得违背）**

钓到瞬间自动记录：鱼种、个体重量、当时条件（区域 / 时段 / 天气）。此后这条鱼被献祭、被吃掉、被偷走、局末放生，均不影响记录。同鱼种重复钓到刷新个人最佳重量；首次钓到开新页。

最容易破的实施陷阱：把「实物鱼」和「记录」做成同一个东西。两者必须彻底分离——实物在鱼护和鱼缸里流转、会消失，记录在图鉴里只增不减。混在一起，偷鱼、献祭、放生的整条下游全崩。

**3. 三态图鉴页**

- **未知**：连影子都没有，只有一个空位（提示给多少见下条）。
- **剪影**：上过钩、看清了是它、最后跑了——留一页黑影和交手次数。「差点抓到」是安慰也是钩子（哪些失败算「差点」——断线 / 捞取扑空 / 脱钩的细则，待定：A2 相关）。
- **已记录**：彩页 + 最佳重量 + 首钓条件回显。

最容易破的实施陷阱：剪影太廉价——随便甩几竿满图鉴都是黑影，念想变成清单压力。剪影应该来自「真刀真枪交过手」，不是路过打了个照面。

**4. 分布线索呈现**

已记录页回显钓到时的条件（玩家自己的经历就是攻略）；未知页给模糊方向性提示（给多少待定）。这直接回应装备册的已知缺口——「玩家不知道为什么用了这个饵没效果」：答案不该靠背规则，该在图鉴里翻到。

最容易破的实施陷阱：线索精确成配方。「某鱼 = 雨天 + 某饵」一条式写死，玩家照单兑换，探索变成对答案。线索指方向，不给公式。

**5. 性格指纹：两案并立（待定：C6）**

- **案 A·逐鱼定制**：每种鱼有独有的咬钩 / 挣扎指纹。收集感最强（钓一条认识一条），老手辨识度最高；内容成本随鱼种数线性上涨。
- **案 B·模板复用**：做一组性格模板（如急躁 / 狡猾 / 沉稳 / 疯癫），鱼种挂模板 + 少量参数微调。成本可控、易平衡；风险是「换皮感」——不同鱼钓起来一个手感。
- 两案共同底线：咬钩阶段能形成「猜猜是哪条」的悬念，搏斗中性格可被感知，老手能听声辨鱼、围观者能跟着起哄。

最容易破的实施陷阱：性格只活在数值表里。挣扎节奏若不能通过漂相、音效、猫的身体语言被读出来，等于没做——感知不到的性格不是性格。

**6. 收集节点与集齐**

区域集齐 / 稀有段集齐 / 全图鉴等里程碑。奖励形态倾向荣誉型：称号、专属演出、抛印记，不给强度（是否附带便利性收益，待定：A5 相关）。

最容易破的实施陷阱：节点奖励碰了强度——收集从自愿变义务，图鉴从手账变作业。

### 3.1.1 猫味演出（①过稿）

- **翻页**：猫爪一下一下拨页；看到馋的鱼页舔嘴咂舌；对剪影页压耳朵哈气，像记仇；页角留爪印当书签。
- **入册瞬间**：新页展开的一刻，猫尾巴「唰」地竖直抖一下（沿用钓鱼册身体语言体系）。
- **破纪录**：猫对着旧数字歪头，然后一爪子把旧纪录拍掉。
- **集齐节点**：猫抱着图鉴打滚，滚完趴在上面不让别人看。
- **多猫同看**：篝火边两只猫头挤在一起看同一页，第三只从背后探头——比图鉴本身就是社交演出。

### 3.1.2 抛印记事件（④过稿；清单式还是规则式，待定：C7）

- 首钓新鱼种：举鱼定格 + 图鉴新页角标。
- 破个人 / 全队重量纪录。
- 稀有鱼首次入册：慢镜头合影（沿用钓鱼册巨物合影规格）。
- **剪影转正**：曾经跑掉的鱼终于入册——印记标注「第 N 次交手，抓到了」。复仇成功是本册最好的名场面。
- 集齐节点：全队围图鉴合影。
- 剪影产生的瞬间（鱼跑掉那一下）要不要也进印记：待定（C4）。

### 3.2 实施考量

- **数据先行 vs 体验先行**：先立 schema 让五册的引用有收口点，但字段从体验需求倒推，不为建模而建模。
- **图鉴呈现形态**：纯 UI 还是世界内物件——猫的世界没有人类手账，形态包装受世界观措辞裁决影响（待定：A4 相关）；无论形态，交互演出的猫味先保住。
- **个人图鉴 + 局内互看**：图鉴跟人走（跨局持久已拍定），局内可以互相翻看比对。「谁的图鉴厚」是炫耀谈资，不做排名不做比拼。

## 4. 系统边界

**硬性**：本册是鱼种分布表与鱼种数据的唯一归属，钓鱼册等五册只消费不定义（沿钓鱼册边界原文）。图鉴只记钓鱼收集数据（钓过什么鱼 / 重量 / 稀有度），照片时刻一律归印记相册（术语表口径），两者不混。本册不写数值本体。

**软性**：鱼名与外观走猫世界观趣味（在 A4 裁决范围内），不用人类文化梗；缸内游动模型与图鉴插画尽量同源，省一份美术成本。

## 5. 涌现案例

- 「就差雨天那条了」——全队陪着等雨、凑条件开局（positive，环境册联动）。
- 老手听咬钩节奏报鱼名，围观猫打赌猜对错（positive，依赖 C6 性格可感知）。
- 收集党与献祭党抢稀有鱼去向——因为图鉴已记，冲突降级为「摆缸里还是献掉」的良性拌嘴（positive，记录模型的护栏价值）。
- 剪影复仇开团：「帮我把那条鱼抓回来」成为一局的自发主题（positive）。
- 为补图鉴独自蹲冷门钓点、整局不参与派对（neutral，单人自由与派对温度的平衡，待观察）。
- 图鉴完成度差距让新玩家露怯（negative 候选——靠「只比故事不比强度」与不做排名规避）。

## 6. 体验锚定数字

（不填数值，只记调它会改什么。）

- **鱼种总数**——调它改收集长线的长度与内容成本。
- **分布密度**（每个条件格里有几种鱼）——调它改「换条件钓鱼」的动机强度。
- **稀有度档数**——调它改惊喜的梯度感。
- **体型档数与协作门槛线**——调它改多人协作被触发的频率（对应 A6）。
- **剪影触发率**——调它改失败安慰的强度与追逐钩子的密度。
- **单局可遇鱼种覆盖率**——调它改单局新鲜感与跨局收集节奏的配比。

## 7. 视觉反馈通道

- 三态页的一眼可辨：空位 / 黑影 / 彩页，翻十秒就知道自己缺什么。
- 入册反馈两层：钓到当下的轻提示（不打断庆祝演出），回图鉴时的开页演出。
- 共用大鱼缸是图鉴的立体版：缸内按实际鱼种游动（营地册口径），看缸等于翻活的图鉴。
- 性格指纹的感知通道：漂相 / 水声 / 猫的身体语言三条冗余，保证围观者也读得到。

已知缺口：未知页提示的模糊度未定；剪影页的视觉规格（纯黑影还是带交手记录）未定；多猫同看图鉴的同步表现未定。

## 8. 何时回审

- A2 / A5 / A6 / C4 / C6 / C7 任一裁决落地时。
- 祭坛重议出结论时（献祭需求用哪些字段表达可能随之变）。
- 河流 / 森林湖与钓点定义统一时（分布·区域字段随之定稿）。
- 盛宴聚鱼与森林湖鱼群事件分工定案时（特殊条件字段挂哪边）。
- 数值阶段填分布表之前（schema 终审）。
- 首次 playtest 之后。

## 9. Playtest 验收预期

- 新玩家翻一遍图鉴，能否自己说出「想钓到那条鱼，我该去哪、什么时候去」。
- 玩家会不会主动为了补一页而换条件开局（等雨 / 换时段 / 换钓点）。
- 剪影出现时玩家的第一反应：是懊恼骂街，还是「下次一定抓到你」。
- 篝火边会不会自发出现比图鉴、看别人图鉴的行为。
- 稀有鱼「献掉还是留缸」的讨论是否真的发生——发生了，说明「图鉴已记」的护栏让人敢献。
