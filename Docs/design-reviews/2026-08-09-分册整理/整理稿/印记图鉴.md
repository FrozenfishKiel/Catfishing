# 印记图鉴

本分册范围：值得记住的瞬间自动抓拍成「印记」（雨夜大鱼 / 篝火相聚等），进相册供回看——局内相册、篝火局末轮播、跨局个人相册。印记相册与鱼类图鉴是仅有的两个跨局持久载体（装备 / 装饰解锁是否跟人走由项目级另议）。

术语口径：册名沿用「印记图鉴」；正文里单张照片叫「印记」，载体统一叫「印记相册」——与「鱼类图鉴」严格分工：图鉴管收集数据（钓过什么 / 尺寸 / 稀有度），印记管照片时刻。「个人钓鱼图鉴」等混称一律清除。

## 1. 设计意图

### 1.1 北极星贡献

- 愿景第三句的本体：「篝火边翻翻今天的照片」。热闹一天是素材，翻照片是余味——治愈底色的主要出口，放在局末，不与热闹抢戏。
- 四问④的系统化载体：各分册写的「抛印记事件」全部投递到本册。别的册负责制造值得记住的瞬间，本册负责真的记住。
- 局制游戏的记忆答案：没有沙盒房间、营地局末清空、剩鱼放生回湖——「这局白玩了吗？」印记相册回答：鱼走了，照片还在。印记是渔获流的情感补偿。
- 联机的长期粘性：联机册点名的风险——「玩家经历过事件，但游戏没有帮助玩家记住」。本册就是那个「帮玩家记住」的系统：让玩家记住故事，而不是数据（联机册原话，保留）。

### 1.2 体验设计

体验一·「刚才那下拍到了吗？」——精彩瞬间不请自来：🎯 玩家不用停下来掏相机，游戏替你记住。🛠️ 自动抓拍：各册抛「印记事件」，本册统一接收、成像、入册；轻快门提示，不打断操作。🔍 触发体系走清单式还是规则式尚在裁决（待定：C7）；最大风险是触发过密导致印记贬值。

体验二·篝火边翻照片——一局的余味：🎯 从热闹切换到安静，「今天真好玩」。🛠️ 局末篝火轮播本局精选 + 局内随时可翻。🔍 与营地册衔接成立（仪式流程归营地册）；轮播的节选策略决定笑点密度与拖沓感。

体验三·「这张里也有你」——共同记忆粘住朋友：🎯 我的相册里有你，你的相册里有我；下次再约的理由。🛠️ 共同印记自动分发给所有参与者与入镜围观者；本人可一键隐藏。🔍 出洋相与隐私的边界靠隐藏权兜底，够不够用要靠 playtest 验证。

体验四·跨局的时间厚度：🎯 玩了很多局之后翻旧相册，「我们都一起经历过这些了」。🛠️ 跨局个人相册持久保存，按局分组、该局全员合影当封面。🔍 存储上限与整理策略待定；要防它长成成就墙。

### 1.3 玩家策略路线

印记是自动的，本册刻意不制造「为拍照而玩」的策略压力（无成就、无进度条）。但它会轻轻影响行为，这是设计想要的：

- 听到那边大鱼上钩：专心钓自己的 vs 跑过去围观凑合影（入镜就能分到共同印记）。
- 出丑照片：留着当团梗 vs 一键隐藏。
- 局末篝火：围坐看完轮播 vs 跳过赶下一局（可跳过，但内容要好到让人舍不得跳——营地册原话）。

### 1.4 设计禁区

- ❌ 不做成就系统。印记数量 / 完成度 / 解锁奖励全不做。破坏：回忆变打卡清单，「为解锁而玩」污染派对动机。替代：收集欲由鱼类图鉴承担。
- ❌ 不做拍照绩效与排名。不给印记评分、不排行。破坏：出洋相变成扣分项，没人敢翻车，四问③崩塌。替代：好笑本身就是回报。
- ❌ 不打断游玩。抓拍不弹窗、不暂停、不抢镜头。破坏：钓鱼手感与沉浸。替代：轻提示，回看放到玩家自己想看的时候。
- ❌ 不羞辱人。出洋相印记的当事猫必须有一键隐藏权；镜头语言站在当事猫这边——拍得可爱，不是拍得惨。破坏：四问③「被整 / 失败的人也笑得出来吗」。
- ❌ 不做外部分享（导出图片 / 分享到社交平台等外部功能）（待定：上线阶段再议，当前版本边界内不做）。
- ❌ 不给印记数值价值。不能卖、不换资源、不加成。照片只是照片。

## 2. 核心循环

1. 湖边发生了值得记住的瞬间（首钓 / 合捕 / 翻车 / 被整 / 偷鱼被抓）。
2. 自动抓拍成印记：轻快门声，相纸飘进相册，游戏不停。
3. 想看随时翻局内相册——等鱼咬钩的空档正好扒拉两下。
4. 局末回营地，篝火围坐，轮播今天的精选，笑完收尾。
5. 共同印记自动进每个参与者的相册；不想要的自己藏。
6. 跨局个人相册一局一页攒下来，改天翻到：「还记得那次吗」。

## 3. 机制清单

### 3.1 设计意图核心

**1. 触发体系（「抛印记事件」的接收端）**

设计意图：全 GDD 的「抛印记事件」有统一投递口；值得记住的瞬间不靠玩家手动抓。

机制：本册只接收、不定义玩法，触发点由各玩法册显式抛出。当前汇总的种子清单——

- 钓鱼册 C7 接口：首钓、合捕成功（双人庆祝 / 巨型鱼慢镜头合影）、落水扑空、被整炸毛、双人庆祝。
- 已拍定的社交事件：偷鱼被抓——物归原主、滚成一团，双方进印记（偷鱼未遂名场面）。
- 营地册：稀有入缸、满缸。
- 公共时刻：大鱼上钩全场猫耳齐转——全员被同一件事吸引的大远景。
- 篝火收尾：每局最后的全员合影（见机制 4）。

框架：**清单式起步、规则式演进**。起步阶段手写触发清单，每条过四问④，短而精；清单跑稳后，从中归纳「印记性」的通用信号（在场猫数、情绪动作幅度、事件稀有度），演进成规则引擎，去捕捉设计师没预料到的涌现瞬间。（待定：C7 裁决中——清单可控但只拍得到设计师想到的，规则能拍到涌现但噪音风险高，尚未拍板。）

失败瞬间（落水扑空 / 被整炸毛 / 断线）是否入印记（待定：C4；已拍定的例外是偷鱼被抓必进印记）。注：分发规则里的「本人可一键隐藏」是 C4 的安全网——若失败入册，当事猫永远有藏起来的权利。

最容易破的实施陷阱：触发过密——每条鱼都咔嚓一下，印记贬值成截图垃圾场，篝火轮播也被灌水。宁缺毋滥。

① 猫味演出：快门不解释、不出现摄影师（无人类双手红线，猫世界的魔法）；定格帧把猫的演出再放大一档——炸毛更炸、瞳孔更圆、踉跄定在最歪的那一帧。

**2. 构图与拍摄（照片长什么样）**

设计意图：印记要一眼好笑或好看——照片本身是内容，不是事件的缩略图。

机制：自动构图追猫脸和动作高潮帧。出洋相构图：扑空的猫四脚朝天占 C 位、水花糊脸的瞬间、炸毛剪影配飞出画面的鱼的残影——圆滚滚的可爱，不是狼狈特写。全员合影自动站位：大鱼居中、钓手主位、围观猫自动找位；总有一只猫在合影里干别的（舔爪 / 看镜头外 / 打哈欠）——不完美是猫味。成像用拍立得相纸质感（待定：美术方向）。

最容易破的实施陷阱：构图算法求稳——张张居中标准照，比不拍还无聊。宁可歪、糊、切掉半只耳朵，也要抓动作最大的那一帧。

① 猫味演出：合影有个短暂摆位瞬间，总有猫绷不住提前动；被拍的猫耳朵会朝快门声抖一下。

④ 抛印记事件：合影摆位时有猫捣乱（挤人 / 抢 C 位）——连拍第二张，把摆好的 pose 塌掉的瞬间也拍下来，常常比第一张好笑。

**3. 局内相册与翻阅**

设计意图：本局的记忆随手可翻；等待期多一件安静的事可做（衔接钓鱼册「等待中可自由活动」）。

机制：局内相册按时间线排本局印记；相册是个人的，公共回看只走篝火轮播这一个舞台。共同印记本来就人手一份，不需要互翻。

最容易破的实施陷阱：相册变成冷冰冰的菜单网格——入口与翻阅必须是场景内的猫演出，浏览效率问题另行解决（见 3.2）。

① 猫味演出：翻相册＝相纸摊在地上，爪子扒拉着一张张拨过去；拨太快相纸散一地，再一张张扒回来；对着某张看久了，猫会歪头。

**4. 篝火局末轮播（与营地册共建）**

设计意图：一局的治愈收尾。分工：营地册持有仪式流程（围坐 → 轮播 → 放生），本册持有轮播内容。

机制：自动节选本局精选——每人至少入镜一张、高光与翻车穿插、以全员篝火合影收尾。相纸围着篝火摊开，镜头逐张推近，猫们凑头看。可跳过，但内容要好到让人舍不得跳（营地册原话）。单人局同样成立：一只猫守着篝火翻自己的相纸，是治愈底色的单人版。

最容易破的实施陷阱：变成强制过场，或者轮播太长变拖沓——节选不贪多，把最好的留下。

① 猫味演出：看到出丑照，全场目光刷地转向当事猫；当事猫可以拍爪认领，也可以把脸埋进爪子里假装不是自己。

④ 抛印记事件：轮播结束自动拍「今日全员合影」——每局固定的最后一张印记，火光打脸，总有一只闭眼或背对镜头；它同时是跨局相册里该局那一页的封面。

**5. 分发与隐藏（共同印记的归属）**

设计意图：「这张里也有你」——共同经历长在每个人自己的相册里。

机制：多人参与的瞬间（合捕、双人庆祝、偷鱼被抓的双方、入镜的围观者）为共同印记，自动分发给所有参与者。在场判定以入镜为准——画面里有你，这张就也是你的。本人可一键隐藏任意一张（只藏自己相册里的这份，不动别人的；隐藏可撤销——藏起来不等于撕掉）。（待定：当事猫能否申请把某张从所有人相册全局撤下——隐私强度问题，与联机册权限体系一起裁。）

最容易破的实施陷阱：分发过滥——站得老远也算「在场」，相册里全是别人的鱼。入镜才算，宁严勿宽。

① 猫味演出：共同印记分发的瞬间，一张相纸在半空一分为几，各自飘向在场的猫。

**6. 跨局个人相册（持久层）**

设计意图：局制游戏里跨局的时间厚度——与鱼类图鉴并列的两个跨局持久载体之一。

机制：印记在局末自动存入个人相册，跨局保留。按局分组、一局一页，封面是该局的全员合影——「和谁玩的那局」是比任何编号都好的记忆索引。照片忠实记录拍摄当时的猫外观与装备（个性表达转移到猫外观后，旧照片自带「那时你还是这身毛色」的时间感）。局内局外都能翻（待定：局外入口形式）；容量上限与整理策略（待定：数值与存储方案阶段）。

最容易破的实施陷阱：两个方向都要防——工程上数据无上限膨胀；设计上把跨局相册做成成就墙（回到禁区）。

① 猫味演出：越老的局，相纸越卷边泛旧——时间感不用日期，用纸的旧。

### 3.2 实施考量

- 猫味演出 vs 浏览效率：全程场景演出会烦（想快速找某一张时）。方向：入口与篝火回看重演出，长相册提供轻量网格，但美术语言保持相纸质感。
- 成像方式：真截取现场帧（所见即所得，画质与时机难控）vs 事后按事件参数重摆拍渲染（可控但可能假）。（待定：实装验证后择一或混用。）
- 触发密度：单局上限与同类合并（如连续扑空合成一张连拍）的规则留数值阶段，原则先立住——宁缺毋滥。
- 多人同步：共同印记必须是同一张照片、同一帧；分发在事件结算时点，掉线重连后补发。

## 4. 系统边界

硬性：

- 不做成就系统、不做印记的数值价值、不做评分排名（见 1.4）。
- 不做外部分享等出游戏边界的功能（待定：上线阶段再议）。
- 不定义玩法：触发点由各玩法册定义并抛出（钓鱼系统册为正式接口基准），本册只接收、成像、存放。
- 数据分工不越界：收集数据归鱼类图鉴，照片时刻归印记相册。

软性：

- 各册新机制过四问④时，顺手把「抛印记事件」写进该册；本册维护触发总清单。
- 快门、相纸、翻页等演出细节与猫通用动画规范对齐（猫咪与状态册）。

## 5. 涌现案例

- 钓鱼系统（positive）：等待期翻相册，等待不空虚再多一个选项；「想进合影」把猫聚到大鱼现场，反哺围观热闹。
- 联机社交（positive）：共同印记成为再开一局的理由（「上次那张笑死我了，再来」）；出丑照沉淀成团梗，翻车变成社交资产。
- 联机社交（negative，靠隐藏权规避）：出丑照被反复调侃、当事人不适——一键隐藏是安全阀；若仍不足，触发 C4 回审。
- 营地（positive）：篝火轮播让「回营地」有了每局固定的期待，收尾仪式有了内容支撑。
- 祭坛与渔获流（positive）：献祭 / 吃掉 / 放生之前和鱼合影留念可能成为自发仪式——鱼走了，照片还在，渔获流的情感补偿闭环。
- 全场围观（neutral，待观察）：为进合影全员扎堆一个钓点、没人钓鱼——与钓鱼册同款涌现，共用观察结论。

## 6. 体验锚定数字

（数值本体归数值阶段，此处只记「调它会改什么」。）

- 单局印记条数上限——调它改「珍贵感 vs 垃圾场」，连带改轮播时长。
- 轮播节选张数——调它改收尾余味与拖沓感，与营地册「回看与放生时长」联动调。
- 共同印记的入镜判定松紧——调它改「这张里也有你」的浓度与滥发程度。
- 跨局相册容量上限——调它改存储成本与「翻旧账」的厚度。
- 抓拍提示强度（声音 / 图标存在感）——调它改「被打断感」与「错过感」的平衡。

## 7. 视觉反馈通道

- 快门与相纸是抓拍的全部语言：轻快门声 + 相纸飘入角落，不弹窗、不暂停、不抢镜头。
- 照片内容的素材本体是猫的身体语言信号系统（钓鱼册：炸毛 / 竖瞳 / 踉跄）——印记等于把这套信号定格并放大。
- 篝火轮播是公共回看的唯一舞台；相纸质感贯穿局内翻阅到跨局相册。
- 已知缺口：远处玩家事后如何知道「刚才那边出了张好照片」（事件本身可感知——猫耳齐转，但印记生成的公共提示待定）；一键隐藏的入口要顺手且无「举报」既视感。

## 8. 何时回审

- C4 / C7 裁决落地时——重写 §3.1-1 触发体系。
- 钓鱼册 C7 接口触发点增删时。
- 首次多人 playtest 后（轮播完看率、隐藏功能使用情况）。
- 存储方案评审时（跨局容量与清理策略）。
- 上线规划阶段重议外部分享边界。

## 9. Playtest 验收预期

- 篝火轮播有多少组完整看完不跳过？看的过程中有没有真实的笑声？
- 被拍到出丑的玩家是笑还是恼？会不会用一键隐藏？（观察结果直接喂给 C4 裁决。）
- 局末问玩家「今天最好笑的瞬间是什么」，答案在不在相册里？（触发覆盖率的体感验证。）
- 老玩家会不会主动翻跨局旧相册？翻的时候在看什么？
- 单人局的相册值不值得翻？（单人可玩底线。）
