钓鱼系统
1. 设计意图
1.1 北极星贡献。
钓鱼是「湖畔派对」的主活动与素材源：为大鱼合力（协作的热闹）、为整蛊炸毛（等待与搏斗中的搞怪空间）、篝火边翻照片（印记素材的主要产地）。猫的真实行为贯穿全流程，是本册的第一设计语言。

1.4 设计禁区。
❌ 人类化操作与动作——所有行为必须能用猫的身体逻辑完成（「无人类双手」红线）。
❌ 强制任务与效率引导——协作与热闹由机制诱发，不下指令。
❌ 把失败做成事故——失败以喜剧演出与可恢复的损失为限。
2. 核心循环
选位与准备：走到水边钓鱼点，装备钓竿，选择窝料与鱼饵。
打窝聚鱼：向水中投掷窝料吸引鱼群，产生持续效果。
抛竿等待：抛出鱼线，等待咬钩；等待中可自由活动。
刺鱼搏斗：咬钩瞬间提竿刺鱼，进入角力拉扯。
拉近收线：收放线控制，将鱼拖至岸边浅水。
抄网捞鱼：自己或队友出手将鱼擒获。
庆祝展示：炫耀战利品，计入图鉴与印记。
单人可完成主循环；大型协作内容（盛宴聚鱼、巨型鱼）面向多人。
3. 机制清单
选位与准备
水边钓鱼点交互掏竿，进入钓鱼待机；背包切换钓竿 / 鱼饵 / 窝料；不同钓竿外观不同（树枝竿 / 玩具竿 / 逗猫棒竿）。多人各自独立准备，可查看队友装备。
打窝聚鱼
选择窝料后蓄力抛掷，抛物线预览；落水泛起涟漪、气泡与鱼影聚拢，窝料光环显示范围与剩余时间。三档窝料：普通（小范围）/ 中等（中范围）/ 魔法料（大范围，概率吸引稀有鱼）。多人可向同一水域投料，多份窝料触发「盛宴聚鱼」——大量鱼群涌现并伴随「水下有巨大的影子出现……」的巨物预告；叠加规则与盛宴的稀缺性约束待定。
抛竿与等待
蓄力决定落点，鱼漂随水波起伏。咬钩信号分三阶段：试探期（鱼漂快速抖动、小水花；此时提竿必空竿，是可学习的规则）→ 真咬期（鱼漂猛然下沉、「咕咚」水声、猫瞳孔缩成竖线）→ 暴击窗（下沉后短窗内刺鱼触发暴击，鱼的反抗力度降低，特殊声效「喵嗷！」）。信号需远距离可感知（声音 + 猫身体语言 + 震动），等待中的玩家可自由活动；普通有效窗口的宽度与错过后果待定。
刺鱼与搏斗
窗口期提竿上钩，进入搏斗。张力-体力对抗：鱼挣扎阶段硬收线会推高张力，拉满断线（丢饵、鱼逃）；鱼放松阶段收线拉近。鱼有隐藏体力，可通过挣扎激烈程度与头顶漩涡标志判读；体力耗尽进入乏力。挣扎 / 放松的切换信号、失败惩罚细则待定。
浅水与捞取
乏力的鱼半浮水面，拖至近岸浅水出「捞鱼！」提示。单人捞取：观察鱼动作停顿的瞬间出手抱鱼，过早出手会扑空（扑空后果待定）。
协作抄网
中型以上鱼的合作玩法：钓手控竿引导鱼头方向，抄网手就位挥网；成功后合力抬鱼，触发双人庆祝（碰鼻子等猫式动作）。巨型鱼需多人合力：队友从背后加入拉竿（代价是鱼冲刺更频繁），两名抄网手同时下网才能捞起；成功触发慢镜头合影。钓手被大鱼拖拽时，队友可拽尾巴救援。
收获展示与结算
举鱼展示（鱼比猫大时被压得颤颤巍巍）、围观猫互动；图鉴在钓到瞬间自动记录（鱼种 / 重量 / 稀有度——此后鱼被献、被吃、被偷均不影响记录）。渔获流向：入随身鱼护（钓点边暂存，可被偷）→ 带回营地入共用大鱼缸 → 献祭 / 吃掉回复饥饿 / 留缸观赏（承担被偷）→ 局末剩鱼放生回湖。鱼缸实体见「营地建造」册，偷吃规则见「联机社交」册。
多人互动层
窝点猫爪标记全队可见并显示剩余时间；上钩求助信号（分级方式待定）；恶作剧（丢石头惊鱼 / 逗猫棒逗空竿）是「搞怪」的主要载体，细则与开关规则待定；协作有连携激励，形式待定。
实施考量
钓鱼状态机的进出与打断规则（主动收竿 / 搏斗中放弃 / 被恶作剧打断后的回退）需先定义再实装；多人同步（窝料叠加、盛宴判定、巨物归属、掉线兜底）是本册最大的工程风险点。

5. 涌现案例
一人续窝、众人垂钓的自发分工（positive）。
恶作剧引发的追逐打闹反而成为社交高光（positive）。
集体叠窝形成「开钓仪式」（positive）。
全员围观一名钓手导致没人钓鱼（neutral，待观察）。
连续被整蛊后玩家退出派对层（negative，靠恶作剧护栏规避）。

7. 视觉反馈通道
猫的身体语言即信号系统：
耳朵支起 = 咬钩前兆；瞳孔缩成竖线 = 真咬。
耳朵压平 + 尾巴炸毛 = 紧张；湿毛抖水 = 落水收场。
鱼线松紧与竿身弯曲承载张力读数；窝料光环承载范围与剩余时间。
已知缺口：挣扎 / 放松切换的可读信号、旁观者视角的信息可见性。全流程逐阶段的演出细节见子页「钓鱼动作表现集」。
