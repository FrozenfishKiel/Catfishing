营地
本分册范围：一局内的固定据点——篝火、共用大鱼缸、烹饪与休息、局末回看与放生。营地建设玩法（自由布置 / 装饰收集 / 营地成长 / 搬迁）已删除；营地跟局走，局末清空。
1. 设计意图
1.1 北极星贡献。
营地是一局的团聚点与收尾场：白天在湖边闹，回营地围着篝火看照片——治愈底色的主要载体；共用大鱼缸让全队成果有处可看、有处可偷。
1.2 体验设计。
体验一·回到营地就放松下来：🎯 从热闹切换到安静的落差感。🛠️ 篝火、烹饪、休息、鱼缸观赏——无任务无压力的安静系统。🔍 依赖视听氛围与猫演出落地。
体验二·全队的收获在一处：🎯 「看，这是我们今天钓的」。🛠️ 共用大鱼缸＋标本位，鱼带主人色环。🔍 观赏与被偷共用一个舞台。
体验三·一局有仪式感的结束：🎯 热闹的余味。🛠️ 篝火围坐翻看今天的照片 → 剩鱼放生回湖。🔍 与印记册衔接，可跳过但要让人舍不得跳。
1.3 玩家策略路线。
回营时机（钓得正热 vs 回去卸鱼护）；献祭还是留缸观赏；生吃应急还是回营烹饪。
1.4 设计禁区。
❌ 营地变成经营系统——无生产链、无建造、无装修，营地是家不是第二个工作场。❌ 回营变成事务处理——管理负担最小化，回营的主体验是放松。
2. 核心循环
外出钓鱼、捣乱、探索
回营地：渔获入缸、烹饪进食、休息修整
献祭推进目标，或留缸观赏
篝火围坐，翻看今天的照片
局末剩鱼放生回湖
带着图鉴与照片，开始下一局
3. 机制清单
3.1 设计意图核心。
1. 营地管理机制。
设计意图：让营地成为生活循环中心。机制：仓库存储、装备整理、修竿点（配合装备册的木块维修）。最容易破的实施陷阱：管理负担过高，玩家回营地变成处理事务。
2. 共用大鱼缸机制。
设计意图：让本局渔获有一个全队共同的容身处——暂存、观赏、被偷的舞台，营地据点感的核心陈列。机制：全队共用一缸（跟局走，局末清空）、鱼带主人色环、缸内鱼按实际鱼种游动、猫趴缸贴玻璃跟鱼；缸是祭坛备货仓（献祭从缸里挑，「献掉推进度还是留缸镇宅」的取舍）；可被偷吃（不设保护，规则见联机册），图鉴钓到已记不受影响；稀有入缸 / 满缸抛印记。最容易破的实施陷阱：缸变成纯仓库 UI——鱼必须实体游动，观赏性和被偷的物理性都依赖这一点。
3. 烹饪与休息点。
设计意图：给状态系统一个营地端出口。机制：烹饪（生鱼→熟鱼，安全回饥饿）、休息恢复疲惫、救援送回的落点（衔接猫咪与状态册）。最容易破的实施陷阱：多人排队等锅——同时使用的吞吐要顺。
4. 篝火回看仪式。
设计意图：一局的治愈收尾。机制：局末围坐 → 轮播今天的印记照片 → 剩鱼放生回湖。最容易破的实施陷阱：变成强制过场——可跳过，但内容要好到让人舍不得跳。
3.2 实施考量。
功能性 vs 治愈体验：营地功能是生活辅助，不是经营系统（保留原稿结论）。固定配置 vs 表达欲：删除建造后，玩家的个性表达转移到猫外观、图鉴与照片，营地不再承担表达功能。
4. 系统边界
硬性：无建造 / 无装饰收集 / 无营地成长与搬迁；设施为固定配置（篝火 / 鱼缸 / 锅 / 仓库与修竿点 / 标本位）。软性：每个设施都要有猫味交互演出（趴缸、蹭火堆取暖、锅边等吃、火边打滚）。
5. 涌现案例
钓鱼系统（positive）：渔获的归宿与展示，钓鱼目标从「获得资源」延伸为「创造记忆」。
装备与道具（positive）：修竿与整理的发生地，强化「外出 → 回家 → 再出发」节奏。
猫咪与状态（positive）：烹饪 / 休息 / 倒地救援送回点。
祭坛（positive）：备货仓与献祭动线，「参与世界 → 回归生活」。
偷窃与权限（positive / negative）：鱼缸是偷吃舞台之一，乐趣与安全感的平衡见联机册。
6. 体验锚定数字
鱼缸容量——调它改献祭储备节奏与被偷的风险池大小。
烹饪耗时——调它改排队压力与生吃的相对价值。
回看与放生时长——调它改收尾仪式的余味与拖沓感。
7. 视觉反馈通道
缸内鱼群实时反映本局收获；篝火点亮＝收尾信号；锅冒烟＝烹饪中；标本位陈列稀有鱼。已知缺口（沿自原稿）：多人在营地里能对彼此做什么的互动细化；开放互动的乐趣是否大于不安全感需试玩验证。
