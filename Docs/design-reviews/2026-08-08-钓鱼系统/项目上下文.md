# 小猫钓鱼 · 项目上下文（评审 Agent 必读）

## 北极星愿景（摘自知识库「北极星愿景」页）

玩家扮演湖畔的猫咪，和好友一同在自然湖畔钓鱼，依靠吃鱼维持饥饿，营造**欢乐 + 治愈**的体验。

**体验基调**：
- 画面：3D 卡通柔和，明亮温暖；开阔湖畔（浅滩湖水、芦苇花草树木），昼夜循环、下雨、黄昏晚霞、月光。
- 角色：造型可爱的猫咪，动作细腻——舔毛、甩尾巴、打哈欠、耷拉耳朵、打滚，**所有动作都是猫的真实行为**（核心设计语言）。
- 玩法感受：单人可玩，最多 8 个好友联机结伴钓鱼、共建营地、休闲互动；等待咬钩时可看花观鸟，也可趁人钓鱼去偷鱼；会累、会被雨淋湿；营地摆鱼标本、点篝火围坐；游戏自动记录高光时刻（雨夜大鱼、篝火相聚）生成**印记记忆图鉴**；**没有强制任务**。

**差异化方向候选**（待拍定）：猫咪真实行为带来的治愈感 / 无强制任务的多人湖畔社交 / 印记记忆图鉴。
