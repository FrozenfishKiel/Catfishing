# 钓鱼系统 v0.1 — 愿景评审

> **评审日期**: 2026-08-08
> **评审对象**: `原文-钓鱼设计-v0.1.md` v0.1
> **评审视角**: 核心愿景一致性（理论基础：Schell Lens #11 统一、Lens #2 本质体验）

**北极星对照基准**：湖畔猫咪与好友钓鱼，欢乐 + 治愈；「所有动作都是猫的真实行为」为核心设计语言；无强制任务的 8 人联机社交；单人可玩；印记记忆图鉴自动记录高光时刻（雨夜大鱼、篝火相聚）。

## 发现列表

### 01 🔴 等待阶段被设计成「注意力测试」，与愿景的开放式等待直接冲突
**问题**：北极星明写「等待咬钩时可看花观鸟，也可趁人钓鱼去偷鱼」，但 v0.1 把等待定义为「进入专注状态」「盯着鱼漂」：试探期提竿必定空杆（陷阱式惩罚提前行动的人）、真咬期时长未定义、0.3 秒完美刺鱼窗口、屏幕边缘红色闪光警示。
**分析**：这套信号链训练出的最优玩家行为是「全程紧盯屏幕、不敢移开视线」——恰好是愿景想要的「湖畔发呆、看花观鸟」的反面。用本质体验透镜检验：想传递的体验是「湖畔的悠闲陪伴」，机制实际传递的是「别眨眼」。等待期是钓鱼玩法中时间占比最大的环节，它的基调就是全游戏的基调；这里失守，治愈感整体失守。
**建议**：
- 明确真咬期为宽容窗口（建议 1.5–2 秒起判；鱼越稀有窗口可越短，形成自然难度梯度）；
- 咬钩信号做成「远距离可感知」：清晰的「咕咚」水声 + 猫耳朵支起 + 手柄震动，保证玩家视角在看鸟、看队友时也能被拉回来；
- 0.3 秒暴击窗保留为纯增益（错过零惩罚）：奖励盯漂党，不惩罚看花党——这是正确的奖励对齐；
- 增加低投入钓法选项：把竿架在岸边石缝，猫去打滚看蝴蝶，咬钩时猫自己竖耳吼一嗓子提示（投入低、收益低，但保住自由节奏与「无强制」的承诺）。[跨系统: 环境与氛围]

### 02 🔴 「被拖下水昏迷」是治愈游戏中过重的硬惩罚，且单人玩家无解
**问题**：互助机制规定「如果无人帮忙，猫会被拖进水里，鱼逃脱，昏迷」。这是丢鱼 + 丢饵 + 失去操控权的三重惩罚；单人玩家钓到超出能力的鱼时必然吃满全套。
**分析**：昏迷 = 剥夺控制权，正踩中「玩家想要做，而不是看」的反面，且是挫败感放大器。愿景基调下，失败应该是喜剧，不是事故。文档其他失败演出（扑空摔嘴啃泥、被溅一脸水委屈呜咽）都做对了，唯独这里滑向了生存游戏的惩罚逻辑。同时「单人可玩」的承诺被打破：单人面对大鱼没有任何止损手段。
**建议**：删除昏迷。替代方案：猫被拖下水扑腾两下、自己狼狈爬上岸，全身湿透（接淋湿状态）、抖毛、耷拉耳朵委屈三秒，自动抓拍「落汤猫」时刻。损失止于丢鱼丢饵，控制权立即归还。队友拽尾巴救援保留，但改为「救回 = 保住搏斗继续 / 保住鱼饵」——让救援是增益而非免刑，单人不因缺队友而被额外处刑。[跨系统: 猫咪与状态] [跨系统: 印记图鉴]

### 03 🔴 「上供古神」「大渔旗帜」等世界观外来物破坏「自然湖畔猫世界」的统一性
**问题**：结算与庆祝环节混入多个与北极星世界观无对应的元素：「上供古神」（神秘学/克系意象）、日式「大渔」旗帜（人类渔业文化符号）、「围观点赞、撒花」（互联网直播语汇）、自动语音表情「快来帮忙！」（若为人话配音则打破猫叙事）。
**分析**：用统一透镜检验：主题是「自然湖畔的真实猫生活」，上述元素没有一个在服务它。尤其危险的是，它们全部出现在情绪峰值位置（庆祝、结算）——玩家记忆最深的时刻，恰是杂质代价最大的位置。「上供古神」只有四个字，但它暗示了一个愿景中完全不存在的超自然叙事层，并入分册前必须拍定或移除。
**建议**：逐个替换为猫世界等价物：
- 上供古神 → 删除；若想保留「处理渔获的仪式感」，改为「叼回营地摆上标本架 / 献给篝火边的伙伴分食」[跨系统: 营地建造]；
- 大渔旗帜 → 花瓣与水珠飞溅的庆祝粒子，或围观猫集体仰头喵叫合唱；
- 点赞撒花 → 围观猫围上来蹭钓手、嗅鱼、兴奋刨地；
- 「快来帮忙！」→ 急促喵叫 + 头顶鱼图标（图标可以是 UI，声音必须是猫）；
- 同时把「魔法料」这类轻奇幻命名列入待拍定清单：明确本作接受的幻想度光谱——「逗猫棒竿」是猫世界内的幽默自洽（可以），「古神」是外来神秘学（不行）。

### 04 🟡 拟人度执行不一致：文档自己立了「无人类双手」的规矩，又多处破戒
**问题**：第三节明确声明「无人类双手，依靠嘴巴+前爪操作钓具」——这是对核心设计语言的正确翻译。但第六节抄网猫「双手举着抄网杆」直接使用「双手」；双人庆祝的「击掌」是人类动作；巨型鱼「抱住钓手的腰」的拔萝卜阵型是人类童话的身体逻辑。
**分析**：「所有动作都是猫的真实行为」是本作的差异化命脉，它的执行标准必须是二值的（是猫 / 不是猫），不能按段落浮动。文档内部已经有正确示范——互助机制里「抓住钓手的尾巴将其拽回」就非常猫——说明作者有这个意识，缺的是一条全文档过稿红线。
**建议**：建立「猫性检查表」作为并入 GDD 的过稿标准：每个动作问「真猫会这样做吗？如果不会，它是否用猫的身体逻辑完成？」具体修改：
- 抄网 → 嘴叼网杆 + 前爪压杆，或双爪抱杆蹲姿挥出；
- 击掌 → 碰鼻子 / 头顶互蹭 / 尾巴缠绕（碰鼻子文档已有，保留即可）;
- 拔萝卜阵型 → 后猫咬住前猫尾巴或叼住后颈皮往后拽，与「拽尾巴救援」统一为同一套猫式发力语言。

### 05 🟡 失败惩罚链可能与饥饿系统咬合成「死亡螺旋」
**问题**：断线 = 丢饵 + 丢鱼；扑空 = 鱼逃回深水前功尽弃；而本作生存回路 = 吃鱼维持饥饿；文档又写明抛投距离受「自身体力状态」影响。四者相扣：连续失败 → 没鱼吃 → 饥饿/疲劳 → 钓鱼性能下降 → 更容易失败。
**分析**：钓鱼文档单看没问题，但它对尚未设计的状态系统埋下了强耦合假设。治愈游戏出现负反馈螺旋是基调级事故——玩家最沮丧的时候，游戏在把他往更沮丧推。必须在两个分册对接前显式斩断这条链。
**建议**：
- 明确保底口粮：浅滩可徒手扑小鱼 / 捡拾螺贝，零装备零门槛，保证饥饿永远有兜底（这本身也是极猫的行为）；
- 失败不双罚：断线丢饵可以保留，但「扑空鱼逃回深水」建议改为鱼退回浅水挣扎区、可再尝试一次（弹性失败：允许不同程度的成功/失败）；
- 体力对钓鱼的影响改为「表现层变笨拙」而非「数值变弱」：累的猫抛竿歪歪扭扭、中途打哈欠——可爱、可读，但不形成数值惩罚闭环。[跨系统: 猫咪与状态] [跨系统: 装备与道具]

### 06 🟡 恶作剧的「皮/毒边界」未定义，高赌注场景会产生真实愤怒
**问题**：丢石头吓跑鱼、逗猫棒晃眼导致空竿，文档仅以「可在设置中关闭友好伤害」兜底，未区分受害者所处阶段的赌注高低，默认开关值也未定义。
**分析**：派对混乱的方向符合「欢乐」，但用情感透镜检验被害者：等待小鱼时被晃逗猫棒 = 好气又好笑；遛了三分钟的稀有鱼被一颗石头清零 = 真实损失、真实愤怒。「设置里可以关」不是设计，是免责声明——毒性交互的正解是让恶作剧的后果天然可恢复，而不是让玩家二选一（要么忍受要么关掉整个社交趣味）。
**建议**：
- 恶作剧只在低赌注阶段生效：等待期可被打扰；进入搏斗期 / 稀有鱼上钩后免疫；
- 后果可恢复：被吓的鱼是「暂离窝点约 10 秒」而非「逃走」；被晃出的空竿不消耗鱼饵；
- 给恶作剧加猫化的反馈循环：被发现的恶作剧猫会被受害猫扑倒滚成一团（冲突本身变成社交演出）；
- 默认开启但首次被恶作剧时提示可关闭，房主可设房间规则。[跨系统: 联机社交]

### 07 🟡 巨型鱼与「盛宴聚鱼」完全锁死在多人后面，单人玩家没有巅峰时刻通道
**问题**：盛宴聚鱼需三名玩家同时同点打窝；巨型鱼「单人无法操作」；慢镜头合影、稀有奖励与称号全部多人专属。
**分析**：北极星承诺「单人可玩」，但 v0.1 的巅峰体验单人份额为零。单人玩家会清晰感知「这游戏最好的东西不属于我」——这不是难度问题，是内容存在性问题。愿景的三个差异化候选（治愈猫行为 / 湖畔社交 / 印记图鉴）中有两个应当对单人成立。
**建议**：
- 单人也能遇见「巨大的影子」：魔法料或特殊天气下低概率触发，即使钓不上来，「影子从鱼漂旁缓缓游过」本身就值得进印记图鉴——玩家只需感知可能性，未发生的事件也能产生情感；
- 保留一条低概率高难度的单人巨物通道（例如巨物把鱼漂拖向浅滩、搁浅瞬间完成单人擒抱），成功率低但存在；
- 多人版保持效率与稳定性优势，联机动机不被稀释。[跨系统: 联机社交]

### 08 🟡 「雨夜大鱼」是愿景钦点的印记时刻，钓鱼系统却与天气/昼夜零联动
**问题**：北极星把「雨夜大鱼」列为印记记忆的示范样本，环境基调包含昼夜循环、下雨、黄昏、月光；但 v0.1 全文没有任何天气或时段对鱼情的影响——打窝、咬钩、鱼种全部与环境无关。
**分析**：高光时刻不会自己发生，需要机制主动制造。「雨夜出大鱼」的规则如果不存在于钓鱼系统里，「雨夜大鱼」的照片就永远不会被拍到——愿景样板间里最重要的一件家具，目前没有生产线。
**建议**：在钓鱼分册预留「环境修正层」接口：雨天咬钩率上升、特定稀有鱼只在雨夜或黄昏时段出现、月光下水面反光改变鱼漂的视觉读法（氛围化的轻微变化，不做成惩罚）。v0.1 可以不填数值，但必须把「环境 × 鱼情」写进结构，供环境分册对接。[跨系统: 环境与氛围] [跨系统: 鱼类图鉴]

### 09 🟡 失败瞬间是本设计最好的喜剧素材，却没有进入记录与补偿循环
**问题**：扑空摔个嘴啃泥、被溅一脸水委屈呜咽、被鱼拖着满地溜——文档把失败演出写得很欢乐（方向正确），但失败只产生损失，不产生留存物。
**分析**：这是消化「压力机制 vs 治愈基调」张力的关键杠杆。治愈游戏处理挫败的成熟手法是让失败产生纪念品：当「摔进泥里的照片」进入印记图鉴、被好友围观大笑时，挫败被转译为社交货币，损失感被幽默补偿。文档已经付了失败动画的成本，却没有收取它的情感回报。
**建议**：印记图鉴同样自动抓拍高质量失败瞬间（扑空入水、四猫抬鱼失手全体压倒、落汤猫上岸抖毛），配可爱命名（如「今天也没吃上鱼」）；允许本人一键隐藏某张失败照（尊重不想被嘲的玩家）。[跨系统: 印记图鉴]

### 10 🟡 经验、称号、合作重量加成悄悄引入进度压力，与「无强制任务」基调存在张力
**问题**：「双方都获得额外经验」「全队获得稀有奖励和称号」「重量合作加成」——「经验」暗示一套等级系统，而愿景与项目上下文从未定义它。
**分析**：无强制任务的游戏一旦出现可刷的数值进度，会自发长出「最优刷法」：玩家开始为效率钓鱼，而不是为湖畔时光钓鱼。外在数值奖励会侵蚀内在动机；正确方向是只奖励玩家本来就想做的事（奖励对齐）。这不是说不能有成长，而是成长的载体必须与愿景同质。
**建议**：先拍定本作的成长观再落笔。若保留成长，绑定到「解锁更多表达」（新庆祝动作、新钓竿外观）而非数值变强；称号写成回忆式描述（「和巨物搏斗过的猫」）而非等级勋章；「合作重量加成」改为「合作钓获在图鉴留下双人合影页」——把奖励从数字改成记忆。[跨系统: 装备与道具] [跨系统: 印记图鉴]

### 11 🟢 窝料无限叠加使「8 人集体叠窝」成为最优解，可能绑架联机节奏
**问题**：「效果叠加」「重叠区域鱼群密度极高」加上三人同点触发盛宴，未见任何递减或冷却约束。
**分析**：8 人房的理性玩法会收敛为全员轮流叠窝的流水线；「各钓各的、看花、偷鱼」的自由社交被效率协作绑架——无强制任务的游戏，被玩家自己发明的「事实任务」绑架，是这类设计最常见的翻车路径。
**建议**：叠加收益递减（第 2 份 60%，第 3 份触发盛宴后窝点进入冷却）；盛宴设为低频惊喜（同窝点每场次限次）而非可量产策略；确保「不参加集体打窝的猫」没有明显机会损失。[跨系统: 联机社交]

### 12 🟢 表现层残留「压力语汇」：红色警示闪光、两处「表情狰狞」、多处剧烈震动
**问题**：真咬期「屏幕边缘出现轻微红色闪光警示」；「表情狰狞又可爱」「挥网瞬间表情狰狞」出现两次；搏斗中「越近红区震动越猛烈」。
**分析**：红色边缘闪光是射击/生存游戏的危险语汇，与 3D 卡通柔和画风冲突；且文档已有更好的信号（瞳孔收缩、胡须前倾、「咕咚」水声），红闪属于冗余的焦虑制造器。「狰狞」二字与「可爱」并置，暴露表现方向的摇摆——这类措辞会直接影响后续动画外包的产出基调。
**建议**：删除红色闪光，咬钩警示完全交给猫的身体语言 + 音效 + 震动——这正是「展示，而非讲述」的机会，也是本作猫表演资产的用武之地；措辞统一到「龇牙咧嘴」「用力到表情夸张」的可爱级别；震动曲线做治愈化调校（短促有弹性，而非持续高强度），提供强度设置。

### 13 🟢 三个「图鉴」概念混用，且「营地鱼缸」是未声明的跨册接口
**问题**：文中出现「计入图鉴」「个人钓鱼图鉴」，愿景另有「印记记忆图鉴」，分册表另有「鱼类图鉴」「印记图鉴」；结算处「丢进营地鱼缸」「放生」对营地系统与生态规则做了隐含假设。
**分析**：鱼类图鉴（收集进度）与印记图鉴（时刻相册）职责完全不同，混用会导致两个分册互相踩线；项目上下文已提示术语表未建立，本文档正是第一个需要它的地方。
**建议**：术语先行：本文档所有「图鉴」改为明确指向（收集 → 鱼类图鉴；照片 → 印记图鉴）；「营地鱼缸 / 标本架」标注为对营地分册的接口需求，「放生」是否有玩法后果留待鱼类图鉴分册定义。[跨系统: 鱼类图鉴] [跨系统: 印记图鉴] [跨系统: 营地建造]

### 14 🟢 愿景明写「趁人钓鱼去偷鱼」，钓鱼流程却没有渔获暴露窗口
**问题**：v0.1 中鱼从抄网直接进入结算与图鉴，渔获没有物理存在的时段——偷鱼这个愿景点名的联机乐趣，在机制上无处发生。
**分析**：偷鱼成立的前提是「渔获在某个时段处于可被偷的暴露状态」。这不是联机分册单方面能补的：暴露窗口必须由钓鱼流程本身提供。
**建议**：在收获与结算之间加入「渔获暂存」实体（岸边鱼桶 / 挂鱼架，鱼以实体存在直到玩家主动收仓）：既给偷鱼留出舞台，也让「满桶的鱼」成为可炫耀的湖畔景观；防偷手段本身可以猫化（把鱼压在屁股底下坐着继续钓）。[跨系统: 联机社交] [跨系统: 营地建造]

## 跨系统发现汇总

- [跨系统: 猫咪与状态] 昏迷状态是否存在需重议（发现02）；饥饿/疲劳与钓鱼性能的耦合方式需防死亡螺旋（发现05）
- [跨系统: 装备与道具] 鱼饵消耗经济与失败惩罚的联动（发现05）；「经验」暗示的成长体系需先拍定成长观（发现10）
- [跨系统: 环境与氛围] 等待期「看花观鸟」的低投入钓法接口（发现01）；「环境 × 鱼情」修正层（发现08）
- [跨系统: 鱼类图鉴] 鱼种与天气/昼夜的分布规则（发现08）；图鉴术语切分（发现13）
- [跨系统: 印记图鉴] 落汤猫/巨影等时刻的抓拍规则（发现02、07）；失败瞬间入图鉴（发现09）；合作合影页（发现10）；术语（发现13）
- [跨系统: 联机社交] 恶作剧的默认规则与房间设置（发现06）；单人/多人内容配比（发现07）；8 人叠窝对社交节奏的绑架（发现11）；偷鱼窗口（发现14）
- [跨系统: 营地建造] 标本架/鱼缸/挂鱼架等渔获去向实体（发现03、13、14）

## 亮点

- ⭐ **猫行为的观察级细节**：瞳孔放大/收缩、耳朵语言、尾巴炸毛、湿毛抖水、忍不住伸爪拨水（可打断）——「所有动作都是猫的真实行为」这条核心设计语言在表演层的执行是模范级的，是全文档最强资产。
- ⭐ **「无人类双手，依靠嘴巴+前爪操作钓具」的红线声明**：正确的猫性约束意识，值得升格为全项目过稿标准（执行不一致处见发现04）。
- ⭐ **用猫的身体语言承载游戏信号**：耳朵支起 = 咬钩前兆、瞳孔收缩 = 真咬——把 UI 信息嵌入角色表演，同时服务功能性与治愈感，是「展示，而非讲述」的教科书案例，建议以此替代红色闪光（见发现12）。
- ⭐ **失败演出的喜剧化底子**：扑空摔嘴啃泥、被溅一脸水委屈呜咽、被鱼拖着满地溜——用欢乐消化挫败的方向完全正确，补上记录与补偿即成闭环（见发现09）。
- ⭐ **「水下有巨大的影子出现……」的悬念设计**：玩家只需感知可能性，未发生的事件也能产生情感——低成本高回报的期待制造器。
- ⭐ **双人抄网分工与四猫抬鱼慢镜头**：主动制造社交高光时刻，是印记图鉴天然的内容生产线。
- ⭐ **逗猫棒竿、玩具竿**：猫世界物件的幽默再利用，恰好示范了本作应有的幻想度光谱（对照「古神」，见发现03）。

## 总体评价

这份 v0.1 在「猫的真实行为」表演层上的执行力远超初稿平均水平：耳朵、瞳孔、尾巴构成的信号系统既是治愈感的来源，也天然承担了玩法反馈职责；多人协作编排（双人抄网、四猫抬鱼）已经在主动制造愿景要求的高光时刻。骨架值得保留，评审目标应是修剪而非重写。

问题集中在三条主线：**其一，压力机制尚未被治愈基调消化**——专注式等待（01）、昏迷惩罚（02）、恶作剧毒性边界（06）、失败惩罚链（05）都还是传统钓鱼/生存游戏的惩罚逻辑，需要系统性地改写为「喜剧演出 + 可恢复损失 + 失败纪念品」（09 提供了转译机制）；**其二，世界观统一性失守**——古神、大渔旗、点赞撒花等外来物（03）与拟人度摇摆（04）需要一条明确的猫性红线，建议随本评审建立「猫性检查表」并作为并入分册的过稿门槛；**其三，与愿景钦点要素的接口缺失**——看花观鸟式等待（01）、雨夜大鱼（08）、偷鱼（14）、单人巅峰时刻（07）在当前设计中没有机制落点。建议优先处理三个 🔴 项后并入钓鱼系统分册，🟡 项在各关联分册启动设计时对齐解决。
