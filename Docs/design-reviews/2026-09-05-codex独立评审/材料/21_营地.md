<title>营地</title>

> 本册范围：营地这一处据点——篝火、共用大鱼缸、局内图鉴、仓库与岸边石像五件固定设施，渔获的归宿与一天的收尾。建造、装修与烹饪玩法已删除，营地是家不是第二个工作场。
> 
> 谁读：策划看 §1～§3 的意图；场景与美术看 §3 的设施与演出。石像的形象口径归世界观页、目标结构归局与进程册，局内图鉴的规则归图鉴册，本册只持它们的场景位置与动线。

# 1. 设计意图

**1.1 北极星贡献。**营地负责一局的收尾：白天在湖边闹，晚上回来把一天松下来。游戏里治愈的部分主要发生在这里。全队钓的鱼都在缸里，想看的看，想偷的偷。

**1.2 体验设计。**

| 体验 | 🎯 想塑造的体验 | 🛠️ 当前设计 | 🔍 达成度与缺口 |
|-|-|-|-|
| 回到营地就放松下来 | 从热闹切换到安静的落差感 | 篝火、休息、鱼缸观赏，都没有任务、没有压力 | 依赖视听氛围 |
| 全队的收获在一处 | 「看，这是我们今天钓的」 | 共用大鱼缸，鱼带主人色环 | 观赏与被偷共用一个舞台 |
| 今天我们一起认识了什么 | 回营地一眼看见这一局的账 | 局内图鉴被动记页，跟鱼缸并列——一个陈列会流走的实物，一个陈列留得住的记录 | 一页给多少信息归图鉴册 |
| 一天末尾松下来 | 热闹的余味 | 篝火是营地的第四个去处，陈列的是猫不是东西——坐下松弛，别的猫凑过来叠成一堆 | 靠视听＋专属演出＋聚集三条立住；印记 Demo 后置期间没有照片轮播 |

**1.3 玩家策略路线。**回营时机（钓得正热 vs 回去卸鱼护）；献祭、卖钱还是留缸观赏；吃掉换成长还是留着凑额度。

**1.4 设计禁区。**

- ❌ **营地变成经营系统**——无生产链、无建造、无装修，营地是家不是第二个工作场。唯一的例外是鱼缸容量可用公款升级（2026-09-04 李前臻拍），它是一个档位不是一套建造系统。
- ❌ **回营变成事务处理**——管理负担最小化，回营的主体验是放松。

# 2. 核心循环

1. 外出钓鱼、捣乱
2. 回营地：渔获入缸、进食
3. 入夜后全队献祭仪式交当日额度（白天不可献），或留缸观赏
4. 想待会儿的去火边坐着，想走的直接翻天
5. 全员同意翻天进入新的一天；局结束时带着图鉴与照片，开始下一局

# 3. 机制清单

## 3.1 设计意图核心

### 1. 营地管理机制

**设计意图。**营地是生活循环的中心。

**机制。**仓库存储、装备整理；地上未被拾取的物品次日清晨出现在营地（物品不灭失，2026-08-16 拍定）。

**⚠️ 最容易破的实施陷阱。**管理负担过高，玩家回营地变成处理事务。

### 2. 共用大鱼缸机制

**设计意图。**本局的渔获全队放同一个缸，暂存、观赏，也会被偷。这也是营地里最主要的陈列。

**机制。**全队共用一缸（跟局走、跨天留存，局末随局清空）。缸是明天献祭额度的储备仓，鱼带主人色环，缸内鱼按实际鱼种游动，猫趴缸贴玻璃跟鱼；缸也是祭坛的备货仓，献祭从缸里挑（夜晚收尾的全队一次性仪式，也是翻天的开关；白天只攒不献）（「今天献掉、留作明天储备、卖掉换货币、还是镇宅观赏」的取舍）；可被偷吃，图鉴钓到已记不受影响。缸有容量上限，装满就钓不进去了；**容量可用公款在商人猫处升级**（2026-09-04 拍，档位与价格待定，见参数页），升级随局清空。这条容量是全局压力的真阀门——缸大就能拿前几天的盈余顶后面几天，缸小就得天天现钓现交，所以「卖鱼换钱升缸」与「献鱼推进度」是同一批鱼上的两条路。

**⚠️ 最容易破的实施陷阱。**缸变成纯仓库 UI。鱼要实体游动，能看到、能被偷走都靠这个。

### 3. 局内图鉴

**设计意图。**全队摊在桌上的公共本子，跟鱼缸并列的第二件陈列——鱼缸摆今天钓到的，图鉴摆今天知道的。

**机制。**营地里的公共陈列，跟局走、局末随营地清空。全队谁钓到一条新鱼，板上自动多一页，页上盖登记归属那几只猫的爪印；玩家不为它做任何操作，只是回来看（规则全归图鉴册，本册只持摆放位置与观看动线）。

**猫味演出①。**新页自己翻出来时在场的猫扭头看一眼，有份的凑过去把爪印按上；夜里几只猫并排蹲在板前从头数到尾。

### 4. 休息点

**设计意图。**倒地的猫送回营地解决

**机制。**救援送回的落点（衔接猫咪与状态册，倒地来源＝吃到重毒鱼）；吃鱼从缸里或鱼护取了直接吃——获得限时 buff 与经验（成长规则见猫册，吃鱼效果见鱼册）。

**⚠️ 最容易破的实施陷阱。** 倒地做成必须干等的挂机。恢复要快，别把玩家钉在营地。

### 5. 篝火

**设计意图。**一局的治愈收尾。

**机制。**每晚献祭之后篝火点亮。想去就去、想走就走——它不是流程里的一环，是玩家主动的行为。坐下后猫进入松弛状态，别的猫凑过来会叠成一堆。不阻塞翻天，夜晚无时限，全员同意后开始新的一天（翻天机制见局与进程册）。缸内的鱼跨天留存，只随局结束一起清空，每晚不清。

印记功能 Demo 后置期间没有照片轮播——照片回来了就多一样可看的，不回来篝火也不空，因为它靠的不是内容。

**为什么走到火边（三条一起立）。**火光暖色与噼啪声；只有火边才有的动作（叠罗汉、烤肚皮、被烤得往后缩爪子）；别人也在那儿——聚集本身产生聚集。

**⚠️ 最容易破的实施陷阱。**把必需的东西只放进篝火。判据是：跳过的人不觉得错过了关键，留下的人觉得值——不追求「好到舍不得跳」。夜晚无限长，走不走是玩家的事。

## 3.2 实施考量

- **功能性 vs 治愈体验**：营地功能是生活辅助，不是经营系统。
- **固定配置 vs 表达欲**：删除建造后，玩家的个性表达转移到猫外观、图鉴与照片，营地这边不再管表达。

# 4. 系统边界

**硬性。**

- 无建造 / 无装饰收集 / 无搬迁。营地唯一可成长的是鱼缸容量，用公款买、随局清空（2026-09-04 开口子）。
- 设施为固定配置（篝火 / 鱼缸 / 局内图鉴 / 仓库 / 岸边石像）。石像的形象口径归世界观页、目标结构归局与进程册，本册只持它的场景位置与献祭动线；局内图鉴同理——规则归图鉴册，本册只持摆放位置与观看动线。

**软性。**

- 每个设施都要有猫味交互演出（趴缸、蹭火堆取暖、缸边挑鱼、火边打滚）。

# 5. 涌现案例

- 钓鱼系统（positive）：渔获的归宿与展示，钓鱼目标从「获得资源」延伸为「创造记忆」。
- 道具（positive）：整理与补给的落点，「外出 → 回家 → 再出发」的节奏靠这一环。
- 猫咪与状态（positive）：倒地救援送回点。
- 祭坛（positive）：备货仓与献祭动线，「参与世界 → 回归生活」。
- 偷窃与权限（positive / negative）：鱼缸鱼护是能偷鱼的地方，乐趣与安全感的平衡见联机册。

# 6. 体验锚定数字

- **鱼缸容量的初始值、档位数与升级价**：它是全局压力的真阀门，决定队伍能不能靠前几天的盈余顶过后面几天，也影响缸里有多少鱼可能被偷。上限还受渲染约束——缸内鱼要实体游动。与局与进程册的任务曲线联动调。

# 7. 视觉反馈通道

- 缸内鱼群实时反映本局收获。
- 篝火点亮＝收尾信号。

已知缺口（沿自原稿）：多人在营地里能对彼此做什么的互动细化；开放互动的乐趣是否大于不安全感需试玩验证。

# 8. 何时回审

- C4（失败瞬间进印记）裁决落定时——印记回看的内容口径随之定；C7 已裁清单式，触发条目随印记册总清单增删。
- 祭坛形象与位置已落定（A4 内容层，2026-08-21：岸边猫神石像）；剩余：石像的精确点位与献祭走位编排随灰盒实测定。
- 多人营地互动细化有结论时（对彼此能做什么，衔接联机册权限）。
- 数值阶段给出鱼缸容量第一版参数时。
- 首次多人 playtest 之后（回看参与率与营地停留感实测）。

# 9. Playtest 验收预期

- 达成额度入夜后，玩家是自然聚到篝火边，还是各玩各的——观察聚过来的人数与赖着的时长，不看跳过率（跳过不是失败）。
- 回营是放松还是像在处理事务——有没有「回家先干三件杂活」的清单感。
- 缸边实际发生什么：观赏、挑鱼、偷吃的比例，被偷的人是笑还是恼。
- 翻天等待（等最后一人同意）会不会让先好的人烦躁。
- 单人局的夜晚是否值得留下来，而不是空等一晚。
