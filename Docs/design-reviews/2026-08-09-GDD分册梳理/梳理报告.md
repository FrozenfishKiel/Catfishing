## 二、逐册评点

### 装备与道具（7.4K）
- **内容**：鱼饵（普通不消耗 / 特殊消耗型）、浮漂专属加成（功能差异非数值）、一次性道具（用 vs 存的决策）、装备解锁成长、**鱼竿耐久 + 下河打捞木块维修**（新机制）。
- **亮点**：禁区写得极好——禁绝对强度差距 / 禁氪金 / 禁复杂词条 / 禁道具必需品 / 禁单一最优解，全部带替代路径，与"功能差异化"方向自洽。
- **待议**：①鱼竿耐久是**第二个消耗惩罚源**，与钓鱼册"断线丢饵为唯一硬经济惩罚"的表述要对齐（消耗系统总量控制）；②"河流打捞木块"引用了环境册的河流设定，但"进入河流钓鱼探索"与愿景"湖畔"的地理措辞未统一；③"王霸比拼""营地生存需求"等引用散落。

### 联机社交（6.1K）
- **内容**：房间联机（持续保存、共同影响世界）、自由行动、合作互动（三人搬营地 / 祭坛共同目标）、营地社交、**王霸比拼**（展示 3 物品 / 随机评委 / 自定义称号 / 王冠）、**偷取与权限**（鱼篮可偷 / 小箱可偷但次日返还 / 权限设置）、玩家关系沉淀。
- **亮点**：偷取的"损失可恢复"设计（次日返还）正对四问③；四类玩家路线（独处 / 轻社交 / 合作 / 互动娱乐）覆盖面好；禁区（禁强制社交 / 禁 MMO 结构 / 禁永久损失）扎实。
- **待议**：①**恶作剧完全缺席**——钓鱼册已拍的分工是"过程干扰＝恶作剧（钓鱼册）、成果掠夺＝偷鱼（联机册）"，本册只接了偷鱼一半，恶作剧作为"搞怪"支柱在社交册里没有回声；②"双人合作钓鱼（待深化）"两处标注待设计——**钓鱼册已有完整的双人抄网 / 巨物合力设计**，两册没互读；③**祭坛"失败触发灾害事件"与治愈底色张力大**（全队失败被灾害惩罚，四问③过不去）；④"生存系统（饥饿/体力）"术语与猫册"饥饿值/疲惫值"不一致。

### 营地建造（4.7K）
- **内容**：自由布置、收藏展示（鱼缸）、营地成长（装饰型非数值型）、营地社交（访问 / 帮搬迁 / 权限）、营地管理（仓库 / 装备整理 / 维修）。
- **亮点**：五组实施考量的取舍方向全部明确（自由度 / 丰富度 / 功能性 / 互动 / 成长感）；"营地是家不是第二个工作场"的边界意识；自列已知缺口 5 条（成长方式 / 装饰来源 / 互动细化 / 猫咪情感反馈 / 安全开放验证）。
- **待议**：①§1 设计意图整节空着（有循环有机制但没写"为什么"）；②鱼缸 / 小箱 / 权限正好承接钓鱼册的"渔获暴露窗口"（偷鱼舞台），但两册没有互相引用；③引用了不存在的"祭坛系统 / 王霸比拼系统 / 仓库系统 / 沙盒房间系统"。

### 猫咪与状态（3.5K）
- **内容**：行为表现（舔毛 / 甩尾 / 打滚…）、饥饿值、疲惫值、生鱼中毒风险、倒地救援（搬运 + 草药）、草药采集；四问式北极星贡献；动画实现方案（已并入）。
- **亮点**：这册和钓鱼册的咬合最好——"晕倒不永久损失 / 单人可休息恢复 / 救援创造多人故事"正是钓鱼册 B3（昏迷归属）和 C5（体力闭环）需要的答案；禁区（禁复杂生存模拟 / 禁宠物养成 / 禁高频死亡惩罚 / 禁复杂烹饪）与轻量定位一致。
- **待议**：①"疲惫值来源含钓鱼"——钓鱼册 C5 的两个方案（表现层 vs 数值层+保底）还没裁，本册实际上已经选了数值层方向，需要回填对齐；②猫册"体力/疲惫"与钓鱼册、联机册的措辞三处不一。

### 环境与氛围（2.8K）
- **内容**：**房间独立时间 + 进入时跟随现实时间**（动森式真实时间制）、天气（雨 / 雾）、**河流（日常）+ 森林湖（探索）双区域**、自然事件（森林湖鱼群 / 萤火虫 / 彩虹）、营地附近小范围环境改造（种花）。
- **亮点**：「环境提供机会而不是制造阻碍」的禁区方向正确；锚定数字六条全部有"调它会改什么"。
- **待议**：①**真实时间制是世界结构级设定**——影响"一局"的概念、事件错过感、钓鱼节奏，全项目还没有任何地方拍过这个板；②双区域（河流+森林湖）与愿景"湖畔"、钓鱼册"钓点"的地理体系要统一定义；③森林湖鱼群事件与钓鱼册"盛宴聚鱼"机制角色重叠（都是"聚鱼高潮时刻"），需要合并或分工。

### 鱼类图鉴（空）
**这是当前最大的结构缺口**：五册都在引用一张不存在的鱼表——装备册（鱼类偏好 / 特殊鱼）、环境册（区域鱼差异 / 森林湖鱼群）、猫册（生鱼 / 熟鱼）、营地册（鱼缸展示）、钓鱼册（分布表 SSOT / 体型稀有两轴 / 鱼种性格）。鱼是全项目的硬通货，图鉴册不立起来，五册的假设没有收口点。

### 印记图鉴（空）
差异化三方向之一"印记记忆"的载体册。联机册"玩家关系沉淀机制"点名的风险（"玩家经历过事件，但游戏没有帮助玩家记住"）正是本册的职责；钓鱼册已产出触发点清单接口。材料齐，只差成册。

## 三、跨册发现（最重要的部分）

### 1. 调性温差：五册是"治愈生活沙盒"，北极星是"热闹派对"
五册的关键词：生活感、陪伴、沉浸、归属、长期投入、轻生存循环——写得都好，但**「热闹为主、快乐与搞怪并存」几乎没有出现**：恶作剧零笔墨、"好笑"不是任何机制的设计意图、四问（好笑吗 / 更热闹吗 / 被整的笑吗 / 留下瞬间吗）没有被任何一册使用。五册大概率在愿景拍定（08-08 晚）之前或平行写就。**这不是推翻**——治愈是底色，五册把底色写厚了；缺的是派对层：每册需要一次"四问过稿"，把热闹与搞怪补进设计意图与机制。

### 2. 分册表之外冒出的新系统，需要归属拍板
| 新概念 | 出现在 | 规模感 | 归属建议待定 |
|---|---|---|---|
| **祭坛系统**（房间阶段目标 / 全员贡献鱼 / 失败灾害） | 联机、营地、环境三册 | 系统级 | 立册？并入联机？（失败灾害与治愈底色的冲突先拍） |
| **王霸比拼**（展示评比 / 称号王冠） | 联机、营地 | 机制级 | 并入联机册已基本成立 |

### 3. 册间失联点（互相有答案却没对上）
- 联机册"双人合作钓鱼（待设计）" ←→ 钓鱼册已有完整双人抄网 / 巨物合力；
- 联机册偷鱼舞台 ←→ 营地册鱼缸 / 小箱 ←→ 钓鱼册"渔获暴露窗口"——三册各写了一段，没互相引用；
- 猫册倒地救援 ←→ 钓鱼册 B3"昏迷归属"——答案已在，回填即可；
- 环境册森林湖鱼群 ←→ 钓鱼册盛宴聚鱼——机制角色重叠待分工；
- 恶作剧：钓鱼册有、联机册无——分工的另一半没接。

### 4. 术语漂移（老问题在新册重现）
体力 / 疲惫值 / 生存系统三种叫法；鱼类收集系统 / 鱼缸展示 / 图鉴多名并存；河流 / 湖畔 / 钓点地理措辞不一。术语表还是没建（D3 的建议在裁决中）。

## 四、建议的设计动作（不排期，只列该做什么）

1. **两个世界结构级设定先拍板**：真实时间制（还是局内时间）、沙盒房间制（房间持续世界是不是本作结构）——它们比任何一册都上游，五册内容都建立在这两个未拍的假设上。
2. **四问过稿**：五册各做一次对照北极星的校准（重点：热闹与搞怪补层、祭坛失败灾害重议）。
3. **鱼类图鉴优先成册**：先立 schema（鱼 × 区域 × 天气 × 时段 × 稀有 × 体型 × 用途），让五册的引用有收口。
4. **印记图鉴成册**：材料已齐（钓鱼册触发点接口 + 联机册沉淀需求 + 篝火回看）。
5. **新系统归属拍板**：祭坛（含失败灾害的调性重议）、王霸、房间、时间制。
6. **册间回填**：恶作剧写进联机册（或明确只在钓鱼册）、双人钓鱼引用钓鱼册、倒地救援回填钓鱼册 B3、盛宴 vs 鱼群事件分工。
7. **术语表**（D3）落地，先收"体力/疲惫、图鉴三名、地理名"三组。
