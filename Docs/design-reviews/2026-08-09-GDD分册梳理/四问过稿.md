## 总评

五册把「治愈底色」写厚了——这部分是资产，保留。共同的缺口有三类：
- **①普遍缺席**：除猫册外，四册的机制都是功能视角，没有"笑点是不是猫"的过稿痕迹；
- **④普遍缺接口**：五册都在制造值得记住的时刻，但没有一册显式写"这个时刻抛给印记图鉴"——印记册空白的连带；
- **结构连带**：联机 / 营地 / 环境三册建立在"沙盒房间 + 真实时间"上的段落需要作废或改写。

## 装备与道具

| 四问 | 判定 | 说明 |
|---|---|---|
| ① | **缺** | 全册功能视角，没有猫味物件。钓鱼册已有先例（树枝竿 / 逗猫棒竿）——鱼饵 / 浮漂 / 道具的命名与形态建议猫世界化（毛线团浮漂、狗尾巴草饵、猫薄荷类兴奋道具），道具使用的演出要好笑 |
| ② | 弱 | 装备是个人准备系统，偏安静（合理）；已有"分享经验 / 展示装备"但只是话题。可考虑：特殊道具做成群体效果（一人使用全场受益），接上集体打窝 / 王霸展示 |
| ③ | 半过 | 断竿时刻是挫败点——断竿演出要滑稽（竿弯成麻花、猫瞪眼），"捞木块维修"作为玩法而非惩罚的方向已对；**特殊饵消耗落空**（用了没钓到稀有鱼）是赌输时刻，需要安慰设计（剪影 / 保底倾向），与钓鱼册方差控制对齐 |
| ④ | **缺** | 无任何印记钩子。候选：首次解锁新竿的仪式、"用 XX 竿钓到 XX 鱼"的成套记录 |

另：鱼竿耐久是第二个消耗惩罚源，与钓鱼册"断线丢饵为唯一硬经济惩罚"对齐消耗总量；"河流"地理措辞与愿景"湖畔"统一。

## 营地建造

| 四问 | 判定 | 说明 |
|---|---|---|
| ① | 缺 | 营地互动没有猫演出——叼着物件摆放、在朋友营地打滚蹭家具、蹭标记地盘，这些是本册的猫味机会 |
| ② | 合理的安静 | 营地是治愈收尾据点（篝火在此），安静是本册的职责；社交层（参观 / 帮搬迁）保留即可 |
| ③ | 过 | 小箱可偷、损失可恢复的思路 ✓（「次日返还」按局制改为局内暂离 / 局末返还）；无重惩罚 ✓ |
| ④ | **本册即"瞬间的实体化"，但没接口** | 鱼标本 / 摆件就是印记的实体版——建议显式打通：**印记照片可以摆进营地（照片墙）**，营地 = 回看的物理空间，与篝火回看衔接成一套 |

结构连带（已拍：**营地跟局走**）：营地是一局内的据点，局结束不带走。改写方向：
- 「访问好友营地」跨局概念作废——局内大家本来就在同一营地/湖畔，参观改为局内互动；
- 「营地长期成长」「我在这里生活了很久」的成长反馈作废——营地的意义改为**本局的成果陈列**（今天钓的鱼、今天的照片），归属感由印记相册跨局承载；
- 「搬迁机制」跨局无意义，至多保留局内选址；
- 装饰品建议拆两层：**解锁跟人走**（收集库存，跨局保留）、**摆放跟局走**（每局重新布置，快速轻量）——待作者确认；
- 锚定数字「装饰获取频率」「搬迁成本」按局制重估。
