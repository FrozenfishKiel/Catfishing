# 1. 读法

吃一条鱼最多得到三样：经验（归「数值成长」§2）、限时 buff、黄色体力——本页只管后两样的**效果目录**，按效果族整理，方便横向比对与配数值；效果按鱼种的分配表在鱼表格。通用规则一句话：同类 buff 只覆盖不叠加、不同类并存、猫神的祝福不可被覆盖（细则见「数值成长」§3）。效果的猫化命名归世界观页，本页先用功能名。

# 2. 增益效果族

| 效果 | 快照数值 | 时长 | 来源 |
|-|-|-|-|
| 移速提升 | +15%／+20%／+25% | 60／90／120 秒 | 小银鱼／泥鳅／森林长尾鱼 |
| 省力（搏斗体力消耗减免） | -25%／-50% | 120 秒／600 秒 | 银月鳟／猫神的祝福 |
| 回复增速 | 体力低于 50% 时，搏斗外自然回复 +50% | 180 秒 | 河口鲈 |
| 瞬回 | 立即回复 50% 体力上限（一次性） | 即时 | 黑鱼 |
| 黄色体力 | +20／+50 | 一次性护盾（定义见数值成长 §4） | 小彩鱼／猫神的祝福（黑鱼、风铃鱼待对账） |
| 打窝增效 | 窝料效果 +50% | 120 秒 | 花瓣鱼 |
| 落水免疫 | 免疫一次落水 | 600 秒内一次 | 猫神的祝福 |

**资源边界注记（装备册 §3.3，吃鱼效果同样要守）**：回复增速与瞬回只在**搏斗外**生效（猫体力搏斗内封闭）；省力合规——它减的是消耗系数，不是回复；打窝增效属出鱼概率类，只改权重、无保底，合规。

纯演出全开放（资源边界第五条）；这一族是「好笑」的主产区，动画归动作表现集。

| 效果 | 表现 | 时长 | 来源 |
|-|-|-|-|
| 变声器 | 叫声变调 | 120 秒 | 风铃鱼（待对账：buff 列写「无」） |
| 满嘴泥巴 | 搞笑状态 | 90 秒 | 泥鳅 |
| 头上长小花 | 头顶开花 | 120 秒 | 花瓣鱼（与打窝增效并存） |
| 请勿靠近 | 周身臭气，无法被恶作剧选中、无法获得帮助和交互 | 90 秒 | 臭臭鱼 |

注：「请勿靠近」不是纯演出——它带恶作剧免疫与交互屏蔽，是用负面包装的保护效果，护栏口径与防骚扰牌子的关系归联机册对齐。

# 4. 负面效果族（中毒体系）

吃鱼效果按鱼种有好有坏（08-17 拍定：中毒＝吃鱼效果之一）；倒地来源全游戏唯一＝中毒重档。表现与倒地救援见册正文中毒条目。

| 效果 | 快照数值 | 时长 | 来源 |
|-|-|-|-|
| 晕倒＋乏力 | 晕倒，苏醒后力量 -50% | 120 秒 | 河豚（「晕倒」需并入中毒档，见对账） |
| 麻痹 | 体力不再自然回复 | 90 秒 | 电鳗 |
| 中毒 | 体力上限 -40% | 120 秒 | 狗鱼 |

# 5. 猫神的祝福（特殊来源）

唯一不来自「吃」的 buff：**献祭湖心巨影**后全队获得，600 秒——省力 -50% ＋ 黄色体力 +50 ＋ 免疫一次落水。不可被同类覆盖（持续期间吃到同类 buff 白吃，经验照得）。巨影本体无法食用。

# 6. 无效果鱼

河纹鱼＝纯经验；咸鱼＝不可食用（它是拿来扔的，投掷用法归联机册恶作剧口径）。

# 7. 对账清单（归鱼册属主，认领后处理）

1. 风铃鱼：buff 列「无」 vs 效果列「变声器＋黄色体力」——定一处。
2. 黑鱼：效果列「增加黄色体力（一次性）」 vs buff 列「瞬回 50%＋临时体力上限 +20」——建议统一为黄色体力口径（+20 护盾），瞬回与护盾二选一。
3. 咸鱼：「不能吃」——buff／效果列建议明标「不可食用」，与巨影同措辞。
4. 河豚「晕倒」：倒地来源唯一＝中毒（08-15 拍定），晕倒应定义为中毒重档触发，不另立晕倒类型。
5. 河豚／电鳗／狗鱼三行缺重量／力量系数／体力／窝料属性（挂号表已记，接入前必须补齐）。
6. 湖心巨影：C 列「不建议食用」 vs buff 列「无法食用」——统一「无法食用」。
7. 小银鱼「多人一起食用获得速度加成」：多人判定（同窝点？时间窗？）未定义——补定义或砍。
