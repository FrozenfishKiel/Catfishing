## 2. 合力钓鱼

<a id="assist"></a>

### 2.1 加入、操作与退出

队友可以搭手帮持竿猫拉鱼。

参与角色为主钓手、辅助手和岸上替补；合力发生在搏斗拉竿阶段，收鱼见[主文收鱼](钓鱼规则-主文.md#landing)。当前力量合成及换人按下节规则。贡献见[操作贡献](#contribution)，实物归属见[主文捕获事件](钓鱼规则-主文.md#capture)。

| 位置 | 操作 | 体力消耗 | 力量贡献 |
|---|---|---|---|
| 钓鱼位（主钓手） | 左键蓄力/收线，右键放线 | 标准速率 | 力量×100%（快照，参数页为准） |
| 辅助位（帮手） | 左键蓄力/发力 | 快速速率（150%） | 力量×75%（快照，参数页为准） |
| 岸上（替补） | 无 | 自然恢复（200%） | 无（快照，参数页为准） |

各角色允许输入与力量贡献由此落定：辅助手无放线权，力量按 `75%` 计入。`150%` 是辅助手的体力消耗速率（相对主钓手标准消耗）；`200%` 是替补的恢复倍率（相对[主文基础自然恢复](钓鱼规则-主文.md#recovery)）——两者分母不同，不共用。入位＝靠近搏斗中的主钓手 `≤1.5 米` 按 F（统一交互半径＋万能交互键）；退出＝再按 F 或走出半径，自由来去无惩罚。辅助体力归零＝弹出辅助位＋`2 秒` 喘气演出，不落水，恢复到 `≥20%`（快照，参数页为准）才可重入（防 1 点体力反复进出抖动）；数量不另设上限，受联机 4 人自然约束（主 1＋辅最多 3）。不引入旧多人方案的帮忙按钮、力量蓄满时间或辅助力量上限。

F 的基础选目标规则见[主文](钓鱼规则-主文.md#target)。本篇注册辅助位目标；视角中心难分（角距接近）时按稀缺窗口 tie-break（鱼＞辅助位）。看着鱼按 F 就是抓鱼，看着主钓手按 F 就是入位。准星态提示当前 F 目标。

候选鱼继续按[当前可用协作能力](钓鱼规则-主文.md#input-fish)过滤；本篇加入、退出、换人与在局人数变化提供能力变化来源，鱼侧具体过滤条件由鱼表给出。

<a id="team-force"></a>

### 2.2 力量组成与消耗倍率

按 [辅助入退](#assist) 位置权限表，`总力量 = 主钓手当前力量×100% + Σ辅助手当前力量×75%`（快照，参数页为准）。

位置差异收进乘数 `K_pos`＝主钓手 `1.0`／辅助手 `1.5`（快照，参数页为准）。

合力变化（辅助加入或退出、换人）触发[主文强度检查](钓鱼规则-主文.md#strength)，提交 F_total 与各参与者 K_pos；鱼体力和猫体力由[主文统一公式](钓鱼规则-主文.md#cost)结算。操作不改变力量。

<a id="team-exit"></a>

### 2.3 归零与放线权限

位置落水只判持竿者；辅助手归零弹出辅助位，不落水，重入条件见[加入与退出](#assist)。辅助手无放线权。只有主钓手可触发[主动放弃](钓鱼规则-主文.md#abandon)，辅助自由退出不触发本竿放弃。放线回复率与是否退出合力的缺口见主文 [open-07](钓鱼规则-主文.md#open-07)。

<a id="swap"></a>

### 2.4 换人

岸上替补可以接过这根鱼竿。

主钓手**任意时刻**可按 E 发起换人请求，再按 E 取消（09-08 李前臻拍：原 `5%` 发起阈值与 `10 秒` 等待窗口删除；`5%` 改为濒死 UI 强提示阈值，快照，参数页为准）。请求无时限挂起，本竿结束自然失效——「超时失败」出口不存在。岸上替补自愿按 E 接手，先按先得、同刻并列按席位序；体力恢复到 `50%` 以上的替补才可接手（快照，参数页为准）。接手瞬间完成：鱼与竿状态完全继承；**猫体力各是各的**（接手者用自己的）；图鉴归属不变，原始上钩者保留（N8 归属基准）。被换下者体力恢复乘 `2`，与岸上替补共用同一个恢复场景乘数，不叠加，见[场景恢复](#scene-recovery)。不从旧方案导入替补当前力量归零、蓄力或旧等待时长。

请求挂起期间无特殊状态：消耗按[主文位移公式](钓鱼规则-主文.md#cost)照扣，归零走[持竿者体力落水](钓鱼规则-主文.md#position)，请求随本竿结束失效。

## 3. 抢收、贡献、求助与展示

<a id="competition"></a>

### 3.1 配合与抢收

队友可以抢先把鱼叼走。

多人搏斗到收鱼仍有两条路径：可抄鱼贴岸抢抄，或鱼翻肚／碾压落岸后抢拾。基础资格、实物归属及并列判序见[主文](钓鱼规则-主文.md#order)。

搏斗中的猫由队友补窝；队友的合法道具状态与[主文补窝闸门](钓鱼规则-主文.md#nest)一致。别人补料不能替持竿者解除道具闸门。

<a id="contribution"></a>

### 3.2 操作贡献与展示

合力拉竿属于这条鱼的操作贡献。

材料的贡献口径包括上钩钓手、有过合力拉竿操作的猫、抄网命中者，以及救援机制成立后的拽尾巴者；打窝与围观不计入该条鱼的操作贡献。岸上拾取按备份与抄取一致。

[主文捕获事件](钓鱼规则-主文.md#capture)持有上钩者与实物持有人分离、剪影与收集的事件时点。后加入与换人贡献补发资格仍未定，不能把贡献名单理解为已完成登记算法。

保留举鱼展示、围观互动与巨物合力成功慢镜头合影的意图，演出由内容层补。连携激励的具体形式未给。

## 4. 合力移动

队伍沿着大家合力的方向移动。

WASD 或方向键控制移动。

`F_net = Σ(猫力量 × 方向单位向量)`（按键者才贡献）；`S = Σ 猫力量`（按键者）；对齐度 `ρ = |F_net| / S`。`S=0`（无人按键）时不进入 ρ 计算，直接走全员静止休息档（[移动消耗与恢复](#move-cost)），不存在除零。（快照，参数页为准）

| 档位 | 条件 | 结果 |
|---|---|---|
| 齐步走 | ρ ≥ 高阈（建议 `0.8` 起测，快照，参数页为准） | 正常移动（快照，参数页为准） |
| 拖行 | 中间 | 队伍朝 F_net 方向龟速走；输入与合力夹角 >90° 者为被拖者（快照，参数页为准） |
| 僵局 | ρ ≤ 低阈（建议 `0.2` 起测，快照，参数页为准） | 两组共线反向 → 对顶：恰 2 人触发顶牛、4 人 2v2 触发拔河，其余组合无特定演出、自然推拉；方向散乱 → 打转（快照，参数页为准） |

- 打转持续超 `5 秒`：恰 3 人 → 被甩飞（随机一只，打破僵局）；≥4 人 → 连环摔倒（互斥）（快照，参数页为准）
- 不按键者不进计票：不贡献力量向量、不拖慢队伍，随队被拖并照 [移动消耗与恢复](#move-cost) 静止档恢复（摸鱼口径见 [移动反馈](#move-feedback)）
- 移动合力是全额力量相加；钓鱼合力才有辅助位 `75%` 折扣（[力量组成](#team-force)），两处口径独立（快照，参数页为准）
- 直觉校验：缅因 `130` 对拉两只普通猫 `100`，`ρ≈0.13` → 僵局・自然推拉（非 2 人／2v2，无特定演出）；对拉一只，`ρ≈0.44` → 拖行（快照，参数页为准）

<a id="move-cost"></a>

### 4.1 移动消耗与归零

移动中某猫体力归零，直接趴下、四肢张开、不能主动移动；无主动拖／背交互。趴下恢复并随队被动拖行，不阻塞编组（见下）。本节归零出口不替换[主文搏斗落水](钓鱼规则-主文.md#position)。

| 移动状态 | 体力消耗 |
|---|---|
| 正常移动 | 1点/秒/人（快照，参数页为准） |
| 龟速移动（被拖行） | 少数派8点/秒，多数派2点/秒（快照，参数页为准） |
| 原地打转 | 5点/秒/人（快照，参数页为准） |
| 顶牛/拔河 | 6点/秒/人（快照，参数页为准） |
| 无人移动（静止） | +5点/秒/人（恢复）（快照，参数页为准） |

「少数派／多数派」按 [合力移动](#move) 合力模型推广为「被拖者（输入与合力夹角 >90°）／顺行者」，格值不变。按龟速档独立复算，上限 `100` 时少数派 `100/8=12.5 秒` 趴下，多数派 `100/2=50 秒`；前者归零时后者仍剩 `100−2×12.5=75 点`（快照，参数页为准）。该差距意味着错误方向的惩罚很快发生；无主动救援接口，但归零猫随队被动拖行（见下），不把它改成永久无法恢复，也不擅加救援。

<a id="scene-recovery"></a>

### 4.2 场景恢复与摸鱼

恢复基数由[主文基础自然恢复](钓鱼规则-主文.md#recovery)提供。场景乘数：全员趴下休息 `×2.0`／岸上替补 `×2.0`／摸鱼与归零随队被拖 `×2.0`（快照，参数页为准）。「静止 +5」与「替补 200%」是同一个数（`2.5×2=5`）的两种写法，参数页一处基数管三处，不叠加成四倍。归零猫被迫趴着按 `×2` 恢复、从 0 起算，到 `≥20%` 可起身重入；合力模型下趴下的猫不进计票、被队伍拖着走——不阻塞编组。

不按键者不进计票、不贡献力量向量、不拖慢队伍，随队被拖、自己 `+5 点/秒` 恢复。两档捣蛋强度由此分明——故意按反方向＝真捣蛋（把全队拖进龟速或打转，人人多耗）；摸鱼＝无害偷懒（只占自己便宜）。（快照，参数页为准）

<a id="move-feedback"></a>

### 4.3 群体演出与可读性

UI 表：屏幕上方按 W/A/S/D 图标显示每个队友当前方向；移动状态文字“齐步走／被拖行／原地打转／顶牛中”；每个角色头顶体力条，趴下时变灰。

甩飞与连环摔倒按人数分割互斥——打转超 `5 秒` 时恰 3 人甩飞、≥4 人连环摔倒（见 [合力移动](#move)）。张佳与内容层补反馈定稿，不补入旧稿的拖背、彩蛋或未定义奖励。（快照，参数页为准）

| 动作 | 效果（触发只读本篇合力档位） |
|---|---|
| 顶牛 | 猫头顶头，四肢刨地，3秒后弹开（快照，参数页为准） |
| 被拖着走 | 被拖的猫脚底摩擦出火星 |
| 原地打转 | 蚊香眼，屏幕旋转模糊特效 |
| 连环摔倒 | 全员趴地2秒（快照，参数页为准） |
| 被甩飞 | 随机一只飞出屏幕再跑回来 |
| 拔河拉长 | 队伍拉长成一条线，弹回摔倒 |
| 趴下休息 | 全员原地坐下/趴下，舔爪子 |

演出触发按[合力档位](#move)执行，动作表原触发条件不作为第二套判定。顶牛、拔河只用于恰两人／四人两两对顶，其余共线组合自然推拉；动作资源细目见迁移对照表的外册待迁落点。
