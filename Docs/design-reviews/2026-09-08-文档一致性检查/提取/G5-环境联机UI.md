- [环境与氛围.md:13] 本分册范围: 局内昼夜与天气（雨/雾/晚霞/月光）、河流与森林湖双区域探索结构、自然事件、看花观鸟的等待体验；环境对鱼情与猫咪状态的修正入口；森林湖特殊看点分布点位
- [环境与氛围.md:65] 局内时间流: 时钟源为局内时间流，开局启动、随局推进、局末即弃；没有现实时间，也没有离线概念
- [环境与氛围.md:77] 天气机制: 晴/雨/雾等按局内时钟切换，对鱼情做机会向修正；天气在猫身上的痕迹（淋湿/抖水）只做演出表现，不带数值惩罚；淋湿规范归猫册，本册只触发
- [环境与氛围.md:89] 双区域: 河流靠近营地、开阔顺手，是日常水域；森林湖藏得深、要走一段路，鱼种与事件偏稀有
- [环境与氛围.md:89] 钓点: **玩家概念而非机制点位**，任意水边可钓，打窝或看中风景即自发成为钓点
- [环境与氛围.md:89] 湖畔: 河流与森林湖两区域同属「湖畔」主场景
- [环境与氛围.md:118-123] 聚鱼时刻: 统一为一个机制、两种触发源——玩家触发（多人向同一水域叠加窝料，规则以钓鱼册为准）与自然触发（森林湖按局内时钟/天气条件自发涌现鱼群，本册供给）；两种触发进入同一套演出与钓鱼收益（鱼群涌现、巨物预告、稀有概率提升），共用一个稀缺预算
- [环境与氛围.md:135] 种花: 若保留则只能是环境册自己的轻量交互——固定花坛点位，种下当局开花，局末随局清空；不存档、不成长、不装修；定位是氛围道具
- [环境与氛围.md:101] 自然事件的可察觉性要求: 必须隔着距离也能察觉（声音 + 光 + 猫身体语言，复用钓鱼册咬钩信号的思路）
- [环境与氛围.md:156] 轴的定义权: 区域/时段/天气三条轴的枚举由本册定义；鱼落在轴上哪一格由鱼册分布表持有
- [环境与氛围.md:187] 猫即信号: 猫群集体扭头看向同一方向＝有事件发生；瞳孔变圆＝入夜；全员抖毛＝雨停

### 2.2 联机社交.md

- [联机社交.md:13] 本分册范围: 最多 4 人同局联机，包括组局、共存、合作、恶作剧、偷鱼、共同目标与共同印记
- [联机社交.md:15] 术语「局」: 本册统一用「局」；口语与旧文里的「房间」都指「一局」；一局的创建者称「**局主**」
- [联机社交.md:19] 本册定位: **放大器**——联机不生产内容，它放大内容
- [联机社交.md:23] 单人口子: 长在别的册里的事故（断竿、落水、中毒倒地、巨影拖走、抄网挥空、脱钩、吃到臭臭鱼），一个人钓也照样出
- [联机社交.md:25] 多人口子: 要有别人在场才成立（偷鱼、恶作剧、抢抄、搅窝），玩法与规则归本册
- [联机社交.md:84] 组局基准: 熟人邀请制，不为生人局做额外设计；房主可踢人；房主离开时自动移交给最早加入者
- [联机社交.md:84] 跨局归属: 身份跟人走（图鉴、印记相册、外观解锁），物资跟局走
- [联机社交.md:118] 防骚扰牌子（B4，2026-08-16 关账）: 玩家在钓点立牌后，想整蛊或偷他的猫会强制进入小动画「有『玩家名』钓鱼真好，我就不添乱了」，把拒绝做成演出而不是设置项
- [联机社交.md:120] 臭臭鱼「请勿靠近」: 搬运算「帮助」会被屏蔽；偷鱼被抓的扑倒反制不算「恶作剧」，臭着的小偷照样被扑
- [联机社交.md:130] 偷鱼对象: 他人鱼护（钓点边随身渔获）与营地共用大鱼缸（团队储备）
- [联机社交.md:130] 偷了就吃或就卖: 叼起就跑——找地方进食，或一路奔向商店卖掉（钱进公款）；进食时间与奔店路程就是追回窗口；吃完或卖出即不可逆
- [联机社交.md:140] 祭坛: 渔获主要去向与全队共同目标；每天一个任务，白天攒缸、夜里全队到石像前一次性上供＝**翻天开关**（白天不可献）；形象＝岸边猫神石像
- [联机社交.md:152] 共同印记: 多人入镜的印记照片进每个入镜者的相册；触发＝清单式起步（C7 已裁 2026-08-15）
- [联机社交.md:154] 事故账本（替代方向，未定）: 一局里每起事故记一笔（谁断了几根竿、谁落水几次、谁被偷了几条、谁救了谁），散局后可翻；落点是局末篝火与结算页
- [联机社交.md:71] 扔物传递（赠送）: 把身上的东西扔下给别人拾取，无交易界面
- [联机社交.md:106] 求助信号（B6 已裁）: 全手动，玩家自己喊，仅巨物保留全体提示；**旁观位不做**

## 3. 流程与规则

### 3.1 环境与氛围.md

- [环境与氛围.md:50-55] 核心循环: 开一局（一天从头开始）→ 光线与天气随局内时钟推移、鱼情跟着变 → 自然事件按时段登场 → 事件里钓鱼/扑萤/围观/抓拍进印记 → 天色沉下来回营地篝火收尾 → 局末环境状态随局清空
- [环境与氛围.md:65] 鱼情修正规则: **只发生在白天时段**（清晨/黄昏差异），**夜晚不钓鱼**；昼夜也决定自然事件在哪个时段出场（萤火虫只在夜里、晚霞只在黄昏）
- [环境与氛围.md:65] 天推进规则: 白天限时推进、夜晚无时限停摆，**全员同意后开始新的一天**（天结构见局与进程册）；篝火在每晚夜色里点亮
- [环境与氛围.md:77] 天气→事件: 有些自然事件要看天气才出（雨后出彩虹）
- [环境与氛围.md:101] 事件出场: 事件按局内时钟与天气条件出场，少而精
- [环境与氛围.md:145] 随机口径: 系统按局内时钟排程周期事件，随机只做小抖动
- [环境与氛围.md:147][环境与氛围.md:153-155] 局末规则: 所有环境状态（时间、天气、事件进度）属于这一局，局末即弃、无持久化；不读现实时钟；无跨局环境存档
- [环境与氛围.md:161] 新事件立项门槛: 先过四问④——会留下值得回看的瞬间吗？既不抛印记也没有演出的事件不要做

### 3.2 联机社交.md

- [联机社交.md:69-74] 核心循环: 开一局（1-4 人）→ 自由活动 → 自然互动（求助信号、围观起哄、追逐打闹、聚鱼时刻、扔物传递）→ 共同目标（向祭坛献祭）→ 收尾（火边或去石像前上供，夜晚无限长）→ 散局（图鉴跟人走）
- [联机社交.md:84] 中途进出规则: 创建/邀请/中途加入与退出对**当事人**不设惩罚；但当日任务在清晨就按当时人数定死、不重算，有人中途退出，留下的人得把那一份也扛完
- [联机社交.md:84] 局末: 世界清空（营地、渔获、祭坛进度归零）
- [联机社交.md:84] 房主规则: 房主可踢人（社交僵局兜底），被踢者跟人走资产无损；房主离开时自动移交给最早加入者
- [联机社交.md:106] 求助广播: 全手动，玩家自己喊；仅巨物保留全体提示；旁观位不做
- [联机社交.md:118] 恶作剧规则层: 本册持权限开关、好友局与生人局默认档位（好友局默认开、生人局更保守）、参与边界；不设系统级频率上限与时机限制；关键搏斗时刻不额外豁免；玩坏了由房主踢人兜底；被整反制＝抓住肇事猫可扑倒滚成一团
- [联机社交.md:120] 臭臭鱼屏蔽: 90 秒内无法被恶作剧选中、无法获得帮助和交互；搬运会被屏蔽（臭着倒地时队友搬不动，只能自己爬或等翻天自动救起）；偷鱼被抓的扑倒反制不受屏蔽
- [联机社交.md:130] 偷鱼规则: 不设保护机制（不上锁、不守缸）；护栏 2 道；被抓现场＝物归原主＋被受害猫扑倒；偷吃获得成长（buff＋经验）
- [联机社交.md:140] 献祭结算: 交齐＝世界进度上涨，未交齐＝下跌，**进度归零才是这一局失败**；白天不可献；从营地共用大鱼缸挑鱼献祭
- [联机社交.md:179] 单人边界（A6，2026-09-02）: 单人局不刷需要多人的鱼（规则归鱼册）；面向多人的门槛内容不算单人义务；不做独立单人模式
- [联机社交.md:186] 恶意用法口径: 搅窝、投掷类鱼（咸鱼/臭臭鱼）、连续抢抄等「合法动作的恶意用法」不设系统护栏，熟人自治，玩坏了由房主踢人兜底
- [联机社交.md:64] 事故表现口径: ❌把事故写成失败——断竿是猫仰面摔坐、落水是湿毛炸成球，**不出红字、不出失败音效**；本册持有，约束钓鱼册、猫咪与状态册与**动作表现集**
- [联机社交.md:187] 信息通道口径: 社交信息优先走猫身体语言与音效，**少用文字弹窗**
- [联机社交.md:258] 接线三件事: 每条单人口子要定同样三件事——隔多远能察觉、别人能做什么、进不进账本
