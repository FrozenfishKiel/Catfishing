# 2. 概念定义

## 体力 / 恢复 / 黄色体力

- `[数值成长.md:27]` 黄色体力: 一次性体力护盾段，绿先扣、当天内可无限叠加、过夜清空；用掉即无，不回复
- `[数值成长.md:50]` 黄色体力（完整定义）: 加在体力条末端的黄色段；搏斗消耗优先扣绿色段，扣完才动黄色；不自然回复、不吃任何回复效果，用掉即无；可叠加且无上限；定位＝能跨场累积的储备，不是当场用掉的即时缓冲
- `[数值成长.md:52]` 黄色体力来源: 特定鱼种的食用效果 ＋ 猫神的祝福（+50 点）
- `[数值成长.md:56]` 搏斗外体力回复: 唯一速率 5 点/秒，站立／岸上替补／摸鱼随队一律同一速率，没有场景乘数
- `[数值成长.md:56]` 搏斗内体力回复: 一律不回复；放线本身不回体，基础速率 0，靠三选一「放线回体速度」加
- `[猫咪与状态.md:15]` 力量与体力: 钓鱼搏斗内口径——猫与鱼各有「力量」与「体力」；品种决定初始力量
- `[猫咪与状态.md:158]` 术语归属: 疲惫＝纯演出；经验／三选一归猫册；搏斗内的力量／体力归钓鱼册
- `[数值成长.md:31]` 资源边界约束（道具册 §3.3）: 任何成长效果不提供搏斗内的体力回复、不回补竿耐久；出鱼概率类效果只改权重、无保底
- `[吃鱼效果.md:31]` 资源边界注记: 省力合规（减的是消耗系数不是回复）；打窝增效属出鱼概率类合规；本目录没有「瞬回」「回复增速」类效果；搏斗外的回复阀只留道具小鱼干

## 疲惫 / 潮湿 / 落水

- `[猫咪与状态.md:90-92]` 疲惫: 纯表现型，疲惫值数值制已废除；随局内时间与活动量触发分档演出（轻→打哈欠；中→走路拖沓、尾巴耷拉；重→坐下就瞌睡点头）；无数值条、无任何玩法惩罚、不影响搏斗体力；回营或原地趴一会儿只是把演出档位归零
- `[猫咪与状态.md:132-134]` 淋湿: 表现型状态不是数值条；雨天渐湿、落水全湿；湿毛贴身瘦一圈；上岸／回檐下后波浪式抖水；半干时毛蓬成一团
- `[猫咪与状态.md:118]` 落水处置（A2）: 鱼逃 ＋ 饵已扣 ＋ 湿身演出，无额外损失；嘴里叼着的鱼保留
- `[猫咪与状态.md:15]` 饥饿与疲惫: 不再是数值状态
- `[猫咪与状态.md:144]` 状态收敛: 数值状态全部退役（饥饿删除、疲惫纯演出），只留中毒一个风险态

## 中毒 / 倒地 / 救援

- `[猫咪与状态.md:102-104]` 中毒: 吃鱼负面效果之一（不再是独立的毒鱼风险机制）；按鱼各配、无渐进升级；最重一档＝吃下即倒地（现行即河豚）
- `[猫咪与状态.md:104]` 「认识一种鱼」两层: 钓到＝记外观与名字；首次吃过＝图鉴补食用效果
- `[猫咪与状态.md:116]` 倒地: 唯一来源＝吃到重毒鱼（中毒重档，按鱼种配置）；倒地者可缓慢爬行；满一段时间自己站起来（占位 60 秒）
- `[猫咪与状态.md:116]` 倒地与翻天: 翻天时仍在倒地的自动救起，清晨在营地醒来；倒地者不计入「全员到齐」的翻天判定

- `[营地.md:61]` 鱼缸规则: 跟局走、跨天留存、局末清空；可被偷吃，图鉴钓到已记不受影响；容量升级随局清空
- `[营地.md:69]` 局内图鉴规则: 全队谁钓到新鱼板上自动多一页，盖登记归属爪印

- `[营地.md:85]` 篝火与收尾: 入夜即自动点亮整夜都在；烤火不设完成条件、不阻塞翻天；互动结算后进度未到 0 或 100% 才开始新的一天；到 0 立即结束、不进结算夜、不再生火；缸内的鱼跨天留存，每晚不清
