# 钓鱼规则页 9.3 草稿

## 一、草稿自己要改的

- [ ] 搏斗消耗公式四处：①ΔD（鱼每秒位移）与 K_speed（1+V/10）是同一个量算两次，消耗正比速度的平方，两者留一个；②封顶保底这版删了，巨影代进去 4×3×1.0×10 ＝ 120×ΔD 点/秒，100 点体力撑不到一秒；③僵持 D 不变 → ΔD ＝ 0 → 整式算出来是 0，而判定表那格写着「仅搏斗消耗」；④式子里没有猫力项，缅因猫和普通猫拉同一条鱼累得一样快。

- [ ] 判定表四处：①W／S 有两套定义，上半表 W＝后退，猫力 < 鱼力那几行 W＝前移；②移动消耗四格对不上公式——公式是前移 ×0.5，「向岸＋S前移」写了 3（该 1.5），「猫力 ≈ 鱼力」×1.5 前移该 2.25、两处都写 3.6；③「猫力 < 鱼力＋向岸」缺「按S」和「放线」，放线全表只有一格；④碾压第一行写「鱼向任意｜猫操作任意」，放线也会飞鱼。

- [ ] 多人段三处「不干活是最优解」：①不按方向键＝静止，每秒回 5 点还被队友带着走（四人队三人一致就正常走），不出力的那个体力最好，而这条写在「趣味交互」里；②放线写「消耗 0、瞬间解脱」；③满员换不了人——只有岸上替补能接手，四人全上阵岸上是 0，按 E 没人响应，10 秒判负，逼出「留一个人全程不干活」。

- [ ] 少数派 8 点/秒、多数派 2 点/秒，按错方向 12.5 秒趴下；而 4.2 写「趴下无法移动，原地休息自行恢复，无拖／背交互（已删除）」，没人能救，队伍只能把他丢下。

- [ ] 咬钩间隔 8 倍断层且没有过渡：T_base 表是「Total > 0 → 15 秒／Total ＝ 0 → 120 秒」，而 2.5 规定 Total < 1 强制归零，Total 永远不落在 0 到 1 之间——Total ＝ 0 是 120 秒，Total ＝ 1 是 14.85 秒，撒一粒窝料就跳过去。

## 二、小修

- [ ] Total 一个变量担两个语义：2.3 叫它「鱼群总量」，2.2／2.5 里是窝料池向量和。

- [ ] 2.4 的二次 roll 要「每条鱼对各饵的偏好权重」，鱼表格没这一列；「基础鱼池（小鱼苗、杂鱼）」也是新概念，要对 RC 20 种鱼里有没有这一档。

- [ ] 7.1 演出表比现行 4.5 全，但少了「绝对碾压 → 鱼甩到身后草地、猫翘尾巴」和「鱼向内游累了 → 耳朵竖起、尾巴甩动」。

## 三、与现行冲突，改哪边二选一

- [ ] 力量不够时会怎样。现行判定顺序②是「鱼力 ≥ 猫力 → 猫被拖下水，直接失败」；草稿改成「被拖向水边、D 增大」，走到 10.4 的「猫离岸距离归零 + 鱼向外游 + 总力量 < 鱼拉力」才落水。这是草稿最大的一处设计改动，还给搏斗新增了「猫的位置」这个现行没有的变量。另外草稿的特殊出口表还留着「猫体力 ≤ 0 → 被拖下水」，两条落水路的关系要说清。

- [ ] 竿强度瞬断。现行判定顺序①是「竿强度 ≤ min(猫力, 鱼力) 立即折断」，竿强度 25／60／210 是静态字段，道具册「付费墙是能钓什么、不是能不能钓」这条分层靠它。草稿的完整判定表里没有这个出口，只剩耐久归零断。

- [ ] 线长 L 与 L_max。现行 D 配 L 与 L_max，L_max 挂竿 60／80／100，道具册把它算作竿的第三重价值。草稿只有 D，竿的第三个属性没有落点。

- [ ] 僵持的三行扣减。现行 4.4 每秒扣三样：竿耐久 -= 鱼力量×0.05、鱼体力 -= 猫力×0.08、猫体力 -= 鱼力量×0.12。草稿把猫体力那行改写成了第四章公式，另外两行没接。三行是一组，动一行要说另两行怎么办。

- [ ] 完美提竿的削减打在哪个量上。现行 4.1 按鱼种削减鱼力量与鱼体力（普通鱼 -20%／-15%）。草稿 7.1 留着「完美中鱼」的演出，但新模型的量名换成了鱼力、鱼向、V_fish、F_fish，削减作用在哪个量上没说——演出在草稿里，规则在现行里，中间断了。

- [ ] 合力有没有代价。钓鱼册 §3 写「中大型鱼靠队友加入拉竿分摊力量与体力，代价是鱼冲刺更频繁」。草稿里合力是纯加法，既没代价也不分摊。补代价，还是改册里那句。

- [ ] 拽尾巴救援接不进新的落水机制。联机册 §1.0 把它列为已有的介入动作，§3.1.3 写「玩法定义全在钓鱼册」，图鉴册按它给收集层资格。草稿 10.4 的落水是位置＋力量判定，队友只能进辅助位发力，没有介入口。

- [ ] 房主。联机册现行：房主可踢人，是一切社交僵局的兜底，房主离开自动移交最早加入者。草稿 10.1：「无身份标签，不存在房主队长」。

- [ ] 抄网的键，现行两处本来就打架。钓鱼规则 5.2 写「按 F 键，猫挥出抄网」；张佳的全局键位表写「Space｜遛鱼状态｜抄鱼」，而同一张表里 F 已派给拾取鱼、放下鱼、叼起鱼护、放下鱼护、献祭。草稿 7.1 沿用了 5.2 的 F。要和张佳定一个。

- [ ] W／S 站位没登记。草稿给搏斗新增了猫的站位维度，W／S 在遛鱼状态下键位表里没有。

- [ ] 主动放弃赔什么。草稿 7.1 写「鱼饵和浮漂被带走了」，浮漂是第二刀，而 A2 已裁「失败预算由丢饵与断竿承担，一次失败只挨一刀」。现行 4.5 主动放弃是个空节，一起定。

- [ ] 单局人数。草稿第九章写「适配 2 人、3 人、4 人及更多」，单局 4 人上限已拍；10.1 位置表也没写辅助位人数上限，主钓手 1 ＋ 辅助 3 就满了。
