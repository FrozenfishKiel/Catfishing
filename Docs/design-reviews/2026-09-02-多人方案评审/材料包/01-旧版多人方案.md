### 2.2 位置切换规则

- 任何人都可以随时从岸上进入辅助位（点击“帮忙”按钮），参与拉线。
- 辅助位人数设上限（受屏幕内可交互人数限制，最多3\~4人）。
- 任何人从钓鱼位移到岸上的唯一途径：换人（体力耗尽请求替换）。
- 任何人从辅助位移到岸上：随时可以主动松开左键并点击“E”按钮退出辅助，或体力耗尽自动退出。

## 三、力量操作机制

### 3.1 蓄力与衰减规则（主钓手与辅助手通用）

<sheet sheet-id="jDimax" token="CyPbsKubshcDS4tefDDc0Hmdnjh"></sheet>

蓄力速度：固定速率，从0到满约 2秒（可调）。无点击频率、无爆发增量等复杂机制。

### 3.2 主钓手特殊规则

- 主钓手按住左键（力量 > 0%） = 收线状态。
- 主钓手松开左键（力量 = 0%） = 放松状态（判定瞬间切换）。
-  主钓手的力量从100%降到0%的过程（1秒），在达到零即被判定为“放线状态”。

### 3.3 辅助手规则

- 辅助手力量 > 0% = 发力状态（计入总力量，消耗体力）。
- 辅助手力量 = 0% = 卸力状态（不贡献，不消耗体力）。

## 四、力量合成公式

### 4.1 当前力量值

text

主钓手当前力量 = 主钓手自身力量属性 × 当前力量百分比（0%\~100%）辅助手当前力量 = 辅助手自身力量属性 × 当前力量百分比（0%\~75%）

### 4.2 总力量值（合力）

text

总力量 = 主钓手当前力量 + Σ(每位辅助手当前力量)

## 五、体力消耗逻辑

### 5.1 消耗速率（按当前力量百分比动态计算）

<sheet sheet-id="3TQ94L" token="CyPbsKubshcDS4tefDDc0Hmdnjh"></sheet>

举例：

- 主钓手基础消耗 = 10点/秒，当前力量80% → 消耗 8点/秒
- 辅助手基础消耗 = 10点/秒，当前力量60% → 消耗 10×1.5×0.6 = 9点/秒

### 5.2 “捣乱”惩罚公式

当主钓手处于放线状态（力量=0%），而任意辅助手力量 > 0%（正在发力）：

text

主钓手额外体力消耗 = Σ(所有捣乱辅助手当前体力消耗) × 50%

举例：3个辅助手在捣乱，各自当前消耗为 9点/秒、6点/秒、3点/秒，总额外消耗 = (9+6+3) × 50% = 9点/秒 附加给主钓手。

> 辅助手自己的体力依然正常扣除（捣乱有成本）。

## 六、换人机制（全自愿 · 拼手速）

### 6.1 换人触发条件

- 主钓手体力 ≤ 5% 时，屏幕出现闪烁提示 “体力不支！按 E 请求换人”。
- 主钓手按下 E键 后，发起换人请求。

### 6.2 换人流程

【第一步】主钓手A按E发起换人请求

         ↓

【第二步】所有在岸上的替补屏幕弹出提示：

         “【A】体力不支！谁来接替钓鱼位？（按 E 接手）”

         ↓

【第三步】岸上替补自由决定是否按E接手（全自愿，无强制）

         ↓

【第四步】若有多人同时按E → 先按先得（拼手速）

         ↓

【第五步】按E成功的替补B 与 主钓手A 交换位置：

         \- A → 从钓鱼位移到岸上（进入虚脱休息，体力恢复速度×2）

         \- B → 从岸上坐到钓鱼位（获得完整控制权）

         ↓

【第六步】状态继承：

         \- 鱼的状态（拉力、位置）完全继承

         \- 鱼竿耐久度完全继承

         \- B的体力 = 自身当前体力（接手时是多少就是多少）

         \- B的当前力量百分比 = 0%（需重新蓄力）

### 6.4 被换下后的体力恢复

### 7.3 耐久归零后果（断杆）

- 鱼直接脱钩逃跑（钓鱼失败）。
- 所有正在拉线的猫被弹飞（倒地动画1秒）。
- 鱼竿进入“损坏”状态，需修复后才能再次使用。

## 八、失败判定

### 8.1 “被拖下水”触发条件

同时满足以下两个条件：

1. 主钓手处于放线状态（力量 = 0%，即松开左键）。
2. 当前 总力量值 < 鱼当前拉力。

### 8.2 被拖下水后果

- 钓鱼强制失败，鱼逃跑。
- 参与拉线的所有猫被拖入水中（落水扑腾动画3秒，无法操作）。

## 十一、完整状态机流程图

【钓鱼进行中】

      │

      ├─ 主钓手按住左键 → 蓄力（力量上升，0→100%）

      │     ├─ 力量 > 0% = 收线状态

      │     ├─ 辅助手按住左键蓄力 → 正常合作（总力量叠加）

      │     └─ 辅助手松开左键衰减 → 单人硬拉

      │

      ├─ 主钓手松开左键 → 力量归零，瞬间进入放线状态

      │     ├─ 辅助手按住左键蓄力 → 捣乱惩罚（主钓手额外耗体）

      │     └─ 辅助手松开左键衰减 → 全员休息（体力缓回）

      │

      ├─ 主钓手体力 ≤ 5% → 按E换人

      │     ├─ 岸上有人按E接手 → 位置交换，继续钓鱼

      │     └─ 5秒无人接手 → 钓鱼失败

      │

      ├─ 辅助手体力归零 → 自动卸力，可退到岸上恢复

      │

      ├─ 总力量 < 鱼拉力 + 主钓手放线 → 被拖下水 → 钓鱼失败

      │

      ├─ 鱼竿耐久归零 → 断杆 → 钓鱼失败

      │

      └─ 鱼耐力归零（外部系统） → ✅ 钓鱼成功！

## 十二、多人场景示例

### 场景一：4人合作钓巨鱼

- 主钓手A按住左键蓄力，力量达到100%（收线状态，贡献100）
- 辅助手B、C、D同时按住左键蓄力，力量各达到75%（各贡献75×3=225）
- 总力量 = 100 + 225 = 325
- 鱼拉力300 → 鱼被拉近 
- 体力消耗：A每秒10点，B/C/D每秒各15点（满力量时）

### 场景二：主钓手想休息但队友在捣乱

- 主钓手A松开左键（力量归零，放线状态）
- 辅助手B没注意，依然按住左键蓄力到75%
- 捣乱惩罚生效：B当前消耗15点/秒 × 50% = 7.5点/秒附加给A
- A体力加速见底，被迫换人

### 场景三：极限换人接力

- 主钓手A体力剩3%，按E请求换人
- 岸上替补C和D同时按E → 系统判定C帧数更快（先按先得）
- C接手钓鱼位（体力当前80%，从0开始蓄力）
- A退到岸上（体力恢复速度×2）
- 鱼的状态不变，钓鱼继续
