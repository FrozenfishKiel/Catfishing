## 一句话判断

这套机制把系统里所有会随时间单调变化的时钟（鱼体力、竿耐久磨损、僵持三扣）全部删掉或归零，只留下一根可双向自由往返的距离轴，结果是：胜负在咬钩瞬间由「总力量 vs 鱼拉力」两个数比大小就已决定，而它想当作高潮的「僵持」在结构上是一个所有状态变量都不再变化的真死锁。

**单位问题另记一条**：`搏斗消耗 = 鱼位移 × 速度系数 × …`，而速度系数本身 `= 1 + V_fish/V_基准`。若「鱼位移」是每秒位移，它就是速度，公式对速度二次计价；若是每帧位移，结果的单位不可能是「点/秒」。速查表里同一行取 位移=1 而 鱼速=10，两者被当成独立变量——这在物理上不成立。同时 §8.1 的轴是 0~100，§5.3 的鱼速上限 20：冲刺 5 秒穿越整根轴，全程结束。

**坐标系硬伤**：同一根 0~100 轴，鱼的 0 = 岸、100 = 极限远（往湖里）；猫的 0 = 水边、95 = 退到最远（往陆上）。**两者用同一个数轴但物理方向相反**，「猫在 20%」和「鱼在 20%」不在同一侧。

## 三条主回路

- **R1（正反馈，主导）**：总力量 ≥ 鱼拉力 → 鱼被拉近 → 位移方向偏向岸 → K_dir 0.2 → 消耗小 → 体力保住 → 维持满力量。镜像分支同样自我强化：输 → K_dir 1.0 → 消耗大 → 体力掉 → 被迫换人/退位 → 更输。**赢的越赢越便宜，输的越输越贵，没有任何平衡回路对冲。**
- **B1（唯一平衡回路）**：放线 → 消耗 0、回体 +5 → 但距离增大。它的增益常数（距离变化速率）没定义，而且由于鱼永不变弱、进度可完全回吐，放线换来的时间买不到任何东西——旧系统里放线之所以是策略，是因为僵持期鱼体力在掉，你是在跟一个正在衰竭的对手换时间。删掉鱼体力，放线从"策略"退化为"纯亏"。
- **B2（换人）**：体力见底 → 换人 → 新体力。被 §10 的资格池写死。

## 极端情况走查

**① 单人打一条标准鱼（鱼力 2~30，普通猫 50）**
总力量 50 ≥ 30 恒成立，蓄力免费且无条件。距离单调递减 → 必赢。搏斗消耗按 K_force = 0.04~0.6 算，一路在 2~12 点/秒，而战斗几秒就结束——**体力条从头到尾不参与**。唯一能输的输入是松手。结论：普通鱼的搏斗段坍缩成「按住左键」，零决策、零风险、零失败分支。

**② 四人打巨影（鱼力 200）**
四普通猫合力上限 = 50 + 3×37.5 = **162.5 < 200** → 距离单调增大 → **必输，且全程无反制手段**：不能变强、鱼不会累、放线只会更快输。玩家会握着按钮看进度条朝错误方向走满全程——最坏形态的失败：漫长、注定、且看起来像正确打法。
主钓手换成缅因：130 + 112.5 = 242.5 > 200 → 反过来变成必赢。**所以巨影能不能打，单点取决于「钓鱼位上坐的是谁」**（主钓手系数 1.0、辅助 0.75）。
再叠上消耗：巨影 K_force = 4.0，K_speed 至少 2.5，搏斗消耗 = 100 → 撞封顶 30/秒；辅助位再 ×1.5。**全队约 3 秒清空体力**，然后集体退岸恢复，总力量归零。实际节拍是「3 秒发力 / 十几秒空窗」，空窗期距离以最大速率外推。除非距离的收/放速率极度不对称，巨影在结构上无解。而巨影是「为大鱼合力」这一愿景中心的唯一载体。

**③ 所有人同时体力见底**
不是死锁，是无出口的螺旋。主钓手 ≤5% 按 E，但 §10 只通知「岸上替补」——而 §2.2 规定辅助位退岸需要主动点或体力耗尽，没有「辅助手可接手主钓位」的通道。**打得越齐心，岸上越空，越必然 10 秒判负。**「体力耗尽自动退岸」的辅助手确实会填进岸上池，但他们体力是 0，而 §10.3 的「恢复到 50% 才能再申请」只约束「被换下的前主钓手」，不约束他们——于是 0 体力接手、立刻 ≤5%、再按 E，连环换人。每次换人新主钓手力量归零、重新蓄力 2 秒，总力量出现周期性真空，距离持续外推。终止条件只有距离撞 100%。

**④ 鱼一直向岸游**
K_dir = 0.2，消耗 4/秒，被定住不可能触发（§9.2）→ 白送的推进。但这里暴露一个结构裂缝：**鱼的游向和鱼的拉力是两个互不约束的变量**。一条「向岸游」的鱼，只要总力量 < 拉力，按 §8.3 距离照样增大——屏幕上会出现「鱼朝岸游、距离在变远」。两套位移引擎没有和解。

**⑤ 主钓手一直不放线**
对普通鱼：8~40 秒的体力储备，而赢只要几秒 → 最优解。对巨影：3.3 秒清空。
真正的病态在中间：**鱼静止/僵持 → K_dir = 0 → 搏斗消耗 = 0**（§5.6 的 0.5 点/秒保底明文限定「鱼在动时」，不覆盖静止）。此时：距离不变、搏斗消耗 0、移动消耗 0（没按 W/S）、收线不回体、鱼体力不存在、竿耐久没有减少规则。**每一个状态变量都停止变化，没有任何时钟在走。** 这不是「僵持」，是挂机。若按 §13.2「静止 +5/秒/人」，主钓手还会一边满力量一边回血，变成可无限维持。而这恰好是整套「合力」幻想想住进去的那个状态。

**胜负边界怎么被推到的**
两条边界都不是被「打」到的，是被算术推到的。蓄力免费、2 秒满、无衰减压力，所以总力量恒等于队伍上限。于是：上限 > 鱼拉力 → 必到 0%；上限 < 鱼拉力 → 必到 100%；相等 → 永不到达任何一端。**中间没有「够得到但要打」的地带**，因为没有任何变量会随打的过程漂移。

## 删掉鱼体力之后，少了什么、多了什么

少了的是这个系统唯一的积分器。鱼体力是把「玩家投入」转成「不可回吐的进度」的那个存量；连带丢的还有翻肚（第二种胜利态）、贴岸抄取与抢抄（唯一的多人瞬时竞争点）、绝对碾压甩上岸、竿强度瞬断，以及僵持期同时下降的三条资源。三个时钟一起消失，所以⑤才会冻住。

多了的是：猫的位置作为状态、按方向/速度计价的消耗、被定住这一局部状态、角色不对称（主钓手 100% / 辅助 75% / 岸上 200% 恢复），以及集体移动的喜剧解算。其中只有角色不对称是真正新增的承重设计，其余四项在最优打法下都不会被触达。

净结果：用一个自带终止条件的三时钟消耗战，换了一个单轴拔河——胜负是阈值比较，中心态是挂机。

## 致命问题

1. **僵持＝全系统冻结。** 鱼静止时 K_dir=0 让搏斗消耗归零，§5.6 的 0.5 点/秒保底明文限定「鱼在动时」不覆盖静止，收线状态不回体，鱼体力被删，竿耐久没有减少规则，不按 W/S 则移动消耗为 0。**所有状态变量同时停止变化，没有任何时钟在走，也没有任何规则能结束这个状态。** 而它正好是「多人合力扛巨物」想住进去的那个状态。

2. **胜负在咬钩瞬间就已决定，之后全是正反馈放大。** 蓄力免费、2 秒满、无衰减压力，所以总力量恒等于队伍上限；于是「上限 > 鱼拉力 → 必到 0%」「上限 < 鱼拉力 → 必到 100%」「相等 → 永不到达任何一端」。R1 回路没有任何平衡回路对冲。

3. **协作最优解直通判负，且强制换人会把必赢翻成必输。** §10 只通知「岸上替补」，而巨影要求所有人都在辅助位——打得越齐心，岸上越空，越必然 10 秒判负。同时主钓手系数 1.0、辅助 0.75，意味着巨影能不能打单点取决于钓鱼位上坐的是谁：主缅因 242.5 > 200 必赢，换成普通猫 162.5 < 200 必输。而换人由「体力≤5%」强制触发、先按先得，队伍没有任何指定接手人的手段。**一个已经赢定的局，会因为「你太累了」而翻成输定的局。**

4. **竿耐久被读不被写，鱼体力被删——三个消耗时钟全没了。** 竿耐久有三处读取、零处写入。后果不止是悬空——竿强度是现行设计里「大鱼的门槛」，也是失败预算两根柱子之一，本方案把它变成了永远不会触发的失败态。

5. **同文档内至少六组规则互斥。** §4.3（总力量<拉力→拖下水判定）vs §8.3（→距离增大）vs §8.4（→还要猫位置≤5%）；§5.8（收线不回体）vs §13.2（静止 +5/秒）；核心原则「无点击频率」vs §9.5④「快速点击左键」；§3.1（松手 1 秒衰减）vs §3.2（松开瞬间即放线）——这一秒算收线还是放线，决定了唯一的逃生窗是否存在；两套互斥的位移引擎；同一根 0~100 坐标轴上猫与鱼的物理方向相反。

**附带一个不算致命、但会让大半篇文档变成死条文的涌现后果**：§9「被定住」必须「猫按 S 键」才触发，而按 S（远离岸边）按 §8.5 要吃 −10% 力量损耗、没有任何收益。于是没人会按 S，§9 六个小节全程不可达；同理没人会按 W/S，§6、§8.2、§8.5、§13 一并失效。最优打法收敛为：所有人按住左键，谁也不动。

## 要用的话必须先补什么

1. **放回至少一个单调递减的时钟。** 鱼体力回归、或给竿耐久写出减少规则、或给搏斗加硬时限，三选一起步。没有它，僵持不会结束、放线不能成为策略、玩家投入无法转成不可回吐的进度——其余所有规则都没有落点。

2. **距离引擎二选一，并写出速率函数。** 位移要么由「总力量 − 鱼拉力」决定，要么由「鱼速 × 方向」决定，删掉另一套；补上僵持容差带的宽度、取等归属（现行规则页已有「取等从严」的先例），以及鱼「向外游但被拉近」时 K_dir 取哪一档。这是整套系统唯一真正承重的常数，现在是空的。

3. **换人资格池改为「全体非主钓手」，并定义交接期的力量真空。** 同时补：0 体力者能否接手、连续换人时 10 秒计时如何重置、队伍能否指定接手人。

## 只改一处的话

把鱼体力放回搏斗——它是这套系统唯一的积分器，删掉它之后，僵持会冻住、放线会失去意义、胜负会退化成咬钩瞬间的两数比大小，而这三件事都不是靠调参数能修的。
