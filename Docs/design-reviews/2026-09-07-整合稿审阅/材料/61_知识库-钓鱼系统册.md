# 1. 设计意图

**1.1 北极星贡献。**钓鱼是「湖畔派对」的主活动：大鱼要几只猫一起弄（协作的热闹），等待和搏斗里有整蛊和炸毛可看（搞怪空间），晚上篝火边翻的照片大多拍自这里（印记素材的主要产地）。猫的真实行为是本册的第一设计语言，全流程都照它来。

**1.2 体验设计。**

|-|-|-|-|

**1.3 玩家策略路线。**（详表待补，见 §11-13。示例取舍：打窝投入 vs 直接开钓；专心钓鱼 vs 帮人抄网 vs 捣乱；追稀有 vs 攒献祭储备与经验。）

**1.4 设计禁区。**

- ❌ 人类化操作与动作。所有行为都要能用猫的身体逻辑完成（「无人类双手」红线）。
- ❌ 强制任务与效率引导：协作和热闹靠机制诱发，不下指令。
- ❌ 把失败做成事故。失败只能是喜剧演出，损失必须可恢复。

# 2. 核心循环

1. 选位与准备：在营地选择鱼竿，携带少量窝料与鱼饵。
2. 打窝聚鱼：向水中投掷窝料吸引鱼群，产生持续效果。
3. 抛竿等待：抛出鱼线，等待咬钩；等待中可自由活动。
4. 刺鱼搏斗：咬钩瞬间提竿刺鱼，进入角力拉扯。
5. 拉近收线：收放线控制，将鱼拖至岸边浅水。
6. 收鱼入手：挥网抄取或拖岸拾取，自己或队友出手将鱼擒获。
7. 庆祝展示：炫耀战利品，计入图鉴与印记。

单人可完成主循环；大型协作内容（聚鱼时刻、巨型鱼）面向多人。鱼的刷新按在场协作能力设上限——单人局不会刷出需要多人的鱼（规则归鱼册）。

## 选位与准备

钓点是玩家概念，不是机制点位：任意水边掏竿就能钓，打窝聚出的位置、自己看中的风景，都能成为一处钓点。这一节的操作规格钓鱼规则暂未收录。［待补 §11-1］

带什么竿、漂、饵、窝料在营地备装时定（格数制携带，清单与命名归道具册）；三种竿（树枝／玩具／逗猫棒）外观各不相同，一眼认得出队友手里拿的是哪把；岸边在带着的饵与窝料之间切换，操作归「交互总规」页（钓鱼规则 2.7）。多人各自独立准备，队友带了什么不开菜单看，看得见手里的、凑近能闻，这是本册的信息可见性红线。

## 打窝聚鱼

打窝把「哪儿有鱼」变成玩家自己造出来的事：往哪投、投什么，决定这片水面接下来上什么鱼。窝料是腥／香／酵三味，窝点各有一个全队共享的窝料池：投料叠加、气味随时间变淡直到散尽；池子越浓咬钩越快，窝料决定上的是哪一类鱼、鱼饵决定是哪一条。补窝是增量，可以先腥引鱼、再香换鱼种。规则见钓鱼规则 1.1 三大气味与第二章（窝点、叠加、上鱼速度、鱼种判定、消散、补窝）；窝料清单与配方归道具册。

另有特殊窝料（魔法料一类）能提高特定鱼概率，清单归道具册。窝料的浓度与鱼量只用美术与粒子粗略表现，不给玩家数字。投料是蓄力抛掷、有抛物线预览（抛竿无蓄力，两者不混）；落水泛涟漪、聚鱼影是演出，见动作表现集。［待补 §11-2］

聚鱼时刻是本册独有规则，规则页还没收录。凑够窝料触发，大量鱼群涌现，同时给出「水下有巨大的影子出现……」的巨物预告。它是统一机制，内置冷却防止珍稀道具批量刷取；另有环境自然事件触发源（见环境册），两种触发共用一套演出、收益与稀缺预算。［待补 §11-3］

## 抛竿与等待

点水面即抛、无蓄力；浮漂三种，决定够得着多远、投得准不准（清单与命名归道具册），漂随水波一起一伏。咬钩分三阶段：试探期、真咬期、完美响应窗。试探期提竿必空竿但不损饵，是留给玩家学的假动作；真咬是漂猛地一沉、一声闷响、猫瞳孔一缩；真咬后短窗内提竿＝完美中鱼，鱼的力量与体力被削一截，配专属声效；超窗不提竿，鱼走饵丢。规则见钓鱼规则 3.1 操作方式、3.2 浮漂属性、4.1 响应窗口；演出定稿归动作表现集。

**鱼种预抽，抽给窝点（2026-08-27 拍定）。**鱼种不是咬钩那一刻才定的，鱼靠近之前就抽好：窝料属性命中出候选池，按窝点里各人当前的鱼饵偏好取一条，鱼影游过来。**抽的对象是窝点、不是竿**——一个窝点全队共享一个窝料池，鱼影是水里的实体，附近的猫都看得见（下没下钩都看得见，与本册的可见性口径一致）。

谁的饵对就上谁的钩；没人的饵对，鱼绕一圈、嫌弃地一摆尾走了，玩家一眼看得出「为什么没上钩」。这一下同时喂三个下游：道具册的错饵摆尾演出与「鱼饵丢失时安慰」（空钓时图鉴出现虚影）、图鉴册的剪影解锁（揭开的就是刚才没上来的那条，揭给下钩的人，围观看见了不算）。

几个人的饵都命中时**随机，看鱼吃哪个**（2026-08-27 拍定）——演出上是鱼自己挑，不做先到先得。

**鱼影只给存在感，不给答案（2026-08-27 拍定）。**看得出有东西来了、大致多大，看不出是哪一种；巨物预告那句「水下有巨大的影子」是体型层面的，不是鱼种层面的。这是硬要求：鱼影一旦能被认出鱼种，玩家就会盯着影子临时切饵，饵的决策就从「出发前想清楚」退化成「看见了再说」。刚才来的到底是什么，事后由图鉴的剪影告诉你——**看不清和揭剪影是一对**。

没有预抽这一步，鱼饵偏好就只是一个玩家感知不到的抽签权重，道具册「不同饵吸引不同鱼」整条线落空。［待补 §11-4］

咬钩信号要隔半个湖也能感知：声音、猫的身体语言、手柄震动。等待中的玩家可以自由活动，震动反馈通道归「交互总规」页。［待补 §11-5］

## 刺鱼与搏斗

三资源对抗，刺鱼、搏斗、拉近收线都在这一节。猫与鱼各有力量与体力，竿有强度与耐久。鱼发力时拖是赌、放是稳。力量碾压就直接甩上岸；不够就进僵持消耗战，竿、猫、鱼三条资源一起掉；放线是猫喘口气的窗口。鱼累了往回游时收线拉近，拉线耗猫体力。反过来，猫体力见底，或鱼的力量压过猫，就会被拖下水；竿强度不够一拖就断，耐久耗尽也断。规则见钓鱼规则 4.2 遛鱼资源条、4.3 操作与判定、4.4 消耗战归零。

鱼的发力／休息节奏见钓鱼规则 4.6（临时方案）与鱼册的「鱼的行为」页（正式方案在审），性格模板（急躁／狡猾／沉稳一类）与鱼表格挂号列同归该页。救援机制现阶段没有（落水即鱼逃），规格后续里程碑补。鱼体力靠挣扎激烈程度与头顶漩涡判读。［待补 §11-6］

为大鱼合力发生在搏斗阶段，不在抄网：中大型鱼靠队友加入拉竿分摊力量与体力，代价是鱼冲刺更频繁；巨型鱼需多人合力，成功触发慢镜头合影。［待补 §11-7］

## 收鱼：抄网与拖岸

鱼被拖到近岸浅水，收鱼就开始了。钩上或翻肚的鱼、贴到岸边就能抄（巨影除外不可抄）；在场任何猫都可以抢抄，先到先得、抄取必中，挥空罚硬直——挥空原因只有没够着和被抢先，全看得见。抄网是道具、非必带、无属性数值（体型上限维度已砍，大鱼的门槛由竿强度承担）。

不带抄网也能收鱼：把鱼遛到翻肚、半浮在水面上，拖上岸拾取，岸上的鱼谁先按谁得；水里翻肚的鱼搁久了会醒过来跑掉，拖上岸就安全。收鱼容错靠挥空硬直与苏醒窗自然限定。规则见钓鱼规则第五章（5.1 可抄判定、5.2 挥网、5.3 无网路径、5.4 多人竞争）。图鉴登记：上钩钓手与抄网命中者同时登记收集层（分层与归属见鱼册）。

## 收获展示与结算

举鱼展示（鱼比猫大时被压得颤颤巍巍）、围观猫互动，细节归动作表现集。图鉴在钓到瞬间自动记录鱼种、重量、稀有度，此后鱼被献、被吃、被偷都不影响记录。［待补 §11-8］

渔获流向：抄起或拾起的鱼叼在嘴里 → 放入随身鱼护暂存（鱼护是道具、非必带，钓点边暂存可被偷）→ 带回营地入共用大鱼缸 → 献祭（夜晚仪式，白天只攒不献）／吃掉换成长（见猫咪与状态册）／卖给商店换金币入公款（分期后做，收购与定价见商店册）／留缸观赏（承担被偷）；局末随局清空。规则见钓鱼规则 5.2 挥网操作、6.2 鱼的去向、6.3 世界进度。鱼缸实体见营地册，偷吃规则见联机社交册。［待补 §11-9］

## 多人互动层

窝点猫爪标记全队可见。［待补 §11-10］求助信号全手动：喊不喊人由玩家自己（急促猫叫＋头顶图标），仅巨物保留全体提示（与巨物预告配套，规则归联机册）。恶作剧（丢石头惊鱼、逗猫棒逗空竿）是「搞怪」的主要来源，开关与护栏归联机册（熟人自治、不设系统频率限制、防骚扰牌子）；过程玩法细则归内容层随实装补充。协作有连携激励。［待补 §11-11］

## 实施考量

进出口径：咬钩前退出零损失，进入咬钩后无论结局都扣一份饵，无饵不能抛，见钓鱼规则 3.4 鱼饵消耗与主动收竿。入夜边界：进入夜晚不再有鱼咬钩，进行中的搏斗允许打完，压哨鱼进夜照常可献。［待补 §11-12］状态机细则（被打断后的回退、窝料保留等）需先定义再实装；多人同步（窝料池叠加、聚鱼时刻判定、巨物归属、抢抄判序、掉线兜底）是本册最大的工程风险点。

# 4. 系统边界

**硬性。**

- 不引入本册之外的成长数值（经验 / 等级由项目级决策统一定夺）。
- 不引入世界观外元素（人类文化符号、超自然意象）。
- 鱼种分布表由鱼册持有，本册只消费不定义。

**软性。**

- 按键与 UI 呈现属交互阶段。
- 猫的通用动画规范（程序化尾巴耳朵、湿毛等）归「猫咪与状态」册，本册只引用。

# 5. 涌现案例

- 一人续窝、众人垂钓的自发分工（positive）。
- 恶作剧引发的追逐打闹反而成为社交高光（positive）。
- 集体叠窝形成「开钓仪式」（positive）。
- 全员围观一名钓手导致没人钓鱼（neutral，待观察）。
- 连续被整蛊后玩家退出派对层（negative，靠恶作剧护栏规避）。

# 6. 体验锚定数字

拍定值全在「数值模拟与参数记录」页，本节只列调哪些数改什么：白天时长（每天有多赶）；咬钩节奏（窝料池基础间隔与浓度换算——一白天能上多少条）；完美窗与响应窗宽度（完美中鱼成不成为胜负手）；竿三档强度／耐久与僵持消耗系数（哪种猫拿哪根竿能遛翻哪条鱼、断竿是不是赌注）；放线回体速度（拉-放-拉循环玩不玩得起来）；鱼饵携带份数（回营节奏）；聚鱼时刻的阈值与冷却（见 §11-3）。

# 7. 视觉反馈通道

猫的身体语言即信号系统：

- 耳朵支起 = 咬钩前兆；瞳孔缩成竖线 = 真咬。
- 耳朵压平 + 尾巴炸毛 = 紧张；湿毛抖水 = 落水收场。
- 张力读数看鱼线松紧和竿身弯曲；窝料光环显示范围与剩余时间。

已知缺口：鱼的挣扎／放松切换缺可读信号，见 §11-6；旁观者视角的信息可见性归联机册的放大通道，本册只出信号。演出以「动作表现集」为唯一标准；实现规格见子页「钓鱼规则」。
