## 第二章：窝料与鱼群生态（服务器全局）

### 2.1 窝点数据结构

- 窝点：以窝料落点为圆心的圆形区域（半径 5 米，数值阶段可调），不预先划分河段。
- 服务器为每个窝点维护唯一变量：
- text
- 当前窝料池 = {X(腥), P(香), J(酵)}初始值 = 首次投料向量

窝点判定规则：

- 浮漂落点落在哪个窝点范围内 → 应用该窝点的窝料池数据
- 多人向同一窝点范围投料 → 直接并池

并池细则：

- 新投料落点圆心落入已有窝点圆内 → 并池（沿用原窝点圆心与半径，向量相加）
- 否则 → 新建窝点
- 浮漂落点处于多个相交窝点范围内 → 取圆心最近的窝点

### 2.2 投放与叠加规则

text

新池子 = 旧池子 + 投掷向量

- 无冲突，无设计上限
- 衰减机制自带稳态收敛
- 猫化描述：多只猫往同一片水面丢吃的，气味越堆越浓，鱼群越聚越多

### 2.3 鱼群总量与上鱼速度

鱼群总量：

text

Total = X_total + P_total + J_total

咬钩基础间隔：

<sheet sheet-id="p0PfOZ" token="Jo1hstir6hyYZSthIBmcVvodn4b"></sheet>

实际间隔公式：

text

T_actual = T_base / (1 + Total / K)K = 100（固定常数）

边界：Total 极大时 T_actual 无限趋近于 0，但永不等于 0。

计时归属（2026-08-18 拍定）：

- 咬钩计时器挂浮漂级——每个浮漂独立计时
- 间隔用其所在窝点的 Total 计算
- Total 变化（补窝/衰减）时，剩余时间按新旧 T_actual 比例折算
- 落点不在任何窝点范围内 → 按 Total = 0 档（120 秒）

### 2.4 鱼种分布与咬钩判定

实时占比计算（仅当 Total > 0）：

text

腥味占比 = X_total / Total香味占比 = P_total / Total酵味占比 = J_total / Total

- 鱼群内部的种族构成比例实时等于属性占比
- 例：池子 {腥20, 香50, 酵30} → 20% 腥鱼、50% 香鱼、30% 酵鱼

咬钩判定流程：

text

【第一步】若 Total > 0：  生成随机数 Rand ∈ [0,1]  按累积概率区间判定偏好属性【第二步】若 Total = 0：  直接进入基础鱼池（无偏好随机）  基础鱼池内鱼种等级较低（小鱼苗、杂鱼）【第三步】属性命中后，在该属性的候选鱼中按鱼饵做第二次 roll：  每条鱼对各饵有偏好权重  目标饵权重高，非目标饵权重低但不为零

### 2.7 聚鱼时刻（爆发增益模块）

#### 触发条件

门槛要求：当前窝料池中，三种属性（腥/香/酵）各自的数值都 ≥ 指定阈值（建议 30\~50）

- 例：{腥:45, 香:52, 酵:38} → 全部 ≥30 → ✅ 可触发
- 例：{腥:45, 香:52, 酵:12} → 酵不足30 → ❌ 无法触发

#### 触发时机与概率

<sheet sheet-id="KLcWTF" token="Jo1hstir6hyYZSthIBmcVvodn4b"></sheet>

可增加概率的因素：

- 投入的窝料品质越高 → 概率小幅提升（+2%\~3%）
- 窝料总量越大 → 概率小幅提升（总量每100点 +1%，上限+5%）

#### 聚鱼时刻效果

触发后进入聚鱼状态，持续 30\~60秒：

- 咬钩速度大幅提升（ 2\~3倍）
- 鱼群密度激增

#### 状态切换

text

普通状态 → 投料满足门槛 → 概率判定 → 触发成功 → 聚鱼状态（倒计时开始）聚鱼状态 → 倒计时归零 → 回到普通状态 → 进入冷却 → 冷却结束 → 再次可触发

- 聚鱼期间投料不重新触发（冷却中）
- 衰减机制依然生效
- 倒计时归零 → 回到普通状态

一句话总结：三种属性都堆到30以上后，每次投窝都有概率触发「全场加速」状态，让均衡投料有惊喜回报。

## 四、公式说明

### 搏斗消耗

text

搏斗消耗 = ΔD × K_speed × K_force × K_dir × R_base

- ΔD：鱼在鱼线方向上的位移
- K_speed：速度系数（1 + V_fish/V_base）
- K_force：力量系数（F_fish/F_base）
- K_dir：方向系数（向外1.0 / 横向0.5 / 向岸0.2）
- R_base：10点/秒

### 移动消耗

text

移动消耗 = 固定3点/秒 × 力量对比系数

- 猫力 > 鱼力：按方向不同（后退1.0×，前移0.5×）
- 猫力 ≈ 鱼力：1.5×
- 猫力 < 鱼力：搏斗×1.3\~1.5 + 额外2点/秒（按S后退时）

#  第九章 · 多人合力移动机制

## 一、设计理念

> 方向一致才能走，方向不一致就搞事。

适配2人、3人、4人及更多，人数越多越容易乱。

## 二、移动规则

### 2.1 基础操作

- WASD / 方向键 控制当前移动方向
- 以 50% 为阈值，超过半数的方向视为“多数方向”

### 2.2 不同人数下的判定

2人队伍：

- 方向一致 → 正常走
- 方向相反 → 顶牛（头顶头，四肢刨地）→ 3秒后双双弹开坐地上
- 方向垂直 → 原地打转

3人队伍：

- 3人一致 → 正常走
- 2人一致，1人不同 → 龟速移动（30%速度），少数派被拖行
- 3人全不同 → 打转 → 5秒后随机一只被甩飞

4人及以上：

- ≥3人一致 → 正常走
- 仅2人一致，其余分散 → 龟速移动（20%速度）
- 无≥3人的多数方向 → 原地打转 → 5秒后连环摔倒
- 2v2完全相反 → 拔河拉长 → 弹回摔倒

#  第十章 · 多人合力钓鱼（整合要点）

## 10.1 位置与权限

<sheet sheet-id="lVzclD" token="Jo1hstir6hyYZSthIBmcVvodn4b"></sheet>

## 10.2 力量合成

text

总力量 = 主钓手当前力量 + Σ(每位辅助手当前力量)

- 绝对碾压判定：总力量 ≥ 鱼力 × 2.0 → 飞鱼上岸
- 消耗战中猫体力扣减： 仅主钓手受到鱼力×0.12的扣减
- 辅助手体力按150%速率独立消耗

## 10.3 换人机制

- 主钓手体力≤5% → 按E发起换人
- 岸上替补按E接手 → 先按先得，全自愿
- 换人后鱼和竿的状态完全继承
- 被换下者体力恢复×2，恢复到50%以上可再次申请
- 10秒无人接手 → 钓鱼失败

## 10.4 猫被拖下水

触发条件：猫离岸距离归零 + 鱼向外游 + 总力量 < 鱼拉力

后果：鱼逃、饵已扣、湿身演出（好笑不惨）
