# 目的与边界

首轮覆盖：搏斗结局矩阵（品种×竿×鱼种蒙特卡洛）、单日渔获吞吐（窝料池动态＋咬钩节奏＋战斗＋竿损耗的整日循环）、世界进度与额度节奏、力量系数缩放扫描。不模拟：网络同步、演出时长、UI 操作耗时。

# 数值 SSOT 约定

拍定参数冻结到「参数与校准记录」页；鱼种数据以「鱼表格·第一版」sheet 为源、装备数值以挂号表格为源；改数值先过模拟验证再落表，不在代码里手调。
