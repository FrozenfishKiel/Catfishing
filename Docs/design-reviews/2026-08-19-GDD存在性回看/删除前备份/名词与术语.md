| 鱼的体力 | 被猫拉的时候一直掉。掉到极限，鱼的力量归零——被钓上来。 |
| 猫的体力 | 拉鱼的时候一直掉。掉到极限，猫的力量归零——被鱼拖下水。 |
| 鱼竿耐久 | 搏斗中竿的承受能力一直变弱。弱到极限，竿断。 |
| 随机系数 | 力量会波动。比如猫正放松着，鱼突然发力，猫一时使不出全力——这时随机系数小于 1。 |
| 鱼竿系数 | 竿决定猫的力量能转化多少成拉力。劣质竿转化不完全，系数小于 1。 |
