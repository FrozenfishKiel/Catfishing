# 3. 机制清单

## 选位与准备

任意水边掏竿即进入钓鱼待机（钓点是玩家概念：打窝聚出的位置，或者自己看中的风景，不设固定机制点位）；背包切换鱼饵 / 窝料；不同钓竿外观不同（树枝竿 / 玩具竿 / 逗猫棒竿）。多人各自独立准备；队友装备不开菜单查看——看得见手里的、凑近能闻。

## 打窝聚鱼

选择窝料后蓄力抛掷，抛物线预览；落水泛起涟漪、气泡与鱼影聚拢，整片水域分为几片窝点，大概通过美术和粒子效果粗略显示窝料浓度和鱼量，不提供具体数值。窝料＝腥 / 香 / 酵三属性向量，窝点维护全队共享的窝料池：投料直接叠加、随时间半衰消散（窝点＝以投料落点为中心的圆形区域，已拍；叠加无设计上限，靠半衰期收敛，代码只留工程安全夹）；池子总量决定上鱼速度，属性占比实时决定鱼种构成——补窝是增量，可以先腥引鱼、再香换鱼种。窝料示例：虫虫（主腥）/ 小鱼干碎（主香）/ 发酵浆果（主酵）；具体清单与配方归装备与道具册（魔法料类特殊窝料概率吸引稀有鱼保留）。多人可向同一水域投料，凑够窝料触发「聚鱼时刻」：大量鱼群涌现，同时给出「水下有巨大的影子出现……」的巨物预告。聚鱼时刻为统一机制，同时存在内置cd，防止珍惜道具批量刷取，另有环境自然事件触发源（见环境册），两种触发共用一套演出、收益与稀缺预算；叠加规则与稀缺约束数值待定。

## 抛竿与等待

点击水面即抛、无蓄力，点哪落哪；鱼漂共 3 种（已拍，种类制），决定投掷距离与落点精准（清单与猫世界化命名归装备册）。鱼漂随水波起伏。咬钩信号分三阶段：试探期（鱼漂快速抖动、小水花；此时提竿必空竿，但不损失鱼饵。是可学习的规则）→ 真咬期（鱼漂猛然下沉、「咕咚」水声、猫瞳孔缩成竖线）→ 完美响应窗（真咬后 1 秒内提竿＝完美中鱼，鱼的力量与体力直接被削一截，特殊声效「喵嗷！」）。信号需远距离可感知（声音 + 猫身体语言 + 震动），等待中的玩家可自由活动。普通响应窗按鱼种 8-15 秒（数值待调）；超窗未响应＝鱼离开、丢饵。

## 刺鱼与搏斗

窗口期提竿上钩，进入搏斗。三资源对抗：猫与鱼各有力量与体力，竿有强度与耐久（已拍）。鱼发力时只能放线跟鱼，猫体力缓慢回复；鱼乏时收线拉近，拉线消耗猫体力。猫体力不足会被鱼拉走往水里拖（队友可拽尾巴救援，拖到底＝落水、鱼逃）；力量与体力占优时可直接强拉起鱼，不够则消耗竿耐久，耐久尽头断竿。鱼的体力可通过挣扎激烈程度与头顶漩涡标志判读，耗尽进入乏力。挣扎 / 放松的切换信号待定。中大型鱼靠搏斗合力：队友加入拉竿分摊力量与体力（代价是鱼冲刺更频繁）；巨型鱼需多人合力拉竿，成功触发慢镜头合影——为大鱼合力发生在搏斗阶段，不在抄网（已拍）。鱼的咬钩与挣扎节奏按性格模板区分（急躁 / 狡猾 / 沉稳等模板＋程序化微调，模板数据归鱼类图鉴册）。

## 浅水与捞取

乏力的鱼半浮水面，拖至近岸浅水出「捞鱼！」提示。单人收鱼两条路：带抄网＝鱼贴岸后挥网抄取（必中；离岸太远或体型超上限则扑空，罚 3 秒硬直）；无抄网＝耗尽鱼体力遛翻后拖上岸拾取（细则见「协作抄网」节）。次数制重试已废除（2026-08-18）：收鱼容错由挥空硬直与翻肚 30 秒苏醒窗自然限定。

## 协作抄网

鱼贴近岸边（离岸小于固定距离，快照 1 米）即进入可抄状态——活鱼与翻肚鱼均可抄，在场任何猫都可以挥抄网抢抄（抄网＝道具、非必带，抄取必中，唯一属性＝可抄体型上限——基础款抄不动大型鱼、无自身长度；属性表归装备册，2026-08-18 拍定）：先到先得，鱼归第一个抄中的；挥空＝扑空，罚 3 秒踉跄硬直（各自独立计算，硬直中别人可继续抄）。不带抄网也能收鱼：搏斗耗尽鱼体力（翻肚）后把鱼拖上岸，岸上的鱼任何猫可拾取（先到先得、必中），拾取后同样叼在嘴里；水里翻肚 30 秒无人处置苏醒逃跑，拖上岸后离水安全。抢抄不算合力——为大鱼合力在搏斗阶段（见上节）；抄起后举鱼展示与庆祝照常。记录归属两轨制（2026-08-16 拍定）：图鉴首钓与个人纪录归上钩钓手，「抄获」为抄网者的独立记录轨（模型归鱼册）。

## 收获展示与结算

举鱼展示（鱼比猫大时被压得颤颤巍巍）、围观猫互动；图鉴在钓到瞬间自动记录（鱼种 / 重量 / 稀有度；此后鱼被献、被吃、被偷都不影响记录）。渔获流向：抄起后叼在嘴里 → 放入随身鱼护暂存（鱼护＝道具、非必带，2026-08-18 拍定；钓点边暂存，可被偷）→ 带回营地入共用大鱼缸 → 献祭（夜晚限定仪式，白天只攒不献，2026-08-16 拍定）/ 吃掉获得成长（限时 buff＋经验，见猫咪与状态册）/ 卖给商店换货币（入口与定价归道具系统）/ 留缸观赏（承担被偷）；局末随局清空。鱼缸实体见「营地」册，偷吃规则见「联机社交」册。

## 多人互动层

窝点猫爪标记全队可见并显示剩余时间；求助信号全手动：喊不喊人由玩家自己（急促猫叫＋头顶图标），仅巨物保留全体提示（与巨物预告配套）；恶作剧（丢石头惊鱼 / 逗猫棒逗空竿）是「搞怪」的主要来源，开关与护栏规则归联机册（防骚扰牌子已入册，B4 已关账：熟人自治、无系统频率限制）；过程玩法细则归内容层随实装补充；协作有连携激励，形式待定。

## 实施考量

进出口径已定：咬钩前退出零损失（主动收竿收回鱼饵）；进入咬钩后无论结局（上鱼／超时／放弃／断竿／落水）均消耗一份鱼饵——上鱼也扣（2026-08-18 拍定）；无饵不能抛竿。入夜边界（2026-08-16 拍定）：进入夜晚后不再有鱼咬钩，进行中的搏斗不受影响、允许打完（压哨鱼进夜后照常可献）。状态机细则（被打断后的回退、窝料保留等）需先定义再实装；多人同步（窝料池叠加、盛宴判定、巨物归属、抢抄判序、掉线兜底）是本册最大的工程风险点。实现规格（窝料池公式 / 三资源判定 / 抢抄参数）见子页「钓鱼规则」；数值拍定见「参数与校准记录」页。
