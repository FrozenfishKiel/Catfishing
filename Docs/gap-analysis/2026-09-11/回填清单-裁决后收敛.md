# 回填清单 · 09-11 六条裁决之后的收敛

> **怎么读这份**：同目录的 `回填清单.md` 是 2026-09-11 那一刻的证据，**不改**。六条方向题当天全部拍完（正文见飞书「设计修改记录」2026-09-11 节），改变了其中 18 行的性质。派活、开条目、回写账本都以本页为准；引证据仍回原件。
>
> 六条裁决：①合力钓鱼基座＝物理抓握 ②偷鱼不是机制只有「拿鱼」 ③游戏永不删档 ④删进搏斗补满、统一出力池 ⑤猫抓猫能推后果照常 ⑥祭坛任一人发起＋可打断倒计时。
